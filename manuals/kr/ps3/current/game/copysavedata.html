저장 데이터를 기록 미디어에 복사하기(백업하기)

본체 스토리지의 저장 데이터를 기록 미디어로 내보낼 수 있으며 내보낸 저장 데이터를 본체 스토리지로 가져올 수 있습니다. 내보내거나 가져올 저장 데이터를 선택하고 버튼을 누른 후 옵션 메뉴에서 [복사]를 선택해 주십시오. 화면의 지시에 따라 조작해 주십시오. 중요한 데이터는 백업용을 복사해 두실 것을 권장합니다.


알아두기

  • 저장 데이터에 따라서는 복사가 금지된 것이 있습니다.
  • 음악 파일 재생과 같은 다른 기능을 사용하는 콘텐츠를 재생하고 있는 경우에는 저장 데이터를 복사할 수 없습니다.
  • PlayStation®2 / PlayStation® 규격 소프트웨어의 저장 데이터를 PlayStation®2 전용 Memory Card(메모리 카드)(8MB) / Memory Card(메모리 카드)에 복사할 수도 있습니다. 상세한 사항은 (게임) > [PlayStation®2 / PlayStation® 규격 소프트웨어 즐기기] > [Memory Card의 저장 데이터 사용하기]를 참조해 주십시오.
  • 사용하시는 PS3™에 따라서는 기록 미디어를 사용하기 위해 별매의 USB 어댑터가 필요한 경우가 있습니다.

중요

  • PS3™에서 일부 PlayStation®2 또는 PlayStation® 규격 소프트웨어가 종래의 PlayStation®2 또는 PlayStation®에서와 다르게 동작하거나 적절히 동작하지 않는 경우가 있습니다.
  • 또한 일부의 PS3™는 PlayStation®2 규격 디스크의 재생에 대응하지 않습니다. 상세한 사항은 [재생할 수 있는 디스크의 종류에 대하여], 각 지역 웹 사이트 또는 제품에 동봉된 사용설명서를 참조해 주십시오.
