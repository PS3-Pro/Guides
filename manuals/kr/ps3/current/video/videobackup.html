동영상 파일 백업/복원하기

PlayStation®Store에서 다운로드한 유료 비디오 콘텐츠를 일시적으로 기록 미디어에 이동할 수 있습니다.

백업하기

PS3™에 기록 미디어를 넣고 백업할 콘텐츠의 아이콘을 선택합니다. 버튼을 누른 후 옵션 메뉴에서 [백업]을 선택합니다. 기록 미디어 내에 (백업 데이터 관리) 폴더가 자동으로 작성되어 콘텐츠가 저장됩니다.

알아두기

  • PS3™로 PlayStation®Store에서 비디오 콘텐츠를 구매/대여하는 서비스는 종료되었습니다.
  • Memory Stick™, SD Memory Card, Compact Flash®, USB 대용량 저장 장치 등에 백업할 수 있습니다. 사용하시는 PS3™에 따라서는 기록 미디어를 사용할 때 별매의 USB 어댑터 등이 필요한 경우가 있습니다. CD-R 등의 디스크 미디어는 사용할 수 없습니다.
  • USB 하드 디스크를 사용하여 데이터를 백업할 때는 FAT32 형식으로 포맷된 것을 사용해 주십시오. NTFS 형식으로 포맷된 하드 디스크는 PS3™에서 인식되지 않습니다.
  • 백업한 콘텐츠는 기록 미디어에서는 재생할 수 없습니다. 재생할 때는 PS3™의 본체 스토리지에 복원해 주십시오.

복원하기

기록 미디어에 백업한 콘텐츠를 PS3™에 복원할 수 있습니다.

1.

백업한 콘텐츠가 저장되어 있는 기록 미디어를 PS3™에 연결합니다.

2.

(비디오)에서 기록 미디어를 선택합니다.

3.

(백업 데이터 관리)에서 복원할 콘텐츠를 선택한 후 버튼을 누릅니다.

4.

[복원]을 선택합니다.

알아두기

  • 백업한 데이터의 폴더명이나 파일명을 변경하면 복원되지 않는 경우가 있습니다.
  • 백업한 뒤에 다음 조작을 하면 바르게 복원되지 않습니다.
  • -본체 스토리지 초기화
  • -PS3™ 초기화
  • PS3™의 사용 상황에 따라서는 바르게 백업/복원할 수 없는 경우가 있습니다.
