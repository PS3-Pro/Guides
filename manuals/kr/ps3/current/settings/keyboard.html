키보드/마우스 설정

키보드와 마우스에 관한 설정을 합니다.

키보드 타입

USB 키보드 또는 Bluetooth® 키보드의 타입을 설정합니다.

키보드 입력 방식

USB 키보드 또는 Bluetooth® 키보드의 입력 방식을 설정합니다. 다음의 경우에만 선택할 수 있는 설정입니다.

  • 시스템 언어가 중국어 번체자로 설정된 경우
  • 시스템 언어가 일본어로 설정되어 있고 [키보드 타입]이 [일본어 키보드] 또는 [영어 키보드 (US Standard)]로 설정된 경우

키 바인딩

키보드의 키 할당을 변경합니다. 이 설정은 시스템 언어가 일본어로 설정되어 있고 [키보드 타입]이 [일본어 키보드] 또는 [영어 키보드 (US Standard)]로 설정된 경우에만 사용할 수 있습니다.

키 반복 시작 시간

USB 키보드 또는 Bluetooth® 키보드에서 하나의 키를 누른 상태일 때 문자가 반복하여 입력되기 시작하는 시간을 설정합니다.

키 반복 속도

USB 키보드 또는 Bluetooth® 키보드에서 하나의 키를 누른 상태일 때 문자가 반복하여 입력되는 속도를 설정합니다.

마우스 타입

USB 마우스 또는 Bluetooth® 마우스에서 주로 사용하는 손에 맞추어 마우스 타입을 설정합니다.

포인터의 속도

USB 마우스 또는 Bluetooth® 마우스에서 포인터가 이동하는 속도를 설정합니다.

  • 음악
  • 비디오
  • TV/비디오 서비스
  • 게임
