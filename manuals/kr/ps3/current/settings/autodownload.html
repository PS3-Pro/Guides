자동 업데이트

일부 기능을 사용하시려면 PlayStation®Plus에 가입하셔야 합니다.

설정을 [켜기]로 하면 매일 지정한 시간대에 PS3™가 기동하여 다음의 조작을 실행한 후 자동으로 전원이 꺼집니다.

끄기 자동 업데이트 기능을 이용하지 않습니다.
켜기 자동 업데이트 기능을 이용합니다.

자동 업데이트할 조작은 다음 항목에서 선택할 수 있습니다.

  • 다른 기기에서 구매한 콘텐츠 다운로드
  • 최신 시스템 소프트웨어 다운로드
  • 게임 패치 다운로드
  • 트로피 정보를 서버와 동기화

알아두기

  • [저장 데이터의 온라인 스토리지 업로드] 항목은 게임별로 설정합니다. 자세한 사항은 (게임) > [PlayStation®3 규격 소프트웨어 즐기기] > [저장 데이터에 대하여]를 참조해 주십시오.
  • [켜기]를 선택한 후 방향키로 자동 업데이트를 실행할 시간대를 선택해 주십시오. PSNSM으로의 자동 로그인 설정을 확인하는 화면이 표시되는 경우에는 화면의 지시에 따라 조작해 주십시오.
  • 이 기능은 Sony Entertainment Network의 한 계정당 1대의 PS3™에만 설정할 수 있습니다. 같은 계정으로 2대 이상의 PS3™에 자동 업데이트를 [켜기]로 설정한 경우에는 마지막에 설정한 PS3™ 이외의 PS3™는 자동으로 [끄기]로 변경됩니다.
  • 자동 업데이트를 실행하는 시간대에 PS3™를 대기상태로 해 두어야 합니다. 본체의 전원 표시등에 빨간색 불이 켜져 있는지 확인해 주십시오.
  • 설치가 필요한 콘텐츠 중 시스템 소프트웨어의 업데이트 데이터는 다운로드만 자동으로 실행합니다. 시스템 소프트웨어의 업데이트는 직접 실행해 주십시오.
  • 자동으로 다운로드한 게임의 패치나 추천 게임 등에는 가 표시됩니다. 다운로드/설치한 후 1개월간 기동하지 않은 콘텐츠는 자동으로 삭제됩니다.
  • 본체 스토리지의 빈 용량이 5 GB 이하인 경우 자동 업데이트를 [켜기]로 설정해 두어도 다운로드가 실행되지 않습니다.
  • 설정을 [끄기]로 하면 자동 업데이트 항목의 선택이 초기값으로 돌아갑니다.
