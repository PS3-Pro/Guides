백업 유틸리티

본체 스토리지에 저장된 데이터를 기록 미디어 또는 USB 대용량 저장소 장치에 백업하거나 백업된 데이터를 복원합니다.

백업 본체 스토리지의 데이터를 기록 미디어 또는 USB 대용량 저장소 장치에 백업합니다.
복원 기록 미디어 또는 USB 대용량 저장소 장치에 백업된 데이터를 본체 스토리지에 복원합니다.
백업 데이터의 삭제 기록 미디어 또는 USB 대용량 저장소 장치에 백업된 데이터를 삭제합니다.

중요

백업 유틸리티에서는 게임에서 획득한 트로피의 데이터를 백업할 수 없습니다. 트로피 데이터를 남기시려면 Sony Entertainment Network의 계정을 만들어 서버에 저장해 주십시오. PSNSM에 로그인한 상태에서 (PlayStation™Network) > (트로피 컬렉션)을 선택하여 버튼을 누른 후 옵션 메뉴에서[서버와 동기화]를 선택합니다. 트로피 데이터가 PSNSM서버에 저장됩니다.


알아두기

  • 데이터를 Memory Stick™, SD Memory Card, CompactFlash® 및 USB 대용량 저장소 장치에 백업할 수 있습니다. 사용하시는 PS3™에 따라서는 기록 미디어를 사용하기 위해 별매의 USB 어댑터가 필요한 경우가 있습니다. CD-R과 같은 디스크 미디어는 사용할 수 없습니다.
  • USB 하드 디스크를 사용하여 데이터를 백업할 수 있으며 아이콘 아래에 표시됩니다. 이 경우 FAT32 파일 형식으로 초기화하여 사용해 주십시오. 다른 파일 형식으로 초기화된 디스크는 PS3™에서 인식되지 않습니다.
  • 백업된 데이터는 [PS3] - [EXPORT] - [BACKUP] 폴더에 저장됩니다. 이 폴더는 자동으로 만들어집니다.
  • 백업된 데이터의 폴더명 또는 파일명을 변경할 경우 데이터를 복원하지 못할 수도 있습니다.
  • 백업 후 다음 조작을 수행할 경우 백업한 데이터 중 저작권 보호된 동영상 파일은 제대로 복원하지 못할 수도 있습니다.
  • - 본체 스토리지 초기화
  • - PS3™의 초기화
  • - 저작권 보호된 비디오의 이동
  • - 저작권 보호된 비디오의 다운로드
  • - 저작권이 보호되어 있고 유효기간이 설정된 동영상의 첫 재생
  • 백업한 후에 데이터 전송 유틸리티 기능으로 데이터 전송을 하면 복사 금지된 저장 데이터는 전송한 쪽과 전송받은 쪽 PS3™ 양쪽 모두에서 복원할 수 없게 되므로 주의해 주십시오.
  • 백업된 데이터 중 일부 형식은 다른 PS3™에서도 복원할 수 있습니다. 다른 PS3™에서 복원할 수 있는 데이터 형식은 다음과 같습니다.
  • - PlayStation®3 규격 소프트웨어의 저장 데이터*1
  • - 미니게임("minis")용 저장 데이터
  • - PSP™Game의 저장 데이터
  • - (사진)의 이미지 파일
  • - (음악)의 음악 파일*2
  • - (비디오)의 동영상 파일*2
  • - (인터넷 브라우저)에 추가된 즐겨찾기
  • - (설정) > (시스템 설정) > [Add / Edit Term (단어의 등록/편집)]을 사용하여 등록된 단어 또는 온스크린 키보드 입력을 통해 자동 완성 입력 후보로 등록된 단어.
    • *1  복사 금지된 데이터는 복원할 수 없습니다. 또한 게임에 따라서는 복원된 데이터를 사용할 수 없는 경우가 있습니다.
    *2  저작권 보호된 데이터는 포함되지 않습니다.
  • 경우에 따라 백업 유틸리티 기능을 사용하여 시스템을 올바로 백업하거나 복원하지 못할 수도 있습니다. 중요한 데이터를 항상 기록 미디어에 복사하거나 이동하여 데이터를 별도로 백업해 놓는 것이 좋습니다.
