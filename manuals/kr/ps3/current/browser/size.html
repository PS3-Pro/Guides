웹 페이지의 표시 크기 변경하기

PS3™의 영상 출력 설정 및 연결된 TV의 조합에 따라서는 웹 페이지가 너무 작게 표시되거나 너무 크게 표시될 수 있습니다. 이런 경우에 다음과 같은 방법으로 표시 크기를 조정할 수 있습니다.

줌 기능 사용하기

포인터가 놓여 있는 화면 영역을 최적의 크기로 자동으로 확대합니다. 포인터가 놓인 부분에 가장 적합한 확대 비율을 자동으로 계산합니다. 확대할 영역에 포인터를 놓고 버튼을 누른 후 옵션 메뉴에서 (표시)의 [줌]을 선택합니다.

텍스트 확대의 예

포인터가 놓인 텍스트 단락의 크기에 따라 확대 비율을 산출하여 줌 모드로 표시합니다.


이미지 확대의 예

포인터가 놓인 이미지의 크기에 따라 확대 비율을 산출하여 줌 모드로 표시합니다.

해상도 변경하기

웹 페이지의 표시 해상도를 변경합니다. PS3™의 영상 출력 해상도에 맞게 웹 페이지를 보기 좋은 크기로 조정할 수 있습니다. 버튼을 누른 후 옵션 메뉴에서 (도구)의 [해상도]를 선택합니다.


PS3™의 영상 출력 설정이 1080p 또는 1080i로 되어 있을 때 해상도를 [-1] 또는 [-2]로 설정하면 화면이 보기 좋게 확대됩니다. PS3™의 영상 출력 설정이 표준 (NTSC: 480i/PAL: 576i) 또는 480p/576p로 되어 있을 때는 해상도를 [+1] 또는 [+2]로 설정하면 화면이 보기 좋게 축소됩니다.

PS3™의 영상 출력 설정이 [1080i]이고 [해상도]가 [-2]로 설정된 경우의 예


PS3™의 영상 출력 설정이 (NTSC: 480i/PAL: 576i)]이고 [해상도]가 [+2]로 설정된 경우의 예
