표시

페이지의 표시 방법을 변경합니다.

줌/줌 해제 화면의 포인터가 있는 부분을 확대하여 표시하거나 줌 표시를 해제합니다.

포인터가 놓인 부분에 가장 적합한 확대 비율을 자동으로 계산합니다.
최대 크기/표준 크기 전체 화면에 표시되도록 창을 확대합니다. / 창을 원래 크기로 표시합니다.
글자 크기 글자 크기를 변경합니다.

다섯 단계로 변경할 수 있습니다.
인코딩 인코딩을 지정합니다.

일반적으로 자동으로 결정되므로 지정할 필요가 없습니다.

알아두기

페이지에 따라서는 문자 크기를 변경하거나 문자 인코딩을 지정할 수 없는 것이 있습니다.

도구

페이지를 열 때의 조건을 설정하거나 본체 스토리지에 저장된 데이터를 삭제합니다.

쿠키 수신 모두 허용: 쿠키 저장을 항상 허용합니다.

모두 차단: 쿠키 저장을 항상 거부합니다.
자바스크립트 켜기: 자바스크립트를 사용합니다.

끄기: 자바스크립트를 사용하지 않습니다.
표시 영역 최대 화면: 창의 표시 영역을 TV의 표시 가능한 영역 가득히 표시합니다.*1

표준 크기: 창의 표시 영역을 5% 축소해 표시합니다.

-1: 창의 표시 영역을 10% 축소해 표시합니다.

-2: 창의 표시 영역을 15% 축소해 표시합니다.
해상도 웹 페이지의 해상도를 변경합니다.

PS3™의 영상 출력 해상도에 맞추어 웹 페이지를 보기 쉽게 조정합니다.
깜빡임 방지 켜기: 문자, 이미지 또는 선에서 깜빡임이 있을 때 깜빡임을 억제합니다.

끄기: 깜박임 방지 기능을 비활성화합니다.

인터레이스로 표시할 때 화면의 깜빡임을 억제하는 효과가 있습니다. PS3™의 영상 출력 설정에서 1080i 등의 해상도를 선택했을 때 [켜기]로 설정합니다. 1080p, 720p 등의 프로그레시브 표시에서는 [끄기]로 설정했을 때 화질이 더 향상됩니다.
브라우저 종료 확인 켜기: （인터넷 브라우저）를 닫을 때 확인 메시지를 표시합니다.

끄기: 확인 메시지를 표시하지 않고 종료합니다.
시작 페이지 (인터넷 브라우저)를 기동하거나 메뉴에서 (홈)을 선택할 때 표시할 페이지를 설정합니다.

[브라우저 기동시 창 복원]을 선택할 경우 브라우저를 닫을 때 열려 있던 페이지가 다음에 브라우저를 기동할 때 표시됩니다.
쿠키 삭제 쿠키를 삭제합니다.
검색 기록 삭제 검색 기록을 삭제합니다.
캐시 삭제 캐시를 삭제합니다.
인증 정보 삭제 인증 정보를 삭제합니다.
브라우저 보안 정지 웹 필터링 서비스 설정을 정지합니다.*2

이 설정을 변경하려면 비밀번호를 입력해야 합니다. 비밀번호에 대한 상세한 사항은  (설정) > (보안 설정) > [비밀번호 변경]을 참조해 주십시오.
*1

일반적인 TV에서는 [최대 화면]을 설정하면 화면의 상하 부분이 잘릴 수 있습니다.
*2

웹 필터링 서비스의 종류는 국가나 지역에 따라 다릅니다.
