단축키/마우스/키보드 사용하기

단축키로 조작하기

메뉴를 사용하지 않고 무선 컨트롤러의 버튼을 사용하여 직접 조작합니다. 브라우즈 모드와 윈도우 모드에서 사용 가능한 조작이 다릅니다.

브라우즈 모드
버튼 링크를 엽니다.
버튼(누르고 있기) 새 창에서 링크를 엽니다.
버튼 + 왼쪽 스틱 텍스트를 선택합니다.
버튼 메뉴를 표시합니다.
버튼 (인터넷 브라우저)를 종료합니다.
버튼(누르고 있기) 창을 닫습니다.*1
START 버튼 주소를 입력합니다.
SELECT 버튼 [내 즐겨찾기]를 엽니다.
L1/R1 버튼 이전 페이지 또는 다음 페이지로 이동합니다.
L2/R2 버튼 다른 창으로 이동합니다.*2
방향키 방향키를 누른 방향의 링크로 포인터를 이동합니다.
버튼 + 방향키 방향키를 누른 방향으로 페이지 스크롤합니다.
왼쪽 스틱 포인터를 원하는 방향으로 이동합니다.
왼쪽 스틱(누름)(L3 버튼) 윈도우 모드로 전환합니다.
오른쪽 스틱 원하는 방향으로 스크롤합니다.
오른쪽 스틱(누름)(R3 버튼) 줌으로 표시합니다./줌 표시를 해제합니다.
PS 버튼 XMB™를 표시합니다.
*1

줌 도중에는 이 조작을 수행할 수 없습니다.
*2

줌 도중에 확대 또는 축소합니다.
윈도우 모드
버튼 선택한 창을 브라우즈 모드로 표시합니다.
버튼 메뉴를 표시합니다.
왼쪽 스틱(누름)(L3 버튼) 브라우즈 모드로 전환합니다.
방향키 다른 창으로 이동합니다.
PS 버튼 XMB™를 표시합니다.

마우스(별매)로 조작하기

시판되는 마우스를 사용하여 조작합니다.

오른쪽 버튼을 누른 상태로 왼쪽으로 끌기 이전 페이지로 돌아갑니다.
오른쪽 버튼을 누른 상태로 오른쪽으로 끌기 다음 페이지로 이동합니다.

키보드(별매) 사용하기

시판되는 키보드를 사용하여 조작합니다.

Ctrl + L/F4 주소를 입력합니다.
Ctrl + R/F5 페이지를 새로 고칩니다.
Ctrl + B/Ctrl + I [내 즐겨찾기]를 엽니다.
PageUp/Shift + Space 위로 스크롤합니다.
PageDown/Space 아래로 스크롤합니다.
Home 페이지 맨 위로 이동합니다.
End 페이지의 맨 아래로 이동합니다.
Tab 커서를 이동합니다.
Alt + ←/BackSpace 이전 페이지로 돌아갑니다.
Alt + →/Shift + BackSpace 다음 페이지로 이동합니다.
Ctrl + ←/Ctrl + Shift + Tab 왼쪽 창으로 이동합니다.
Ctrl + →/Ctrl + Tab 오른쪽 창으로 이동합니다.
