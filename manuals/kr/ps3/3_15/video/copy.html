동영상 파일 복사/이동하기

기록 미디어에 저장된 동영상 파일을 하드 디스크로 가져오거나 가져온 파일을 기록 미디어에 복사할 수 있습니다. 가져오거나 복사할 파일을 선택한 상태에서 버튼을 누른 후 옵션 메뉴에서 [복사]를 선택합니다. 화면의 지시에 따라 조작해 주십시오.

복사와 이동의 차이점

파일의 종류에 따라 복사(복제)할 수 있는 것과 이동할 수 있는 것이 있습니다. 복사 제한이 걸려있는 파일은 이동하는 것만 가능합니다. 파일을 이동하면 원래 저장 위치에는 남아있지 않습니다.

동영상 파일의 종류 대응 방식 동영상 파일의 저장 위치
일반 동영상 파일 복사
  • PS3™의 하드 디스크
  • 기록 미디어
복사 제한이 걸려있는 동영상 파일(파일 형식이 MGV, ETS 등) 이동
  • PS3™의 하드 디스크
  • Memory Stick PRO™ *
PlayStation®Store에서 다운로드한 SD 해상도의 대여 콘텐츠(파일 타입:MNV) 이동
  • PSP™go의 본체 메모리
*

Memory Stick PRO-HG™, Memory Stick Micro™도 포함됩니다.

알아두기

  • PlayStation®Store에서 다운로드한 HD 해상도의 유료 콘텐츠(파일 타입:MNV)는 복사/이동할 수 없습니다. PlayStation®Store에서 다운로드한 유료 비디오 콘텐츠를 일시적으로 기록 미디어에 이동하고 싶은 경우에는 개별적으로 백업해 주십시오. 상세한사항은 (비디오) > [동영상 파일 백업/복원하기]를 참조해 주십시오.
  • 사용연령제한이 있는 동영상 파일을 복사하거나 이동할 경우 비밀번호를 입력해야 합니다. (설정) > (보안 설정)의 [비밀번호 변경]에서 비밀번호를 설정할 수 있습니다.
  • 사용하시는 기기에 따라서는 복사한 동영상 파일을 표시할 수 없는 경우가 있습니다.
  • 사용하시는 PS3™에 따라서는 기록 미디어를 사용하기 위해 별매의 USB 어댑터 등이 필요한 경우가 있습니다. 또한 복사가 제한된 동영상 파일을 이동할 경우 PSP™ 또는 MSAC-US40(Sony 제품) 등 Memory Stick™의 저작권 보호기능에 대응하는 USB 기기가 필요합니다.
  • 사용하시는 PS3™에 Memroy Stick™ 슬롯이 있는 경우에 Memory Stick Micro™를 사용할 때는 반드시 Memory Stick Micro™를 M2 Duo 사이즈 어댑터에 넣어서 사용해 주십시오.
  • 저작권 보호된 일부 동영상 파일의 경우 이동 기능을 사용하지 못할 수도 있습니다.
  • 타인의 지적 재산권을 침해하지 않도록 주의해 주십시오.
  • 재생중에는 동영상 파일을 복사하거나 이동할 수 없습니다.*

    • * 음악 파일을 재생하는 등 다른 기능에서 콘텐츠를 재생하고 있는 경우도 포함됩니다.

동영상 파일을 PSP™에 복사/이동하여 보기

동영상 파일을 PSP™에 복사/이동해서 볼 수 있습니다.

1.

USB 케이블로 PSP™와 PS3™를 연결합니다.
Memory Stick™에 파일을 복사하는 경우에는 PSP™에 미리 Memory Stick™을 넣어 둡니다.

2.

PSP™의 (설정)에서 (USB 연결)을 선택합니다.

3.

PS3™의 (비디오)에서 복사/이동할 동영상 파일을 선택한 후 버튼을 누릅니다.

4.

[복사] 또는 [이동]을 선택합니다.
화면의 지시에 따라 복사/이동해 주십시오. 복사/이동된 동영상 파일은 PSP™의 (비디오) > (Memory Stick™) 또는 (본체 메모리)에서 재생할 수 있습니다.

알아두기

  • PSP™에서 볼 때의 조작 방법은 PSP™ 사용자 가이드를 참조해 주십시오.
  • 복사/이동할 동영상 파일의 종류에 따라서는 Memory Stick PRO Duo™가 필요한 경우가 있습니다.
