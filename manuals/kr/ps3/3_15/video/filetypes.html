재생할 수 있는 파일 형식

(비디오)에서는 아래 형식의 파일을 표시할 수 있습니다.

  • Memory Stick 비디오 포맷
  • - MPEG-4 SP(AAC LC)
  • - H.264/MPEG-4 AVC Main Profile(AAC LC)
  • - MPEG-2 TS（H.264/MPEG-4 AVC, AAC LC）
  • MP4 파일 포맷
  • - H.264/MPEG-4 AVC High Profile（AAC LC）
  • MPEG-1(MPEG Audio Layer 2)
  • MPEG-2 PS(MPEG2 Audio Layer 2, AAC LC, AC3(Dolby Digital), LPCM)
  • MPEG-2 TS（MPEG2 Audio Layer 2, AC3（Dolby Digital）, AAC LC）
  • MPEG-2 TS（H.264/MPEG-4 AVC, AAC LC）
  • AVI
  • - Motion JPEG (Linear PCM)
  • - Motion JPEG (μ-Law)
  • AVCHD (.m2ts / .mts)
  • DivX
  • VC-1（WMV）
  • - VC-1（WMA Standard V2）

알아두기

  • 데이터 형식에 따라서는 재생할 수 없거나 재생중에 제어판의 일부 항목이 기능하지 않는 경우가 있습니다.
  • 인터넷 등에서 배포된 동영상 파일에는 재생 방법이 제한되어 있는 경우가 있습니다. 상세한 사항은 해당 파일을 배포한 곳에 문의해 주십시오.
  • WMV 형식의 파일을 재생할 때는 (설정)>(시스템 설정)>[WMA 재생 활성화하기]를 설정해야 합니다.
  • USB 어댑터를 사용하여 동영상 파일을 재생하는 경우 저작권 보호 기능에 대응하는 USB 어댑터(별매)를 사용해야 할 수도 있습니다.(저작권 보호된 파일을 재생하는 경우)
  • Memory Stick™에 저장된 AVCHD 형식의 동영상 재생시에 USB 어댑터를 사용하는 경우 Hi-Speed USB(USB 2.0)를 지원하는 기기를 사용해 주십시오.
  • WMV 형식의, 저작권이 보호된 파일은 재생할 수 없습니다.
