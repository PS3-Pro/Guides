인터넷 접속 설정(유선)

인터넷 접속 방법을 설정합니다. LAN 케이블을 사용하여 유선으로 접속할 경우 화면 지시에 따라 조작을 진행하면 표준적인 설정이 자동으로 선택됩니다.


인터넷 접속 설정은 사용하시는 네트워크 환경과 기기에 따라 다릅니다. 여기서는 LAN 케이블을 사용하여 인터넷에 접속할 때(유선)의 표준적인 설정의 예를 설명합니다.

1.

PS3™에 LAN 케이블을 연결합니다.

2.

(설정)에서 (네트워크 설정)을 선택합니다.

3.

[인터넷 접속 설정]을 선택합니다.
인터넷 접속이 끊어진다는 확인 화면이 표시되면 [예]를 선택합니다.

4.

[간단]을 선택합니다.

네트워크 구성 확인이 끝나면 설정 목록이 표시됩니다.

사용하시는 네트워크 환경에 따라서는 PPPoE나 프록시 서버, IP 주소 등의 추가 설정이 필요한 경우가 있습니다. 설정 내용에 대해서는 인터넷 서비스 제공자(ISP)에서 제공되는 정보와 사용하시는 네트워크 기기에서 제공되는 사용설명서를 참조해 주십시오.

5.

설정을 저장합니다.

6.

접속 테스트를 합니다.
[접속 테스트하기]를 선택하면 인터넷에 접속합니다.

7.

접속 테스트 결과를 확인합니다.
접속이 성공하면 네트워크에 대한 정보가 표시됩니다.

알아두기

접속에 실패하면 화면의 지시에 따라 설정 내용을 확인해 주십시오. 또한 인터넷 서비스 제공자(ISP)에서 제공되는 정보와 사용하시는 네트워크 기기에서 제공되는 사용설명서를 참조해 주십시오.
