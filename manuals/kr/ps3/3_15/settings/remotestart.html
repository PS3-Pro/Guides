리모트 기동

PSP™를 사용해 리모트 플레이할 때 대기중인 PS3™의 전원을 자동으로 켤 수가 있습니다(Wake On LAN). 이 기능을 사용하려면 먼저 다음을 수행해야 합니다.

PS3™의 무선랜 경유/액세스 포인트 경유로 리모트 플레이를 할 때
  • PSP™의 시스템 소프트웨어를 버전 3.72 이상으로 업데이트합니다.
  • PS3™의 (유저)에서 자동 로그인을 설정해 둡니다.

인터넷 경유로 리모트 플레이를 할 때
  • PSP™와 PS3™의 시스템 소프트웨어를 최신 버전으로 업데이트해 둡니다.
  • PS3™의 (유저)에서 자동 로그인을 설정해 둡니다.
  • PS3™의 (유저)에서 자동 로그인을 설정합니다.
  • PlayStation®Network의 계정을 작성해 둡니다.
  • PlayStation®Network의 자동 로그인을 설정해 둡니다.

알아두기

  • (유저)의 자동 로그인에 대한 상세한 사항은 (유저)>[로그인하기]>[자동 로그인 설정하기]를 참조해 주십시오.
  • PlayStation®Network의 자동 로그인에 대한 상세한 사항은 （PlayStation®Network)>[비밀번호 저장하기/자동으로 로그인하기]를 참조해 주십시오.

리모트 기동 활성화하기

1.

(설정)에서 (리모트 플레이 설정)을 선택합니다.

2.

[리모트 기동]>[켜기]를 선택합니다.

3.

표시된 화면에서 [OK]를 선택합니다.
인터넷 경유로 리모트 플레이를 할 때는 [인터넷을 경유한 리모트 기동 활성화하기]에 체크해 주십시오.

4.

PS3™의 전원을 끕니다.
(유저)에서 (본체의 전원 끄기)를 선택하여 전원을 꺼 대기 상태로 합니다. 본체의 전원 표시등에 빨간색 불이 들어왔는지 확인해 주십시오.

5.

PSP™에서 리모트 플레이를 합니다.
리모트 플레이의 조작 방법에 대한 상세한 사항은 (네트워크)>(리모트 플레이)>[리모트 플레이하기]를 참조해 주십시오.

알아두기

리모트 기동을 활성화하면 PS3™의 전원을 끈 후에도 본체의 내장 팬이 계속 동작합니다.

리모트 기동 비활성화하기

1.

(설정)에서 (리모트 플레이 설정)을 선택합니다.

2.

[리모트 기동]>[끄기]를 선택합니다.

인터넷을 경유한 리모트 기동에 대하여

사용하시는 네트워크 기기에 따라서는 인터넷을 경유한 리모트 기동에 성공하지 못하는 경우가 있습니다. 그러한 경우에는 다음의 정보를 참고해 주십시오.

중요

인터넷을 경유한 리모트 기동을 활성화하면 사용하시는 네트워크 기기의 종류에 따라서는 의도하지 않게 PS3™가 기동되는 경우가 있습니다. 기동 후, 일정 시간 내에 리모트 플레이가 실행되지 않는 경우에는 PS3™의 전원이 자동으로 꺼집니다. 또한 이런 현상을 방지하기 위해 인터넷을 경유한 리모트 기동이 자동으로 비활성화되는 경우가 있습니다.

  • 인터넷을 경유한 리모트 기동을 하려면 라우터가 필요합니다.
  • 사용하시는 라우터가 UPnP에 대응하는 경우에는 라우터의 UPnP 기능을 활성화하기로 설정해 주십시오.
  • UPnP에 대응하지 않는 라우터를 사용하시는 경우에는 라우터의 포트 포워딩을 설정하여 인터넷에서 PS3™로의 통신을 허가해야만 합니다. 리모트 플레이 및 리모트 기동에서 사용되는 포트 번호는 TCP : 9293, UDP : 9293입니다. 설정 방법에 대해서는 라우터의 사용설명서를 참조해 주십시오.
  • 포트 포워딩이란 특정 포트(입구)에 도착한 신호를 지정된 다른 포트(출구)로 전달하는 기능입니다. "포트 매핑" 또는 "주소 변환"이라고도 합니다.
  • PS3™가 대기 상태일 때 라우터의 IP 주소(글로벌 IP 주소)가 변경되면 리모트 기동에 실패합니다.
