초기화 유틸리티

Memory Stick™, SD Memory Card, CompactFlash® 또는 하드 디스크를 초기화(포맷)합니다. 화면의 지시에 따라 조작해 주십시오.


중요

  • 초기화를 하면 기록 미디어 또는 하드 디스크의 모든 데이터가 삭제됩니다. 삭제된 데이터는 복원할 수 없으므로 중요한 데이터를 삭제하지 않도록 주의해 주십시오. 데이터 손실이나 손상은 사용자의 책임입니다.
  • 초기화 도중에 PS3™의 전원을 끄거나 기록 미디어를 빼지 마십시오. 초기화가 도중에 중단되면 고장의 원인이 됩니다.
  • 하드 디스크 초기화(포맷) 도중에는 본체 전면의 전원 버튼 및 무선 컨트롤러의 PS 버튼이 기능하지 않게 됩니다.
  • 하드 디스크를 초기화하더라도 시스템 소프트웨어는 삭제되지 않습니다.
  • (인터넷 브라우저)의 즐겨찾기 등과 같이 하드 디스크에 저장된 설정은 삭제됩니다.
  • 하드 디스크 초기화 방법으로 [빠른 포맷]을 선택하면 초기화(포맷) 시간을 단축시킬 수 있으나 더욱 확실하게 데이터를 삭제하려는 경우에는 [포맷]을 선택해 주십시오.
  • 미디어 슬롯이 탑재되지 않은 PS3™에서는 이 기능을 사용하여 Memory Stick™, SD Memory Card 또는 CompactFlash®를 초기화할 수 없습니다.
