게임을 PSP™에 복사하여 즐기기

(PlayStation®Store)에서 다운로드(구매)한 게임이 PSP™에 대응하는 경우에는 PSP™에 복사하여 즐길 수 있습니다.

1.

게임을 다운로드(구매)한 PlayStation®Network 계정으로 (PlayStation®Network)에 로그인합니다.

2.

USB 케이블을 사용하여 PSP™와 PS3™를 연결합니다.
Memory Stick™에 파일을 복사하는 경우에는 PSP™에 미리 Memory Stick™을 넣어 둡니다.

3.

PSP™의 (설정)에서 (USB 연결)을 선택합니다.

4.

PS3™의 (게임)에서 복사할 게임을 선택한 후 버튼을 누릅니다.

5.

[복사]를 선택합니다.
화면의 지시에 따라 복사해 주십시오. 복사된 게임은 PSP™의 (게임) > (Memory Stick™) 또는 (본체 메모리)에서 기동할 수 있습니다.

알아두기

  • 이 기능을 사용하려면 PSP™의 시스템 소프트웨어가 3.40 버전 이상이어야 합니다.
  • PSP™에서 게임을 플레이할 때의 조작 방법은 PSP™의 사용자 가이드를 참조해 주십시오.

PS3™와 PSP™ 양쪽에서 즐기기

게임이 PS3™와 PSP™ 양쪽에 대응하는 경우에는 게임의 저장 데이터를 PSP™에 복사하여 밖에서 플레이하거나 PS3™로 다시 옮겨 게임을 계속 즐길 수 있습니다. 게임의 종류에 따라 저장 데이터의 복사 방법이 다릅니다.

PlayStation® 규격 소프트웨어의 저장 데이터

PlayStation® 규격 소프트웨어의 저장 데이터는 하드 디스크에 작성된 가상 Memory Card에 저장됩니다. 저장 데이터를 PSP™에 복사하려면 게임의 데이터를 복사하는 순서의 2~3 뒤에, PS3™에서  (게임) > (Memory Card 유틸리티 (PS/PS2)) > (가상 Memory Card (PS))에서 복사할 저장 데이터의 아이콘을 선택한 후 버튼을 눌러 옵션 메뉴에서 [복사]를 선택합니다.

알아두기

  • 저장 데이터를 PSP™에서 사용하기 위해서는 데이터 형식을 변환해야 합니다. 복사 중에 확인 화면이 표시되는 경우에는 [예]를 선택해 주십시오.
  • PSP™의 Memory Stick™ 또는 본체 메모리에는 하나의 게임에 대해 복수의 가상 Memory Card가 만들어집니다.
  • PS3™의 카드 슬롯이나 별매의 USB 어댑터를 사용하여 Memory Stick™에 복사하는 경우에는 저장 데이터가 인식되지 않습니다. 반드시 USB 케이블로 PSP™와 PS3™를 직접 연결해 주십시오.

PSP™의 기기인증에 대하여

(PlayStation®Store)에서 다운로드(구매)한 게임은 기기인증된 PSP™에서만 기동할 수 있습니다. PSP™에서 게임을 기동할 때 기기인증이 필요하다는 내용의 메시지가 표시되는 경우에는 다음의 순서로 인증해 주십시오.

1.

USB 케이블을 사용하여 PSP™를 PS3™에 연결합니다.

2.

PSP™의 (설정)에서 (USB 연결)을 선택합니다.

3.

PS3™의 (PlayStation®Network)에서 (계정 관리)를 선택합니다.

4.

(기기인증)을 선택합니다.
화면의 지시에 따라 인증 절차를 완료해 주십시오.

알아두기

  • 기기인증을 하려면 PlayStation® 규격 소프트웨어를 다운로드할 때 로그인했던 유저로 PS3™에 로그인해야 합니다.
  • 기기인증은 콘텐츠의 저작권을 보호하기 위한 수단으로, 인증된 기기에서만 콘텐츠 재생을 허용하는 절차입니다.
