게임 시작/종료하기

게임 시작하기

디스크를 삽입하면 게임이 자동으로 시작됩니다.

게임 끝내기

게임 플레이 중에 무선 컨트롤러의 PS 버튼을 눌러 표시되는 화면에서 [게임 종료]를 선택합니다.

중요

PlayStation®2 규격 소프트웨어의 기동/종료시에는 컨트롤러의 번호 할당이 해제됩니다. 다음 순서로 컨트롤러 번호를 할당해 주십시오.

게임 기동시: 게임 화면이 표시되면 컨트롤러의 PS 버튼을 누릅니다.
게임 종료시: 화면에 XMB™가 표시되면 컨트롤러의 PS 버튼을 누릅니다.

알아두기

PlayStation®2/PlayStation® 규격 소프트웨어의 데이터를 저장하려면 가상 Memory Card를 작성해야 합니다. 가상 Memory Card에 대한 상세한 사항은 (게임)  > [PlayStation®2 / PlayStation® 규격 소프트웨어 즐기기 > [저장 데이터에 대하여]를 참조해 주십시오.

게임 리셋하기

게임중에 무선 컨트롤러의 PS 버튼을 눌러 표시되는 화면에서 [게임 리셋]을 선택합니다. PlayStation®2 / PlayStation® 규격 소프트웨어를 플레이하는 경우에만 조작할 수 있습니다.

중요

  • PS3™에서 일부 PlayStation®2 또는 PlayStation® 규격 소프트웨어가 종래의 PlayStation®2 또는 PlayStation®에서와 다르게 동작하거나 적절히 동작하지 않는 경우가 있습니다.
  • 또한 일부의 PS3™는 PlayStation®2 규격 소프트웨어의 재생에 대응하지 않습니다. 상세한 사항은 [재생할 수 있는 디스크의 종류에 대하여], 각 지역 웹 사이트 또는 제품에 동봉된 사용설명서를 참조해 주십시오.
