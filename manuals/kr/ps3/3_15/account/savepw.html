PlayStation®Network > 비밀번호 저장하기/자동으로 로그인하기

비밀번호 저장하기/자동으로 로그인하기

이 기능을 사용하려면 시스템 소프트웨어를 업데이트해야하는 경우가 있습니다.


비밀번호를 저장하면 로그인 화면에  비밀번호가 미리 입력되어, 비밀번호를 입력하지 않고 로그인할 수 있게 됩니다. 또한 자동으로 로그인하도록 설정하면 PS3™의 전원을 켰을 때 PlayStation®Network에 자동으로 로그인됩니다.

중요

  • 비밀번호를 저장하면 제삼자가 네트워크 서비스를 이용하거나 계정 정보를 볼 수 있게 되므로 주의해 주십시오.
  • PS3™를 AS에 보낼 때에는 PlayStation®Network의 비밀번호 저장 옵션을 해제해 주십시오. 해제하지 않으면 제삼자가 개인정보 및 신용카드 정보 등을 보거나 도용할 가능성이 있습니다.
  • PS3™를 타인에게 양도하거나 반품(일부 지역에 한함)하는 경우에는 PS3™ 내의 데이터를 삭제해 주십시오. PlayStation®Network의 비밀번호 저장을 해제해도 로그인 ID의 정보가 남기 때문에 데이터를 삭제하시기를 권합니다. 삭제하지 않으면 제삼자가 개인정보 및 신용카드 정보 등을 보거나 도용할 가능성이 있습니다.

1.

（PlayStation®Network）에서 (로그인)을 선택합니다.

2.

로그인 ID (이메일 주소)와 비밀번호를 입력합니다.

3.

[비밀번호 저장하기] 및 [다음부터 자동으로 로그인하기]를 선택합니다.
[다음부터 자동으로 로그인하기]를 선택하면 [비밀번호 저장하기]가 자동으로 선택됩니다.

알아두기

[다음부터 자동으로 로그인하기]가 설정되면 (로그인) 아이콘이 더 이상 표시되지 않습니다.

자동 로그인 옵션 해제하기

(PlayStation®Network) > (계정 관리)를 선택한 후 버튼을 눌러 옵션 메뉴에서 [자동 로그인 끄기]를 선택합니다. PS3™를 켜도 자동으로 로그인되지 않게 됩니다.

비밀번호 저장을 해제하기(비밀번호 지우기)

1.

（PlayStation®Network）에서 (로그인)을 선택합니다.

2.

로그인 ID(이메일 주소)와 비밀번호를 입력하는 화면에서 [비밀번호 저장하기]의 체크를 해제합니다.

알아두기

  • 자동 로그인을 설정한 경우에는 (로그인) 아이콘이 표시되지 않습니다. 자동 로그인 설정을 해제해 주십시오.
  • 자동 로그인 설정을 해제하더라도 로그인 중에 일시적으로 네트워크 접속이 끊어진 경우 등에는 자동으로 다시 로그인합니다.
