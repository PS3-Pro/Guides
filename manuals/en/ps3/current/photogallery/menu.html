Photo Gallery
User's Guide

List of menu items

You can perform various operations or adjust settings from the menu that is displayed when you press the button. Menu items vary depending on where you are in the application when you access the menu.

Copy (Import)

Copy selected photos to the system storage of the PS3™ system.

Go To Playlist Area / Go to Library Area / Go to PSNSM Area

Switch between [Playlist Area] and [Library Area].

Print

Print photos using a connected printer.

Add to Playlist

Add photos to a playlist.

Add Network Service

Add network service account information to the PS3™ system.

Clear Network Service

Delete network service account information from the PS3™ system.

Share

Share an album with your PSNSM Friends.

Edit

Add a description to a photo.

Comment

Add comments to a photo.

Slideshow

View all the photos in a selected event or playlist in slideshow format.

Edit

Edit the playlist or the album.

Group

Arrange photos in groups.

Move

Move a photo or a playlist to another location.

Rotate

Rotate a photo or the photo frame for a playlist.

Delete

Delete a photo, playlist or album.

Sort

Change the order in which photos are displayed.

Display

Set to display or hide information about a selected event or playlist.

Help

View help screens that provide information about [Library Area] and [Playlist Area] and the main functions on the wireless controller when used with Photo Gallery. You can also view a list of the menu items.

Tools

Set preferences for Photo Gallery.

Key Tone Turn the key tone on or off.
Music Turn the background music on or off.
Surface Brightness Select the brightness of the surface that is used in the background.
Surface Type Select the surface type that is used in the background.

Exit

Quit Photo Gallery.
