Printing photos

To print a photo, you must first set up a printer in [Printer Selection] under (Settings) > (Printer Settings).

1.

Connect a printer to the PS3™ system.

2.

Select the photo that you want to print, and then press the button.

3.

Select (Print).

4.

Check the print settings.
You can press the button to display the options menu. You can adjust settings such as the number of copies to be printed. The settings that are available vary depending on the printer in use.

5.

Select [Print].
The photo is printed.

Hint

Printers that can be used vary depending on the country or region. For details, visit the SIE Web site for your region.
