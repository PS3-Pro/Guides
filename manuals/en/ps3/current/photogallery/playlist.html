User's Guide

Creating a playlist of selected photos

You can select photos to create a playlist. With a playlist, you can view the selected photos in the same order at any time.

Creating a playlist

1.

From [Library Area], select a photo that you want to add to the playlist, press the button, and then select   (Add to Playlist).
[Playlist Area] is displayed.

2.

Use the left stick to move to an empty area in [Playlist Area], and then press the button.
A new playlist is added in that location.

3.

Set the following options for the playlist.
After you have set these options, the playlist will be created.

Photo Frame Select a frame for the playlist.
Playlist Create a name for the playlist.
Slideshow Style Select the way photos are displayed in the slideshow.
Slideshow Speed Select the slideshow speed.
Slideshow Music Select the music to play in the background during the slideshow from music content that is provided with the Photo Gallery application.
Select the music to play in the background during the slideshow from the (Music) category in the XMB™ screen.

Hints

  • The playlist settings can be edited later under (Edit).
  • Each playlist can have its own settings.

Adding photos to a playlist

1.

Select the photos that you want to add to the playlist, press the button, and then select (Add to Playlist).
The Playlist screen is displayed.

2.

Select the playlist, and then press the button.
The selected photos are added to the playlist.

Editing settings for a playlist

You can edit settings for a playlist. Select the playlist that you want to edit, press the button, and then select (Edit).

Moving a playlist

You can move a playlist to another location. Select the playlist that you want to move, press the button, and then select (Move). You can move the playlist using the left stick.

Hint

You can also move a playlist without accessing the menu. Select the playlist, and then press and hold down the button while using the left stick to move the playlist.

Deleting a playlist

To delete a playlist, select the playlist that you want to delete, press the button, and then select (Delete).
