Register Keyboard / Mouse

Adjust settings for a keyboard or mouse.

Keyboard Type

Set the type of the keyboard that is connected to the system via a USB cable or Bluetooth® technology.

Keyboard Entry Method

Set the entry method of the keyboard that is connected to the system via a USB cable or Bluetooth® technology. This setting is available only in the following cases:

  • When the system language is set to display traditional Chinese characters
  • When the system language is set to Japanese and [Keyboard Type] is set to [Japanese Keyboard] or [English Keyboard (US Standard)]

Key Binding

Adjust the key assignment for the keyboard. This setting is available only when the system language is set to Japanese and [Keyboard Type] is set to [Japanese Keyboard] or [English Keyboard (US Standard)].

Key Repeat Interval

Set the amount of time before a character is repeated when a key is held down on a USB keyboard or Bluetooth® keyboard.

Key Repeat Speed

Set the speed at which a character is repeated when a key is held down on a USB keyboard or Bluetooth® keyboard.

Mouse Type

Set the type of mouse that is connected via a USB cable or Bluetooth® technology. Set the type based on which hand you use to control the mouse.

Pointer Speed

Set the speed at which the mouse pointer moves.
