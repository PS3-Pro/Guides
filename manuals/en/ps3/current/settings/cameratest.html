Camera Device Settings

Test the image of a USB camera (sold separately) that is connected to the system using a USB cable. You can adjust settings to reduce flickering for some cameras. By adjusting the power frequency to that for the region where the camera is being used, you may be able to reduce flickering. The items that are displayed vary depending on the camera in use.

Off Set to disable flicker reduction.
Camera Default Settings Use the default settings for the camera.
50 Hz Set to this option if the power frequency of the region where you live is 50 Hz.
60 Hz Set to this option if the power frequency of the region where you live is 60 Hz.

Hints

  • You can use a compatible EyeToy™ USB camera / PlayStation®Eye / USB camera compliant with USB video class (UVC) on the PS3™ system.
  • When connecting a USB camera using a USB hub, use a hub that supports USB 2.0. If a hub that does not support USB 2.0 is used, quality may be reduced or the image may not be displayed.
  • For information on supported peripherals and usage instructions, contact the retailer where the peripherals are sold.
