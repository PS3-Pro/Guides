Adding to your Friends list

To use this feature, you may be required to update the system software.


To add someone to your Friends list, you must first send a message requesting approval.

1.

Select (Friends) > (Add a Friend).
A blank message that you can use to request to add a Friend is displayed.

2.

Select the [To] field.
Enter the online ID of the person you want to add as a Friend.

3.

Type a message, and then select [Send].
Your message is sent and the Friend's avatar is displayed under (Friends).

The message is received. If the person accepts your request, the person will be added to your Friends list and you will also be added to the person's Friends list.

Hints

  • An online ID is registered when you create (sign up for) a Sony Entertainment Network account. To request to add a Friend, you will first need to ask the person you want to add for his or her online ID.
  • If the person selects [Do Not Add] in response to your request to add the person as a Friend, the avatar for that person will be removed from your list.

Receiving a request to be added as a Friend

If you receive a request to be added as a Friend, reply to the request so that you are added as a Friend.

1.

Select the avatar of the person who sent the request to add a Friend under (Friends).
The person's profile is displayed.

2.

Select (Reply to Friend Request).
Follow the on-screen instructions to be added as a Friend. After you have been added, the avatars for both of you will be added to each other's Friends list.
