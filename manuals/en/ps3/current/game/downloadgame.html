Downloading games

You can download games (as a purchase or for free) from (PlayStation®Store). Several types of games are available, including games that you can play only on PS3™ systems and games that you can copy to and play on PS Vita systems or PSP™ systems. For details about game types and compatible systems, refer to the information provided in PlayStation®Store.


Hints

  • For details on PlayStation®Store, see (PlayStation™Network) > (PlayStation®Store) > [PlayStation®Store overview].
  • To play software on a PSP™ system, you must first copy data for the software to the PSP™ system. For details, see (Game) > [Playing games downloaded from PlayStation®Store] > [Copying games to play on a PSP™ system] in this guide.
  • Copy PS Vita system and PSP™ system games that have been downloaded but are (uninstalled). A game that is already installed in the system storage of the PS3™ system must be downloaded again from the Download List on (PlayStation®Store) to set its status to uninstalled.
  • Some PlayStation® format software may not be compatible with both PSP™ and PS3™ systems at the time of initial release. When the PlayStation® format software that you downloaded for use on the PSP™ system later becomes available for the PS3™ system, you can re-download it without additional charge from Download List in (PlayStation®Store).
