Playing downloaded games

You can play games that you download (as a purchase or for free) from (PlayStation®Store). How you play a game varies depending on the game type. Information on the game type is displayed next to the game icon.

Hint

To sort games by type, select a game icon, press the button, and then select [Sort By] > [Format] from the options menu.

Playing PlayStation®3 format software

In general, you can play PlayStation®3 format software that is downloaded from (PlayStation®Store) in the same way as PlayStation®3 format software that is available on disc media. For details, see (Game) > [Playing PlayStation®3 format software] in this guide.

Playing PlayStation® format software

In general, you can play PlayStation® format software that is downloaded from (PlayStation®Store) in the same way as PlayStation® format software that is available on disc media. For details, see (Game) > [Playing PlayStation®2 / PlayStation® format software] in this guide.


Software manuals

You may be able to view the software manual for the PlayStation® format software that you have downloaded. To view the manual, press the PS button on the wireless controller during gameplay, and then select [Software Manual] from the screen that is displayed.


Games that require switching of discs

Some PlayStation® format software that are downloaded require the switching of discs. When playing such games on the PS3™ system, the switching of discs is performed virtually. If a message asking you to switch discs is displayed, press the PS button on the wireless controller, and then select [Switch Discs] from the screen that is displayed. Follow the on-screen instructions to complete the operation.

Select a PC Engine or NEOGEO format game.

For details on playing games in PC Engine or NEOGEO format, refer to the instruction manual supplied with the game. The method for viewing the instruction manual may vary depending on the game. The PC Engine and NEOGEO formats may not be available depending on the country or region.
