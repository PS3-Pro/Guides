Copying playlists to a PSP™ system

You can copy music as playlists and then play them on the PSP™ system.

1.

Connect the PSP™ system to your PS3™ system using a USB cable.
To copy files to Memory Stick™ media, insert the Memory Stick™ media into the PSP™ system.

2.

On the PSP™ system, select (Settings) > (USB Connection).

3.

On the PS3™ system, select (Music) > (Playlists).

4.

Select the playlist icon you would like to use, and then press the button.

5.

Select [Copy].
Select (PSP™ (PlayStation®Portable)) or (PSP™ (PlayStation®Portable)) as the destination.

Hints

  • To use this feature, the system software of the PSP™ system must be version 3.10 or higher.
  • You cannot copy playlists from the PSP™ system to the PS3™ system.
