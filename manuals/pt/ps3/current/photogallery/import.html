Importar fotografias para o sistema PS3™

Para visualizar as fotografias guardadas no armazenamento do sistema PS3™, basta iniciar Photo Gallery. Se não tiverem sido guardadas fotografias no armazenamento do sistema, é possível importar fotografias guardadas numa câmara digital ou num suporte de armazenamento para o sistema de armazenamento, para serem utilizadas no Photo Gallery.


Para importar fotografias, ligue a câmara digital ou um adaptador USB (com suporte de armazenamento inserido) ao sistema PS3™ utilizando um cabo USB. Utilize o manípulo esquerdo para seleccionar o ícone da câmara digital apresentado e, em seguida, prima o botão . Siga as instruções do ecrã para importar as fotografias para o armazenamento do sistema.

Notas

  • As fotografias importadas também podem ser visualizadas em (Fotografia) no ecrã XMB™ (XrossMediaBar).
  • Não pode exportar fotografias para o suporte de armazenamento quando estiver a utilizar a Photo Gallery. Para exportar fotografias, saia do Photo Gallery e vá para (Fotografia) no ecrã XMB™.
  • Poderá não ser possível importar fotografias a partir de algumas câmaras digitais e dispositivos de armazenamento.
  • Deve-se tomar cuidado para não se infringir a propriedade intelectual de terceiros.
