Utilizar dados guardados para minis minis e software PSP™Game (Jogo PSP™)

Copiar dados guardados de PSP™Game para um sistema PS3™ (Jogo PSP™)

1.

Ligue o sistema PSP™ ao sistema PS3™ utilizando um cabo USB.

2.

No sistema PS3™, seleccione (Jogo) > (Utilitário de Dados Guardados (minis / PSP™)).

3.

Seleccione os dados que pretende copiar e, em seguida, prima o botão .

4.

Seleccione [Copiar].

Notas

  • Os dados guardados são geridos separadamente por cada utilizador. Se existir mais do que um Utilizador em (Utilizadores),
    os itens apresentados em (Utilitário de Dados Guardados (minis / PSP™)) irão variar dependendo do Utilizador que tiver sessão iniciada.
  • Se seleccionar um ícone de dados guardados e premir o botão , pode ordenar os dados guardados por data de actualização ou agrupar os dados guardados por título no menu apresentado.
  • Os jogos para o sistema PSP™ (em formato Jogo PSP™) não podem ser reproduzidos no sistema PS3™.
  • Alguns jogos podem ter limitações ao uso de dados guardados. Consulte os manuais do software para mais informações.
  • O software de formato PlayStation® transferido da PlayStation®Store e guardado no sistema PSP™ é apresentado em (Utilitário do Memory Card).
