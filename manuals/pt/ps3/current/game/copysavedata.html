Copiar dados guardados para suporte de armazenamento (fazer uma cópia)

Os dados guardados no armazenamento do sistema podem ser exportados para um suporte de armazenamento e os dados guardados que foram exportados podem ser importados para o armazenamento do sistema. Seleccione os dados que pretende exportar ou importar, prima o botão e, em seguida, seleccione [Copiar] a partir do menu das opções. Siga as instruções no ecrã para concluir a operação. É aconselhável que faça cópias de segurança dos dados importantes.


Notas

  • Alguns dados guardados não podem ser copiados.
  • Não é possível copiar dados guardados durante a reprodução de conteúdo utilizando outras funções, tal como a reprodução de ficheiros de música.
  • Os dados guardados em software do formato PlayStation®2 ou PlayStation® podem também ser copiados para um memory card (8MB) (para PlayStation®2) ou para um memory card. Para mais informações, consulte [Utilizar dados guardados em memory cards] em (Jogo) > [Jogar software de formato PlayStation®2 / PlayStation®] neste manual.
  • Em alguns modelos do sistema PS3™ é necessário um adaptador USB apropriado (não incluído) para usar suportes de armazenamento.

Atenção

  • Algum software do formato PlayStation®2 ou PlayStation® poderá ter um comportamento no sistema PS3™ diferente que nos sistemas PlayStation®2 ou PlayStation® ou pode não funcionar correctamente no sistema PS3™.
  • Além disso, alguns sistemas PS3™ não reproduzem discos de formato PlayStation®2. Para obter mais informações, consulte [Tipos de discos reproduzíveis], visite o Web site da SIE da sua região ou consulte a documentação incluída no seu sistema PS3™.
