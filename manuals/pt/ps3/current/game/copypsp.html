Copiar jogos para jogar num sistema PSP™

Se o jogo que transferiu (comprado ou gratuito) de (PlayStation®Store) for compatível com o sistema PSP™, pode copiar o jogo para o jogar num sistema PSP™.

1.

Inicie a sessão em PSNSM com a conta de Sony Entertainment Network que utilizou para transferir o jogo.

2.

Ligue o sistema PSP™ ao sistema PS3™ usando um cabo USB.
Para copiar ficheiros para o suporte Memory Stick™, introduza o suporte Memory Stick™ no sistema.

3.

No sistema PSP™, seleccione (Definições) > (Ligação USB).

4.

No menu inicial do sistema PS3™, seleccione o jogo que pretende copiar em (Jogo) e prima o botão .

5.

Seleccione [Copiar].
Siga as instruções no ecrã para copiar o jogo. Após a conclusão da cópia, pode iniciar o jogo em (Jogo) > (Memory Stick™) ou (Jogo) > (Memória do Sistema) no sistema PSP™.

Notas

  • Para utilizar esta função, a versão do software do sistema PSP™ tem de ser 6.50 ou posterior.
  • Para obter informações sobre jogar jogos no sistema PSP™, consulte o manual do utilizador do sistema PSP™.

Jogos que é possível jogar no sistema PS3™ ou PSP™

Se estiver a jogar um jogo compatível com os dois sistemas, pode copiar os dados guardados do jogo de um sistema para outro, de forma a poder continuar a jogar a partir de onde terminou. O método de cópia dos dados guardados varia consoante o tipo de jogo.

Dados guardados para software de formato PlayStation®

Os dados guardados do software de formato PlayStation® são guardados num memory card interno criado no armazenamento do sistema. Para copiar os dados guardados para um sistema PSP™, efectue os passos 2 e 3 anteriores e seleccione (Jogo) > (Utilitário do Memory Card) > (Memory Card interno (PS)) no sistema PS3™. Em seguida, seleccione o ícone de dados guardados a copiar, prima o botão e seleccione [Copiar] no menu das opções.

Notas

  • É necessário converter o formato dos dados guardados para permitir que sejam utilizados num sistema PSP™. Se for apresentado um ecrã de confirmação sobre a conversão de dados durante a cópia, seleccione [Sim] para continuar.
  • São criados diversos memory cards internos para cada título de software guardado no suporte Memory Stick™ (introduzido no sistema PSP™) ou na memória do sistema PSP™go.
  • Se copiar os dados guardados para o suporte Memory Stick™ introduzido numa ranhura do sistema PS3™ ou utilizar um adaptador USB (vendido em separado), os dados guardados não serão reconhecidos.

Activar um sistema PSP™

Os jogos que são transferidos (comprados ou gratuitos) da (PlayStation®Store) podem ser jogados num sistema PSP™ activado. Se for apresentada uma mensagem a indicar que a activação é necessária quando o jogo é iniciado no sistema PSP™, active o dispositivo utilizando o seguinte procedimento.

1.

Ligue o sistema PSP™ ao sistema PS3™ usando um cabo USB.

2.

No sistema PSP™, seleccione (Definições) > (Ligação USB).

3.

No sistema PS3™, seleccione (PlayStation™Network) > (Gestão de Contas).

4.

Seleccione (Activação do sistema).
Siga as instruções no ecrã para concluir o procedimento de activação.

Notas

  • Para efectuar a activação do dispositivo, tem de ter sessão iniciada no sistema PS3™ como o mesmo utilizador com sessão iniciada quando foi transferido o software de formato PlayStation®.
  • A activação do dispositivo é um procedimento que permite a reprodução de conteúdo em dispositivos autenticados. Este procedimento é necessário como uma forma de proteger os direitos digitais do conteúdo.
