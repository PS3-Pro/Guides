Sobre a activação do sistema

A activação do sistema é um procedimento de protecção dos direitos de autor e outros direitos digitais de conteúdos. Os conteúdos e as aplicações disponíveis na PlayStation®Store só podem ser utilizados em sistemas activados.

Pode associar a sua conta Sony Entertainment Network a diversos sistemas, mas o número de sistemas que pode activar por tipo de conteúdo é limitado em cada conta. Quando o número de sistemas activados atinge o limite, é apresentada uma mensagem de erro quando tenta transferir (comprar) conteúdos num sistema desactivado. Para utilizar o conteúdo nesse sistema, terá que desactivar em primeiro lugar um dos seus outros sistemas.

Activar manualmente um sistema

Normalmente, o seu sistema é activado automaticamente quando transfere (compra) conteúdos. Se, contudo, for apresentada uma mensagem a indicar que é necessária uma activação do sistema quando tenta reproduzir os conteúdos, deve activar manualmente o seu sistema.

Inicie a sessão na PSNSM no seu sistema PS3™. Seleccione (PlayStation™Network) > (Gestão de Contas) > (Activação do sistema) e siga as instruções no ecrã.

Notas

  • Pode activar um sistema PS3™ para visualizar conteúdo de vídeo, no máximo 3 vezes, num prazo de 90 dias por conta. Não pode utilizar uma conta para activar uma quarta vez o mesmo sistema, num prazo de 90 dias. Poderá voltar a activar o sistema 90 dias depois de o ter activado pela primeira vez.
  • A venda/o aluguer de conteúdos de vídeo da PlayStation®Store no sistema PS3™ foi descontinuado.

Desactivar um sistema

Se tentar ultrapassar o limite do sistema activado para a sua conta, é apresentada uma mensagem a indicar que não é possível comprar (transferir) o conteúdo seleccionado. Caso isto aconteça, desactive um dos seus outros sistemas.

Inicie a sessão na PSNSM no seu sistema PS3™. Seleccione (PlayStation™Network) > (Gestão de Contas) > (Activação do sistema) e siga as instruções no ecrã.

Quando não é possível desactivar um sistema

Quando não é possível desactivar um sistema activado utilizando esse sistema, por exemplo, devido a uma avaria ou porque o sistema foi eliminado, contacte a linha de suporte técnico da sua região.
Também pode desactivar todos os sistemas activados para cada tipo de conteúdo a partir do seguinte Web site:

http://account.sonyentertainmentnetwork.com/
Vá a [Conta] > [Multimédia e dispositivos] e, em seguida, seleccione [Desativar todos] para o tipo de conteúdo em relação ao qual pretende desactivar todos os sistemas activados.

Notas

  • Dependendo do tipo de conteúdo, poderá não ser possível desactivar todos os sistemas activados utilizando esta página.
  • Este Web site só está disponível em determinados países ou regiões.
