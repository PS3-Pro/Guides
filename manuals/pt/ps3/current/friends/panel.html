Utilizar o painel de controlo das opções

Para utilizar esta função, poderá ter de actualizar o software de sistema.


Efectue diversas operações com o menu no painel de controlo das opções. É possível visualizar ou ocultar o menu, premindo o botão .

Convidar um amigo

Convide um amigo para a sala de conversação.

Nota

Apesar de ser possível convidar diversos amigos para a conversação, só aparecem os avatares dos cinco primeiros amigos que seleccionou no ecrã. Podem estar até seis pessoas numa sala de conversação.

Ferramentas

Visualize uma imagem de (Fotografia) ou crie uma mensagem para os membros da conversação.

Alterador de voz Altere o tom da sua voz.

É possível verificar a forma como a voz se altera, seleccionando um valor e falando para o microfone.  Os valores definidos aqui são reflectidos em (Definições) > (Definições de acessórios) > [Alterador de voz].
Apresentar fotografia Para visualizar uma imagem de (Fotografia) no ecrã.
Criar mensagem para todos Para criar uma mensagem para todas as pessoas numa sessão de conversação.

Visualização

Para regular as definições relativas à apresentação do ecrã de conversação.

Apresentar Para definir a velocidade de transmissão de áudio/vídeo para verificar o estado da transferência de dados.

Quando abandonar a conversação, a definição é cancelada e a velocidade deixa de aparecer.
Modo de Ecrã Para alterar o modo de apresentação do ecrã.

Só é possível alterar o modo do ecrã durante a conversação entre duas pessoas. Não é possível apresentar alguns modos consoante a definição de saída de vídeo do sistema PS3™.

Normal: Para definir a apresentação da imagem ajustada ao tamanho do ecrã.

Normal (Ocultar-se): Para definir a apresentação da imagem ajustada ao tamanho do ecrã. A sua imagem ou avatar não aparece no televisor.*

Zoom: Para definir a apresentação da imagem no ecrã inteiro. As proporções são mantidas e as partes superiores e inferiores da imagem são cortadas conforme necessário.

Zoom (Ocultar-se): Para definir a apresentação da imagem para o ecrã interior mantendo as proporções da imagem (as partes superior e inferior da imagem podem ser cortadas). A sua imagem ou avatar não aparece no televisor.*

Original: Para definir a apresentação da imagem no tamanho original.

Quando abandonar a conversação de voz/vídeo, a definição passa para [Zoom] ou [Normal].
O valor de retorno varia consoante a definição de saída de vídeo do sistema PS3™.

*  Mesmo que seleccione ocultar a sua imagem no ecrã que visualiza, a sua imagem ou avatar aparece no televisor da pessoa com quem está a conversar.

Definições de conversação

Regule as definições de áudio ou vídeo para uma conversação de voz/vídeo.

Câmara ligada/Câmara desligada Para ligar e desligar a câmara.

Regule esta definição quando não pretende enviar vídeo para a pessoa com quem está a conversar. Se seleccionar [Câmara desligada], o seu avatar aparece na sala de conversação. Quando abandonar uma conversação de voz/vídeo, esta definição volta à opção seleccionada em (Definições) > (Definições de conversação).
Microfone ligado/Microfone desligado Para ligar e desligar o microfone.

Regule esta definição quando não pretende enviar áudio para a pessoa com quem está a conversar. Quando abandonar uma conversação de voz/vídeo, esta definição passa para [Microfone ligado].
Definições de Dispositivos Áudio Regule as definições para dispositivos utilizados para entrada/saída de áudio.

Nível de microfone: Para definir o volume do microfone.

Dispositivo de Entrada: Para seleccionar o dispositivo de entrada a utilizar.

Dispositivo de Saída: Para seleccionar o dispositivo de saída a utilizar.

Os valores definidos aqui são reflectidos em (Definições) > (Definições de Acessórios) > [Definições de Dispositivos Áudio].
Controlo de volume Para regular o nível do volume de uma conversação.

Quando abandona uma conversação, esta definição passa para [Normal].

Sair

Para sair da sala de conversação.

Nota

Se a pessoa que iniciou a conversação de voz/vídeo sair, a sala de conversação fecha.
