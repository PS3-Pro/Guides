Utilizar a Reprodução remota (através da LAN sem fios do sistema PS3™)

Ligue um dispositivo compatível com reprodução remota, como um sistema PSP™ ou sistema PS Vita, ao sistema PS3™ através da funcionalidade de LAN sem fios do sistema PS3™. Este método de ligação encontra-se disponível apenas em sistemas PS3™ equipados com a funcionalidade de LAN sem fios.

Preparar para a utilização

Para utilizar a reprodução remota pela primeira vez, o utilizador deve registar (emparelhar) o dispositivo compatível com reprodução remota, como um sistema PS Vita ou um sistema PSP™, com o sistema PS3™. Para registar (emparelhar) o dispositivo, seleccione (Definições) > (Definições de Reprodução Remota) > [Registar o Dispositivo].

Utilizar a reprodução remota num sistema PS Vita

1.

No seu sistema PS Vita, toque em (Reprodução remota da PS3) > [Iniciar].

2.

No sistema PS3™, seleccione (Rede) > (Reprodução remota).
O sistema PS3™ aguarda que o sistema PS Vita estabeleça a ligação de reprodução remota.

3.

No seu sistema PS Vita, toque em [Ligar através de rede privada].
Quando a ligação entre os dispositivos é correctamente estabelecida, o ecrã do sistema PS3™ é apresentado no seu sistema PS Vita.

Utilizar a reprodução remota num sistema PSP™

1.

No sistema PS3™, seleccione (Rede) > (Reprodução remota).
O sistema entra em modo de espera da ligação de reprodução remota.

2.

No sistema PSP™, seleccione (Rede) > (Reprodução Remota).

3.

Seleccione [Ligar através de Rede Privada].

4.

Seleccione [PlayStation(R)3] na lista de ligações.
Se a ligação for bem sucedida, o ecrã do sistema PS3™ será apresentado no sistema PSP™.

Notas

  • A reprodução remota pode ser utilizada no raio de alcance da ligação LAN sem fios do sistema PS3™.
  • Se activar a definição de início remoto no sistema PS3™, pode definir o sistema para ser ligado automaticamente (Acordar com a LAN). Para mais informações, consulte (Definições) > (Definições de Reprodução Remota) > [Início remoto] neste manual.
  • Se for ao ecrã LiveArea™ de Reprodução remota ou de uma aplicação diferente durante a reprodução remota, a ligação de reprodução remota é fechada após 30 segundos.
