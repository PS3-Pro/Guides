Operações durante a reprodução remota

Durante a reprodução remota, os botões do sistema PSP™ ou do sistema PS Vita são utilizados para controlar o sistema PS3™.

Utilizar um sistema PS Vita para usar o sistema PS3™

Durante a reprodução remota, o utilizador controla a maioria das funções do sistema PS3™ com os botões do sistema PS Vita.
O utilizador usa várias funções com a barra de ferramentas. Toque no ecrã para apresentar a barra de ferramentas.


Utilizar o botão PS do sistema PS3™

Isto replica a acção de premir o botão PS no comando sem fios do sistema PS3™.

1.

Toque no ecrã.

2.

Toque em (PS).

Nota

O ícone (PS) não suporta as operações em que mantém premido o botão PS no comando sem fios do sistema PS3™ durante um ou mais segundos. Para desligar o sistema PS3™, toque em (Desligue) e siga as instruções no ecrã.


Alterar a atribuição dos botões

Pode seleccionar entre a atribuição dos botões [Tipo 1] e [Tipo 2]. Se seleccionar [Tipo 2], pode efectuar algumas operações premindo simultaneamente em combinações de botões que não estão disponíveis no sistema PS Vita, como os botões L2 e R3.

1.

Toque no ecrã.

2.

Toque em (Definições) > [Botões Atribuir].

3.

Toque na atribuição dos botões que pretende utilizar.

Definir a qualidade de imagem

Pode definir a qualidade de imagem [+1], [Padrão] ou [-1].

1.

Toque no ecrã.

2.

Toque em (Definições) > [Qualidade da imagem].

3.

Toque na qualidade de imagem pretendida.

Nota

Dependendo do ambiente de rede, o vídeo e o áudio associado podem falhar quando é utilizada uma qualidade de imagem elevada.


Restaurar as definições da reprodução remota

Para limpar o registo do dispositivo e restaurar a atribuição dos botões e a definição da qualidade de imagem para os seus valores padrão:

1.

Toque no ecrã.

2.

Toque em (Definições) > [Restaurar definições] > [Restaurar] > [OK].

Nota

Também pode restaurar as definições a partir do ecrã onde selecciona o método de ligação de reprodução remota. Toque em (Opções) > [Definições] > [Restaurar definições] e siga as instruções no ecrã.


Activar o modo de ecrã

Pode activar o modo de ecrã tocando duas vezes no ecrã.

Nota

Não pode activar o modo de ecrã quando a barra de ferramentas é apresentada no ecrã ou enquanto joga um jogo.

Utilizar um sistema PSP™ para usar o sistema PS3™

Se estiver a utilizar um sistema PSP™ para a reprodução remota, quando prime o botão PS (botão HOME (início)), é apresentado um menu para utilizar o sistema PS3™.

Itens de menu

Os itens de menu que estão disponíveis no sistema PSP™ variam dependendo da versão do software de sistema utilizado.

Botão PS Efectue as mesmas operações que as efectuadas para o botão PS no comando sem fios.*1
Abandone a apresentação remota Abandone a apresentação remota.

Sair e desligar o sistema PS3™: Abandone a apresentação remota e, em seguida, desligue o sistema PS3™.

Sair sem desligar o sistema PS3™: Abandone a apresentação remota e deixe o sistema PS3™ ligado. Seleccione esta opção se estiver a utilizar o sistema PS3™ para copiar ficheiros ou para executar transferências em segundo plano e outras tarefas que necessitem que o sistema continue ligado.
Definições Para regular as definições relativas aos botões do sistema PSP™.

Botões Atribuir: Utilize os botões do sistema PSP™ da mesma forma que os botões do comando sem fios do sistema PS3™. Seleccione um dos dois tipos de atribuição.

Definições de Comunicação: Defina a velocidade de resposta dos botões do sistema PSP™. Seleccione um dos cinco níveis que combinam a velocidade de resposta com a qualidade de imagem ou seleccione [Personalizado].*2
Estado da Ligação Defina para apresentar o estado da ligação de reprodução remota.
*1

Não são suportadas as operações em que o botão PS é premido no mínimo 2 segundos.
*2

Apesar de a definição de [Velocidade de resposta] e [Qualidade da Imagem] no nível máximo proporcionar uma maior velocidade de resposta e melhor qualidade da imagem, a imagem ou o áudio poderão ficar distorcidos.
