Sobre a reprodução remota

A reprodução remota é uma funcionalidade que permite que o ecrã do sistema PS3™ seja apresentado num dispositivo compatível com reprodução remota, como um sistema PS Vita ou sistema  PSP™, e lhe permite utilizá-lo remotamente através de uma rede LAN sem fios.

Nota

Para utilizar a funcionalidade de reprodução remota de um sistema PSP™, deve actualizar o software de sistema do sistema PSP™ para a versão 3.72 ou posterior.

Operações que podem ser efectuadas a partir de um dispositivo compatível com reprodução remota

As principais funções do sistema PS3™ que podem ser utilizadas através da reprodução remota variam consoante o tipo de dispositivo utilizado. Com um sistema PS Vita ou sistema PSP™, estão disponíveis as seguintes funções:

  • (Definições) *1
  • (Fotografia) *1
  • (Música)
  • (Vídeo) *2
  • (Jogo) *1*3
  • (Rede)
  • (PlayStation™Network) *1
  • (Amigos)

*1

Com a reprodução remota, só é possível rever funções limitadas.
*2

Não é possível reproduzir discos Blu-ray nem DVDs. Além disso, os ficheiros de vídeo protegidos por direitos de autor não podem ser reproduzidos.
*3

alguns jogos suportam a reprodução remota.
