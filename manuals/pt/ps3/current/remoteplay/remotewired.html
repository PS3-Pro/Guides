Utilizar a reprod. remota (através de um ponto de acesso)

Ligue o sistema PS3™ a um ponto de acesso com um cabo Ethernet. Utilize a função de rede sem fios de um dispositivo compatível com reprodução remota, como um sistema PS Vita ou um sistema PSP™, para ligar ao sistema PS3™ através do ponto de acesso.

Exemplo de uma configuração comum

Notas

  • Um router sem fios é um dispositivo que adiciona a funcionalidade de ponto de acesso a um router. Um ponto de acesso é um dispositivo que lhe permite estabelecer uma ligação sem fios a uma rede. Um router é um dispositivo utilizado na partilha de uma ligação à Internet por vários dispositivos.
  • Um modem pode estar equipado com a funcionalidade de router. Ligue o sistema PS3™ a um dispositivo equipado com funcionalidade de router.
  • Se tanto o ponto de acesso como o modem estiverem equipados com funcionalidade de router, desligue esta funcionalidade em um dos dispositivos. O sistema PS3™ e o dispositivo compatível com reprodução remota devem estar ligados à mesma rede. Se forem utilizados dois ou mais routers simultaneamente, é possível que o sistema PS3™ e o dispositivo sejam ligados a redes separadas, não permitindo a utilização da reprodução remota.

Preparar para a utilização (sistema PS3™ e dispositivo compatível com reprodução remota)

Para utilizar a reprodução remota pela primeira vez, o utilizador deve registar (emparelhar) o dispositivo compatível com reprodução remota, como um sistema PS Vita ou um sistema PSP™, com o sistema PS3™. Para registar (emparelhar) o dispositivo, seleccione (Definições) > (Definições de Reprodução Remota) > [Registar o Dispositivo].

Preparar para a utilização (dispositivo compatível com reprodução remota)

Crie uma ligação de rede para ligar o dispositivo a um ponto de acesso. Se o dispositivo já tiver uma ligação de rede guardada, não é necessário criar uma nova. Para mais informações sobre como criar uma ligação de rede no dispositivo, consulte o manual do utilizador do dispositivo.

Utilizar a reprodução remota num sistema PS Vita

1.

No seu sistema PS Vita, toque em (Reprodução remota da PS3) > [Iniciar].

2.

No sistema PS3™, seleccione (Rede) > (Reprodução remota).
O sistema PS3™ aguarda que o sistema PS Vita estabeleça a ligação de reprodução remota.

3.

No seu sistema PS Vita, toque em [Ligar através de rede privada].
Quando a ligação entre os dispositivos é correctamente estabelecida, o ecrã do sistema PS3™ é apresentado no seu sistema PS Vita.
Se o ecrã de definições de Wi-Fi for apresentado, seleccione o ponto de acesso que está ligado ao sistema PS3™.

Utilizar a reprodução remota num sistema PSP™

1.

No sistema PS3™, seleccione (Rede) > (Reprodução Remota).
O sistema entra em modo de espera da ligação de reprodução remota.

2.

No sistema PSP™, seleccione (Rede) > (Reprodução Remota).

3.

Seleccione [Ligar através de Rede Privada].

4.

Na lista de ligações, seleccione a ligação para o ponto de acesso a ser utilizada para reprodução remota.
Se a ligação for bem sucedida, o ecrã do sistema PS3™ será apresentado no sistema PSP™.

Notas

  • A reprodução remota pode ser utilizada no raio de alcance do sinal do ponto de acesso.
  • Se activar a definição de início remoto no sistema PS3™, pode definir o sistema para ser ligado automaticamente (Acordar com a LAN). Para mais informações, consulte (Definições) > (Definições de Reprodução Remota) > [Início remoto] neste manual.
  • Se for ao ecrã de uma aplicação diferente durante a reprodução remota, a ligação de reprodução remota é fechada após 30 segundos.
