Controlo para HDMI

Esta função está disponível a partir da série CECH-2000 do sistema PS3™.


Pode utilizar o comando à distância de uma TV BRAVIA™ (um produto da Sony Corporation) para utilizar o sistema PS3™. A TV tem de suportar a função de sincronização BRAVIA™ e o sistema PS3™ tem de estar ligado à TV com um cabo HDMI. Para activar esta função, defina [Controlo para HDMI] para [Ligado].

Desligado Desactiva a função Controlo para HDMI.
Ligado Activa a função Controlo para HDMI.

As principais funções da TV Bravia podem ser realizadas no sistema PS3™

Reprodução Um Toque Ligar o sistema PS3™ faz com que a TV conectada seja ligada e que a entrada de vídeo do sistema PS3™ seja seleccionada automaticamente.

As principais funções do sistema PS3™ podem ser realizadas na TV Bravia

Reprodução Um Toque Premir o botão LINK no comando à distância da TV e seleccionar [PS3™] no menu da TV faz com que o sistema PS3™ seja ligado.
Operar o menu com o comando à distância O comando à distância da TV pode ser utilizado para operar algumas funções do sistema PS3™.
Desligar sistemas conectados em simultâneo Desligar a TV fará com que o sistema PS3™ conectado seja desligado (entra em modo de espera).

Notas

  • As funções BRAVIA™ Sync disponíveis variam consoante a TV utilizada. Para mais informações, consulte o manual de instruções da TV.
  • Mesmo quando [Ligado] está seleccionada, esta função pode não estar disponível nos seguintes casos:
  • - Quando se utilizam determinadas funções do sistema PS3™, tais como a reprodução de jogos ou de vídeo.
  • - Quando o sistema PS3™ não está seleccionado como fonte de entrada para a TV.
  • A BRAVIA™ Sync (Controlo para HDMI) é uma função que permite a interoperabilidade dos dispositivos conectados utilizando a especificação CEC (Consumer Electronics Control), que faz parte da especificação HDMI. Esta função só está disponível nos dispositivos Sony que suportem Controlo para HDMI. Produtos desenvolvidos por outras empresas que suportem a especificação CEC podem ser operados através de Controlo para HDMI, mas não há a garantia de que todas as funções sejam compatíveis com estes produtos.
