Actualização Automática

Para utilizar algumas funcionalidades deve subscrever o serviço de subscrição PlayStation®Plus.

Quando esta definição é [Ligado], o sistema PS3™ é iniciado automaticamente na hora especificada todos os dias, efectua as operações especificadas e depois desliga-se.

Desligado Defina para não utilizar a função de actualização automática
Ligado Defina para utilizar a função de actualização automática

Pode seleccionar as operações de actualização automática para os seguintes itens.

  • Transferir os itens de conteúdo adquiridos com outros dispositivos
  • Transferir o software de sistema mais recente
  • Transferir patches de jogos
  • Sincroniza as informações de troféus com o servidor

Notas

  • Defina [Carregar dados guardados para armazenamento online] para cada jogo. Para mais informações sobre como definir este item, consulte (Jogo) > [Jogar software de formato PlayStation®3] > [Utilizar dados guardados] neste manual.
  • Depois de seleccionar [Ligado], utilize os botões de direcção para seleccionar o período de tempo durante o qual pretende que a actualização automática seja realizada. Siga as instruções no ecrã se aparecer um ecrã a solicitar-lhe que confirme as definições para o início de sessão automático na PSNSM.
  • Esta função só pode ser utilizada num sistema PS3™ por cada conta Sony Entertainment Network. Se a função de actualização automática estiver definida para [Ligado] em dois ou mais sistemas PS3™ na mesma conta, ela permanecerá [Ligado] no último sistema que foi definido e será [Desligado] automaticamente em todos os outros sistemas.
  • O sistema PS3™ deve estar no modo de espera (indicador de alimentação aceso a vermelho) durante o período de tempo durante o qual pretende que o sistema realize a actualização automática.
  • Os dados de actualização do software de sistema serão transferidos automaticamente, mas não instalados. Deve instalar os dados de actualização do software de sistema manualmente.
  • é apresentado para patches de jogo e jogos recomendados que tenham sido automaticamente transferidos. Qualquer conteúdo que tenha sido transferido e instalado automaticamente, mas que não tenha sido utilizado, será automaticamente eliminado ao fim de um mês.
  • Mesmo se [Actualização Automática] estiver definida para [Ligado], os conteúdos não serão transferidos se a quantidade de espaço livre no armazenamento do sistema for inferior a 5 GB.
  • Definir para [Desligado] para restaurar todas as opções de actualização automática seleccionadas para as predefinições.
