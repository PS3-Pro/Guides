Ligar o sistema PS Vita utilizando a rede

Defina se quer utilizar Wi-Fi para transferir dados com um sistema PS Vita. Para mais detalhes, consulte (Gestor de conteúdo) > [PS3™] > [Transferir dados utilizando Wi-Fi de e para um sistema PS3™] no manual do utilizador do sistema PS Vita.

Desligado Defina não utilizar Wi-Fi para transferir dados.
Ligado Defina utilizar Wi-Fi para transferir dados.

Notas

  • Esta definição é utilizada depois de ter ligado a um sistema PS Vita uma vez utilizando o (Gestor de conteúdo) no sistema PS Vita. A predefinição é [Ligado].
  • Para utilizar esta funcionalidade, a versão do software de sistema do sistema PS Vita tem de ser 3.00 ou posterior.
