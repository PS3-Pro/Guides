Registar Teclado / Rato

Definições de ajuste de um teclado ou rato.

Tipo de Teclado

Defina o tipo de teclado ligado ao sistema através de um cabo USB ou tecnologia Bluetooth®.

Método de Digitação do Teclado

Defina o método de entrada do teclado ligado ao sistema através de um cabo USB ou tecnologia Bluetooth®. Esta definição só está disponível nos seguintes casos:

  • Quando o idioma do sistema está definido para apresentar caracteres tradicionais de Chinês.
  • Quando o idioma do sistema está definido para Japonês e [Tipo de Teclado] está definido para [Teclado Japonês] ou [Teclado inglês (Padrão dos EUA)]

Ligação de Teclas

Ajuste a atribuição de tecla para o teclado. Esta definição está disponível apenas quando o idioma do sistema está definido para Japonês e [Tipo de Teclado] está definido para [Teclado Japonês] ou [Teclado inglês (Padrão dos EUA)]

Intervalo de Repetição de Teclas

Defina a quantidade de tempo antes de um carácter ser repetido quando uma tecla é mantida premida num teclado USB ou num teclado Bluetooth®.

Velocidade de Repetição de Teclas

Defina a velocidade a que um carácter é repetido quando uma tecla é mantida premida num teclado USB ou num teclado Bluetooth®.

Tipo de Rato

Defina o tipo de rato ligado através de um cabo USB ou tecnologia Bluetooth®. Defina com qual mão se baseia para controlar o rato.

Velocidade do Ponteiro

Define a velocidade de deslocação do cursor.
