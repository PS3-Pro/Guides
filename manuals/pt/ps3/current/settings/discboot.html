Auto-arranque do disco

Defina se o disco deve ou não ser iniciado automaticamente quando é introduzido.

Desligado Defina para não iniciar automaticamente o disco.
Ligado Defina para iniciar automaticamente o disco.

Notas

  • Mesmo que esteja definido [Ligado], o disco não é automaticamente iniciado nas seguintes situações:
  • - Quando o sistema é ligado com um disco inserido.
  • - quando estiver a ser realizada outra operação da barra de menu da XMB™
  • - quando é introduzido um CD-R ou outro tipo de disco de dados
  • - ao iniciar o sistema, quando existem vários utilizadores e o início automático de sessão não foi definido
  • Nos discos com várias camadas de dados gravadas, como os super audio CDs, a camada de dados que é iniciada automaticamente varia consoante o disco.

Atenção

Alguns sistemas PS3™ não reproduzem Super Audio CD. Para obter detalhes, consulte [Tipos de discos reproduzíveis].
