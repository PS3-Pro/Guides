Definições de Data e Hora

Ajuste as definições relacionadas com a data e a hora do sistema.

Data e Hora

Defina a data e hora do sistema.

Configurar Manualmente Ajusta manualmente o ano / mês / dia / hora / minuto / segundo (e AM / PM quando utiliza um relógio de 12 horas).
Configurar através da Internet Obtenha as informações de data e hora na Internet e depois defina a data e hora do sistema utilizando essas informações.

Definir automaticamente

Quando esta opção é definida para ligado [Ligado], sempre que iniciar sessão na PSNSM, a data e hora correctas são obtidas automaticamente via Internet e definidas no seu sistema.

Desligado Não definir a data e hora automaticamente neste sistema.
Ligado Definir a data e hora automaticamente no sistema.

Nota

Se um jogo ou alguns tipos de aplicações estiverem a ser executados quando iniciar sessão na PSNSM, a data e hora não são definidas automaticamente.

Formato da Data

Define a ordem de apresentação para ano / mês / dia.

Formato da Hora

Define a apresentação da hora em relógio de 12 ou de 24 horas.

Fuso Horário

Define o fuso horário que servirá de base para a apresentação da data e da hora. Seleccione uma cidade ou região perto do local onde vive. A data e a hora irão mudar consoante o fuso horário que for seleccionado.

Hora de Verão

Ajusta como hora de Verão.

Padrão Para não ajustar como hora de Verão.
Hora de Verão Para ajustar como hora de Verão.
