Copiar / mover ficheiros de vídeo

Copie ficheiros de vídeo guardados em suportes de armazenamento para o disco rígido, ou copie ou mova ficheiros importados do disco rígido para suportes de armazenamento. Seleccione o ficheiro que quer importar ou copiar, prima o botão e, em seguida, seleccione [Copiar] ou [Mudar] no menu de opções. Siga as instruções no ecrã para concluir a operação.

Diferenças entre copiar e mover

A operação que é possível efectuar depende do tipo de ficheiro. Os ficheiros de vídeo protegidos por direitos de autor não podem ser movidos. Se um ficheiro for movido, não voltará a estar disponível no local onde foi originalmente guardado.

Tipos de ficheiros de vídeo Operações suportadas Destinos para guardar
Ficheiros de vídeo sem protecção de direitos de autor Copiar

Ficheiros de vídeo protegidos por direitos de autor
(Tipos de ficheiros: MGV, ETS e outros)		 Mover

Incluindo Memory Stick PRO-HG™ e Memory Stick Micro™

Notas

  • Quando copiar ou mover ficheiros de vídeo com restrições de controlo paternal, deve introduzir uma palavra-passe. Pode definir a palavra-passe em [Mudar a palavra-passe], em (Definições) > (Definições de Segurança).
  • Dependendo do dispositivo utilizado, pode não ser possível reproduzir algumas cópias.
  • Dependendo do modelo do sistema PS3™ utilizado, pode ser necessário um adaptador USB apropriado (não incluído) para utilizar suportes de armazenamento. Além disso, quando mover ficheiros de vídeo para o suporte Memory Stick PRO™, é necessário um dispositivo USB que suporte funções de protecção de direitos de autor do suporte Memory Stick™, tal como o sistema PSP™ ou o MSAC-US40 (um produto da Sony).
  • Quando utilizar o suporte Memory Stick Micro™ com um sistema PS3™ equipado com uma ranhura para Memory Stick™, deve utilizar o suporte com um Adaptador Memory Stick™ M2 Duo.
  • Em alguns ficheiros de vídeo protegidos por direitos de autor, pode não ser possível utilizar a função para Mover.
  • Tenha cuidado para não violar os direitos de propriedade intelectual de terceiros.
  • Os ficheiros de vídeo não podem ser copiados ou movidos durante a reprodução.*

    • * Inclui a reprodução de conteúdo utilizando outras funções, tal como a reprodução de ficheiros de música.

Copiar ou mover vídeo para visualizar num sistema PSP™

Copiar ou mover ficheiros de vídeo para visualizar num sistema PSP™.

1.

Ligue o sistema PSP™ ao sistema PS3™ com um cabo USB.
Para copiar ficheiros para o suporte Memory Stick™, introduza o suporte Memory Stick™ no sistema.

2.

No sistema PSP™, seleccione (Definições) > (Ligação USB).

3.

No sistema PS3™, seleccione o ficheiro de vídeo que pretende copiar ou mover e, em seguida, prima o botão .

4.

Seleccione [Copiar] ou [Mudar].
Siga as instruções no ecrã para copiar ou mover o ficheiro. Pode reproduzir o ficheiro de vídeo copiado ou movido seleccionando o ficheiro em (Vídeo) > (Memory Stick™) em (Vídeo) > (Memória do Sistema) no sistema PSP™.

Notas

  • Para obter informações sobre a reprodução de ficheiros de vídeo no sistema PSP™, consulte o manual do utilizador do sistema PSP™.
  • Dependendo do tipo de vídeo que pretende copiar ou mover, deve utilizar um suporte Memory Stick PRO Duo™.
  • Se o conteúdo for movido do sistema PSP™, não é possível voltar a movê-lo para o sistema PS3™.
  • Não é possível mover conteúdo de vídeo gravado em resolução HD.
