Inscreva-se na PlayStation®Network

Para utilizar esta função, poderá ter de actualizar o software de sistema.


Depois de ter criado uma conta PlayStation®Network, pode fazer compras online na (PlayStation®Store), juntar-se a uma conversação em (Amigos) ou utilizar diversos serviços online da PlayStation®Network. Seleccione (Inscrever-se na PlayStation®Network) em (PlayStation®Network) e, em seguida, siga as instruções no ecrã para criar uma conta.

Principais itens necessários para criar uma conta
Informação pessoal Introduza informações do utilizador registado, que incluem data de nascimento e o nome e endereço do utilizador.
Conta mestra / subconta Há dois tipos de contas PlayStation®Network: contas mestras e subcontas.

Conta mestra:
A conta padrão para utilizar a PlayStation®Network. Uma conta mestra pode ser criada por um utilizador registado de idade igual ou superior ao especificado. Os titulares de contas mestras podem definir determinadas condições de utilização para subcontas associadas.

Subconta:
Utilizadores que não cumprem os requisitos de elegibilidade para uma conta mestra na sua região só podem utilizar uma subconta. Os titulares de uma subconta não podem criar carteiras, mas podem utilizar a carteira associada à conta mestra para pagar produtos e serviços. Não é possível criar uma subconta se não existir uma conta mestra associada.


Os requisitos de elegibilidade para contas mestras e subcontas varia consoante o país ou região de residência. Para mais informações, visite o Web site da SCE da sua região.
ID de início de sessão (endereço de correio electrónico) Registe uma ID para usar quando iniciar a sessão na PlayStation®Network. Utilize um endereço de correio electrónico válido que possa ser utilizado para receber mensagens de confirmação em situações como compras em (PlayStation®Store).
Palavra-passe

Crie uma palavra-passe de acordo com o seguinte:

  • Use pelo menos seis letras ou números.
  • Use uma combinação de letras e números.
  • Não use mais do que duas ocorrências consecutivas do mesmo carácter.
  • Utilize um código diferente da sua ID de início de sessão e ID Online.
  • As letras são sensíveis a maiúsculas/minúsculas.
Pergunta de segurança Seleccione uma pergunta de segurança para utilizar quando repuser uma palavra-passe esquecida.‎
ID Online

Registe um nome que será apresentado publicamente na PlayStation®Network. Depois de criar a sua ID Online não é possível alterá-la. Crie uma ID Online de acordo com as seguintes indicações:

  • A ID Online deve ter 3 a 16 caracteres e pode ser composta por letras, números, hífenes (-) e caracteres de sublinhado (_).
  • O primeiro carácter tem de ser uma letra.
  • A ID Online não deve ser igual à sua palavra-passe.
  • As letras não são sensíveis a maiúsculas/minúsculas.

Notas

  • Dependendo da idade do menor, é necessário um PC para criar a subconta. Durante o processo de criação da conta, é enviada uma para o endereço de correio electrónico associado à ID de início de sessão do titular da conta mestra. Siga as instruções no na mensagem electrónica para completar o registo num PC.
  • Para iniciar a sessão na PlayStation®Network com a subconta criada, é necessário associar a conta a um Utilizador que irá efectuar o login no sistema PS3™. Consulte [Utilizar uma conta existente] em (PlayStation®Network) neste manual.
  • A sua ID de início de sessão (endereço de correio electrónico) e a palavra-passe não serão apresentadas publicamente. Tenha cuidado para não partilhar esta informação com outras pessoas.
  • Só pode criar uma conta por cada Utilizador no sistema PS3™. Para criar contas adicionais, vá a (Utilizadores) e crie utilizadores adicionais.
  • Para informações sobre o tratamento de informações pessoais relacionadas com os utilizadores, visite o Web site da SCE da sua região.
  • Para aceder à PlayStation®Network é necessário um serviço de Internet de banda larga. Tenha em atenção que a ligação comutada não é suportada.
  • A PlayStation®Network está disponível apenas em determinadas regiões e idiomas. Para obter detalhes, contacte a linha de suporte técnico da sua região.
  • (Inscrever-se na PlayStation®Network) é apresentado apenas se não tiver sido criada uma conta PlayStation®Network.
