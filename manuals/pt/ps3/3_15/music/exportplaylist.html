Copiar listas de reprodução para um sistema PSP™

É possível copiar música como listas de reprodução e, em seguida, reproduzi-las no sistema PSP™.

1.

Ligue o sistema PSP™ ao seu sistema PS3™ com um cabo USB.
Para copiar ficheiros para o suporte Memory Stick™, introduza o suporte Memory Stick™ no sistema PSP™.

2.

No sistema PSP™, seleccione (Definições) > (Ligação USB).

3.

No sistema PS3™, seleccione (Música) > (Listas de reprodução).

4.

Seleccione o ícone da lista de reprodução que pretende utilizar e, em seguida, prima o botão .

5.

Seleccione [Copiar].
Seleccione (PSP™ (PlayStation®Portable)) ou (PSP™ (PlayStation®Portable)) como o destino.

Notas

  • Para utilizar esta função, a versão do software do sistema do sistema PSP™ tem de ser 3.10 ou superior.
  • Não é possível copiar listas de reprodução de um sistema PSP™ para o sistema PS3™.
