Utilizar teclas de atalho / rato / teclado

Utilizar teclas de atalho

Pode operar directamente com os botões do comando sem fios sem utilizar o menu. As operações disponíveis variam entre o modo de pesquisa e o modo de janela.

Modo de pesquisa
Botão Abrir o link.
Botão (manter premido) Abre o link numa nova janela.
Botão + manípulo esquerdo Seleccionar texto.
Botão Apresenta o menu.
Botão Fecha o (Navegador de Internet).
Botão (manter premido) Fecha a janela. *1
Botão START (iniciar) Para introduzir um endereço.
Botão SELECT (seleccionar) Abre [Os meus marcadores].
Botões L1 / R1 Para retroceder ou ir para a frente uma página.
Botões L2 / R2 Para mover para uma janela diferente. *2
Botões de direcção Movem o cursor para um link na direcção do botão premido.
Botão + botão de direcção Deslizar na página na direcção do botão premido.
Manípulo esquerdo Move o cursor na direcção desejada.
Manípulo esquerdo (premido) (Botão L3) Muda para o modo de janela.
Manípulo direito Desliza na direcção desejada.
Manípulo direito (premido) (Botão R3) Utiliza a apresentação com zoom./Cancela a apresentação com zoom.
Botão PS Visualizar o menu XMB™.
*1

Esta operação não pode ser utilizada durante o zoom.
*2

Aumenta ou reduz durante o zoom.
Modo de janela
Botão Apresenta a janela seleccionada no modo de pesquisa.
Botão Apresenta o menu.
Manípulo esquerdo (premido) (Botão L3) Muda para o modo de pesquisa.
Botões de direcção Para mover para uma janela diferente.
Botão PS Visualizar o menu XMB™.

Utilizar um rato (não incluído)

Pode trabalhar com um rato disponível no mercado.

Arrastar para a esquerda enquanto mantém premido o botão direito Volta à página anterior.
Arrastar para a direita enquanto mantém premido o botão direito Avança para a página seguinte.

Utilizar um teclado (não incluído)

Utilize um teclado disponível no mercado.

CTRL + L (ou F4) Introduzir um endereço.
CTRL + R (ou F5) Actualizar a página.
CTRL + B (ou CTRL + I) Abrir [Os meus marcadores].
PAGE UP (ou SHIFT + BARRA DE ESPAÇOS) Deslocar-se para cima.
PAGE DOWN (ou BARRA DE ESPAÇOS) Deslocar-se para baixo.
Home (Início) Move para o início da página.
Fim Move para o fim da página.
TAB Mudar o cursor.
ALT + SETA PARA A ESQUERDA (ou RETROCESSO) Regressar à página anterior.
ALT + SETA PARA A DIREITA (ou SHIFT + RETROCESSO) Ir para a página seguinte.
CTRL + SETA PARA A ESQUERDA (ou CTRL + SHIFT + TABULAÇÃO) Ir para a janela esquerda.
CTRL + SETA PARA A DIREITA (ou CTRL + TABULAÇÃO) Ir para a janela direita.
