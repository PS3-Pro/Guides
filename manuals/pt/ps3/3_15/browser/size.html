Alterar o tamanho de apresentação de uma página Web

A apresentação das páginas Web pode ser demasiado pequena ou demasiado grande, consoante a combinação da definição da saída de vídeo do sistema PS3™ e da TV que está ligada. Se for este o caso, pode realizar o seguinte procedimento para ajustar o tamanho de apresentação.

Usar a funcionalidade de zoom

Aumenta automaticamente para o tamanho ideal a área do ecrã onde o cursor está posicionado. A taxa de aumento ideal é calculada automaticamente para a área onde o cursor está posicionado. Posicione o cursor na área que pretende aumentar, prima o botão e, em seguida, seleccione [Zoom] em (Visualização) no menu das opções.

Exemplo de como fazer zoom num texto

O sistema calcula a taxa de aumento com base no tamanho do parágrafo do texto que se encontra na área onde o cursor está posicionado e depois apresenta o texto no modo de zoom.


Exemplo de como fazer zoom numa imagem

O sistema calcula a taxa de aumento com base no tamanho da imagem que se encontra na área onde o cursor está posicionado e depois apresenta a imagem no modo de zoom.

Alterar a resolução

Altere a resolução de ecrã de uma página Web. Pode ajustar a apresentação da página Web para um tamanho de fácil visualização, de modo a que se adapte à resolução de saída de vídeo do sistema PS3™. Prima o botão e, em seguida, seleccione [Resolução] em (Ferramentas) no menu das opções.


Se a resolução for definida para [-1] ou [-2] quando a resolução de saída de vídeo do sistema PS3™ estiver definida para 1080p ou 1080i, a apresentação será aumentada, facilitando a visualização. Se for definida a resolução [+1] ou [+2] quando a resolução para a saída de vídeo do sistema PS3™ estiver definida para Standard (NTSC: 480i / PAL: 576i) ou 480p / 576p, a apresentação é reduzida, facilitando a visualização.
