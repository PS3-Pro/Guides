Criar / Enviar mensagens

Para utilizar esta função, poderá ter de actualizar o software de sistema.


Pode criar e enviar mensagens a pessoas que tenham IDs online registadas para usar na PlayStation®Network. Tem de estar registado na PlayStation®Network para criar e enviar mensagens.

1.

Seleccione (Amigos) > (Caixa de Mensagens).

2.

Seleccione (Criar Mensagem).

3.

Seleccione [Para:].
Seleccione [Seleccionar em Amigos] ou [Introduzir uma ID online]. Neste caso terá que escrever a ID online da pessoa para quem quer enviar.

4.

Escreva uma mensagem e, em seguida, seleccione [Enviar].
A mensagem é enviada. Pode verificar as mensagens que enviou em (Amigos) > (Caixa de Mensagens) > (Enviada).

Notas

  • Não pode enviar nem receber mensagens com endereços de correio electrónico padrão.
  • Uma ID online é criada quando se inscreve na PlayStation®Network. Antes de enviar uma mensagem, peça à pessoa a quem quer enviar a mensagem a sua ID online.
  • Pode introduzir até 18 caracteres num título e até 512 caracteres no corpo da mensagem.
  • Pode utilizar emoticons seleccionando a partir do teclado ao criar uma mensagem.
  • Pode guardar até 200 mensagens enviadas. Quando alcançar este limite, a sua mensagem mais antiga será eliminada automaticamente sempre que enviar uma mensagem nova.

Anexar ficheiros

Se seleccionar (Anexar) no ecrã de criação da mensagem, pode anexar um ficheiro de imagem de (Fotografia).

Notas

  • Não é possível anexar ficheiros com mais que 3 MB.
  • Só é possível anexar um ficheiro de cada vez.
  • Para cancelar a anexação de um ficheiro, seleccione o ficheiro, prima o botão e, em seguida, seleccione [Cancelar Anexo] no menu de opções.
