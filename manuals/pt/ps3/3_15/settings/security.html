Definições de Segurança

Ajuste as definições de segurança do sistema.

Nota

Estas definições controlam conteúdo local (conteúdo digital armazenado no disco rígido, conteúdo dos suportes de armazenamento e discos). Tenha atenção que estas definições não limitam o acesso ao conteúdo online.


Mudar a palavra-passe

Mude a palavra-passe necessária para regular definições de sistema. É necessária uma palavra-passe nas seguintes situações:

  • Quando reproduz conteúdo com restrições de controlo paternal
  • Quando altera o nível de controlo paternal do sistema ou a definição do Controlo de Início do navegador de Internet
  • Quando inicia o navegador com o Controlo de Início do navegador de Internet definido para [Ligado].
  • Quando muda a palavra-passe actual

Anote a sua palavra-passe nova. A palavra-passe é definida como [0000] nas definições padrão.

Nota

Se seleccionar (Definições) > (Definições de Sistema) > [Restaurar as Definições Padrão], pode repor a palavra-passe em [0000]. Tenha em conta que todas as outras definições serão também restauradas para os seus valores padrão.

Controlo Parental BD

Regule o nível de reprodução para discos Blu-ray (BDs) definido com restrições de controlo paternal. É necessária uma palavra-passe para alterar esta definição.

Não Restringir (Desligado) Reproduz qualquer BD independentemente nível do controlo paternal.
Restringir (Ligado) Reproduz apenas BDs com o nível de controlo paternal especificado.

Depois de definir [Restringir (Ligado)], pode seleccionar uma restrição de idade no ecrã seguinte. Tenha em atenção que quanto menor for o valor, maior será a restrição.

Código da Região de Controlo paternal BD / DVD

Defina uma região como base para os níveis padrão de controlo paternal para BDs e DVDs. É necessária uma palavra-passe para alterar esta definição.

EUA Define os níveis padrão de controlo paternal para os EUA.
Outros Define os níveis padrão de controlo paternal para outras regiões.

Se seleccionar [Outros], pode seleccionar uma região no ecrã seguinte.

Controlo parental DVD

Regule o nível de reprodução para DVDs definidos com controlo paternal. É necessária uma palavra-passe para alterar esta definição.

Desligado Reproduz qualquer DVD independentemente do nível de controlo paternal.
Nível 8 a 1 Reproduz apenas DVDs com o nível de controlo paternal especificado.

Tenha em atenção que quanto menor for o valor, maior será a restrição.

Controlo Paternal

Regule o nível de reprodução para jogos definidos com restrições de controlo paternal. É necessária uma palavra-passe para alterar esta definição.

Desligado Reproduz qualquer conteúdo independentemente do nível de controlo paternal.
Nível 11 a 1 Reproduz apenas conteúdo com o nível de controlo paternal especificado.

Tenha em atenção que quanto menor for o valor, maior será a restrição. Se seleccionar [Restringir o início de jogo sem definições de controlo parental], pode restringir o uso de jogos não classificados na sua região.

Notas

  • As definições de controlo paternal para jogos variam consoante a região em que os jogos são vendidos. Para mais informações, visite o Web site da SCE da sua região. Dependendo da região, alguns manuais de software podem conter informação sobre estas definições.
  • Os níveis de controlo parental variam dependendo do jogo.

Controlo de Início do navegador de Internet

Pode restringir a capacidade para iniciar o Navegador de Internet. É necessária uma palavra-passe para alterar esta definição.

Desligado Para não usar o controlo de início.
Ligado Para usar o controlo de início. É necessária uma palavra-passe para iniciar o navegador.
