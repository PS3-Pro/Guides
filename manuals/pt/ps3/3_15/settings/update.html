Actualização do Sistema

As actualizações de software podem incluir correcções do programa de segurança, definições e características novas ou revistas e outros artigos, que irão mudar o seu sistema operativo actual. É aconselhável fazer sempre a manutenção do seu sistema para utilizar a versão mais recente do software de sistema.

Pode actualizar o sistema de duas maneiras:

  • Actualizar através da Internet
  • Actualizar através de Suportes Armazenados

Atenção

  • Não desligue o sistema nem retire o suporte de armazenamento durante uma actualização. Se uma actualização for cancelada antes da sua conclusão, o software de sistema pode ser danificado e o sistema pode precisar de manutenção ou de troca.
  • Durante uma actualização, o botão de alimentação na parte dianteira do sistema e o botão PS no comando sem fios não estão activos.
  • Dependendo do conteúdo, pode não ser capaz de o reproduzir sem antes actualizar o software de sistema.

Actualizar através da Internet

Transfira os dados de actualização directamente da Internet para o sistema. A última actualização será transferida automaticamente.

1.

Seleccione (Definições) > (Actualização do Sistema).

2.

Seleccione [Actualizar através da Internet].
Transfira da Internet os dados de actualização mais recentes. Siga as instruções no ecrã para concluir a operação.

Actualizar através de Suportes Armazenados

Utilize dados de actualização guardados num disco, Memory Stick™ ou noutro suporte. Transfira os dados de actualização de um Web site utilizando um PC. Para mais informações, visite o Web site da SCE da sua região.

Notas

  • Os dados de actualização também podem estar incluídos em determinados discos de jogos, software de vídeo BD disponível comercialmente e outros tipos de discos. Quando reproduzir um disco com dados de actualização, será apresentado um ecrã que o orientará no processo de actualização. Siga as instruções no ecrã para realizar a actualização.
  • Em alguns modelos é necessário um adaptador USB apropriado (não incluído) para usar suportes de armazenamento.
