Utilidade de segurança

Faça uma cópia de segurança dos dados guardados no disco rígido para os suportes de armazenamento ou para um dispositivo de armazenamento em massa USB, ou restaure dados dos quais já existe cópia de segurança.

Fazer cópia de segurança Efectue uma cópia de segurança dos dados do disco rígido para suportes de armazenamento ou para um dispositivo de armazenamento de massa USB.
Restaurar Restaure os dados que foram sujeitos a cópias de segurança nos suportes de armazenamento ou num dispositivo USB para o disco rígido.
Eliminar dados da cópia de segurança Elimina dados dos quais já existe cópia de segurança no suporte de armazenamento ou dispositivo de armazenamento em massa USB

Atenção

Não pode fazer cópias de segurança das suas informações de troféus com o utilitário de cópias de segurança. Se pretender fazer cópias de segurança das suas informações de troféus, é recomendável criar uma conta PlayStation®Network e gravar as informações no servidor PlayStation®Network. Para fazer uma cópia de segurança das suas informações de troféus no servidor da PlayStation®Network, seleccione (Jogo) > (Colecção de Troféus), prima o botão e seleccione [Sincronização com o Servidor] no menu das opções.


Notas

  • As cópias de segurança dos dados podem ser efectuadas num Memory Stick™, SD Memory Card, CompactFlash® ou em dispositivos de armazenamento em massa USB. Em alguns modelos é necessário um adaptador USB apropriado (não incluído) para usar suportes de armazenamento. Os suportes em disco, como o CD-R, não podem ser utilizados.
  • Pode também utilizar um disco rígido USB para fazer cópias de segurança de dados; esse disco rígido será apresentado com o ícone quando estiver ligado. De notar, no entanto, que o disco deve ser formatado no sistema de ficheiros FAT32 para ser reconhecido pelo sistema PS3™.
  • Os dados das cópias de segurança são guardados na pasta [PS3] - [EXPORT] - [BACKUP]. As pastas são criadas automaticamente.
  • Se mudar o nome da pasta ou do ficheiro dos dados das cópias de segurança, poderá não ser possível restaurar os dados.
  • Se efectuar algumas das seguintes operações após a criação de cópias de segurança, os ficheiros de vídeo com protecção de direitos de autor dos dados dessas cópias poderão não ser devidamente restaurados.
  • - Formatar o disco rígido
  • - Restaurar o sistema PS3™
  • - Mover vídeo protegido com direitos de autor
  • - Transferir vídeo protegido com direitos de autor
  • - Reproduzir pela primeira vez vídeo com protecção de direitos de autor que tenha restrição de tempo
  • Se fizer cópias de segurança dos dados num sistema PS3™ e depois transferir os dados para outro sistema PS3™ utilizando o utilitário de transferência de dados, os dados guardados com protecção contra cópia incluídos na cópia de segurança não podem ser restaurados em nenhum dos sistemas.
  • Alguns tipos de dados de cópias de segurança podem ser restaurados noutro sistema PS3™. Os tipos de dados que podem ser restaurados noutro sistema são os seguintes:
  • - dados guardados do software de formato PlayStation®3 *1
  • - ficheiros de imagem em (Fotografia)
  • - ficheiros de música em (Música) *2
  • - ficheiros de vídeo em (Vídeo) *2
  • - marcadores adicionados em (Navegador de Internet)
  • - termos que foram adicionados através de (Definições) > (Definições de Sistema) > [Adicionar/Editar Termo] ou termos intuitivos que foram "assimilados" pelo teclado no ecrã
    • *1  Não é possível restaurar dados protegidos por direitos de autor. Além disso, dados guardados que foram restaurados poderão não ser utilizáveis nalguns jogos.
    *2  Não inclui dados protegidos por direitos de autor.
  • Em determinados casos, poderá não ser capaz de utilizar a funcionalidade Utilidade de segurança para fazer cópias de segurança ou restaurar o sistema correctamente. É aconselhável que copie ou mova sempre os dados importantes para suportes de armazenamento de modo a fazer cópias de segurança independentes dos seus dados.
