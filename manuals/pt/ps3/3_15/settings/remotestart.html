Início remoto

É possível ligar automaticamente um sistema PS3™ que esteja no modo de espera se utilizar um sistema PSP™ para reprodução remota (Wake On LAN). Para utilizar esta funcionalidade, é necessário realizar primeiro os seguintes passos:

Para utilizar a reprodução remota através da função de LAN sem fios do sistema PS3™ ou através de um ponto de acesso:
  • Actualize o software do sistema PSP™ para a versão 3.72 ou posterior.
  • Defina o início automático de sessão em (Utilizadores) no sistema PS3™

Para utilizar a reprodução remota através da Internet:
  • Actualize o sistema PSP™ e o sistema PS3™ para a versão mais recente do software do sistema.
  • Defina para iniciar sessão automaticamente em (Utilizadores) no sistema PS3™.
  • Conclua as definições de rede no sistema PS3™ para que seja possível ligar à Internet.
  • Crie uma conta PlayStation®Network.
  • Defina para registar automaticamente na PlayStation®Network.

Notas

  • Para detalhes sobre o início automático de sessão nos (Utilizadores), consulte (Utilizadores) > [Iniciar sessão] > [Definir o início automático de sessão] neste manual.
  • Para detalhes sobre o registo automático na PlayStation®Network, consulte (PlayStation®Network) > [Guardar a palavra-passe / Registar automaticamente] neste manual.

Activar o início remoto

1.

Seleccione (Definições) > (Definições de Reprodução Remota).

2.

Seleccione [Início remoto] > [Ligado].

3.

Seleccione [OK] no ecrã apresentado. Para utilizar a reprodução remota através da Internet, seleccione [Activar Início Remoto através da Internet].

4.

Desligue o sistema PS3™.
Seleccione (Utilizadores) > (Desligue) para desligar o sistema e colocá-lo no modo de espera. Certifique-se de que o indicador de alimentação está aceso a vermelho.

5.

Proceda à reprodução remota utilizando o sistema PSP™.
Para detalhes sobre a reprodução remota, consulte (Rede) > (Reprodução Remota) > [Utilizar a reprodução remota] neste manual.

Nota

Se a reprodução remota estiver activada, a ventoinha interna do sistema PS3™ irá continuar a funcionar mesmo depois do sistema ter sido desligado.

Desactivar a Reprodução Remota

1.

Seleccione (Definições) > (Definições de Reprodução Remota).

2.

Seleccione [Início remoto] > [Desligado].

Início remoto através da Internet

Poderá não ser possível utilizar a reprodução remota através da Internet dependendo do dispositivo de rede em utilização. Se isto acontecer, verifique as seguintes informações:

Atenção

Dependendo do tipo de router, o sistema PS3™ poderá ser repetidamente iniciado em intervalos fixos, se o início remoto estiver activado. Se não for estabelecida uma ligação de reprodução remota num determinado período de tempo depois do sistema PS3™ ter iniciado, o sistema desliga-se automaticamente. Para impedir que esta situação aconteça, o início remoto através da Internet pode ser desactivado automaticamente.

  • É necessário um router para utilizar o início remoto através da Internet.
  • Se o router em utilização suportar UPnP, active a função UPnP do router.
  • Se o router em utilização não suportar UPnP, tem de definir o reencaminhamento da porta do router para permitir a comunicação com o sistema PS3™ a partir da Internet. O número da porta utilizada para reprodução remota e início remoto é TCP: 9293 ou UDP: 9293. Para informações sobre como definir esta opção, consulte as instruções fornecidas com o router.
  • O reencaminhamento de porta é uma funcionalidade para reencaminhar sinais que chegam a uma porta específica (entrada) para outra porta (saída). Também pode ser designado "mapeamento de porta" ou "conversão de endereços".
  • Se o endereço IP do router (endereço IP global) for alterado quando o sistema PS3™ estiver no modo de espera, o início remoto não será bem sucedido.
