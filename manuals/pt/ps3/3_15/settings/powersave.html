Definições de Poupança de Energia

Regule as definições para a função de poupança de energia. Para poupar energia, o sistema PS3™ e os controladores sem fios podem ser definidos para desligarem automaticamente após um determinado período de inactividade.

Desligar Automático do Sistema

Após 1 hora O sistema desliga-se após o período de inactividade especificado.
Após 2 horas
Após 3 horas
Após 5 horas
Desligado O sistema não está definido para desligar automaticamente.

Nota

O sistema não desliga automaticamente durante condições especiais, como durante um jogo, reprodução de vídeo ou a reprodução de uma apresentação. Se pretender que o sistema desligue automaticamente mesmo durante estas condições especiais, seleccione [Desligar o sistema automaticamente mesmo durante condições especiais] no ecrã apresentado depois de activar a opção Desligar Automático do Sistema.

Desligar Automático do Controlador

Desligado O controlador não está definido para desligar automaticamente.
Ligado O controlador desliga automaticamente.
