Restaurar o Sistema PS3™

Elimine todo o conteúdo do disco rígido e restaure o software de sistema com as suas definições padrão. Siga as instruções no ecrã para realizar esta operação.


Quando a operação estiver concluída, será apresentado o ecrã das definições iniciais. Siga as instruções no ecrã para concluir a operação.


Atenção

  • Quando realiza esta operação, todos os dados no disco rígido serão eliminados. Além disso, o software de sistema será restaurado com as suas definições padrão. Tenha cuidado para não apagar dados importantes acidentalmente. As alterações não podem ser anuladas. A perda ou alteração de dados é da responsabilidade do utilizador.
  • Não desligue o sistema PS3™ durante esta operação. Se esta operação for cancelada antes da sua conclusão, o software de sistema pode ser danificado e o sistema pode precisar de manutenção ou de troca.
  • Durante esta operação, o botão de alimentação na parte dianteira do sistema e o botão PS do comando sem fios não estão activos.
  • Não é possível utilizar esta funcionalidade para regressar a uma versão anterior do software de sistema.
  • Pode diminuir o tempo de formatação seleccionando [Formatação Rápida] nos métodos de formatação do disco rígido. Recomenda-se que seleccione [Formatação Total] quando formatar um disco rígido que contém dados importantes ou delicados.
