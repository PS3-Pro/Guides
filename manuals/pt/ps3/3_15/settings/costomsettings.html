Definições de Ligação Personalizada

Esta definição está apenas disponível nos sistemas PS3™ equipados com a funcionalidade de LAN sem fios.


Se um sistema PSP™ estiver registado com um sistema PS3™ equipado com a funcionalidade de LAN sem fios, é automaticamente criada para ambos os sistemas uma ligação de rede para reprodução remota, com um SSID específico e uma chave de encriptação (chave WPA), e os sistemas poderão comunicar entre si no modo de infra-estrutura. Se seleccionar [Definições de Ligação Personalizada], pode alterar manualmente o SSID e a chave de encriptação que estão definidos no sistema PS3™. Normalmente não é necessário ajustar estas definições.

SSID Defina o SSID.

Pode introduzir o SSID que quiser.
Definição de Segurança WLAN Defina o método de segurança.

Pode apenas seleccionar [WPA-PSK (AES)] para as definições de reprodução remota.
Chave WPA Define uma chave de encriptação.

Pode introduzir a chave que quiser. A chave de encriptação é apresentada como uma série de asteriscos. A chave que definir aqui será necessária para alterar a ligação de rede para o sistema PSP™. Anote a chave para consultas futuras.

Nota

Se o SSID e a chave WPA forem alterados para o sistema PS3™, o SSID e a chave WPA também têm de ser alterados para os mesmos valores para a ligação de rede do sistema PSP™. Não se esqueça de registar o sistema PSP™ novamente depois de alterar estes valores.
