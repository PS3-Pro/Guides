Opgeslagen data van Memory Cards (geheugenkaarten) gebruiken

Om opgeslagen data op een Memory Card (8 MB) (voor PlayStation®2) of een Memory Card te gebruiken om een game te spelen, moet u de data naar een interne Memory Card in de systeemopslag kopiëren. U moet een Memory Card-adapter (los verkrijgbaar) gebruiken om de data te kopiëren.

Let op

  • Sommige PlayStation®2- of PlayStation®-softwaretitels kunnen anders werken op het PS3™-systeem dan op PlayStation®2- of PlayStation®-systemen of werken soms niet goed op het PS3™-systeem.
  • Discs in PlayStation®2-formaat kunnen niet afgespeeld worden op sommige PS3™-systemen. Voor meer informatie kunt u [Types afspeelbare discs] raadplegen, de SIE-website voor uw regio bezoeken of de documentatie bekijken die met uw PS3™-systeem meegeleverd werd.

1.

Selecteer (Game) > (Diensten voor Memory Card).

2.

Sluit de geheugenkaartadapter aan op het PS3™-systeem en plaats een geheugenkaart.
Een pictogram voor (Memory Card (PS)) of (Memory Card (PS2)) wordt weergegeven.

3.

Selecteer het pictogram van de opgeslagen data die u wenst te kopiëren van de weergegeven geheugenkaart en druk vervolgens op de -toets.

4.

Selecteer [Kopiëren].
Selecteer het doel waarnaar u wilt kopiëren. Als er geen doelen beschikbaar zijn, selecteer dan (Maak een nieuwe interne Memory Card) en volg de instructies op het scherm om een interne memory card te maken.

5.

Sleuven toewijzen
Selecteer de interne Memory Card die u wilt gebruiken uit (Diensten voor Memory Card) en druk vervolgens op de -toets. Selecteer [Sleuven toewijzen] in het optiesmenu.

Opmerkingen

  • Afhankelijk van het datatype, wordt opgeslagen data als volgt van een Memory Card (geheugenkaart) (8MB) (voor PlayStation®2) of een Memory Card (geheugenkaart) naar een interne Memory Card gekopieerd.

  • Voor bepaalde opgeslagen data kan het kopiëren verschillende minuten in beslag nemen.
  • Om alle opgeslagen data te kopiëren van een geheugenkaart (8MB) (voor PlayStation®2) of een geheugenkaart, selecteert u de geheugenkaart in stap 3, drukt u op de -toets, en selecteert u vervolgens [Kopiëren] in het optiesmenu.
  • Het is mogelijk dat het verboden is bepaalde opgeslagen data te kopiëren. Wanneer u dergelijke data gebruikt op een PS3™-systeem, selecteert u [Verplaatsen] in stap 4. De opgeslagen data worden verplaatst naar de systeemopslag en worden verwijderd van de Memory Card.
  • U kunt de opgeslagen data later terug verplaatsen naar de geheugenkaart.

Opgeslagen data kopiëren naar een geheugenkaart

Opgeslagen data van PlayStation®2-/PlayStation®-software die waren opgeslagen in de systeemopslag kopiëren naar een Memory Card of een Memory Card (8 MB) (voor PlayStation®2). U moet een Memory Card-adapter (los verkrijgbaar) gebruiken om de data te kopiëren.

1.

Selecteer (Game) > (Diensten voor Memory Card).

2.

Sluit de geheugenkaartadapter aan op het PS3™-systeem en plaats een geheugenkaart.

3.

Selecteer het pictogram van de opgeslagen data die u wilt kopiëren van (Interne Memory Card (PS)) of (Interne Memory Card (PS2)) waar de data zijn opgeslagen en druk vervolgens op de -toets.

4.

Selecteer [Kopiëren].
Specificeer (Memory Card (PS)) of (Memory Card (PS2)) als de kopieerbestemming.

Opmerkingen

  • Meerdere opgeslagen data op een interne geheugenkaart kunnen niet tegelijk worden gekopieerd naar een geheugenkaart.
  • Het is mogelijk dat het verboden is bepaalde opgeslagen data te kopiëren. Wanneer u dergelijke data gebruikt op een PS3™-systeem, selecteert u [Verplaatsen] in stap 4. De opgeslagen data worden verplaatst naar de systeemopslag en worden verwijderd van de interne Memory Card.
  • U kunt de opgeslagen data later terug verplaatsen naar de geheugenkaart.
