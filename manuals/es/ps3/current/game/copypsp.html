Copia de juegos para utilizarlos en un sistema PSP™

Si el juego que ha descargado (de compra o gratuito) a través de (PlayStation®Store) es compatible con el sistema PSP™, puede copiarlo para reproducirlo en un sistema PSP™.

1.

Inicie sesión en PSNSM con la cuenta de Sony Entertainment Network que ha utilizado para descargar el juego.

2.

Conecte el sistema PSP™ al sistema PS3™ mediante un cable USB.
Para copiar archivos a un soporte Memory Stick™, inserte el soporte Memory Stick™ en el sistema PSP™.

3.

En el sistema PSP™, seleccione (Ajustes) > (Conexión USB).

4.

En el sistema PS3™, seleccione el juego que desee copiar en (Juego) y, a continuación, pulse el botón .

5.

Seleccione [Copiar].
Siga las instrucciones que aparecen en la pantalla para copiar el juego. Una vez completada la copia, puede iniciar el juego en (Juego) > (Memory Stick™) o en (Juego) > (Almacenamiento del sistema) en el sistema PSP™.

Notas

  • Para utilizar esta función, el software del sistema PSP™ debe corresponder a la versión 6.50 o superior.
  • Si desea obtener información acerca del funcionamiento de los juegos en el sistema PSP™, consulte la guía de usuario del sistema PSP™.

Juegos que pueden utilizarse en sistemas PS3™ o PSP™

Si está utilizando un juego compatible con ambos sistemas, puede copiar los datos guardados del juego de un sistema al otro para poder seguir jugando en el punto en el que lo dejó. El método de copia de los datos guardados varía en función del tipo de juego.

Datos guardados del software de formato PlayStation®

Los datos guardados del software de formato PlayStation® se guardan en una Memory Card (Tarjeta de Memoria) interna creada en el almacenamiento del sistema. Para copiar los datos guardados a un sistema PSP™, realice los pasos 2 y 3 anteriores y, a continuación, seleccione (Juego) > (Herramienta de Memory Card) > (Memory Card (PS) interna) en el sistema PS3™. A continuación, seleccione el icono de los datos guardados para copiarlos, pulse el botón y seleccione [Copiar] en el menú de opciones.

Notas

  • Debe convertir el formato de los datos guardados para poder utilizar los datos en un sistema PSP™. Si aparece una pantalla de confirmación acerca de la conversión de datos durante la operación de copia, seleccione [Sí] para continuar.
  • Se crean múltiples tarjetas de memoria interna para cada título de software que se guarda en un soporte Memory Stick™ (insertado en el sistema PSP™) o en el sistema de almacenamiento del sistema PSP™go.
  • Si copia los datos guardados en el soporte Memory Stick™ que está insertado en la ranura del soporte de un sistema PS3™ o que utiliza un adaptador USB (a la venta por separado), los datos guardados no se reconocerán.

Activación del sistema PSP™

Un sistema PSP™ activado le permite jugar a los juegos que se descargue (comprados o gratuitos) de (PlayStation®Store). Si aparece un mensaje que solicita la activación al iniciar el juego en el sistema PSP™, active el dispositivo utilizando el siguiente procedimiento.

1.

Conecte el sistema PSP™ al sistema PS3™ mediante un cable USB.

2.

En el sistema PSP™, seleccione (Ajustes) > (Conexión USB).

3.

En el sistema PS3™, seleccione (PlayStation™Network) > (Administración de cuentas).

4.

Seleccione (Activación del sistema).
Siga las instrucciones que aparecen en la pantalla para completar el procedimiento de activación.

Notas

  • Para llevar a cabo la activación del dispositivo, es necesario haber iniciado sesión en el sistema PS3™ con el mismo usuario con el que ha iniciado sesión al descargar el software de formato PlayStation®.
  • La activación del dispositivo es un procedimiento que permite reproducir contenido en dispositivos autenticados. Este procedimiento es necesario para proteger los derechos digitales del contenido.
