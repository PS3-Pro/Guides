Copia en un soporte de almacenamiento (realización de copias de seguridad)

Los datos guardados en el almacenamiento del sistema pueden exportarse a soportes de almacenamiento, y los datos guardados que se han exportado pueden importarse al almacenamiento del sistema. Seleccione los datos guardados que desea exportar o importar, pulse el botón y, a continuación, seleccione [Copiar] en el menú de opciones. Siga las instrucciones en pantalla para completar la operación. Es recomendable que copie datos importantes para efectuar copias de seguridad de los mismos.


Notas

  • Es posible que algunos datos guardados no se puedan copiar.
  • No es posible copiar datos guardados durante la reproducción de contenido o el uso de otras funciones como, por ejemplo, la reproducción de archivos de música.
  • Los datos guardados de software de formato PlayStation®2 o PlayStation® también pueden copiarse en una Memory Card (tarjeta de memoria) o una Memory Card (tarjeta de memoria) (8MB) (para PlayStation®2). Para obtener más información, consulte [Uso de datos guardados en una memory card (tarjeta de memoria)] en (Juego) > [Reproducción de software de formato PlayStation®2 y PlayStation®] en esta guía.
  • Para poder utilizar los soportes de almacenamiento con determinados modelos del sistema PS3™, necesitará un adaptador USB apropiado (no incluido).

Avisos

  • Es posible que algunos títulos de software de formato PlayStation®2 o PlayStation® funcionen de manera diferente en el sistema PS3™ que en los sistemas PlayStation®2 o PlayStation®, o que no funcionen correctamente en el sistema PS3™.
  • Además, los discos de formato PlayStation®2 no pueden reproducirse en algunos sistemas PS3™. Para obtener más información, consulte [Tipos de discos que se pueden reproducir], visite el sitio Web de SIE de su región o revise la documentación suministrada con su sistema PS3™.
