Configuración de ajustes de juego

Es posible configurar los ajustes del mando y de la pantalla durante el juego. Pulse el botón PS en el mando inalámbrico durante el juego y, a continuación, seleccione [Ajustes de mando] o [Otros ajustes] en la pantalla que aparece.

Vuelva a asignar el mando

Es posible modificar la asignación de puerto o número de mando. Si el software especifica el puerto o número del mando, asigne el número de mando adecuado.*

*  No es posible asignar el puerto de mando [2-D] mediante el sistema PS3™.

Nota

Si pulsa el botón PS del mando podrá consultar las asignaciones de mando actuales.

Cambiar modo analógico

Es posible modificar el modo del mando. Seleccione un modo compatible con el software. Tenga en cuenta que en ocasiones el software seleccionará automáticamente el modo.

Función de vibración

Es posible activar o desactivar la función de vibración. Esta función únicamente se encuentra disponible si se utiliza un mando compatible con la función de vibración del sistema PS3™.

Notas

  • Este ajuste es efectivo para todos los mandos conectados que sean compatibles con la función de vibración.
  • Si esta opción se ajusta en [No], el mando no vibrará incluso si la función de vibración está activada en el juego.

Modo de pantalla

Cambia de modo de pantalla. Puede ajustar el modo de pantalla únicamente si se ha seleccionado una resolución de 1080p, 1080i o 720p en los ajustes de salida de vídeo del sistema PS3™.

Normal Configure este ajuste para que el contenido que se muestre coincida con el tamaño de la pantalla, sin cambiar las proporciones.
Pantalla completa Configure este ajuste para mostrar el contenido a pantalla completa mediante la modificación de las proporciones y la extensión de la imagen de arriba hacia abajo y de la izquierda hacia la derecha.

Nota

Si se ha ajustado [PS - Mejorar resolución] en (Ajustes) > (Ajustes de juego) en [No], este ajuste no se mostrará.

Suavizado

Ajuste la calidad de imagen del título de software de formato PlayStation®2 o PlayStation®.

No Desactiva el suavizado.
Sí Utilice este ajuste para suavizar la imagen que aparece en pantalla.

Nota

Es posible que según el software utilizado, el efecto de suavizado no se perciba o que la calidad de la imagen se vea reducida incluso si esta opción se encuentra ajustada en [Sí]. En tal caso, ajuste la opción en [No].

Avisos

  • Es posible que algunos títulos de software de formato PlayStation®2 o PlayStation® funcionen de manera diferente en el sistema PS3™ que en los sistemas PlayStation®2 o PlayStation®, o que no funcionen correctamente en el sistema PS3™.
  • Además, los discos de formato PlayStation®2 no pueden reproducirse en algunos sistemas PS3™. Para obtener más información, consulte [Tipos de discos que se pueden reproducir], visite el sitio Web de SIE de su región o revise la documentación suministrada con su sistema PS3™.
