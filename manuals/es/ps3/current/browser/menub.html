Menú del modo navegación

Visualización

Cambia el modo en que se muestra la página.

Zoom / Cancelar zoom Permite ampliar la imagen automáticamente hasta obtener un tamaño óptimo o cancelar la ampliación del área de la pantalla en la que se encuentra el puntero.

La relación de ampliación óptima se calcula automáticamente en función del tipo de contenido que hay en el área en la que se encuentra el puntero.
Tamaño máximo / Tamaño estándar Amplía la ventana para que ocupe toda la pantalla. / Visualiza la ventana en su tamaño original.
Tamaño de carácter Cambia el tamaño del texto.

Es posible mostrar el texto en cinco tamaños distintos.
Codificación de caracteres Asigna la codificación de caracteres.

En la mayoría de los casos, la codificación de caracteres se determina automáticamente, por lo que no es necesario asignarla.

Nota

En algunas páginas, no es posible cambiar el tamaño de los caracteres ni tampoco asignarles una codificación.

Herramientas

Permite ajustar las condiciones para abrir páginas y eliminar los datos guardados en el almacenamiento del sistema.

Cookies Permitir: Permite que se guarden las cookies siempre.

Bloquear: Impide que se guarden las cookies siempre.
JavaScript Sí: Utiliza JavaScript.

No: No utiliza JavaScript.
Superficie de pantalla Full pixel: Muestra la ventana en todo el área de visualización de la pantalla del televisor. *1

Tamaño estándar: Reduce el tamaño de la ventana en un 5%.

-1: Reduce el tamaño de la ventana en un 10%.

-2: Reduce el tamaño de la ventana en un 15%.
Resolución Cambia la resolución de la visualización de las páginas Web.

Ajusta las páginas Web para facilitar la visualización haciéndola coincidir con la resolución de salida de vídeo del sistema PS3™.
Reducción del parpadeo Sí: Suprime el parpadeo en elementos en pantalla que presentan parpadeo, como texto, imágenes y líneas.

No: Desactiva la función de reducción del parpadeo.

Este ajuste resulta eficaz para suprimir el parpadeo de una pantalla entrelazada. Seleccione [Sí] si se ha seleccionado una resolución como 1080i para el ajuste de la salida de vídeo del sistema PS3™. Seleccione [No], para mejorar la calidad de la imagen de las pantallas progresivas, como las de 1080p o 720p.
Confirmar cierre de navegador Sí: Muestra un mensaje de confirmación al cerrar el (Navegador de Internet).

No: Cierra el navegador sin que aparezca ningún mensaje de confirmación.
Página de inicio Permite ajustar la página que se mostrará al iniciar el (Navegador de Internet) o al seleccionar (Inicio) en el menú.

Si selecciona [Restablecer la ventana al inicio de navegador], la página que estaba abierta al cerrar el navegador se mostrará la próxima vez que lo inicie.
Eliminar cookies Permite eliminar cookies.
Eliminar historial de búsqueda Permite eliminar la información del historial de búsqueda.
Eliminar caché Permite eliminar la caché.
Eliminar información de autenticación Permite eliminar la información de autenticación.
Dar de baja la seguridad del navegador Permite interrumpir la utilización de los servicios de filtrado web. *2

Para modificar este ajuste, deberá introducir una contraseña. Para obtener información acerca de las contraseñas, consulte (Ajustes) > (Ajustes de seguridad) > [Cambiar contraseña] en esta guía.
*1

Si utiliza un televisor estándar, es posible que las partes superior e inferior de la imagen queden cortadas al utilizar el ajuste [Full pixel].
*2

Los tipos de servicios de filtrado web disponibles varían en función del país o la región.

Lista de ventanas

Cambia al modo ventana.

Buscar

Permite realizar una búsqueda en Internet a partir de una palabra clave o una frase.

Archivo

Entrada de dirección Introduce una dirección.
Abrir en ventana nueva Abre el vínculo sobre el que se encuentra el puntero en una ventana nueva.
Cerrar ventana Cierra las ventanas que se encuentren abiertas.
Guardar imagen Guarda la imagen activa en el almacenamiento del sistema o en el soporte de almacenamiento.*
Guardar destino Permite guardar el contenido vinculado que ha seleccionado con el puntero en el almacenamiento del sistema o en un soporte de almacenamiento. *
Copiar la dirección de esta página Permite copiar la dirección de la página que se visualiza en ese momento.
Copiar la dirección de este enlace Permite copiar la dirección del enlace sobre el que está situado el puntero.
Agregar a marcadores Permite añadir a sus marcadores el vínculo sobre el que tiene situado el puntero del ratón.
Imprimir esta pantalla Imprime la pantalla que se está visualizando.

Para utilizar esta función, primero debe seleccionar (Ajustes) > (Ajustes de impresora) > [Selección de impresora] para configurar una impresora.
Guardar captura de pantalla Guarda la pantalla que se está visualizando como una imagen.

La captura de pantalla se guarda en (Foto).
Información de página Muestra el título o la dirección de la página abierta.
Mostrar certificado Muestra los certificados de servidor que envían las páginas compatibles con SSL.
*

Para poder utilizar los soportes de almacenamiento con determinados modelos del sistema PS3™, necesitará un adaptador USB apropiado (no incluido).

Atrás

Muestra la página abierta anteriormente.

Adelante

Muestra la página que estaba abierta antes de realizar la operación (Atrás).

Actualizar / Cancelar

Actualiza la página abierta con el contenido más reciente. / Detiene la carga de la página.

Inicio

Muestra la página ajustada como página de inicio.

Marcadores

Añade las páginas favoritas del usuario como marcadores. Para abrir los marcadores, vaya a [Mis marcadores].

Mis marcadores Añade la página Web como un marcador y muestra una lista de los marcadores guardados.
PlayStation®3 Muestra el sitio Web de Sony Interactive Entertainment.

Nota

La lista de marcadores se organiza en orden cronológico, encabezándola los marcadores que se han añadido más recientemente.

Seguridad del navegador

Utilice un servicio de filtrado de direcciones webs para comprobar el tipo y las propiedades de los sitios web, así como para bloquear automáticamente la visualización de sitios web inadecuados cuando se utilice Internet.

i-Filter for PS3™*1 Abre la página Web del proveedor del servicio ［i-Filter for PS3™].*2
Trend Micro™ for PS3™ Abre la página Web del proveedor del servicio [Trend Micro™ for PS3™]. *2
*1

Esta función sólo se encuentra disponible en los sistemas PS3™ vendidos en Japón.
*2

Se aplicarán tasas por el uso de servicios de filtro Web.

Historial

Las páginas abiertas se guardan automáticamente en el historial. Los títulos de las páginas que se han abierto se mostrarán en una lista, donde podrán abrirse con tan sólo seleccionarlas, sin necesidad de introducir la dirección.

Nota

Las páginas se organizan en orden cronológico, empezando por las páginas que se han consultado más recientemente.
