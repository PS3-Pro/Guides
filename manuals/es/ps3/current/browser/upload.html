Cargar / Descargar

Puede cargar en Internet contenido guardado en el almacenamiento del sistema o en un soporte de almacenamiento, así como descargar contenido de Internet al almacenamiento del sistema o a un soporte de almacenamiento.

Subir

Es posible realizar esta operación desde páginas Web que dispongan de función de carga. El procedimiento de carga variará en función de la página Web.

Notas

  • Solo es posible cargar desde el almacenamiento del sistema el contenido guardado en (Foto).
  • Para poder utilizar los soportes de almacenamiento con determinados modelos, necesitara un adaptador USB apropiado (no incluido).

Descargar

1.

Seleccione el contenido que desea descargar de la página Web.

2.

Seleccione la ubicación en la que desea guardar el contenido y, a continuación, pulse el botón START (Iniciar).

Notas

  • Es posible que la ubicación de destino se haya asignado previamente en función del contenido.
  • El contenido que no se pueda reproducir en el sistema PS3™ sólo se podrá guardar en un soporte de almacenamiento.
  • Para poder utilizar los soportes de almacenamiento con determinados modelos del sistema PS3™, necesitará un adaptador USB apropiado (no incluido).
  • Puede realizar otras operaciones durante la descarga de un elemento de datos de gran volumen o de varios elementos de datos. Para obtener más información, consulte (Red) > (Administración de descargas) > [Descarga en segundo plano] en esta guía.
