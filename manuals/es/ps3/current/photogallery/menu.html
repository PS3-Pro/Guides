Photo Gallery
Guía del usuario

Lista de los elementos de menú

Puede realizar varias operaciones o establecer ajustes desde el menú que se muestra cuando se pulsa el botón . Los elementos de menú varían en función de la ubicación en la que se encuentra cuando accede al menú.

Copiar (Importar)

Permite copiar las fotografías seleccionadas al almacenamiento del sistema del sistema PS3™.

Ir al área de lista de reproducción Ir al área de biblioteca / Ir al área PSN

Cambiar entre [Área de lista de reproducción] y [Área de biblioteca].

Imprimir

Permite imprimir fotografías mediante una impresora conectada.

Agregar a lista de reproducción

Permite añadir fotografías a una lista de reproducción.

Añadir servicio de red

Permite añadir información de la cuenta del servicio de red al sistema PS3™.

Borrar servicio de red

Permite eliminar información de la cuenta del servicio de red del sistema PS3™.

Compartir

Permite compartir un álbum con sus amigos de PSNSM.

Editar

Permite añadir una descripción a una fotografía.

Comentar

Permite añadir comentarios a una fotografía.

Galería

Permite visualizar todas las fotografías de un evento o una lista de reproducción seleccionada en formato galería.

Editar

Permite editar la lista de reproducción o el álbum.

Agrupar

Permite organizar las fotografías en grupos.

Mover

Permite desplazar una fotografía o una lista de reproducción a otra ubicación.

Rotar

Permite rotar una fotografía o el marco de la fotografía para una lista de reproducción.

Eliminar

Permite eliminar una fotografía, lista de reproducción o álbum.

Ordenar

Permite cambiar el orden de visualización de las fotografías.

Visualizar

Permite ajustar la opción de visualizar u ocultar la información relacionada con un evento o una lista de reproducción seleccionada.

Ayuda

Permite visualizar las pantallas de ayuda que proporcionan información acerca de [Área de biblioteca] y [Área de lista de reproducción], así como las funciones principales del controlador inalámbrico cuando se utiliza junto con Photo Gallery. Asimismo, puede visualizar una lista de los elementos de menú.

Herramientas

Permite ajustar las preferencias para Photo Gallery.

Tono de la tecla Permite activar o desactivar el tono de la tecla.
Música Permite activar o desactivar la música de fondo.
Brillo de la superficie Permite seleccionar el brillo de la superficie que se utiliza en el fondo.
Tipo de superficie Permite seleccionar el tipo de superficie que se utiliza en el fondo.

Salir

Permite salir de Photo Gallery.
