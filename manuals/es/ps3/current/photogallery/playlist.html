Creación de una lista de reproducción de las fotografías seleccionadas

Puede seleccionar fotografías para crear una lista de reproducción. Con una lista de reproducción, puede visualizar las fotografías seleccionadas en el mismo orden en cualquier momento.

Creación de una lista de reproducción

1.

En [Área de biblioteca], seleccione una foto que desee agregar a la lista de reproducción, pulse el botón y, a continuación, seleccione (Agregar a lista de reproducción).
Aparecerá [Área de lista de reproducción].

2.

Utilice el joystick izquierdo para moverse hacia un área vacía de [Área de lista de reproducción] y, a continuación, pulse el botón .
Se agregará una nueva lista de reproducción en esa ubicación.

3.

Ajuste las siguientes opciones en la lista de reproducción.
Después de ajustar estas opciones, se creará la lista de reproducción.

Marco de fotos Seleccione un marco para la lista de reproducción.
Lista de reproducción Cree un nombre para la lista de reproducción.
Estilo de galería Seleccione la forma en la que se visualizarán las fotografías en la galería.
Velocidad de cambio Seleccione la velocidad de cambio de la galería.
Música de galería Seleccione la música que se reproducirá de fondo durante la galería a partir del contenido de música que se proporciona con la aplicación Photo Gallery.
Seleccione la música que se reproducirá de fondo durante la galería en la categoría (Música) en la pantalla XMB™.

Notas

  • Es posible editar los ajustes de la lista de reproducción más adelante en (Editar).
  • Cada lista de reproducción puede disponer de sus propios ajustes.

Adición de fotografías a una lista de reproducción

1.

Seleccione las fotografías que desee añadir a la lista de reproducción, pulse el botón y, a continuación, seleccione (Agregar a lista de reproducción).
Se mostrará la pantalla Lista de reproducción.

2.

Selecciona la lista de reproducción y, a continuación, pulse el botón .
Se agregarán las fotografías seleccionadas a la lista de reproducción.

Edición de los ajustes de una lista de reproducción

Puede editar los ajustes de una lista de reproducción. Seleccione la lista de reproducción que desea editar, pulse el botón y, a continuación, seleccione (Editar).

Desplazamiento de una lista de reproducción

Puede desplazar una lista de reproducción a otra ubicación. Seleccione la lista de reproducción que desea desplazar, pulse el botón y, a continuación, seleccione (Mover). Puede desplazar la lista de reproducción con el joystick izquierdo.

Nota

También es posible desplazar una lista de reproducción sin acceder al menú. Seleccione la lista de reproducción y, a continuación, mientras mantiene pulsado el botón , utilice el joystick izquierdo para mover la lista de reproducción.

Eliminación de una lista de reproducción

Para eliminar una lista de reproducción, seleccione la que desea eliminar, pulse el botón y, a continuación, seleccione (Eliminar).
