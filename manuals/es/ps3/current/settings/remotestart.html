Inicio a distancia

Puede encender a distancia un sistema PS3™ que se encuentre en modo de espera (Wake On LAN) mediante un dispositivo que admita la función de uso a distancia, como un sistema PS Vita o un sistema PSP™. Antes de utilizar esta función, deberá seguir los pasos que se indican a continuación:

Cuando utilice la función de uso a distancia a través de la función LAN inalámbrica del sistema PS3™ o a través de un punto de acceso:
  • Si utiliza un sistema PSP™ para la función de uso a distancia, actualice el software del sistema PSP™ a la versión 3.72 o posterior.
  • Ajuste el inicio de sesión automático en (Usuarios) en el sistema PS3™.

Cuando utilice la función de uso a distancia a través de Internet
  • Si utiliza un sistema PSP™ para la función de uso a distancia, actualice el sistema PSP™ y el sistema PS3™ a la versión más reciente del software del sistema.
  • Ajuste el inicio de sesión automático en (Usuarios) en el sistema PS3™.
  • Complete los ajustes de la red del sistema PS3™ para poder conectarse a Internet.
  • Cree una cuenta de usuario en Sony Entertainment Network.
  • Establezca el inicio de sesión automático en PSNSM.

Notas

  • Para usar la función de inicio a distancia, los usuarios de los sistemas PS3™ de las series CECH-4302, CECH-4303, CECH-4304 y CECH-4308 deben estar conectados a una red que use la función LAN inalámbrica del sistema PS3™.
  • Para obtener más información sobre el inicio de sesión automático en (Usuarios), consulte (Usuarios) > [Inicio de sesión] > [Ajuste del inicio de sesión automático] en esta guía.
  • Para obtener más información sobre el inicio de sesión automático en PSNSM, consulte (PlayStation™Network) > [Guardar contraseña (inicio de sesión automático) / inicio de sesión automático] en esta guía.

Habilitar el inicio a distancia

1.

Seleccione (Ajustes) > (Ajustes de uso a distancia).

2.

Seleccione [Inicio a distancia] > [Sí].

3.

Seleccione [OK] en la pantalla que aparece. Para utilizar el uso a distancia a través de Internet, seleccione [Activar inicio a distancia mediante Internet].

4.

Apague el sistema PS3™.
Seleccione (Usuarios) > (Apagar sistema) para apagar el sistema y ajustarlo en modo de espera. Verifique que el indicador de encendido esté iluminado en rojo intenso.

5.

Controle la reproducción a distancia mediante un dispositivo que admita la función de uso a distancia, como un sistema PS Vita o un sistema PSP™.
Para obtener más información acerca del uso a distancia, consulte las instrucciones suministradas con el dispositivo que está utilizando.

Notas

  • Para obtener más información acerca del uso a distancia mediante un sistema PS Vita o un sistema PSP™, consulte (Red) > (Uso a distancia) > [Utilización de la función de uso a distancia] en esta guía.
  • Si el inicio a distancia está habilitado, el ventilador interno del sistema PS3™ seguirá funcionando incluso tras apagarse el sistema.

Desactivar el inicio a distancia

1.

Seleccione (Ajustes) > (Ajustes de uso a distancia).

2.

Seleccione [Inicio a distancia] > [No].

Inicio a distancia mediante Internet

Es posible que no pueda utilizar el uso a distancia a través de Internet en función del dispositivo de red utilizado. En tal caso, consulte la información facilitada a continuación:

Aviso

Según el tipo de router, el sistema PS3™ puede iniciarse accidentalmente cuando el inicio a distancia está activado. Si transcurrido cierto tiempo desde el inicio del sistema PS3™ no se establece ninguna conexión para el uso a distancia, el sistema se apaga automáticamente. Para evitar que esto ocurra, puede desactivar automáticamente el inicio a distancia a través de Internet.

  • Para utilizar el inicio a distancia mediante Internet, es necesario un router.
  • Si el router utilizado es compatible con UPnP, habilite la función UPnP del router.
  • Si el router utilizado no es compatible con UPnP, deberá ajustar el reenvío de puerto para poder comunicarse con el sistema PS3™ a través de Internet. El número de puerto utilizado para el uso a distancia y el inicio a distancia es TCP: 9293 o UDP: 9293. Para obtener más información acerca del ajuste de esta opción, consulte las instrucciones suministradas con el router.
  • El reenvío de puerto es una función que consiste en reenviar las señales recibidas en un puerto específico (entrada) a otro puerto específico (salida). Esta función también se denomina "asignación de puerto" o "conversión de dirección".
  • Si la dirección IP (dirección IP global) del router se modifica cuando el sistema PS3™ está en modo de espera, el sistema no se iniciará a distancia.
