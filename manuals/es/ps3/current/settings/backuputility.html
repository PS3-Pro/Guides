Herramienta de copia de seguridad

Realice una copia de seguridad de los datos guardados en el almacenamiento del sistema en un soporte de almacenamiento o un dispositivo de almacenamiento masivo USB, o recupere los datos de los que se ha efectuado una copia de seguridad.

Crear copia de seguridad Permite hacer una copia de seguridad de los datos del almacenamiento del sistema en un soporte de almacenamiento o un dispositivo USB de almacenamiento masivo.
Restaurar Permite restaurar en el almacenamiento del sistema los datos de los que se ha realizado una copia de seguridad en un soporte de almacenamiento o dispositivo USB.
Eliminar datos de copia de seguridad Elimina datos que han sido respaldados en un soporte de almacenamiento o dispositivo de almacenamiento masivo USB.

Aviso

No es posible realizar una copia de seguridad de la información de trofeos mediante la función de herramienta de copia de seguridad. Si desea guardar la información de trofeos, se recomienda que cree una cuenta de Sony Entertainment Network y guarde la información en el servidor. Para efectuar una copia de seguridad de la información de trofeos en el servidor PSNSM, seleccione (PlayStation™Network) > (Colección de trofeos), pulse el botón y, a continuación, seleccione [Sincronizar con servidor] en el menú de opciones.


Notas

  • Se puede efectuar una copia de seguridad de los datos en un Memory Stick™, una SD Memory Card, un CompactFlash® y en dispositivos de almacenamiento masivo USB. Para poder utilizar los soportes de almacenamiento con determinados modelos del sistema PS3™, necesitará un adaptador USB apropiado (no incluido). No se pueden utilizar discos como los CD-R.
  • También es posible utilizar un disco duro USB para realizar copias de seguridad de datos. Cuando lo conecte, aparecerá el icono . No obstante, tenga en cuenta que el disco debe formatearse en el sistema de archivo FAT32 para que el sistema PS3™ lo reconozca.
  • Los datos guardados se almacenarán en la carpeta [PS3] - [EXPORT] - [BACKUP]. Las carpetas se crean automáticamente.
  • Si cambia el nombre de la carpeta o el archivo de los datos guardados, es posible que no pueda restaurarlos.
  • Si realiza una de las siguientes operaciones después de crear una copia de seguridad, es posible que los archivos de vídeo protegidos por copyright en la información de las copias de seguridad no se restauren correctamente:
  • - Formatear el almacenamiento del sistema
  • - Restaurar el sistema PS3™.
  • - Mover vídeo protegido por copyright.
  • - Descargar vídeo protegido por copyright.
  • - Reproducir por primera vez un vídeo con fecha de expiración y protegido por derechos de autor.
  • Si realiza una copia de seguridad en un sistema PS3™ y, a continuación, transfiere datos a otro sistema PS3™ mediante la herramienta de transferencia de datos, no podrá restaurar en ninguno de los sistemas los datos guardados protegidos contra copia que se incluyen en los datos de copia de seguridad.
  • Algunos tipos de datos de los cuales se ha realizado una copia de seguridad pueden restaurarse en otro sistema PS3™. Los tipos de datos que pueden restaurarse en otro sistema son los siguientes:
  • - Datos guardados desde software de formato PlayStation®3 *1
  • - Uso de datos guardados para minijuegos ("minis")
  • - Datos guardados para el software PSP™Game (juegos de PSP™)
  • - Archivos de imagen de (Foto)
  • - Archivos de música de (Música)*2
  • - Archivos de vídeo de (Vídeo)*2
  • - Marcadores añadidos en (Navegador de Internet)
  • - Términos que se han añadido mediante (Ajustes) > (Ajustes del sistema) > [Agregar/Editar término] o términos predictivos que han sido "memorizados" por el teclado en pantalla.
    • *1  Los datos protegidos contra copia no se pueden restaurar. Además, es posible que los datos guardados que se han restaurado no puedan utilizarse en algunos juegos.
    *2  No se incluyen datos protegidos por derechos de autor.
  • En algunos casos, es posible que no pueda utilizar la función de Herramienta de copia de seguridad para realizar una copia de seguridad o restaurar el sistema correctamente. Se recomienda que siempre copie o mueva la información importante a un soporte de almacenamiento para crear una copia de seguridad de los datos independiente.
