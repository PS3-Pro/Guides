Actualización automática

Para utilizar determinadas funciones, tiene que suscribirse al servicio de suscripción de PlayStation®Plus.

Cuando este ajuste sea [Sí], el sistema PS3™ se iniciará automáticamente a la hora especificada todos los días, realizará las operaciones especificadas y, a continuación, se apagará.

No Ajuste esta opción para no utilizar la función de actualización automática.
Sí Ajuste esta opción para utilizar la función de actualización automática.

Puede seleccionar las operaciones de actualización automática para los siguientes elementos.

  • Descargar elementos de contenido comprados con otros dispositivos
  • Descargar el último software del sistema
  • Descargar parches de juegos.
  • Sincronizar información de trofeos con el servidor.

Notas

  • Ajuste [Subir datos guardados al almacenamiento online] para cada juego. Para obtener información sobre cómo configurar este elemento, consulte (Juego) > [Jugar a software de formato PlayStation®3] > [Uso de datos guardados] en esta guía.
  • Después de seleccionar [Sí], utilice los botones direccionales para seleccionar el periodo de tiempo durante el cual desea que se realice la actualización automática. Siga las instrucciones que aparecen en pantalla si aparece una pantalla en la que se le solicita que compruebe los ajustes para el inicio de sesión automático en PSNSM.
  • Esta función puede utilizarse en un solo sistema PS3™ por cada cuenta Sony Entertainment Network. Si la función de actualización automática está ajustada en [Sí] en dos o más sistemas PS3™ en la misma cuenta, permanecerá ajustada en [Sí] en el último sistema ajustado y se ajustará en [No] automáticamente en todos los demás sistemas.
  • Es necesario que el sistema PS3™ esté en modo de espera (que el indicador de encendido esté iluminado de manera ininterrumpida) durante el periodo de tiempo en el que desea que el sistema realice la actualización automática.
  • Los datos de actualización del software del sistema se descargarán automáticamente, pero no se instalarán. Debe instalar los datos de actualización del software del sistema de forma manual.
  • se muestra para los parches de juegos y los juegos recomendados que se han descargado automáticamente. Los contenidos que se han descargado e instalado automáticamente pero no se han utilizado se eliminarán automáticamente una vez transcurrido un mes.
  • Incluso si [Actualización automática] está ajustado en [Sí], el contenido no se descargará si la cantidad de espacio libre en el almacenamiento del sistema es inferior a 5 GB.
  • Ajuste esta opción en [No] para restablecer los ajustes predeterminados de todas las opciones de actualización automática seleccionadas.
