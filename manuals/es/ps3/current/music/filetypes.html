Tipos de archivo que se pueden reproducir

Desde (Música) se pueden reproducir los siguientes tipos de archivo.

  • Memory Stick de audio en formato (ATRAC)
  • MP3
  • - MPEG-1/2 Audio Layer3
  • - MP3 Surround
  • MP4 (MPEG-4 AAC)
  • WAVE (PCM lineal)
  • WMA

Notas

  • Algunos archivos no se podrán reproducir debido al tipo de datos que contengan.
  • Algunos archivos de música distribuidos por Internet presentan restricciones de reproducción. Para obtener más información al respecto, póngase en contacto con el proveedor de contenido.
  • Para reproducir archivos en formato ATRAC debe dirigirse a (Ajustes) > (Ajustes del sistema) y establecer [Activar ATRAC].
  • Para reproducir archivos de formato WMA, debe dirigirse a (Ajustes) > (Ajustes del sistema) y ajustar [Activar reproducción WMA].
  • Los archivos con formato WMA protegidos por copyright no pueden reproducirse.
  • Los archivos de MP3 Surround solamente pueden reproducirse si el sistema está ajustado para la emisión de audio en formato PCM Lineal.
  • Cuando utilice un adaptador USB para reproducir archivos de música, es posible que necesite un adaptador USB compatible (no incluido) que admita las funciones de protección de derechos de autor (para reproducir archivos protegidos por derechos de autor).
