Copia de listas de reproducción en un sistema PSP™

Es posible copiar música como listas de reproducción y, a continuación, reproducirla en el sistema PSP™.

1.

Conecte el sistema PSP™ al sistema PS3™ mediante un cable USB.
Para copiar archivos a un soporte Memory Stick™, inserte el soporte Memory Stick™ en el sistema PSP™.

2.

En el sistema PSP™, seleccione (Ajustes) > (Conexión USB).

3.

En el sistema PS3™, seleccione (Música) > (Listas de reproducción).

4.

Seleccione el icono de la lista de reproducción que desee utilizar y, a continuación, pulse el botón .

5.

Seleccione [Copiar].
Seleccione (PSP™ (PlayStation®Portable)) o (PSP™ (PlayStation®Portable)) como destino.

Notas

  • Para utilizar esta función, el software del sistema PSP™ debe corresponder a la versión 3.10 o posterior.
  • No se pueden copiar listas de reproducción del sistema PSP™ al sistema PS3™.
