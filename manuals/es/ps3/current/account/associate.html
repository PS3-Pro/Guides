Utilización de una cuenta existente

Para utilizar esta función, debe mantener siempre el software del sistema actualizado con la versión más reciente.


Es posible asociar una cuenta Sony Entertainment Network existente con un Usuario del sistema PS3™. Es posible utilizar una cuenta principal existente o una subcuenta creada en un sistema PS Vita o en un sistema PSP™.

1.

En (Usuarios), inicie sesión como el usuario al que desea asociar la cuenta.

2.

Seleccione (Inscribirse) en (PlayStation™Network).

3.

En la pantalla que se visualiza, seleccione [Usar una cuenta existente].
Siga las instrucciones en pantalla para completar la operación. Cuando se haya completado la asociación de la cuenta con el Usuario, se mostrará el ícono (Iniciar sesión) y el Usuario podrá iniciar sesión en PSNSM mediante la cuenta existente.

Notas

  • PSNSM y (PlayStation®Store) sólo se encuentran disponibles en determinados países o regiones e idiomas. Para obtener más información, póngase en contacto con el servicio de atención al cliente de su región.
  • Solo se puede asociar una cuenta con cada usuario del sistema PS3™.
