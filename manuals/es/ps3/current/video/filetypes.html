Tipos de archivo que se pueden reproducir

Desde el menú (Vídeo) se pueden reproducir los siguientes tipos de archivo.

  • Formato de vídeo de Memory Stick
  • - MPEG-4 SP (AAC LC)
  • - H.264/MPEG-4 AVC High Profile （AAC LC）
  • - MPEG-2 TS（H.264/MPEG-4 AVC, AAC LC）
  • Formato de archivo MP4
  • - H.264/MPEG-4 AVC de perfil alto (AAC LC)
  • MPEG-1 (MPEG Audio Layer 2)
  • MPEG-2 PS (MPEG2 Audio Layer 2, AAC LC, AC3 (Dolby Digital), LPCM)
  • MPEG-2 TS (MPEG2 Audio Layer 2, AC3 (Dolby Digital), AAC LC)
  • MPEG-2 TS（H.264/MPEG-4 AVC, AAC LC）
  • AVI
  • - Motion JPEG (PCM Lineal)
  • - Motion JPEG (μ-Law)
  • AVCHD (.m2ts / .mts)
  • DivX
  • WMV
  • - VC-1（WMA Standard V2）

Notas

  • En función del tipo de datos, es posible que algunos archivos no se puedan reproducir o que algunas opciones del panel de control no funcionen durante la reproducción.
  • Algunos archivos de vídeo distribuidos por Internet presentan restricciones de reproducción. Para obtener más información al respecto, póngase en contacto con el proveedor de contenido.
  • Para reproducir archivos de formato WMV, debe dirigirse a (Ajustes) > (Ajustes del sistema) y ajustar [Activar reproducción WMA].
  • Cuando utilice un adaptador USB para reproducir archivos de vídeo, es posible que necesite un adaptador USB (no incluido) compatible con las funciones de protección de derechos de autor (para reproducir archivos protegidos por derechos de autor).
  • Cuando utilice un adaptador USB para reproducir archivos de vídeo de formato AVCHD almacenados en un soporte Memory Stick™, utilice un dispositivo compatible con Hi-Speed USB (USB 2.0).
  • Los archivos de formato WMV protegidos por derechos de autor no se pueden reproducir.
