Copia / desplazamiento de archivos de vídeo

Copie los archivos de vídeo guardados en el soporte de almacenamiento en el almacenamiento del sistema o mueva los archivos importados desde el almacenamiento del sistema al soporte de almacenamiento. Seleccione el archivo que desea importar o copiar, pulse el botón y, a continuación, seleccione [Copiar] o [Mover] en el menú de opciones. Siga las instrucciones en pantalla para completar la operación.

Diferencias entre copiar y mover

Las operaciones que puede realizar varían según el tipo de archivo. Únicamente es posible mover los archivos protegidos contra copia. Si se mueve un archivo, deja de existir en la ubicación original.

El contenido de pago (tipo de archivo: MNV), grabado en resolución HD, que se ha descargado desde PlayStation®Store no se puede copiar ni mover, pero se puede seleccionar para realizar una copia de seguridad. Para realizar copias de seguridad de manera selectiva de los contenidos descargados desde la tienda de vídeos de PlayStation®Store, utilice la función de copia de seguridad del sistema PS3™. Para obtener más información, consulte (Vídeo) > [Realización de una copia de seguridad o restauración de archivos de vídeo] en esta guía.

Notas

  • Se ha suspendido la venta y el alquiler de contenidos de vídeo de PlayStation®Store en el sistema PS3™.
  • Cuando copie o mueva archivos de vídeo que tengan restricciones de control paterno, debe introducir una contraseña. Es posible ajustar la contraseña en [Cambiar contraseña] en (Ajustes) > (Ajustes de seguridad).
  • En función del dispositivo que se utilice, es posible que algunos archivos copiados no se puedan reproducir.
  • En función del modelo del sistema PS3™ que esté utilizando, es posible que sea necesario el uso de un adaptador USB adecuado (no incluido) para utilizar soportes de almacenamiento. Asimismo, al mover archivos de vídeo a soportes Memory Stick PRO™, es necesario utilizar un dispositivo USB compatible con las funciones de protección de los derechos de autor del soporte Memory Stick™ como, por ejemplo, el sistema PSP™ o MRW-F3 (un producto Sony).
  • Al utilizar un soporte Memory Stick Micro™ con un sistema PS3™ equipado con una ranura para Memory Stick™, deberá utilizar el soporte con un adaptador para Memory Stick™ M2 Duo.
  • No es posible mover ciertos archivos de vídeo protegidos contra copia.
  • Procure no infringir la propiedad intelectual de otras personas.
  • Los archivos de vídeo no se pueden copiar ni mover durante la reproducción.*

    • * Incluida la reproducción de contenido mediante otras funciones como, por ejemplo, la reproducción de archivos de música.

Copiar o mover vídeo para visualizarlo en un sistema PSP™

Permite copiar o mover archivos de vídeo para visualizarlos en un sistema PSP™.

1.

Conecte el sistema PSP™ al sistema PS3™ mediante un cable USB.
Para copiar archivos a un soporte Memory Stick™, inserte el soporte Memory Stick™ en el sistema PSP™.

2.

En el sistema PSP™, seleccione (Ajustes) > (Conexión USB).

3.

En el sistema PS3™, seleccione el archivo de vídeo que desea copiar o mover y, a continuación, pulse el botón .

4.

Seleccione [Copiar] o [Mover].
Siga las instrucciones en pantalla para copiar o mover el archivo. Es posible reproducir el archivo de vídeo copiado o movido si selecciona el archivo en (Vídeo) > (Memory Stick™) o en (Vídeo) > (Almacenamiento del sistema) en el sistema PSP™.

Notas

  • Para obtener información acerca de la reproducción de archivos de vídeo en el sistema PSP™, consulte en la guía del usuario del sistema PSP™.
  • Según el tipo de archivo de vídeo que copie o mueva, debe utilizar un soporte Memory Stick PRO Duo™.
  • El contenido de vídeo grabado en resolución HD no se puede mover.
