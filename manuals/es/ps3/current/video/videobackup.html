Realización de una copia de seguridad o restauración de archivos de vídeo

Utilice la función de copia de seguridad del sistema PS3™ para realizar una copia de seguridad de forma selectiva del contenido que se ha descargado desde la tienda de vídeos de PlayStation®Store en el soporte de almacenamiento. Puede restaurar los archivos de los que ha realizado copia de seguridad mediante esta función en el mismo sistema PS3™.

Realización de una copia de seguridad de un archivo de vídeo

Conecte un soporte de almacenamiento en el sistema PS3™. Seleccione el icono del contenido del que desee realizar copias de seguridad. Pulse el botón y, a continuación, seleccione [Crear copia de seguridad] desde el menú de opciones. La carpeta (Herramienta de copia de seguridad de datos) se creará automáticamente en el soporte de almacenamiento y el contenido se guardará.

Notas

  • Se ha suspendido la venta y el alquiler de contenidos de vídeo de PlayStation®Store en el sistema PS3™.
  • Esta función se puede utilizar para realizar una copia de seguridad de los datos en dispositivos de memoria Memory Stick™, SD Memory Card, Compact Flash® y en dispositivos de almacenamiento masivo USB. Para poder utilizar los soportes de almacenamiento con determinados modelos del sistema PS3™, necesitará un adaptador USB apropiado (no incluido). No se pueden utilizar discos como los CD-R.
  • Un disco duro USB también se puede utilizar para realizar copias de seguridad de datos. No obstante, tenga en cuenta que el disco debe formatearse como un sistema de archivos FAT32 para que el sistema PS3™ lo reconozca. El sistema PS3™ no puede reconocer un disco duro que se encuentre en formato NTFS (sistema de archivo NT).
  • El contenido del que se ha realizado una copia de seguridad no puede reproducirse desde un soporte de almacenamiento. Para reproducir el contenido, primero debe restablecerlo en el almacenamiento del sistema del sistema PS3™.

Restauración de un archivo de vídeo del que se ha realizado copia de seguridad

El contenido del que se ha realizado copia de seguridad en un soporte de almacenamiento se puede restaurar en el sistema PS3™.

1.

Conecte el soporte de almacenamiento que incluye el contenido del que se ha realizado copia de seguridad al sistema PS3™.

2.

Seleccione el icono del soporte de almacenamiento en (Vídeo).

3.

Seleccione el contenido que desea restaurar en (Herramienta de copia de seguridad de datos) y, a continuación, pulse el botón .

4.

Seleccione [Restaurar].

Notas

  • Si se ha cambiado el nombre de la carpeta o el nombre de archivo de los datos de los que se ha realizado copia de seguridad, es posible que no pueda restaurar dicho contenido.
  • Si realiza cualquiera de las siguientes operaciones después de realizar una copia de seguridad de contenido, es posible que el contenido no se restaure correctamente.
  • - Formatear el almacenamiento del sistema
  • - Restaurar el sistema PS3™.
  • En algunos casos, es posible que no pueda utilizar la función de copia de seguridad para realizar una copia de seguridad o restaurar el contenido en el sistema correctamente.
