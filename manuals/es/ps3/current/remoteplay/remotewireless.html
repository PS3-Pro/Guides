Utilización de la función de uso a distancia (a través de la función de WLAN del sistema)

Conecte un dispositivo que admita la función de uso a distancia, como un sistema PS Vita o un sistema PSP™, al sistema PS3™ mediante la función de red LAN inalámbrica del sistema PS3™. Este método de conexión solamente está disponible en los sistemas PS3™ que cuentan con la función de red LAN inalámbrica.

Preparación para su utilización

Para utilizar la función de uso a distancia por primera vez, debe registrar (emparejar) el dispositivo que admite el uso a distancia, como un sistema PS Vita o un sistema PSP™, con el sistema PS3™. Para registrar (emparejar) el dispositivo, seleccione (Ajustes) > (Ajustes de uso a distancia) > [Registrar dispositivo].

El uso a distancia en un sistema PS Vita

1.

En el sistema PS Vita, toque (Uso a distancia de PS3) > [Inicio].

2.

En el sistema PS3™, seleccione (Red) > (Uso a distancia).
El sistema PS3™ espera que el sistema PS Vita establezca la conexión de uso a distancia.

3.

En el sistema PS Vita, toque [Conectarse mediante una red privada].
Cuando los dispositivos se conecten correctamente, la pantalla del sistema PS3™ aparecerá en el sistema PS Vita.

El uso a distancia en un sistema PSP™

1.

En el sistema PS3™, seleccione (Red) > (Uso a distancia).
El sistema entrará en modo de espera de conexión para uso a distancia.

2.

En el sistema PSP™, seleccione (Red) > (Uso a distancia).

3.

Seleccione [Conectarse a través de una red privada].

4.

Seleccione [PlayStation(R)3] en la lista de conexiones.
Si la conexión se establece correctamente, la pantalla del sistema PS3™ se visualizará en el sistema PSP™.

Notas

  • La función de uso a distancia puede utilizarse dentro del alcance de la LAN inalámbrica del sistema PS3™.
  • Si activa el ajuste de inicio a distancia en el sistema PS3™, puede configurarlo para que se encienda automáticamente (Wake on LAN). Si desea obtener más información, consulte (Ajustes) > (Ajustes de uso a distancia) > [Inicio a distancia] en esta guía.
  • Durante el uso a distancia, si va a la pantalla LiveArea™ de Uso a distancia o de otra aplicación, la conexión de uso a distancia se cierra después de 30 segundos.
