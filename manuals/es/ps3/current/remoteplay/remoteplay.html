Acerca de la función de uso a distancia

La función de uso a distancia permite visualizar la pantalla del sistema PS3™ en un dispositivo que admita el uso a distancia (como un sistema PS Vita o un sistema PSP™) y utilizar el sistema de forma remota a través de una red LAN inalámbrica.

Nota

Para utilizar la función de uso a distancia con un sistema PSP™, debe actualizar el software del sistema PSP™ a la versión 3.72 o posterior.

Operaciones que se pueden realizar desde un dispositivo compatible con el uso a distancia

Las principales funciones del sistema PS3™ que se pueden utilizar a través de la función de uso a distancia varían en función del tipo de dispositivo que esté utilizando. Con un sistema PS Vita o un sistema PSP™ están disponibles las funciones siguientes:

  • (Ajustes) *1
  • (Foto) *1
  • (Música)
  • (Vídeo) *2
  • (Juego) *1*3
  • (Red)
  • (PlayStation™Network) *1
  • (Amigos)

*1

Únicamente algunas características limitadas se pueden cambiar a través del uso a distancia.
*2

Los discos Blu-ray Disc y DVD no pueden reproducirse. Tampoco es posible reproducir archivos de vídeo protegidos por derechos de autor.
*3

Algunos juegos admiten el uso a distancia.
  • Acerca del menú XMB™
  • Usuarios
  • Ajustes
  • Foto
  • Música
  • Vídeo
  • Servicios de TV/Vídeo
  • Juego
  • Red
  • PlayStation™Network
  • Amigos
