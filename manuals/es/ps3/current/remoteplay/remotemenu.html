Operaciones durante el uso a distancia

Durante el uso a distancia, los botones del sistema PS Vita o del sistema PSP™ se utilizan para controlar el sistema PS3™.

Uso de un sistema PS Vita para controlar el sistema PS3™

Durante el uso a distancia, puede controlar la mayoría de las funciones del sistema PS3™ mediante los botones del sistema PS Vita.
Puede controlar varias funciones mediante la barra de herramientas. Toque la pantalla para visualizar la barra de herramientas.


Funcionamiento del botón PS del sistema PS3™

Esta opción es una réplica de la acción de pulsar el botón PS en el mando inalámbrico del sistema PS3™.

1.

Toque la pantalla.

2.

Toque (PS).

Nota

El icono (PS) no admite las operaciones en las que mantiene pulsado el botón PS del mando inalámbrico del sistema PS3™ durante un segundo o más. Para apagar el sistema PS3™, toque (Apagar sistema) y, a continuación, siga las instrucciones que aparecen en pantalla.


Cambio de las asignaciones de los botones

Puede elegir entre las asignaciones [Tipo 1] y [Tipo 2] de los botones. Si elije [Tipo 2], puede realizar algunas operaciones si pulsa simultáneamente las combinaciones de botones que no están disponibles en el sistema PS Vita, como los botones L2 y R3.

1.

Toque la pantalla.

2.

Toque (Ajustes) > [Asignar botones].

3.

Toque el tipo de asignación de botones que desee utilizar.

Configuración de la calidad de imagen

Puede ajustar la calidad de imagen en [+1], [Estándar] o [-1].

1.

Toque la pantalla.

2.

Toque (Ajustes) > [Calidad de imagen].

3.

Toque la calidad de imagen deseada.

Nota

Según el entorno de red, con una alta calidad de imagen, el vídeo y el audio asociado se pueden entrecortar.


Restauración de los ajustes del uso a distancia

Para borrar el registro del dispositivo y restablecer las asignaciones de los botones y la configuración de la calidad de imagen a sus valores predeterminados:

1.

Toque la pantalla.

2.

Toque (Ajustes) > [Restaurar ajustes] > [Restaurar] > [OK].

Nota

También puede restablecer los ajustes desde la pantalla donde selecciona el método de conexión de uso a distancia. Toque (Opciones) > [Ajustes] > [Restaurar ajustes] y siga las instrucciones que aparecen en pantalla.


Cambio del modo de pantalla

Puede tocar dos veces la pantalla para cambiar el modo de pantalla.

Nota

No puede cambiar el modo de pantalla cuando la barra de herramientas se visualice en la pantalla ni mientras se encuentre en un juego.

Uso de un sistema PSP™ para controlar el sistema PS3™

Si utiliza un sistema PSP™ para el uso a distancia, cuando pulse el botón PS (botón HOME (menú principal)), aparecerá un menú para controlar el sistema PS3™.

Elementos del menú

Los elementos del menú disponibles en el sistema PSP™ pueden variar según la versión del software del sistema en uso.

Botón PS Permite efectuar las mismas operaciones que el botón PS del mando inalámbrico.*1
Salir del uso a distancia Salir del uso a distancia.

Salir y apagar el sistema PS3™: Salir del uso a distancia y, a continuación, apagar el sistema PS3™.

Salir sin apagar el sistema PS3™: Salir del uso a distancia y dejar el sistema PS3™ encendido. Seleccione esta opción si está utilizando el sistema PS3™ para copiar archivos, o para realizar descargas en segundo plano y otras tareas que requieren que el sistema esté encendido.
Ajustes Configure los ajustes relacionados con los botones del sistema PSP™.

Asignar botones: Utilice los botones del sistema PSP™ de la misma manera que los botones del mando inalámbrico del sistema PS3™. Seleccione uno de los dos tipos de asignación.

Ajustes de comunicación: Defina la velocidad de respuesta de los botones del sistema PSP™. Seleccione uno de los cinco niveles que combinan velocidad de respuesta con calidad de imagen, o seleccione [Personalizados].*2
Estado de la conexión Ajústelo para visualizar el estado de conexión del uso a distancia.
*1

No se admiten operaciones en las que se pulsa el botón PS durante como mínimo 2 segundos.
*2

A pesar de que el ajuste de [Velocidad de respuesta] y [Calidad de imagen] al nivel máximo puede producir una velocidad de respuesta más rápida y una calidad de imagen superior, es posible que la imagen o el audio aparezcan distorsionados.
