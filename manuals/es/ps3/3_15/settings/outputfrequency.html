Frecuencia de salida

Ajuste la frecuencia de salida del contenido de música. Ajústela para que coincida con la del dispositivo de audio en uso.

48 kHz Configure este ajuste para emitir audio a una frecuencia de muestreo de 48 kHz.
44.1 / 88.2 / 176.4 kHz Configure este ajuste para emitir audio a la frecuencia de muestreo más elevada que permita el dispositivo utilizado. Seleccione entre 44.1, 88.2 o 176.4 kHz.

Notas

  • Puede aumentar la frecuencia de muestreo del contenido de música para emitir audio a 88,2 o 176,4 kHz.
  • Es necesario que se cumplan las condiciones siguientes para emitir audio a 88,2 kHz o 176,4 kHz.
  • - El dispositivo de audio debe admitir una frecuencia de muestreo de 88.2 kHz o 176.4 kHz.
  • - Debe seleccionarse [PCM Lineal 2 C. 88.2 kHz] o [PCM Lineal 2 C. 176.4 kHz] cuando está ajustado [HDMI] o [Salida digital (Óptica)] en (Ajustes) > (Ajustes de sonido) > [Ajustes de salida de audio].
  • Mientras se reproduce música o cuando (Ajustes) > (Ajustes de música) > [Frecuencia de salida] está establecida en [44,1 / 88,2 / 176,4 kHz], no se pueden usar las funciones de (Foto) ni (Navegador de Internet), entre otras. Para hacer uso de estas funciones, seleccione [48 kHz].
  • Es posible que el sonido no se pueda emitir desde el dispositivo si éste no admite frecuencias de 88.2 kHz ni 176.4 kHz. Asimismo, incluso si admite 88.2 kHz y 176.4 kHz, es posible que el sonido sea intermitente o que no se emita desde algunos dispositivos de audio. En este caso, deseleccione las casillas [PCM Lineal 2 C. 88.2 kHz] y [PCM Lineal 2 C. 176.4 kHz] en (Ajustes) > (Ajustes de sonido) > [Ajustes de salida de audio].
