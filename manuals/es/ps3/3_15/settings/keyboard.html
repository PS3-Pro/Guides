Registrar teclado / ratón

Configure los ajustes de un teclado o ratón.

Tipo de teclado

Establezca el tipo de teclado conectado al sistema mediante un cable USB o tecnología Bluetooth®.

Método de entrada del teclado

Establezca el método de entrada del teclado conectado al sistema mediante un cable USB o tecnología Bluetooth®. Este ajuste se encuentra disponible únicamente en los siguientes casos:

  • Cuando el idioma del sistema está configurado para mostrar caracteres de chino tradicional.
  • Cuando el idioma del sistema está configurado en japonés y el [Tipo de teclado] está ajustado en [Teclado japonés] o en [Teclado inglés (estándar EE. UU.)].

Asignación de tecla

Ajuste la asignación de teclas para el teclado. Este ajuste se encuentra disponible únicamente cuando el idioma del sistema está ajustado en japonés y el [Tipo de teclado] está ajustado en [Teclado japonés] o en [Teclado inglés (estándar EE. UU.)].

Intervalo de repetición de tecla

Establezca el tiempo que debe transcurrir antes de que se repita un carácter cuando mantiene pulsada una tecla en un teclado USB o Bluetooth®.

Velocidad de repetición de tecla

Establezca la velocidad a la que debe repetirse un carácter cuando mantiene pulsada una tecla en un teclado USB o Bluetooth®.

Tipo de ratón

Establezca el tipo de ratón conectado mediante un cable USB o tecnología Bluetooth®. Establezca el tipo en función de la mano que utilice para controlar el ratón.

Velocidad del puntero

Permite ajustar la velocidad de movimiento del puntero del ratón.
