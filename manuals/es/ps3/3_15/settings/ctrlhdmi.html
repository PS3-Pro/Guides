Control por HDMI

Esta función solo está disponible en la serie CECH-2000 del sistema PS3™.


Si conecta el sistema PS3™ y un televisor BRAVIA™ (producto de Sony Corporation) compatible con la función BRAVIA™ Sync mediante un cable HDMI, puede usar el mando a distancia del televisor para controlar tanto el sistema PS3™ como el televisor.

No Se desactiva la función Control por HDMI.
Sí Se activa la función Control por HDMI.

Funciones disponibles en el sistema PS3™

Reproducción mediante una pulsación Al encender el sistema PS3™, se enciende también el televisor conectado y la entrada de vídeo del sistema PS3™ se selecciona automáticamente.

Funciones disponibles en el televisor

Reproducción mediante una pulsación Si pulsa el botón LINK del mando a distancia del televisor y selecciona [PS3™] desde el menú del televisor, el sistema PS3™ se encenderá.
Control del menú con el mando a distancia El mando a distancia del televisor se puede usar para controlar algunas funciones del sistema PS3™.
Apagado de dispositivos conectados al mismo tiempo Si apaga el televisor, se apagará también el sistema PS3™ conectado (entrará en el modo de espera).

Notas

  • Las funciones BRAVIA™ Sync disponibles varían en función del televisor que se utilice. Para obtener más información, consulte el manual de instrucciones suministrado con el televisor.
  • Aunque se seleccione [Sí], es posible que esta función no esté disponible en los siguientes casos:
  • - Si utiliza determinadas funciones del sistema PS3™, como juegos o reproducción de vídeo.
  • - Si el sistema PS3™ no se ha seleccionado como fuente de entrada del televisor.
  • BRAVIA™ Sync (Control por HDMI) es una función que permite la interoperabilidad de dispositivos conectados mediante la especificación CEC (Consumer Electronics Control), que forma parte de la especificación HDMI. Esta función solo se encuentra disponible en dispositivos Sony compatibles con la función Control por HDMI. Los productos desarrollados por otras empresas compatibles con la especificación CEC pueden funcionar con Control por HDMI, pero no se garantiza que todas las funciones sean compatibles con estos productos.
