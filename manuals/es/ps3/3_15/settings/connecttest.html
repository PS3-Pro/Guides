Prueba de conexión a Internet

Permite probar la conexión a Internet y visualizar los resultados.

Obtener dirección IP Compruebe si se ha obtenido una dirección IP.
Conexión a Internet Compruebe si se ha establecido la conexión a Internet.
PlayStation®Network* Compruebe si ha sido posible iniciar sesión en PlayStation®Network o no.
UPnP* Compruebe el estado de UPnP (Universal Plug and Play).

Disponible: puede utilizar UPnP.

No disponible: no puede utilizar UPnP.

Desactivado: se ha desactivado UPnP en los ajustes de red del sistema PS3™.
Tipo de NAT* Compruebe cómo se ha conectado el sistema PS3™ a Internet. Esta información puede utilizarse para determinar la facilidad o la dificultad de conexión de otros sistemas PS3™ cuando se utiliza el chat de voz o vídeo o las funciones de comunicación de los juegos.

Tipo 1: conectado directamente a Internet.

Tipo 2: conectado a Internet mediante un router.

Tipo 3: conectado a Internet mediante un router.

Con el tipo 3, es posible que no pueda comunicarse con otros sistemas PS3™ y que las funciones de chat de voz y vídeo, y de comunicación de los juegos se vean restringidas. En ese caso, consulte [Conexión a PlayStation®Network] en esta guía.
Velocidad de conexión (descarga) Compruebe la velocidad de conexión a la cual el sistema PS3™ descarga datos de Internet.
Velocidad de conexión (subida) Compruebe la velocidad de conexión a la cual el sistema PS3™ carga datos en Internet, como la transmisión de un mensaje.
*

Se muestra únicamente si se ha creado una cuenta PlayStation®Network.

Notas

  • Si aparece [Error] como resultado de [Obtener dirección IP] o [Conexión a Internet], siga las instrucciones en pantalla para comprobar los ajustes de red. Es posible definir los ajustes de red en (Ajustes) > (Ajustes de red) > [Ajustes de conexión a Internet]. Si desea obtener más información acerca de los ajustes necesarios, consulte la información de su proveedor de servicios de Internet o las instrucciones suministradas con el dispositivo de red.
  • Puede crear una cuenta de PlayStation®Network en （PlayStation®Network） > (Inscribirse en PlayStation®Network).
  • Si aparece [Ninguna] para [UPnP], es posible que el dispositivo de red que se está utilizando no sea compatible con UPnP o que UPnP esté desactivado en los ajustes de red. Si desea obtener más información, consulte las instrucciones suministradas con el dispositivo de red.
  • Si aparece [Tipo 3] en [Tipo de NAT], es posible que el sistema PS3™ o el dispositivo de red no puedan utilizar UPnP. Compruebe el elemento [UPnP].
  • Un router es un dispositivo que permite la conexión de varios dispositivos a una única línea de Internet.

Conexión a PlayStation®Network

Si utiliza PlayStation®Network en una oficina o en un complejo de viviendas, es posible que las funciones de seguridad como el firewall bloqueen las comunicaciones. En este caso, consulte las siguientes instrucciones.

En PlayStation®Network, es posible comunicarse con servidores PlayStation®Network de Internet o directamente con otros sistemas PS3™. La comunicación con servidores de PlayStation®Network de Internet se efectúa principalmente:

  • Al iniciar/finalizar sesión.
  • Al utilizar la lista de amigos o la lista de bloqueados.
  • Al intercambiar mensajes.
  • Al utilizar (PlayStation®Store).

Los números de puerto de los servidores de PlayStation®Network utilizados para esto son TCP: 80, 443, 5223 y UDP: 3478, 3479.

Para el chat de voz o vídeo y los juegos online, se utiliza la comunicación directa con otros sistemas PS3™ para la transmisión de dichos datos. El número de puerto utilizado para ello es UDP: 3658. Sin embargo, es posible que necesite utilizar un número de puerto diferente cuando esté conectado mediante un router NAT.

Notas

  • Si utiliza un router, es posible que la comunicación directa con otros sistemas PS3™ esté restringida en función del tipo de router y de sus ajustes. Si utiliza un router compatible con UPnP, active la función UPnP.
  • Es posible que el router o las funciones de seguridad facilitadas por el proveedor de servicios de Internet restrinjan la comunicación. Consulte las instrucciones suministradas con el dispositivo de red y la información de su proveedor de servicios de Internet.
