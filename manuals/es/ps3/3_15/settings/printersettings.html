Ajustes de impresora

Configure los ajustes para una impresora o confirme el estado de la impresora. Es posible utilizar una impresora que se encuentre conectada al sistema PS3™ a través de un cable USB o de una red.

Notas

  • Las impresoras que se pueden utilizar varían en función del país o la región. Para obtener más información, visite el sitio Web de SCE de su región.
  • No se pueden conectar impresoras HP al sistema PS3™ mediante una conexión USB.

Administración de impresoras

Confirme el estado de la impresora que se encuentra conectada al sistema PS3™.

Selección de impresora

Permite seleccionar la impresora que se va a utilizar. Siga las instrucciones que aparecen en pantalla para seleccionar la impresora.

Nota

Si selecciona [Otro (estándar de red)], se mostrará una lista de todas las impresoras que se encuentran disponibles en la red del sistema PS3™ independientemente del fabricante de la impresora.

  • Acerca del menú XMB™
  • Usuarios
  • Ajustes
  • Foto
  • Música
  • Vídeo
  • Juego
  • Red
  • PlayStation®Network
  • Amigos
