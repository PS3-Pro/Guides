Sistema predeterminado

Puede establecer qué software del sistema desea utilizar de manera predeterminada al encender el sistema. Este ajuste está disponible únicamente si hay otras opciones de software del sistema instaladas en el disco duro.

PS3™ Permite iniciar el software del sistema PS3™.
Otro sistema operativo Permite iniciar otro software del sistema que esté instalado en el disco duro.

Notas

  • Para volver a ajustar el sistema predeterminado en el software del sistema estándar PS3™, consulte el manual de instrucciones suministrado con el software del otro sistema que esté utilizando.
  • Aunque se establezca otro software del sistema como el sistema predeterminado, el software del sistema PS3™ estándar se iniciará si toca el botón de encendido situado en la parte frontal del sistema durante más de cinco segundos al activar la alimentación.
