Ajustes de seguridad

Puede establecer los ajustes de seguridad del sistema.

Nota

Estos ajustes permiten controlar el contenido local (contenido digital almacenado en el disco duro o en los soportes de almacenamiento y discos). Tenga en cuenta que estos ajustes no restringen el acceso al contenido online.


Cambiar contraseña

Permite cambiar la contraseña necesaria para establecer los ajustes del sistema. Es necesaria una contraseña en los siguientes casos:

  • Para reproducir contenido con restricciones de control paterno.
  • Para cambiar el nivel de control paterno del sistema o el ajuste del control de inicio del navegador de Internet.
  • Para iniciar el navegador con el control de inicio del navegador de Internet ajustado en [Sí].
  • Para cambiar la contraseña actual.

Anote la contraseña que establezca. La contraseña viene ajustada en [0000] de manera predeterminada.

Nota

Si selecciona (Ajustes) > (Ajustes del sistema) > [Restablecer ajustes predeterminados], podrá volver a ajustar la contraseña en [0000]. Tenga en cuenta que también se restablecerán los valores predeterminados del resto de ajustes.

Control paterno de BD

Permite ajustar el nivel de reproducción de los discos Blu-ray (BD) ajustados con restricciones de control paterno. Para cambiar este ajuste, es necesario introducir una contraseña.

No restringir (desactivado) Permite reproducir cualquier BD sin tener en cuenta el nivel de control paterno.
Restringir (activado) Permite reproducir solamente los BD que presenten el nivel de control paterno especificado.

Una vez ajustado [Restringir (activado)], podrá seleccionar una restricción de edad en la siguiente pantalla. Tenga en cuenta que cuanto menor sea el valor, mayor será la restricción.

Código de región de control paterno BD / DVD

Permite ajustar una región como base de los niveles de control paterno estándar para discos BD y DVD. Para cambiar este ajuste, es necesario introducir una contraseña.

Estados Unidos Permite ajustar los niveles de control paterno estándar de Estados Unidos.
Otros Permite ajustar niveles de control paterno estándar de otras regiones.

Si selecciona [Otros], podrá seleccionar una región en la siguiente pantalla.

Control paterno de DVD

Permite ajustar el nivel de reproducción de los discos DVD con control paterno. Para cambiar este ajuste, es necesario introducir una contraseña.

No Permite reproducir cualquier DVD sin tener en cuenta el nivel de control paterno.
Nivel 8-1 Permite reproducir solamente los DVD que presenten el nivel de control paterno especificado.

Tenga en cuenta que cuanto menor sea el valor, mayor será la restricción.

Control paterno

Permite ajustar el nivel de reproducción de los juegos con restricciones de control paterno. Para cambiar este ajuste, es necesario introducir una contraseña.

No Permite reproducir cualquier contenido sin tener en cuenta el nivel de control paterno.
Nivel 11-1 Permite reproducir solamente contenido con un nivel de control paterno inferior o igual al especificado.

Tenga en cuenta que cuanto menor sea el valor, mayor será la restricción. Si selecciona [Restringir el inicio de juegos sin ajustes de control paterno], podrá restringir el uso de juegos sin nivel especificado para su región.

Notas

  • Los ajustes de control paterno de los juegos variarán en función de la región de venta. Para obtener más información al respecto, visite el sitio Web de SCE de su región. Según la región, es posible que algunos manuales de software contengan o no información acerca de estos ajustes.
  • Los niveles de control paterno varían según el juego.

Control de inicio del navegador de Internet

Permite restringir la capacidad de iniciar el navegador de Internet. Para cambiar este ajuste, es necesario introducir una contraseña.

No Para no utilizar el control de inicio.
Sí Para utilizar el control de inicio. Para iniciar el navegador, es necesario introducir una contraseña.
