Instalar otro sistema operativo

Esta función no está disponible en los sistemas de la serie CECH-2000.


Puede instalar otro software del sistema en el disco duro. Para obtener más información sobre los tipos de software del sistema compatibles y cómo adquirir el instalador, visite Open Platform for PlayStation®3.

Avisos

  • No apague el sistema PS3™ ni extraiga el disco o el soporte de almacenamiento durante la instalación. Si lo hace, puede provocar daños en el software del sistema.
  • Durante esta operación, el botón de encendido de la parte frontal del sistema y el botón PS del mando inalámbrico están inactivos.

1.

Inserte el soporte de almacenamiento que contiene el instalador en el sistema.

2.

Seleccione (Ajustes) > (Ajustes del sistema).

3.

Seleccione [Instalar otro sistema operativo].
El sistema buscará el instalador. Una vez encontrado el instalador, se mostrará el contenido y ubicación del mismo.

4.

Compruebe el contenido del instalador y, a continuación, seleccione [Iniciar].
Después de comprobar el instalador, la instalación se iniciará automáticamente.

Notas

  • Para iniciar el software del sistema recién instalado, diríjase a (Ajustes) > (Ajustes del sistema) > [Sistema predeterminado] y, a continuación, seleccione [Otro sistema operativo] para reiniciar el sistema.
  • Para poder utilizar los soportes de almacenamiento con determinados modelos de sistema PS3™, necesitará un adaptador USB apropiado (no incluido).
