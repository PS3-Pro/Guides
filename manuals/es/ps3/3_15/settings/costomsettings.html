Ajustes de conexión personalizados

Este ajuste está disponible únicamente en los sistemas PS3™ equipados con la función de red LAN inalámbrica.


Si un sistema PSP™ se ha registrado en un sistema PS3™ equipado con función de red LAN inalámbrica, se creará automáticamente una conexión de red para uso a distancia con un SSID y una clave de encriptación (clave WPA) específicos entre ambos sistemas, que podrán comunicarse entre sí en modo infraestructura. Si selecciona [Ajustes de conexión personalizados], podrá cambiar manualmente el SSID y la clave de encriptación definidos en el sistema PS3™. Generalmente, no es necesario realizar estos ajustes.

SSID Defina el SSID.

Puede introducir el SSID que desee.
Ajuste de seguridad WLAN Defina el método de seguridad.

Sólo puede seleccionar [WPA-PSK (AES)] para los ajustes de uso a distancia.
Clave WPA Para ajustar una clave de encriptación.

Puede introducir la clave que desee. La clave de encriptación se visualiza como una serie de asteriscos. Necesitará la clave que defina en este momento para cambiar la conexión de red del sistema PSP™. Anote la clave para consultarla en el futuro.

Nota

Si se cambian el SSID y la clave WPA del sistema PS3™, los nuevos ajustes también deberán aplicarse al SSID y a la clave WPA de la conexión de red del sistema PSP™. Asegúrese de volver a registrar el sistema PSP™ después de cambiar estos valores.
