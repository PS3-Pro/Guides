Si olvida su contraseña

Para utilizar esta función, debe mantener siempre el software del sistema actualizado con la versión más reciente.


Es posible utilizar el siguiente método para restablecer su contraseña si la olvida.

1.

Seleccione (PlayStation®Network) > (Iniciar sesión).

2.

Seleccione [¿Olvidó su contraseña?] en la pantalla de ID de inicio de sesión (dirección de correo electrónico) y contraseña.

3.

Introduzca el ID de inicio de sesión (dirección de correo electrónico) y la fecha de nacimiento.

4.

Seleccione el método para cambiar la contraseña.

Restablecer utilizando la pregunta de seguridad Puede restablecer su contraseña si proporciona la respuesta a la pregunta de seguridad seleccionada cuando creó su cuenta PlayStation®Network.

Siga las instrucciones que aparecen en la pantalla para completar la operación.
Restablecer utilizando el correo electrónico Puede restablecer su contraseña utilizando un ordenador.

Se enviará un mensaje de correo electrónico a la dirección utilizada como ID de inicio de sesión. Siga los pasos que se indican en el mensaje de correo electrónico para restablecer la contraseña utilizando un ordenador.
