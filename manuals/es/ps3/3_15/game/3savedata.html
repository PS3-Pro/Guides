Uso de datos guardados

Los datos guardados para software de formato PlayStation®3 se guardan en el disco duro del sistema. Los datos se muestran en (Herramienta de datos guardados).


Notas

  • Los datos guardados son gestionados individualmente por cada usuario. Si la categoría (Usuarios) contiene más de un usuario, los elementos que aparecen en (Herramienta de datos guardados) variarán en función del usuario que haya iniciado sesión.
  • Si selecciona el icono correspondiente a los datos guardados y pulsa el botón , puede organizar los datos guardados por fecha de actualización o los datos guardados del grupo por título en el menú que se muestra.
