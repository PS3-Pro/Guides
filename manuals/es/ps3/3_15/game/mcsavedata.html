Uso de datos guardados en una Memory Card (tarjeta de memoria)

Para utilizar los datos guardados en una Memory Card (tarjeta de memoria) (8MB) (para PlayStation®2) o una Memory Card para jugar a un juego, debe copiar los datos en una Memory Card interna del disco duro. Debe utilizar un adaptador para Memory Card (tarjeta de memoria) (se vende por separado) para copiar los datos.

Avisos

  • Es posible que algunos títulos de software de formato PlayStation®2 o PlayStation® funcionen de manera diferente en el sistema PS3™ que en los sistemas PlayStation®2 o PlayStation®, o que no funcionen correctamente en el sistema PS3™.
  • Además, el software de formato PlayStation®2 no puede reproducirse en algunos sistemas PS3™. Para obtener más información, consulte [Tipos de discos que se pueden reproducir], visite el sitio Web de SCE de su región o revise la documentación suministrada con su sistema PS3™.

1.

Seleccione (Juego) > (Herramienta de Memory Card (PS/PS2)).

2.

Conecte el adaptador para Memory Card (tarjeta de memoria) al sistema PS3™ e inserte una Memory Card (tarjeta de memoria).
Se mostrará un icono para (Memory Card (PS)) o (Memory Card (PS2)).

3.

Seleccione el icono correspondiente a los datos guardados que desea copiar desde la Memory Card (tarjeta de memoria) visualizada y, a continuación, pulse el botón .

4.

Seleccione [Copiar].
Seleccione el destino en el que desea efectuar la copia. Si no se indican destinos, seleccione (Crear nueva Memory Card interna) y, a continuación, siga las instrucciones en pantalla para crear una Memory Card interna.

5.

Asignar ranuras
Seleccione la Memory Card interna que desea utilizar de (Herramienta de Memory Card (PS/PS2)) y, a continuación, pulse el botón . Seleccione [Asignar ranuras] del menú de opciones.

Notas

  • Según el tipo de datos, los datos guardados en una Memory Card (tarjeta de memoria) (8MB) (para PlayStation®2) o una Memory Card (tarjeta de memoria) se copiarán en una Memory Card interna tal como se muestra a continuación.

  • Es posible que la copia de determinados datos guardados tarde varios minutos.
  • Para copiar todos los datos guardados en una Memory Card (tarjeta de memoria) o una Memory Card (tarjeta de memoria) (8MB) (para PlayStation®2), seleccione la tarjeta de memoria en el paso 3, pulse el botón y, a continuación, seleccione [Copiar] en el menú de opciones.
  • Es posible que la copia de determinados datos guardados no esté permitida. Cuando utilice este tipo de datos en un sistema PS3™, seleccione [Mover] en el paso 4. Los datos guardados se moverán al disco duro y se eliminarán de la tarjeta de memoria.
  • Posteriormente podrá copiar los datos almacenados de nuevo en la Memory Card (tarjeta de memoria).

Copia de datos guardados a una Memory Card (tarjeta de memoria)

Copie los datos de software de formato PlayStation® y PlayStation®2 guardados en el disco duro a una Memory Card (tarjeta de memoria) o una Memory Card (tarjeta de memoria) (8MB) (para PlayStation®2). Es necesario utilizar un adaptador para tarjetas de memoria (a la venta por separado) para copiar los datos.

1.

Seleccione (Juego) > (Herramienta de Memory Card (PS/PS2)).

2.

Conecte el adaptador para Memory Card al sistema PS3™ e introduzca una Memory Card.

3.

Seleccione el icono correspondiente a los datos guardados que desea copiar de (Memory Card (PS) interna) o (Memory Card (PS2) interna) donde se encuentran guardados los datos y, a continuación, pulse el botón .

4.

Seleccione [Copiar].
Especifique (Memory Card (PS)) o (Memory Card (PS2)) como el destino en el que desea efectuar la copia.

Notas

  • No es posible copiar de forma colectiva varios elementos de datos guardados en una Memory Card (tarjeta de memoria) interna a una Memory Card (tarjeta de memoria).
  • Es posible que la copia de determinados datos guardados no esté permitida. Al utilizar dichos datos en un sistema PS3™, seleccione [Mover] en el paso 4. Los datos guardados se copiarán en el disco duro y se eliminarán de la Memory Card (tarjeta de memoria) interna.
  • Posteriormente podrá copiar los datos almacenados de nuevo en la Memory Card (tarjeta de memoria).
