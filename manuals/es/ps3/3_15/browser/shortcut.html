Uso de las teclas de método abreviado, del ratón y del teclado

Uso de las teclas de método abreviado

Puede utilizar directamente los botones del mando inalámbrico sin utilizar el menú. Las operaciones disponibles varían según se encuentre en los modos navegación o ventana.

Modo navegación
Botón Abre el vínculo.
Botón (mantener pulsado) Abre el vínculo en una ventana nueva.
Botón + joystick izquierdo Permite seleccionar texto.
Botón Muestra el menú.
Botón Cierra el (Navegador de Internet).
Botón (mantener pulsado) Cierra la ventana. *1
Botón START (Iniciar) Introduce una dirección.
Botón SELECT (selección) Abre [Mis marcadores].
Botones L1 / R1 Permiten retroceder o avanzar una página.
Botones L2 / R2 Permiten desplazarse hasta otra ventana. *2
Botones direccionales Permiten desplazar el puntero hasta un vínculo en la dirección del botón pulsado.
Botón + botón direccional Permite desplazarse por la página en la dirección del botón que se ha pulsado.
Joystick izquierdo Permite desplazar el puntero en la dirección deseada.
Joystick izquierdo (pulsar) (botón L3) Cambia al modo ventana.
Joystick derecho Permite desplazarse en la dirección deseada.
Joystick derecho (pulsar) (botón R3) Permite utilizar la pantalla Zoom / cancelar zoom.
Botón PS Muestra el menú XMB™.
*1

Esta operación no puede realizarse durante la utilización del zoom.
*2

Se ampliará o reducirá durante la utilización del zoom.
Modo ventana
Botón Muestra la ventana seleccionada en el modo navegación.
Botón Muestra el menú.
Joystick izquierdo (pulsar) (botón L3) Cambia al modo navegación.
Botones direccionales Permiten desplazarse hasta otra ventana.
Botón PS Muestra el menú XMB™.

Uso del ratón (no incluido)

Realice las operaciones con un ratón disponible en el mercado.

Arrastre el puntero hacia la izquierda mientras mantiene pulsado el botón derecho del ratón Volver a la página anterior.
Arrastre el puntero hacia la derecha mientras mantiene pulsado el botón derecho del ratón Ir a la página siguiente.

Uso del teclado (no incluido)

Utilice un teclado disponible en el mercado.

CTRL + L (o F4) Permite introducir una dirección.
CTRL + R (o F5) Permite actualizar la página.
CTRL + B (o CTRL + I) Permite abrir [Mis marcadores].
Retroceder página (o Mayús + Barra espaciadora) Permite desplazarse hacia arriba.
Avanzar Página (o Barra espaciadora) Permite desplazarse hacia abajo.
Inicio Permite desplazarse al inicio de la página.
Fin Permite desplazarse al final de la página.
TAB Permite mover el cursor.
ALT + Flecha izquierda (o Retroceso) Permite volver a la página anterior.
ALT + Flecha derecha (o Mayús + Retroceso) Permite ir a la página siguiente.
CTRL+ Flecha izquierda (o CTRL + Mayús + TAB) Permite desplazarse hacia la ventana izquierda.
CTRL+ Flecha derecha (o CTRL + TAB) Permite desplazarse hacia la ventana derecha.
