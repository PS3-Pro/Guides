Obtención o edición de información de un CD de audio

Obtención de información de un CD de audio

Cuando introduce un CD de audio, el sistema PS3™ se conecta automáticamente a Internet y obtiene información sobre dicho CD. Para obtener información del CD, primero deberá aceptar el acuerdo de usuario que aparece en la pantalla.

Notas

  • Asimismo, es posible obtener información del CD desde el menú de opciones. Con el icono de CD seleccionado, pulse el botón y, a continuación, seleccione [Obtener información de CD]. Siga las instrucciones en pantalla para completar la operación.
  • Si no ha obtenido información del CD, no se mostrarán los nombres del álbum y las pistas cuando introduzca el CD en el sistema.

Edición de información de un CD de audio

Puede editar la información obtenida de un CD. Con el CD de audio o el icono correspondiente a la pista seleccionado, pulse el botón y, a continuación, seleccione [Información] en el menú de opciones. Seleccione el elemento que desee editar.

Notas

  • También es posible enviar información modificada a través de Internet a la compañía All Media Guide si la información del CD obtenida automáticamente mediante el sistema PS3™ no es correcta. Seleccione el icono correspondiente al CD de audio, pulse el botón y, a continuación, seleccione [Enviar información de CD] en el menú de opciones.
  • La compañía All Media Guide ofrece una base de datos de información de CD.
  • No es posible enviar información a All Media Guide si los campos [Álbum], [Artista] y [Género] están vacíos.
  • No es posible cambiar ni enviar información de CD de discos Super Audio CD.

Aviso

Los discos Super Audio CD no se pueden reproducir en ciertos sistemas PS3™. Para más información, consulte [Tipos de discos que se pueden reproducir].
