遊戲設定

調整PlayStation®2 / PlayStation®規格軟件的輸出設定。

重要

  • 部分PlayStation®2、PlayStation® 規格之軟件可能會於插入PS3™啟動時，出現與以往之PlayStation®2 或PlayStation® 主機不同的動作，或是無法正常啟動的現象。
  • 此外，部份PS3™並不支援PlayStation®2規格光碟的播放。詳細請參閱[關於可播放的光碟種類]、各區域的官方網站或主機隨附的使用說明書。

PS - 向上轉換

替以SD解析度(NTSC：480p / 480i、PAL：576p / 576i)錄製的影像，自動轉換並以HD解析度(1080p / 1080i / 720p)顯示的機能。因PlayStation®2 / PlayStation®規格軟件皆是以SD解析度錄製影像，故能向上轉換輸出。因此，只需啓用向上轉換輸出，即可享受到解析度更高的精緻影像。

關 停用向上轉換輸出。
標準 配合螢幕尺寸並向上轉換輸出。
全景 不變更縱橫比，但延伸圖像至整個螢幕中並向上轉換輸出。

提示

  • 若要使用此機能，需經由HDMI連接線或影像色差連接線連接支援HD高清輸出的電視機。其次，PS3™的影像輸出設定需調整為1080p、1080i、720p。
  • 向上轉換輸出時若出現圖像紛亂或感覺不自然的情形，請調整為［關］。
  • 此項目在部份機型上會顯示為[PS／PS2 - 向上轉換]。

PS - 平滑化

關 停用平滑化處理。
開 降低圖像的粗糙後顯示。

重要

  • 部分軟件若調整為［開］，可能會出現平滑化效果不明顯或難以辨識，以及圖像紛亂的情形。此時請調整為［關］。
  • 此項目在部份機型上會顯示為[PS／PS2 - 平滑化]。
