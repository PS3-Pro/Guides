網路連線測試

進行與網路間的連線測試，並顯示結果。

取得IP位址 顯示是否可取得IP位址。
網路連線 顯示是否可與網路連線。
PSNSM* 顯示是否能登入PSNSM。
UPnP* 顯示UPnP（Universal Plug and Play）的利用狀況。

有：可使用UPnP。

無：不可使用UPnP。

無效：將PS3™網路設定的UPnP設定為無效。
NAT類型* 顯顯示PS3™與網路的連線方式。使用AV聊天或遊戲的通訊機能等時候，可確認與其他PS3™間的連線穩定性。

Type 1：與網路直接連線。

Type 2：透過路由器與網路連線。

Type 3：透過路由器與網路連線。

顯示［Type 3］時，可能會出現無法與其他PS3™順利通訊，AV聊天或遊戲之通訊機能受到限制的情形。此時請參閱［與PLAYSTATION®Network的連線］。
連線速度（下載） 顯示在PS3™閱覽網路上的情報時的連線速度。
連線速度（上傳） 顯示傳送簡訊等從PS3™將資料傳送至網路時的連線速度。
*

僅於建立（登入）Sony Entertainment Network帳戶時顯示。

提示

  • 選擇［取得IP位址］或［網路連線］但顯示［失敗］時，請遵循畫面指示，再度確認設定內容。選擇（設定）＞（網路設定）＞［網路連線設定］，即可變更網路設定。同時亦請參閱網路服務商提供之資料和您使用之網路裝置隨附的使用說明書。
  • 選擇（PlayStation™Network）＞（登入），即可建立帳戶。
  • ［UPnP］顯示［無］時，代表您使用的網路裝置可能不支援UPnP或網路裝置的UPnP被調整為停用或無效。詳細請參閱網路裝置隨附的使用說明書。
  • ［NAT類型］顯示［Type 3］時，代表您使用的PS3™或網路裝置可能暫時無法使用UPnP。請確認［UPnP］項目的設定內容。
  • 路由器（Router）乃是能讓數種裝置同時共有一條網路線的裝置。

與PSNSM的連線

在辦公室或集合住宅等地方使用PSNSM時，可能會因防火牆等安全性（加密）機能，而出現通訊遭阻擋的情形。此時請參考以下資訊。

進入PSNSM後，會與網路上的PSNSM伺服器通訊並與其他PS3™直接通訊。主要會於下列場合與網路上的PSNSM伺服器進行通訊。

  • 登入／登出
  • 利用好友名單／黑名單
  • 交換簡訊
  • 利用（PlayStation®Store）

此時使用的PSNSM伺服器之Port碼為TCP : 80, 443,  3478, 3479, 3480, 5223, 8080 以及UDP : 3478, 3479。

使用AV聊天或線上遊戲的通訊對戰時，會與其他PS3™直接通訊。此時使用的Port碼為UDP : 3658。不過，若經由NAT路由器連線，可能會使用不同的Port碼。

提示

  • 使用Router（路由器）時，可能會因路由器的種類或設定，而限制與其他PS3™間的直接通訊。使用支援UPnP的路由器時，請務必啟用UPnP機能。
  • 通訊可能因路由器或網路服務商提供的安全性（加密）機能而受到限制。請同時參閱您使用之網路裝置隨附的使用說明書和網路服務商提供之資料。
