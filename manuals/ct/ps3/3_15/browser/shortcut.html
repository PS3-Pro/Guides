使用快捷鍵／滑鼠／鍵盤操作

使用快捷鍵操作

亦可不使用選單，透過無線控制器的按鈕操作。可操作之項目內容會因選擇瀏覽模式或視窗模式而異。

瀏覽模式
按鈕 開啟超連結。
按鈕（長按） 新增視窗開啟超連結。
按鈕＋左操作桿 選擇文字。
按鈕 顯示選單。
按鈕 關閉（網路瀏覽介面）。
按鈕（長按） 關閉視窗。*1
START（開始）按鈕 輸入位址
SELECT（選擇）按鈕 開啟［我的書籤］。
L1按鈕／R1按鈕 回到上一頁／進入下一頁。
L2按鈕／R2按鈕 移往其他視窗。*2
方向按鈕 讓指標移往方向按鈕之按下方向的超連結。
按鈕＋方向按鈕 朝方向按鈕推動的方向捲動網頁。
左操作桿 朝希望的方向移動指標。
左操作桿（按壓）（L3按鈕） 更換為視窗模式。
右操作桿 朝希望的方向捲動。
右操作桿（按壓）（R3按鈕） 啟動／解除縮放顯示。
PS按鈕 顯示XMB™。
*1

縮放時無法操作。
*2

縮放時為擴大／縮小。
視窗模式
按鈕 以瀏覽模式顯示選擇的視窗。
按鈕 顯示選單。
左操作桿（按壓）（L3按鈕） 更換為瀏覽模式。
方向按鈕 移動視窗。
PS按鈕 顯示XMB™。

使用滑鼠操作

可使用市售的滑鼠操作。

按住右鍵時往左拖動 回到上一頁。
按住右鍵時往右拖動 進入下一頁。

使用鍵盤操作

使用市售的鍵盤操作。

CTRL + L / F4 輸入位址。
CTRL + R / F5 更新網頁。
CTRL + B / CTRL + I 開啟［我的書籤］。
PAGE UP / SHIFT + 空白鍵 往上捲動。
PAGE DOWN / 空白鍵 往下捲動。
Home 移動至網頁的最上方。
End 移動至網頁的最下方。
TAB 移動游標。
ALT + 向左鍵 / 退格鍵 回到上一頁。
ALT + 向右鍵 / 退格鍵 進入下一頁。
CTRL+ 向左鍵 / CTRL + SHIFT + TAB 移往左邊的視窗。
CTRL+ 向右鍵 / CTRL + TAB 移往右邊的視窗。
