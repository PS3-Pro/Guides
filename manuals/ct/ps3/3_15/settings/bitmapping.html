設定 > 音樂設定 > Bitmapping

Bitmapping

可調整音樂內容的聲音輸出設定。請配合樂曲或喜好選擇設定。

關 停用Bitmapping。
Type 1 運用Dithering（細微過網）手法，降低輸出資料時引發的雜訊或扭曲。
Type 2 運用Noise shaper（噪音過濾）手法，降低可聆聽音域的雜訊。
Type 3 使用專為PS3™所獨自開發的技術，播放更細緻的音樂

提示

播放音樂內容時，僅於以88.2kHz、176.4kHz的周波數輸出聲音時，方可啟用此機能。若要以88.2kHz或176.4kHz的周波數輸出聲音，需滿足以下條件。

  • 您使用的音響裝置需支援88.2kHz或176.4kHz周波數。
  • （設定）＞（聲音設定）＞ [聲音輸出設定]設定為[HDMI]或[光纖]時，需選擇[Linear PCM 2ch 88.2 kHz]或[Linear PCM 2ch 176.4 kHz]。
  • （設定）＞（音樂設定）＞[輸出周波數]需設定為[44.1 / 88.2 / 176.4 kHz]。
