Bruke lagrede data på memory card

Hvis du vil bruke lagrede data på et Memory card (8MB) (for PlayStation®2) eller et Memory card for å spille et spill, må du kopiere dataene til et internt memory card i harddisken. Du må bruke en memory card adapter (selges separat) til å kopiere dataene.

Merknader

  • Enkelte PlayStation®2 eller PlayStation®-programvareformattitler kan ha en annen prestasjon på PS3™-systemet enn på PlayStation®2 eller PlayStation®-systemene, eller fungerer muligens ikke ordentlig med PS3™-systemet.
  • PlayStation®2 programvareformat kan dessuten ikke spilles av på enkelte PS3™-systemer. For mer informasjon, se [Typer plater som kan spilles av], besøk SCE-websiden for ditt område eller se dokumentasjonen som fulgte med PS3™-systemet.

1.

Velg (Spill) > (Memory Card tjeneste (PS / PS2)).

2.

Kople til minnekortadapteren til PS3™ systemet og sett inn et minnekort.
Et ikon for (Memory Card (PS)) eller (Memory Card (PS2)) vises.

3.

Velg ikonet for de lagrede dataene som du ønsker å kopiere fra det viste minnekortet, og trykk på -tasten.

4.

Velg [Kopi].
Velg målet å kopiere til. Hvis ingen mål er listet opp, velg (Lag nytt internt Memory Card) og følg instruksjonene på skjermen for å opprette et internt memory card.

5.

Tilordne spor
Velg det interne memory card du vil bruke, fra (Memory Card tjeneste (PS/PS2)), og trykk deretter på knappen. Velg [Tildel spor] fra alternativmenyen.

Tips

  • Lagrede data fra et Memory card (8 MB) (for PlayStation®2) eller et Memory card kopieres til et internt memory card som vist nedenfor, avhengig av datatypen.

  • For enkelte lagrede data, kan kopieringen ta opp til flere minutter.
  • For å kopiere alle lagrede data som er lagret på minnekortet (8MB) (for PlayStation®2) eller et minnekort, velg minnekort i trinn 3, trykk på -tasten, og velg dereter [Kopier] fra alternativmenyen.
  • Det kan være forbudt å kopiere noen lagrede data. Når du bruker slike data på et PS3™ system, velg [Flytt] i trinn 4. De lagrede dataene vil bli flyttet til harddisken og vil bli slettet fra minnet.
  • Du kan flytte lagrede data tilbake til minnekortet senere.

Kopiere lagrede data til et minnekort

Kopiere lagrede data fra PlayStation®2 / PlayStation® Formatering programvare som er lagret på harddisken til et minnekort eller til et minnekort (8 MB) (for PlayStation®2). Du må bruke en minnekortadapter (selges separat) for å kopiere dataene.

1.

Velg (Spill) > (Memory Card tjeneste (PS/PS2)).

2.

Kople til minnekortadapteren til PS3™-systemet og sett inn et minnekort.

3.

Velg ikonet til de lagrede dataene som du vil kopiere fra (Internt Memory Card (PS)) eller (Internt Memory Card (PS2)) der dataene ble lagret, og trykk deretter på -tasten.

4.

Velg [Kopi].
Spesifiser (Memory Card (PS)) eller (Memory Card (PS2)) som plassering der det skal kopieres til.

Tips

  • Flere lagrede dataelementer på et internt minnekort kan ikke kopieres samlet til et minnekort.
  • Det kan være forbudt å kopiere noen lagrede data. Når du bruker slike data på et PS3™-system, velg [Flytt] i trinn 4. De lagrede dataene blir flyttet til harddisken og blir slettet fra det interne minnekortet.
  • Du kan flytte lagrede data tilbake til minnekortet senere.
