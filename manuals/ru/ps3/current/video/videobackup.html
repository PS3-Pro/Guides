Резервное копирование или восстановление видеофайлов

Используйте функцию резервного копирования системы PS3™ для выборочного создания резервных копий материалов, загруженных из раздела Video Store магазина PlayStation®Store на носитель информации. Файлы, резервные копии которых созданы с помощью этой функции, можно будет восстановить на той же системе PS3™.

Резервное копирование видеофайла

Подключите носитель информации к системе PS3™. Выберите значок материалов, резервную копию которых вы хотите создать. Нажмите кнопку и выберите [Создать резервную копию] в меню параметров. Материалы будут сохранены в папке (Утилита резервного копирования данных), автоматически созданной на носителе информации.

Подсказки

  • Продажа и прокат видеоматериалов из PlayStation®Store для системы PS3™ прекращены.
  • Эту функцию можно использовать для резервного копирования данных на карты Memory Stick™, SD Memory Card, Compact Flash® и устройства-накопители USB. При использовании носителей информации с некоторыми моделями системы PS3™ требуется соответствующий адаптер USB (не входит в комплект поставки). Записываемые диски, например компакт-диски, использовать нельзя.
  • Резервную копию можно сохранить на жесткий диск USB. Следует учитывать, что диск распознается системой PS3™ только в том случае, если он отформатирован в файловой системе FAT32. Жесткий диск, отформатированный в NTFS (файловой системе NT), не будет распознан системой PS3™.
  • Резервные копии данных нельзя воспроизвести с носителя информации. Для воспроизведения эти данные нужно сначала восстановить на системный накопитель системы PS3™.

Восстановление резервной копии видеофайла

Резервные копии файлов, сохраненные на носителях информации, можно восстановить в системе PS3™.

1.

Подключите носитель информации с резервными копиями материалов к системе PS3™.

2.

Выберите значок носителя информации в меню (Видео).

3.

Выберите данные, которые вы хотите восстановить, в разделе (Утилита резервного копирования данных) и нажмите кнопку .

4.

Выберите [Восстановить].

Подсказки

  • Если название папки или файла с резервной копией данных были изменены, вы не сможете восстановить эти данные.
  • Вы не сможете успешно восстановить данные, если после сохранения резервной копии выполнялись перечисленные ниже действия.
  • - Форматирование системного накопителя
  • - Восстановление системы PS3™
  • В некоторых случаях не удастся воспользоваться функцией резервного копирования для создания резервной копии или правильного восстановления данных в системе.
