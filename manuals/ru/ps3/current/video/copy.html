Копирование/перемещение видеофайлов

Копирование на системный накопитель видеофайлов, сохраненных на носителе информации, копирование или перемещение импортированных файлов с системного накопителя на носитель информации. Выбрав файл, который необходимо импортировать или скопировать, нажмите кнопку , затем выберите в меню параметров [Копировать] или [Переместить]. Далее следуйте указаниям на экране.

Различия между копированием и перемещением

Доступные действия зависят от типа файлов. Видеофайлы, защищенные от копирования, можно только переместить. После перемещения в исходной папке файла уже не будет.

Платные материалы (тип файлов: MNV), записанные в разрешении HD и загруженные из PlayStation®Store, нельзя скопировать или переместить, но можно выборочно создать их резервные копии. Для выборочного создания резервных копий материалов, загруженных из раздела Video Store магазина PlayStation®Store, используйте функцию резервного копирования системы PS3™. Подробнее см. в разделе (Видео) > [Резервное копирование или восстановление видеофайлов] данного Руководства.

Подсказки

  • Продажа и прокат видеоматериалов из PlayStation®Store для системы PS3™ прекращены.
  • При копировании или перемещении видеофайлов с ограничениями доступа в рамках родительского контроля необходимо ввести пароль. Пароль можно задать в разделе [Изменить пароль] в меню (Настройки) > (Настройки безопасности).
  • В зависимости от используемого устройства некоторые скопированные файлы нельзя воспроизвести.
  • В зависимости от модели используемой системы PS3™ для использования носителя может потребоваться соответствующий адаптер USB (не входит в комплект поставки). Для перемещения видеофайлов на карту Memory Stick PRO™ требуется устройство USB, поддерживающее функцию защиты от копирования карты Memory Stick™ - например, система PSP™ или MRW-F3 (производства Sony).
  • При использовании карты Memory Stick Micro™ с системой PS3™, в которой есть гнездо Memory Stick™, требуется адаптер Memory Stick™ M2 Duo.
  • Некоторые видеофайлы с защитой от копирования переместить нельзя.
  • Не нарушайте права интеллектуальной собственности других пользователей.
  • Видеофайлы нельзя скопировать или переместить во время воспроизведения.*

    • * Это касается также воспроизведения контента с помощью других функций, например воспроизведения музыкальных файлов.

Копирование или перемещение видеофайлов для просмотра в системе PSP™

Копируйте или перемещайте видеофайлы для просмотра в системе PSP™.

1.

Подключите систему PSP™ к системе PS3™ с помощью кабеля USB.
Чтобы скопировать файлы на карту Memory Stick™, вставьте карту Memory Stick™ в систему PSP™.

2.

В системе PSP™ выберите (Настройки) > (Соединение USB).

3.

В системе PS3™ выберите видеофайл, который хотите скопировать или переместить, и нажмите кнопку .

4.

Выберите [Копировать] или [Переместить].
Далее следуйте инструкциям на экране. Для воспроизведения скопированного или перемещенного видеофайла выберите файл в меню (Видео) > (Memory Stick™) или (Видео) > (Память системы) в системе PSP™.

Подсказки

  • Подробнее о воспроизведении видеофайлов в системе PSP™ см. в соответствующем разделе Руководства пользователя системы PSP™.
  • В зависимости от типа копируемого или перемещаемого видеофайла используйте соответствующую карту Memory Stick PRO Duo™.
  • Видеоматериалы, записанные в разрешении HD, переместить нельзя.
