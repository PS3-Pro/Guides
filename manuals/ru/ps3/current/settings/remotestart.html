Дистанционный запуск

Вы можете дистанционно включить систему PS3™, находящуюся в режиме ожидания (Wake On LAN), с помощью устройства, поддерживающего дистанционное воспроизведение, например системы PS Vita или системы PSP™. Перед использованием данной функции необходимо выполнить следующие действия.

Для использования функции дистанционного воспроизведения через беспроводную локальную сеть системы PS3™ или точку доступа:
  • Если система PSP™ используется для дистанционного воспроизведения, обновите программное обеспечение системы PSP™ до версии 3.72 или более поздней.
  • В системе PS3™ установите автоматическую регистрацию в системе в меню (Пользователи)

Для использования функции дистанционного воспроизведения через Интернет:
  • Если система PSP™ используется для дистанционного воспроизведения, обновите программное обеспечение системы PSP™ и системы PS3™ до последних версий системного программного обеспечения.
  • Установите автоматический вход в меню (Пользователи) в системе PS3™.
  • Выполните сетевые настройки системы PS3™ для подключения к сети Интернет.
  • Создайте учетную запись Sony Entertainment Network.
  • Установите флажок для автоматического входа в систему PSNSM.

Подсказки

  • Чтобы использовать функцию дистанционного запуска, пользователи систем серий CECH-4302, CECH-4303, CECH-4304 и CECH-4308 PS3™ должны быть подключены к сети с помощью функции беспроводной сети LAN системы PS3™.
  • Подробнее об автоматической регистрации в системе в меню (Пользователи) см. (Пользователи) > [Регистрация в системе] > [Установка автоматической регистрации в системе] в данном руководстве.
  • Подробнее об автоматическом входе в систему PSNSM см. (PlayStation™Network) > [Сохранить пароль (Автоматический вход в сеть)] в данном руководстве.

Активизирование дистанционного запуска

1.

Выберите (Настройки) > (Настройки дистанционного воспроизведения).

2.

Выберите [Дистанционный запуск] > [Включить]

3.

Выберите [OK] на отображающемся экране. Для работы дистанционного воспроизведения через Интернет установите флажок [Активировать дистанционный запуск через Интернет].

4.

Выключите систему PS3™.
Выберите (Пользователи) > (Отключить систему), чтобы отключить систему и перевести ее в режим ожидания. Убедитесь, что индикатор питания светится красным.

5.

Воспользуйтесь функцией дистанционного воспроизведения на устройстве, поддерживающем такую функцию, например на системе PS Vita или системе PSP™.
Дополнительная информация об использовании функции дистанционного воспроизведения находится в документации к соответствующему устройству.

Подсказки

  • Подробнее об использовании функции дистанционного воспроизведения на системе PS Vita или системе PSP™ можно прочитать в разделе (Сеть) > (Дистанционное воспроизведение) > [Дистанционное воспроизведение] данного руководства.
  • Если активизирован дистанционный запуск, встроенный вентилятор системы PS3™ продолжает работать даже после выключения системы.

Отключение дистанционного запуска

1.

Выберите (Настройки) > (Настройки дистанционного воспроизведения).

2.

Выберите [Дистанционный запуск] > [Выключить].

Дистанционный запуск через Интернет

При использовании некоторых сетевых устройств функция дистанционного воспроизведения через Интернет может оказаться недоступной. В этом случае воспользуйтесь приведенными ниже рекомендациями.

Примечание

В зависимости от типа маршрутизатора система PS3™ может быть включена случайно, если функция дистанционного запуска включена. Если в течение определенного времени после запуска системы PS3™ не будет установлено соединение для дистанционного воспроизведения, система автоматически выключится. Чтобы этого не произошло, дистанционный запуск через Интернет может быть автоматически отключен.

  • Для использования дистанционного запуска через Интернет требуется маршрутизатор.
  • Если используемый маршрутизатор поддерживает UPnP, включите функцию UPnP маршрутизатора.
  • Если используемый маршрутизатор не поддерживает UPnP, необходимо установить функцию переадресации портов маршрутизатора, чтобы обеспечить доступ к системе PS3™ из сети Интернет. Для дистанционного воспроизведения и дистанционного запуска используются следующие номера портов: для TCP - 9293 или для UDP - 9293. Информацию об установке этой функции можно найти в руководстве по эксплуатации маршрутизатора.
  • Переадресация портов – это функция перенаправления сигналов, поступающих в определенный порт (входной), на другой определенный порт (выходной). Эта операция также называется "отображением портов" или "преобразованием адресов".
  • Если IP-адрес маршрутизатора (глобальный IP-адрес) изменяется, когда система PS3™ находится в режиме ожидания, дистанционный запуск не сможет быть выполнен.
