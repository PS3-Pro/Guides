Автоматическое обновление

Для пользования некоторыми функциями необходимо подписаться на службу PlayStation®Plus.

Если для параметра установлено значение [Включить], система PS3™ будет автоматически включаться каждый день в указанное время, выполнять запланированные действия и выключаться.

Выключить Установите это значение, чтобы не использовать функцию автоматического обновления
Включить Установите, чтобы использовать функцию автоматического обновления

Вы можете задать параметры автоматического обновления для следующих пунктов.

  • Загрузка материалов, приобретенных с помощью другого устройства
  • Загрузка обновлений для системного программного обеспечения
  • Загрузка исправлений для игр
  • Синхронизация информации о призах с сервером

Подсказки

  • Выставляйте значение [Загрузка сохраненных данных в интернет-хранилище] для каждой игры. Подробнее об этом можно прочитать в разделе (Игра) > [Воспроизведение программного обеспечения формата PlayStation®3] > [Сохраненные данные] данного руководства.
  • Выбрав [Включить], воспользуйтесь кнопками направлений для выбора периода времени, в течение которого должно быть произведено автоматическое обновление. Если появится окно с предложением проверить параметры настройки автоматического входа в сеть PSNSM, следуйте инструкциям на экране.
  • Эта функция доступна только на одной системе PS3™ для одной учетной записи Sony Entertainment Network. Если для функции автоматического обновления выбрано значение [Включить] на двух и более системах PS3™ для одной и той же учетной записи, на последней из систем останется значение [Включить], а на всех остальных будет автоматически установлено значение [Выключить].
  • В течение отрезка времени, указанного вами для автоматического обновления, система PS3™ должна находиться в режиме ожидания (индикатор питания светится красным).
  • Обновление системного программного обеспечения будет загружено автоматически, но не установлено. Установку обновления системного программного обеспечения вы должны провести самостоятельно.
  • Значок обозначает игровые обновления и рекомендуемые игры, которые были загружены автоматически. Все материалы, которые были загружены и установлены, но не использовались, будут автоматически удалены по истечении одного месяца.
  • Даже если для функции [Автоматическое обновление] выбрано значение [Включить], материалы не будут загружены, если на системном накопителе менее 5 Гб свободного пространства.
  • Выберите пункт [Выключить], чтобы для всех выбранных параметров автоматического обновления установить значения по умолчанию.
