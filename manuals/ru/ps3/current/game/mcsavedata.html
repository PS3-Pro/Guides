Использование данных, сохраненных на Memory Card

Чтобы использовать для игры данные, сохраненные на Memory Card (8 Мб) (для PlayStation®2) или на карте Memory Card, скопируйте эти данные на внутреннюю Memory Card на системном накопителе. Для копирования данных следует использовать адаптер карты памяти (продается отдельно).

Примечания

  • В системе PS3™ некоторое программное обеспечение формата PlayStation®2 и PlayStation® может воспроизводиться не так, как в системах PlayStation®2 или PlayStation®, или вообще не работать.
  • Программное обеспечение формата PlayStation®2 не воспроизводится в некоторых системах PS3™. Подробнее см. в разделе [Типы воспроизводимых дисков], на региональном веб-сайте SIE или в документации к системе PS3™.

1.

Выберите в разделе (Игра) > (Утилита управления Memory Card).

2.

Подключите адаптер карты памяти к системе PS3™ и вставьте карту памяти.
На экране появится значок (Memory Card (PS)) или (Memory Card (PS2)).

3.

Выберите значок сохраненных данных, которые требуется скопировать с активной карты памяти, и нажмите кнопку .

4.

Выберите [Копировать].
Выберите место назначения для копирования данных. Если места назначения недоступны, выберите (Создать новую внутреннюю Memory Card) и следуйте инструкциям на экране, чтобы создать новую внутреннюю Memory Card.

5.

Назначьте гнезда
Выберите внутреннюю Memory Card, которую хотите использовать, в категории (Утилита управления Memory Card) и нажмите кнопку . В меню параметров выберите [Назначить гнезда].

Подсказки

  • В зависимости от типа данных сохраненные данные с Memory Card (8 МБ) (для PlayStation®2) или Memory Card копируются на внутреннюю Memory Card, как показано ниже.

  • Процесс копирования некоторых сохраненных данных может продолжаться до нескольких минут.
  • Для копирования всех данных, сохраненных на карте памяти (8 Мбайт) (для PlayStation®2) или карте памяти, выберите карту памяти на шаге 3, нажмите кнопку и затем выберите [Копировать] в меню параметров.
  • Копирование некоторых сохраненных данных может быть запрещено. При использовании таких данных на системе PS3™ выберите [Переместить] на шаге 4. Сохраненные данные будут перемещены на системный накопитель и удалены с Memory Card.
  • Сохраненные данные можно впоследствии переместить обратно на карту памяти.

Копирование сохраненных данных на карту памяти

Копирование данных программного обеспечения формата PlayStation®2 / PlayStation®, сохраненных на системном накопителе, на карту Memory Card или Memory Card (8 Мб) (для PlayStation®2). Для копирования данных следует использовать адаптер карты памяти (продается отдельно).

1.

Выберите в разделе (Игра) > (Утилита управления Memory Card).

2.

Подключите адаптер карты памяти к системе PS3™ и вставьте карту памяти.

3.

Выберите значок сохраненных данных, которые требуется скопировать с карты (Внутренняя Memory Card (PS)) или (Внутренняя Memory Card (PS2)), затем нажмите кнопку .

4.

Выберите [Копировать].
Укажите (Memory Card (PS)) или (Memory Card (PS2)) в качестве устройства назначения для копирования данных.

Подсказки

  • Одновременное копирование нескольких блоков сохраненных данных с внутренней Memory Card на карту памяти невозможно.
  • Копирование некоторых сохраненных данных может быть запрещено. При использовании таких данных на системе PS3™ выберите [Переместить] на шаге 4. Сохраненные данные будут перемещены на системный накопитель и удалены с внутренней Memory Card.
  • Сохраненные данные можно впоследствии переместить обратно на карту памяти.
