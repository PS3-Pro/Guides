Сохраненные данные

Сохраненные данные для программного обеспечения формата PlayStation®3 сохраняются на системном накопителе. Данные отображаются в пункте (Утилита управления сохраненными данными (PS3™)).


Подсказки

  • Работа с сохраненными данными производится отдельно для каждого пользователя. Если в меню (Пользователи) присутствует несколько пользователей, элементы, отображаемые в меню (Утилита управления сохраненными данными (PS3™)), различаются в зависимости от зарегистрированного в системе пользователя.
  • Выбрав значок сохраненных данных и нажав кнопку , можно отсортировать сохраненные данные по дате обновления или группе сохраненных данных (по названию), используя отображаемое меню.

Сохранение данных на сервере PSNSM

Сохраненные данные программного обеспечения формата PlayStation®3 можно хранить на сервере PSNSM и загружать в другую систему PlayStation®3, чтобы продолжить игру. Для использования этой функции требуется учетная запись Sony Entertainment Network и подписка на услугу PlayStation®Plus.

Автоматическое сохранение данных

Новые и недавно обновленные сохраненные данные можно автоматически и регулярно отправлять в сетевое хранилище.
Эта функция настраивается отдельно для каждой игры.

1.

В разделе (Игра) выберите игру, сохраненные данные которой вы хотите отправлять в сетевое хранилище, и нажмите кнопку .

2.

Для параметра [Автозагрузка сохраненных данных] выберите значение [Включить].

Подсказки

  • Если отметить этот пункт, все обновленные сохраненные данные будут загружаться на сервер автоматически.
  • В разделе (Настройки) для параметра (Настройки системы) > [Автоматическое обновление] выберите значение [Выключить], чтобы отключить автоматическое обновление сохраненных данных.
Сохранение данных вручную

1.

Выберите (Игра) > (Утилита управления сохраненными данными (PS3™)), затем выберите данные, которые требуется отправить, и нажмите кнопку .

2.

Выберите [Копировать].

3.

Выберите путь сохранения [Сетевая память].

Загрузка сохраненных данных из сетевой памяти в систему PS3™

1.

Выберите (Игра) > (Утилита управления сохраненными данными (PS3™)), затем выберите [Сетевая память].

2.

Выберите сохраненные данные для загрузки и нажмите кнопку .

3.

Выберите [Копировать].

Подсказки

  • Вам доступен 1 Гб свободного пространства, где можно сохранить до 1000 файлов с данными.
  • Можно сохранить только данные программного обеспечения формата PlayStation®3 , PC Engine и NEOGEO.
  • Если сохраненные данные защищены от копирования:
  • - Отправка в сетевую память: без ограничений.
  • - Загрузка сохраненных данных из сетевой памяти: после отправки или загрузки из сетевой памяти данных с защитой от копирования повторить загрузку тех же данных можно будет не менее чем через 24 часа.
  • Для некоторых игр использование сетевой памяти не предусмотрено. Узнать больше об играх и услугах, не поддерживающих использование сетевой памяти, можно здесь.
