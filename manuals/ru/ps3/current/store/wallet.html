Использование бумажника

Для использования этой функции может потребоваться обновление системного программного обеспечения.


Используйте бумажник для приобретения продуктов в (PlayStation®Store). Для каждой основной учетной записи Sony Entertainment Network создается один бумажник. Перед покупками в бумажник необходимо добавить средства.

Добавление средств

Для добавления средств в бумажник можно использовать кредитную карту, а также карты PlayStation®Network Card. Способы добавления средств, вид валюты и ограничения по объемам операций зависят от страны и региона проживания. За дополнительной информацией обратитесь в службу технической поддержки вашего региона.

1.

Выберите (PlayStation™Network) > (Управление учетной записью).

2.

Выберите (Управление транзакциями).

3.

Выберите [Внести средства].
Далее следуйте инструкциям на экране.

Настройка автоматического добавления средств

Если с вашей учетной записью связана подписка, при нехватке средств для обновления подписки можно задать автоматическое добавление средств с кредитной карты в бумажник. Эта возможность может отсутствовать в вашей стране или регионе. За дополнительной информацией обратитесь в службу технической поддержки вашего региона.

1.

Выберите (PlayStation™Network) > (Управление учетной записью).

2.

Выберите (Управление транзакциями).

3.

Выберите [Автоматическое добавление средств].

Подсказки

  • Подписка - это служба, которую можно использовать в течение определенного периода, например 30 или 60 дней. После истечения срока подписки автоматически приобретается подписка на следующий период.
  • Для учетной записи будет добавлено недостающее количество средств для услуги подписки или минимальное количество средств, которое должно быть в бумажнике, в зависимости от того, какая сумма больше.
  • [Автоматическое добавление средств] автоматически устанавливается в положении [Включить] при приобретении подписки.

Использование бумажника держателями дополнительных учетных записей

Держатели дополнительных учетных записей не могут создать бумажник, но могут использовать бумажник основной учетной записи, чтобы расплачиваться за товары и услуги. Держатель основной учетной записи может назначить лимит ежемесячно расходуемых средств для связанных дополнительных учетных записей. Чтобы установить лимит расходов, выберите (Управление дополнительной учетной записью) в (PlayStation™Network) > (Управление учетной записью).
