Удаление пользователей

Если пользователей несколько, можно удалить тех из них, которые больше не нужны. Войдите в систему в качестве пользователя, которого необходимо удалить. Выберите значок пользователя, нажмите кнопку и выберите команду [Удалить] в меню параметров. Если пользователь удален, с системного накопителя будут удалены данные этого пользователя следующих типов.

  • Данные, загруженные (за соответствующую плату) из (PlayStation®Store), например, игры или дополнительные компоненты для игр*
  • Отправленные и полученные сообщения в категории (Друзья)
  • Закладки, история и настройки, зарегистрированные в разделе (Веб-браузер)
  • Сохраненные данные для программного обеспечения формата PlayStation®3
  • Данные, сохраненные в разделе (Утилита управления приложениями системы PS Vita)
  • Резервные копии файлов PS Vita
  • Сохраненные данные для мини-игр ("minis")
  • Сохраненные данные PSP™Game (игр для PSP™)
  • Сведения об изображении, установленном в качестве фонового рисунка в меню (Фото)
  • Слова из словаря распознаваемого текста, текст, введенный с клавиатуры, и другой контент, сохраненный в разделе (Настройки) > (Настройки системы) > [Добавить/Изменить термин]
  • Параметры клавиатуры и мыши устанавливаются в меню (Настройки) > (Настройки дополнительных устройств)
  • Настройка изменения голоса в меню (Настройки) > (Настройки дополнительных устройств) > [Изменить голос]
  • Такие параметры, как тема, цвет, фон и шрифт в меню (Настройки) > (Настройки темы)

*  Демонстрационные версии и другие виды данных, загруженные бесплатно из (PlayStation®Store), не могут быть удалены.


Подсказка

Только текущий пользователь может быть удален.

  • Меню XMB™
  • Пользователи
  • Настройки
  • Фото
  • Музыка
  • Видео
  • Услуги ТВ/видео
  • Игра
  • Сеть
  • PlayStation™Network
  • Друзья
