Поиск в Интернете

Поиск в Интернете по ключевому слову или фразе выполняется на экране XMB™.

1.

Выберите (Поиск в Интернете) в меню (Сеть).
Отобразится экранная клавиатура.

2.

Введите ключевое слово для поиска.
Введите ключевое слово, затем выберите для подтверждения ввода текста. Откроется страница с результатами поиска.
  • Меню XMB™
  • Пользователи
  • Настройки
  • Фото
  • Музыка
  • Видео
  • Игра
  • Сеть
  • PlayStation®Network
  • Друзья
