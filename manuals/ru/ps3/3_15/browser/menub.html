Просмотр

Изменение вида отображения страницы.

Масштаб/Восстановить исходное изображение Автоматическое увеличение области экрана, на которой располагается указатель, до оптимального размера или отмена увеличения.

Коэффициент увеличения для области, в которой располагается указатель, вычисляется автоматически в зависимости от типа содержимого.
Максимальный размер/Стандартный размер Увеличение окна для отображения во весь экран. / Просмотр окна в исходном размере.
Размер знаков Изменение размера текста.

Возможность отображения текста в пяти различных размерах.
Кодировка знаков Назначение кодировки знаков.

В большинстве случаев кодировка знаков определятся автоматически, и нет необходимости назначать ее.

Подсказка

На некоторых страницах размер знаков изменить нельзя и кодировку знаков выполнить невозможно.

Инструменты

Задание условий для открытия страниц и удаление данных, сохраненных на жестком диске.

Cookies Разрешить: Разрешается всегда сохранять файлы cookies.

Блокировать: Всегда запрещается сохранять файлы cookies.
JavaScript Включить: Использование JavaScript.

Выключить: Запрет на использование JavaScript.
Область отображения Полноэкранное изображение: Служит для отображения окна форматом во весь телевизионный экран.*1

Обычный: Устанавливается для уменьшения размера окна на 5%.

-1: Устанавливается для уменьшения размера окна на 10%.

-2: Устанавливается для уменьшения размера окна на 15%.
Разрешение Изменение разрешения отображения веб-страницы.

Настройка удобного просмотра веб-страниц в соответствии с разрешением видеовыхода системы PS3™.
Снижение мерцания Включить: подавление мерцания элементов на экране, таких как текст, изображения и линии.

Выключить: отключение снижения мерцания.

Эта функция эффективна для подавления мерцания экрана на дисплее с чересстрочной разверткой. Задайте значение [Включить], когда для разрешения видеовыхода системы PS3™ выбрано значение 1080i. При задании значения [Выключить] качество изображения для дисплея с прогрессивной разверткой (например, 1080p или 720p) улучшится.
Подтвердить закрытие браузера Включить: Устанавливается для отображения сообщения с запросом на подтверждение закрытия (Веб-браузер).

Выключить: Устанавливается для закрытия без отображения сообщения с запросом на подтверждение.
Домашняя страница Установка страницы, которая будет отображаться при запуске (Веб-браузер) или выборе (Домой) в главном меню.

Если выбрать параметр [Восстановите приложение Window при запуске браузера], в следующий раз при запуске браузера отобразится страница, которая была открыта при закрытии браузера.
Удалить Cookies Удаление cookies.
Удалить историю поиска Удаление истории поисковых запросов.
Удалить временные файлы Удаление временных файлов.
Удалить информацию подтверждения подлинности Удаление информации подтверждения подлинности.
Отказаться от услуги безопасности браузера Отключение функции фильтрации содержимого веб-страниц. *2

Для изменения данной настройки необходимо ввести пароль. Подробнее о паролях см. в разделе (Настройки) > (Настройки безопасности) > [Изменить пароль] данного руководства.
*1

Верхняя и нижняя части фотографии могут быть отрезаны, если включена функция [Full Pixel] (полноэкранное изображение) при использовании обычного телевизора.
*2

Доступные методы фильтрации содержимого веб-страниц зависят от страны и региона.

Использование фильтрации содержимого веб-страниц позволяет определить тип и допустимость материалов веб-сайтов, и автоматически блокировать отображение недопустимых веб-сайтов при использовании Интернета.

*1

*2

История

Открываемые веб-страницы автоматически сохраняются как история. Заголовки ранее открытых страниц отображаются в виде списка и могут быть открыты без ввода адреса с помощью простого выбора заголовка в списке.

Подсказка

Страницы упорядочены в хронологическом порядке и отображаются, начиная со страниц, открытых последними.
