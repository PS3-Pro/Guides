Режим просмотра

Окно отображается по всей высоте и ширине экрана. При открытии нескольких окон они отображаются рядом друг с другом. Для перехода по окнам можно использовать кнопку L2 или R2.

Режим окна

Изменение параметров экрана для отображения нескольких открытых окон. Выберите окно с помощью кнопок направления и нажмите кнопку для отображения окна в режиме просмотра.

Изменить режимы

Существуют следующие варианты переключения между режимом просмотра и режимом окна:

Режим просмотра > режим окна Нажмите кнопку вниз на левом джойстике (кнопка L3).
