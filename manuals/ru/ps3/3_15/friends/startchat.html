Запуск или окончание голосового/видео-чата

Для использования этой функции может потребоваться обновление системного программного обеспечения.


Можно провести голосовой/видео-чат с людьми, занесенными в список друзей. Для проведения голосового чата потребуется устройство ввода/вывода звука (например, гарнитура, которая продается отдельно). Для проведения чата с использованием видео также потребуется USB-камера (продается отдельно).

Запуск голосового/видео-чата

1.

Выберите (Друзья) > (Начать новый чат).

2.

Выберите (Начало голосового/видео чата).
Отображается чат-комната.

3.

В отображаемом на экране меню выберите (Пригласить друга).
В случае выбора лица, с которым Вы хотите начать чат, из списка друзей и нажатия клавиши [Enter] отображается экран приглашения в чат.

4.

Введите приглашение и выберите [Отправить].
В чат-комнате отображается аватар приглашенного друга.

Если данное лицо присоединяется к чату, появляется назначенное ему изображение и начинается голосовой чат или видеочат.

Подсказки

  • Система PS3™ поддерживает голосовой/видео-чат. Дополнительные параметры чата, например чат во время игры, могут быть доступны при использовании игрового программного обеспечения. Для получения подробной информации см. инструкции, прилагаемые к используемому программному обеспечению.
  • Для проведения чата необходимо зарегистрироваться в PlayStation®Network.
  • Хотя возможно приглашение в чат большого количества друзей, в чат-комнате отображаются аватары только пяти друзей, которые были выбраны на экране первыми.
  • В чате могут участвовать до шести человек.
  • Функцию голосового/видео-чата невозможно использовать, если ограничения на ее использование установлены в настройках учетной записи PlayStation®Network. Подробнее о функции родительского контроля см. в разделе [Меню XMB™] > [Использование настройки родительского контроля] в данном руководстве.
  • К системе PS3™ можно подключить гарнитуру USB / гарнитуру Bluetooth® / USB камеру EyeToy™ / камеру PlayStation®Eye / USB камеру, совместимую с классом видеоустройств USB (UVC) и системой PS3™.
  • При подключении USB-камеры с помощью концентратора USB используйте концентратор, поддерживающий USB 2.0. Если используется концентратор, который не поддерживает USB 2.0, может возникнуть искажение изображения или изображение может не отображаться.
  • Для получения информации о поддерживаемых периферийных устройствах и инструкций по их использованию, обратитесь к продавцу, у которого было приобретено периферийное оборудование.

Выход из чат-комнаты (окончание голосового/видео-чата)

Нажмите кнопку во время чата, затем выберите на панели управления (Покинуть).

Подсказка

Если лицо, начавшее голосовой или видео-чат, выходит из чата, то чат-комната закрывается.
