Создание/отправка сообщений

Для использования этой функции может потребоваться обновление системного программного обеспечения.


Можно создавать и отправлять сообщения людям, которые имеют зарегистрированный сетевой ID для использования с PlayStation®Network. Для создания и отправки сообщений необходимо зарегистрироваться в PlayStation®Network.

1.

Выберите (Друзья) > (Окошко сообщений).

2.

Выберите значок (Создать сообщение).

3.

Выберите [Кому:].
Выберите параметр [Выбрать из списка друзей] или параметр [Введите сетевой ID.], при выборе которого потребуется ввести сетевой ID человека, которому нужно отправить сообщение.

4.

Введите текст сообщения и выберите [Отправить].
Сообщение отправлено. Отправленные сообщения можно просмотреть в разделе (Друзья) > (Окошко сообщений) > (Отправленные).

Подсказки

  • Невозможно отправлять или получать сообщения, используя стандартные адреса электронной почты.
  • Сетевой ID создается, когда вы регистрируетесь в PlayStation®Network. Перед отправкой сообщения узнайте сетевой ID человека, которому хотите отправить сообщение.
  • Можно ввести до 18 символов в названии и до 512 символов в тексте сообщения.
  • При создании сообщения можно вставить значки эмоций, выбрав с помощью клавиатуры.
  • Можно сохранить до 200 отправленных сообщений. По достижении этого предела самые старые сообщения будут автоматически удаляться при каждой отправке нового сообщения.

Вложение файлов

Если на экране создания сообщения выбрать (Приложить файл), можно приложить файл изображения (Фото).

Подсказки

  • Невозможно выполнить вложение файлов более 3 Мб.
  • Одновременно можно вложить только один файл.
  • Чтобы отменить операцию приложения файла, выберите файл и нажмите кнопку , затем выберите в меню параметров [Отменить приложение].
