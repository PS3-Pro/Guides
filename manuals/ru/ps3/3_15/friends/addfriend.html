Добавление в список друзей

Для использования этой функции может потребоваться обновление системного программного обеспечения.


Для добавления пользователя в список "Друзья" необходимо сначала отправить сообщение с запросом на получение одобрения.

1.

Выберите (Друзья) > (Добавить друга).
Отобразится сообщение без текста, в котором вы можете написать запрос о добавлении друга.

2.

Выберите поле [Кому].
Введите сетевой идентификатор пользователя, которого вы хотите добавить в список друзей.

3.

Введите текст сообщения и выберите [Отправить].
Сообщение будет отправлено, и аватар друга отобразится в разделе (Друзья).

Далее поступит сообщение. Если пользователь примет ваш запрос, он будет добавлен в ваш список друзей, а вы будете добавлены в его список друзей.

Подсказки

  • Вам присваивается сетевой ID, когда вы регистрируетесь в PlayStation®Network. Чтобы выполнить запрос на добавление друга, вам сначала потребуется узнать (спросить) сетевой ID пользователя, которого вы хотите добавить.
  • Если пользователь выберет [Не добавлять] в ответ на ваш запрос, аватар этого пользователя будет удален из вашего списка.

Получение запроса на добавление друга

При получении запроса на добавление друга вы можете ответить положительно, чтобы автор запроса добавил вас в свой список друзей.

1.

Выберите аватар пользователя, направившего запрос, в разделе (Друзья).
Отобразится профиль выбранного пользователя.

2.

Выберите [Ответ на запрос о добавлении друга].
Далее следуйте инструкциям на экране. После этого аватар каждого из вас будет добавлен в список друзей другого.
