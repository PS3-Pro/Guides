Дистанционное воспроизведение (через точку доступа)

Подключите систему PS3™ к точке доступа через кабель Ethernet и установите соединение с системой PS3™ через точку доступа с помощью функции беспроводной локальной сети, предусмотренной в системе PSP™.

Пример стандартной конфигурации

Подсказки

  • Беспроводной маршрутизатор - это устройство, добавляющее маршрутизатору функцию точки доступа. Точка доступа - это устройство, используемое для беспроводного подключения к сети. Маршрутизатор - это устройство, используемое для одновременного подключения нескольких устройств при одном подключении к Интернету.
  • Модем может иметь функциональные возможности маршрутизатора. Подключите систему PS3™ к устройству, имеющему функциональные возможности маршрутизатора.
  • Если точка доступа и модем имеют функциональные возможности маршрутизатора, выключите функцию маршрутизатора одного из этих устройств. Система PS3™ и система PSP™ должны быть подключены в пределах одной сети. Если одновременно используется не менее двух маршрутизаторов, система PS3™ и система PSP™ могут быть подключены к различным сетям, и будет невозможно использовать дистанционное воспроизведение.

Подготовка к работе (система PS3™ и система PSP™)

Для использования дистанционного воспроизведения в первый раз следует зарегистрировать (подключить) систему PSP™ с системой PS3™. Зарегистрируйте систему в категории (Настройки) > (Настройки дистанционного воспроизведения) > [Регистрация устройства].

Подготовка к работе (система PSP™)

Создайте сетевое соединение для подключения системы PSP™ к точке доступа. Если в системе PSP™ уже сохранено сетевое соединение, предназначенное для подключения к сети через точку доступа, создавать новое сетевое соединение не требуется. Для получения подробной информации о создании сетевого соединения см. руководство пользователя системы PSP™.

Использование дистанционного воспроизведения

1.

В системе PS3™ выберите (Сеть) > (Дистанционное воспроизведение).
Система перейдет в режим ожидания соединения для дистанционного воспроизведения.

2.

В системе PSP™ выберите (Сеть) > (Дистанционное воспроизведение).

3.

Выберите [Соединение через частную сеть].

4.

В списке подключений выберите подключение к точке доступа, которая используется для дистанционного воспроизведения.

При успешном подключении в системе PSP™ отобразится экран системы PS3™.

Подсказки

  • Дистанционное воспроизведение может использоваться в пределах радиуса действия точки доступа.
  • При включении параметра дистанционного запуска в системе PS3™ она может включаться автоматически (Wake on LAN). В таком случае вам не придется выполнять шаг 1, описанный выше. Подробнее см. в разделе (Настройки) > (Настройки дистанционного воспроизведения) > [Дистанционный запуск] в данном Руководстве.

Выход из дистанционного воспроизведения

Нажмите кнопку PS (Кнопка HOME) на системе PSP™ и выберите [Выйти из дистанционного воспроизведения] > [Выйти и отключить систему PS3™].

Подсказка

Выберите [Выйти без отключения системы PS3™], если в системе PS3™ выполняется копирование файлов, фоновая загрузка или другие задачи.
