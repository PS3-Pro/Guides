Специальные настройки соединения

Данная настройка доступна только на системах PS3™ с функцией беспроводной сети LAN.


Если система PSP™ зарегистрирована с системой PS3™, которая имеет функцию беспроводной сети LAN, сетевое соединение для дистанционного воспроизведения с определенным SSID и ключом шифрования (ключ WPA) создается автоматически для обеих систем, и между системами устанавливается связь в режиме инфраструктуры. Если выбрать [Специальные настройки соединения], можно вручную изменить SSID и ключ шифрования, которые установлены на системе PS3™. Обычно эти настройки не требуется изменять.

SSID Установка SSID.

Можно ввести любой SSID.
Настройки безопасности WLAN Установка способа защиты.

Для настроек дистанционного воспроизведения можно выбрать только [WPA-PSK (AES)].
Ключ WPA Установка ключа шифрования.

Можно ввести любой ключ. Ключ шифрования отображается в виде нескольких звездочек. Ключ, установленный здесь, может потребоваться при изменении сетевого соединения для системы PSP™. Запишите ключ, чтобы в дальнейшем его можно было посмотреть.

Подсказка

Если SSID и ключ WPA изменены для системы PS3™, SSID и ключ WPA следует также изменить на схожие значения для сетевого соединения системы PSP™. Обязательно зарегистрируйте систему PSP™ повторно после изменения данных значений.

  • Меню XMB™
  • Пользователи
  • Настройки
  • Фото
  • Музыка
  • Видео
  • Игра
  • Сеть
  • PlayStation®Network
  • Друзья
