Контроль по HDMI

Эта функция поддерживается только в системах PS3™ серии CECH-2000.


При подключении к системе PS3™ телевизора BRAVIA™ (производства корпорации Sony), поддерживающего функцию BRAVIA™ Sync через кабель HDMI, вы можете использовать пульт ДУ телевизора для управления и системой PS3™, и телевизором.

Выключить Отключение функции "Контроль по HDMI".
Включить Включение функции "Контроль по HDMI".

Функции, доступные для системы PS3™

Воспроизведение одним нажатием При включении системы PS3™ подсоединенный к ней телевизор тоже будет включен, и будет автоматически выбран видеовход для системы PS3™.

Функции, доступные для телевизора

Воспроизведение одним нажатием При нажатии кнопки LINK на пульте ДУ телевизора и выборе в меню варианта [PS3™] система PS3™ будет включена.
Управление в меню с помощью пульта ДУ Пульт ДУ используется для управления некоторыми функциями системы PS3™.
Одновременное выключение соединенных устройств При отключении телевизора соединенная с ним система PS3™ тоже будет выключена (перейдет в режим ожидания).

Подсказки

  • Набор доступных функций BRAVIA™ Sync зависит от используемого телевизора. Дополнительная информация находится в документации, прилагающейся к телевизору.
  • Даже если выбрано [Включить], эта функция может быть недоступной в следующих случаях.
  • - При использовании некоторых функций системы PS3™-например, при воспроизведение видео или игры.
  • - Когда система PS3™ не выбрана в качестве источника входящего сигнала для телевизора.
  • Функция BRAVIA™ Sync (Контроль по HDMI) обеспечивает взаимодействие соединенных устройств посредством CEC (Consumer Electronics Control), являющегося частью стандарта HDMI. Эта функция доступна только в устройствах Sony, поддерживающих функцию "Контроль по HDMI". Разработанные другими компаниями устройства с поддержкой CEC также могут поддерживать функцию "Контроль по HDMI", но полная совместимость таких устройств не гарантируется.
