Y Pb / Cb  Pr / Cr Super-White (HDMI)

Установка параметров видеовыхода для телевизоров с поддержкой входных сигналов Y Pb / Cb Pr / Cr. Вывод сигнала Super-white возможен при воспроизведении диска DVD или Blu-ray (BD), а также видеоданных в формате AVCHD. Параметр используется при подключении телевизора к системе PS3™ с помощью кабеля HDMI.

Выключить Отключение выходного сигнала Super-White.
Включить Включение выходного сигнала Super-White.

Подсказки

  • Установите значение [Выключить], если при выборе значения [Включить] ухудшается качество изображения или появляются искажения.
  • Для параметра [Формат вывода видео BD / DVD (HDMI)] в меню (Настройки) > (Настройки видео) необходимо установить значение [Автоматически] или [Y Pb / Cb  Pr / Cr].*

    • *  При установке значения [Автоматически] подключенный телевизор должен поддерживать входной сигнал Y Pb / Cb  Pr / Cr.

О формате x.v.Color/x.v.Colour

Если для этой функции задано значение [Включить], воспроизведение данных из видеофайлов формата AVCHD, записанных в формате x.v.Color/x.v.Colour, возможно с широким диапазоном цветов.


x.v.Color/x.v.Colour является торговой маркой, предложенной корпорацией Sony в качестве наименования для устройств, которые поддерживают формат "xvYCC," – международный стандарт для цветового пространства в подвижных изображениях. Преимущество стандарта x.v.Color / x.v.Colour заключается в воспроизведении более широкого диапазона цветов по сравнению с обычным стандартом.

Подсказки

  • Телевизор, совместимый со стандартом x.v.Color / x.v.Colour, следует подключить с помощью кабеля HDMI.
  • Этот параметр применяется только к видеофайлам формата AVCHD, записанным в формате x.v.Color / x.v.Colour.
