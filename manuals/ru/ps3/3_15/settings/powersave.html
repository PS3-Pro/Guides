Настройки энергосбережения

Настройка параметров энергосбережения. Для экономии энергии можно использовать автоматическое отключение системы PS3™ и беспроводных контроллеров по истечении определенного периода бездействия.

Автоматическое отключение системы

Через 1 час Если не пользоваться системой в течение заданного времени, то система автоматически отключится.
Через 2 часа
Через 3 часа
Через 5 часов
Выключить Система не будет отключаться автоматически.

Подсказка

Система не будет отключаться автоматически при некоторых условиях – например, во время игры, воспроизведения видео или слайд-шоу. Чтобы система отключалась автоматически при любых условиях, выберите [Автоматически отключать систему даже в особых условиях] на экране, который отображается после включения функции автоматического отключения системы.
