Soittolistat kopioiminen PSP™-järjestelmään

Voit kopioida musiikkia soittolistoihin ja toistaa niitä PSP™-järjestelmässä.

1.

Kytke PSP™-järjestelmä PS3™-järjestelmään USB-kaapelilla.
Jos haluat kopioida tiedostoja Memory Stick™ -muistikorttiin, aseta Memory Stick™ -muistikortti PSP™-järjestelmään.

2.

Valitse PSP™-järjestelmässä (Settings) > (USB Connection).

3.

Valitse PS3™-järjestelmässäsi (Musiikki) > (Soittolistat).

4.

Valitse käytettävän soittolistan kuvake ja paina sitten -näppäintä.

5.

Valitse [Kopioi].
Valitse kohteeksi (PSP™ (PlayStation®Portable)) tai (PSP™ (PlayStation®Portable)).

Vihjeitä

  • Tämän toiminnon käyttäminen edellyttää, että PSP™-järjestelmän käyttöjärjestelmän versio on 3.10 tai uudempi.
  • Soittolistoja ei voi kopioida PSP™-järjestelmästä PS3™-järjestelmään.
