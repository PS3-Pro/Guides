Pelien kopioiminen pelattaviksi PSP™-järjestelmällä

Jos (PlayStation®Store) -toiminnolla (ostamalla tai ilmaiseksi) lataamasi peli on yhteensopiva PSP™-järjestelmän kanssa, voit kopioida pelin pelattavaksi PSP™-järjestelmällä.

1.

Kirjaudu sisään PSNSM -verkkoon käyttämällä Sony Entertainment Network-käyttäjätunnusta, jolla latasit pelin.

2.

Yhdistä PSP™-järjestelmä PS3™-järjestelmään USB-kaapelilla.
Jos haluat kopioida tiedostoja Memory Stick™ -muistikorttiin, aseta Memory Stick™ -muistikortti PSP™-järjestelmään.

3.

Valitse PSP™-järjestelmässä (Asetukset) > (USB Connection).

4.

Valitse kopioitava peli PS3™-järjestelmässä kohdasta (Pelit) ja paina sitten -näppäintä.

5.

Valitse [Kopioi].
Kopioi peli noudattamalla näytössä näkyviä ohjeita. Kun kopiointi on suoritettu, voit aloittaa pelaamisen kohdasta (Pelit) > (Memory Stick™) tai (Pelit) > (System Storage) PSP™-järjestelmässä.

Vihjeitä

  • Tämän toiminnon käyttäminen edellyttää, että PSP™-järjestelmän käyttöjärjestelmän versio on 6.50 tai uudempi.
  • Lisätietoja pelien pelaamisesta PSP™-järjestelmällä on PSP™-järjestelmän käyttöoppaassa.

Pelit, joita voi pelata sekä PS3™- että PSP™-järjestelmillä

Jos pelattava peli on yhteensopiva kummankin järjestelmän kanssa, voit kopioida pelistä tallennetut tiedot järjestelmästä toiseen, joten voit jatkaa pelaamista keskeytyskohdasta. Tallennettujen tietojen kopiointitapa vaihtelee pelityypin mukaan.

PlayStation®-muotoisen ohjelmiston tallennetut tiedot

PlayStation®-muotoisen ohjelmiston tiedot tallennetaan sisäiselle muistikortille, joka luodaan järjestelmän tallennustilaan. Voit kopioida tallennetut tiedot PSP™-järjestelmään suorittamalla edellä mainitut vaiheet 2 ja 3 sekä valitsemalla sitten (Pelit) > (Memory Card -työkalu) > (Sisäinen Memory Card (PS) -muistikortti) PS3™-järjestelmässä. Valitse sitten kopioitava tallennettujen tietojen kuvake, paina -näppäintä ja valitse asetusvalikosta [Kopioi].

Vihjeitä

  • Tallennettujen tietojen muoto on muunnettava, jotta tietoja voidaan käyttää PSP™-järjestelmässä. Jos kopioinnin aikana näkyviin tulee tietojen muuntamisen vahvistusnäyttö, jatka valitsemalla [Kyllä].
  • Kustakin Memory Stick Duo™ -muistikortille (joka on asetettu PSP™-järjestelmään) tai PSP™go-järjestelmän muistiin tallennettavasta ohjelmistosta luodaan useita sisäisiä muistikortteja.
  • Jos kopioit tallennetut tiedot Memory Stick™ -muistikortille, joka asetetaan PS3™-järjestelmän korttipaikkaan, tai käytät USB-sovitinta (lisävaruste), tallennettuja tietoja ei tunnisteta.

PSP™-järjestelmän aktivoiminen

(PlayStation®Store)-kaupasta ladattuja (ostettuja tai ilmaisia) pelejä voi pelata aktivoidulla PSP™-järjestelmällä. Jos näkyviin tulee aktivointia pyytävä ilmoitus, kun peli käynnistetään PSP™-järjestelmällä, aktivoi laite seuraavassa kuvatulla tavalla.

1.

Yhdistä PSP™-järjestelmä PS3™-järjestelmään USB-kaapelilla.

2.

Valitse PSP™-järjestelmässä (Asetukset) > (USB Connection).

3.

Valitse PS3™-järjestelmässä (PlayStation™Network) > (Käyttäjätietojen hallinta).

4.

Valitse (Järjestelmän aktivointi).
Suorita aktivointitoiminto noudattamalla näyttöön tulevia ohjeita.

Vihjeitä

  • Laitteen aktivoiminen edellyttää, että olet kirjautunut PS3™-järjestelmään samana käyttäjänä kuin joka oli kirjautuneena järjestelmään PlayStation®-muotoista ohjelmistoa ladattaessa.
  • Laitteen aktivoinnilla varmistetaan, että sisältöä toistetaan vain todennetuilla laitteilla. Tämän tarkoituksena on suojata digitaalisen sisällön käyttöoikeudet.
