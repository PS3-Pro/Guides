Memory card tallennettujen tietojen käyttäminen

Memory Card -kortille (8MB) (PlayStation®2) tai Memory Card -kortille tallennettujen tietojen käyttäminen pelin pelaamista varten edellyttää, että tiedot kopioidaan järjestelmän tallennustilassa olevalle sisäiselle muistikortille. Tietojen kopioimiseen on käytettävä muistikorttisovitinta (lisävaruste).

Huomautukset

  • Jotkin PlayStation®2- ja PlayStation®-muotoiset ohjelmistot voivat käyttäytyä eri tavoin PS3™-järjestelmässä kuin PlayStation®2- tai PlayStation®-järjestelmissä, ja ne eivät ehkä toimi PS3™-järjestelmässä oikein.
  • PlayStation®2-muotoisia levyjä ei voi käyttää joissakin PS3™-järjestelmissä. Lisätietoja on kohdassa [Toistettavat levytyypit], oman alueesi SIE-verkkosivustossa ja PS3™-järjestelmän mukana toimitetuissa asiakirjoissa.

1.

Valitse (Pelit) > (Memory Card -työkalu).

2.

Yhdistä muistikorttisovitin PS3™-järjestelmään ja aseta muistikortti laitteeseen.
Näyttöön tulee (Memory Card (PS))- (Memory Card (PS2)) -kuvake.

3.

Valitse näytössä näkyvästä muistikortista kopioitavien tietojen kuvake ja paina sitten -näppäintä.

4.

Valitse [Kopioi].
Valitse kopiointipaikka. Jos paikkoja ei ole, valitse (Luo uusi sisäinen Memory Card -muistikortti) ja luo sitten uusi sisäinen muistikortti näytön ohjeiden mukaan.

5.

Paikkojen määrittäminen
Valitse sisäinen muistikortti, jota haluat käyttää, kohdasta (Memory Card -työkalu), ja paina sitten -näppäintä. Valitse toimintovalikosta [Osoita muistikorttipaikat].

Vihjeitä

  • Memory Card -kortille (8 MB) (PlayStation®2) tai Memory Card -kortille tallennetut tiedot kopioidaan sisäinen muistikortti alla näytetyllä tavalla.

  • Joidenkin tallennettujen tietojen kopioiminen voi kestää useita minuutteja.
  • Jos haluat kopioida kaikki PlayStation®2:n Memory Card -muistikortille (8 Mt) tai Memory Card -muistikortille tallennetut tiedot, valitse muistikortti vaiheessa 3, paina -näppäintä ja valitse sitten asetusvalikosta [Kopioi].
  • Joidenkin tallennettujen tietojen kopioiminen saattaa olla kiellettyä. Kun käytät sellaisia tietoja PS3™-järjestelmässä, valitse [Siirrä] vaiheessa 4. Tallennetut tiedot siirretään järjestelmän tallennustilaan ja poistetaan muistikortilta.
  • Voit siirtää tallennetut tiedot takaisin muistikortille jälkeenpäin.

Tallennettujen tietojen kopioiminen muistikortille

Voit kopioida PlayStation®2- tai PlayStation®-muotoisen ohjelmiston järjestelmän tallennustilaan tallennetut tiedot Memory Card -muistikortille tai Memory Card -muistikortille (8MB) (PlayStation®2). Tietojen kopioimiseen on käytettävä muistikorttisovitinta (lisävaruste).

1.

Valitse (Pelit) > (Memory Card -työkalu).

2.

Liitä muistikorttisovitin PS3™-järjestelmään ja aseta muistikortti laitteeseen.

3.

Valitse niiden tallennettujen tietojen kuvake, jotka haluat kopioida, tallennuskohteesta (Sisäinen Memory Card (PS) -muistikortti) tai (Sisäinen Memory Card (PS2) -muistikortti), ja paina sitten -painiketta.

4.

Valitse [Kopioi].
Valitse kopioinnin kohteeksi (Memory Card (PS)) tai (Memory Card (PS2)).

Vihjeitä

  • Useita sisäisen Memory Card -muistikortin tallennettuja kohteita ei voi kopioida yhdessä muistikortille.
  • Joidenkin tallennettujen tietojen kopioiminen saattaa olla kiellettyä. Kun käytät sellaisia tietoja PS3™-järjestelmässä, valitse [Siirrä] vaiheessa 4. Tallennetut tiedot siirretään järjestelmän tallennustilaan ja poistetaan sisäiseltä muistikortilta.
  • Voit siirtää tallennetut tiedot takaisin muistikortille jälkeenpäin.
