Pikanäppäinten käyttäminen

Voit tehdä valintoja suoraan langattoman ohjaimen painikkeilla käyttämättä valikkoa. Käytössä olevat toiminnot ovat erilaisia selaustilassa ja ikkunatilassa.

Selaustila
-näppäin Avaa linkki.
-näppäin (pidä pohjassa) Avaa linkki uuteen ikkunaan.
-näppäin + vasen sauva Valitse tekstiä.
-näppäin Avaa valikko.
-näppäin Sulje (Internet-selain).
-näppäin (pidä pohjassa) Sulje ikkuna.*1
START-näppäin Syötä osoite.
SELECT-näppäin Avaa [Kirjanmerkkini].
L1 / R1 -näppäimet Siirry edelliselle tai seuraavalle sivulle.
L2 / R2 -näppäimet Siirry toiseen ikkunaan.*2
Suuntanäppäimet Siirry seuraavan painetun näppäimen suunnassa olevaan linkkiin.
Vasen sauva Liikuta osoitinta haluamaasi suuntaan.
Vasen sauva (paina alas) (L3-näppäin) Siirry ikkunatilaan.
Oikea sauva Vieritä mihin tahansa suuntaan.
Oikea sauva (paina alas) (R3-näppäin) Käytä suurennostoimintoa tai palauta alkutila.
PS-näppäin Näytä XMB™-valikko.
*1

Tätä toimintoa ei voi käyttää suurennostoiminnon aikana.
*2

Suurennostoiminnon aikana näillä näppäimillä voi suurentaa tai pienentää näkymää.
Ikkunatila
-näppäin Avaa valittu ikkuna selaustilassa.
-näppäin Avaa valikko.
Vasen sauva (paina alas) (L3-näppäin) Siirry selaustilaan.
Suuntanäppäimet Siirry toiseen ikkunaan.
PS-näppäin Näytä XMB™-valikko.

Hiiren (lisävaruste) käyttäminen

Ohjaa toimintoja erikseen myytävällä hiirellä.

Pidä kakkospainiketta pohjassa ja liikuta vasemmalle Palaa edelliselle sivulle.
Pidä kakkospainiketta pohjassa ja liikuta oikealle Siirry seuraavalle sivulle.

Näppäimistön (lisävaruste) käyttäminen

Käytä kaupasta hankittavaa näppäimistöä.

CTRL + L (tai F4) Anna osoite.
CTRL + R (tai F5) Päivitä sivu.
CTRL + B (tai CTRL + I) Avaa [Kirjanmerkkini].
PAGE UP (tai SHIFT + välilyönti) Selaa ylöspäin.
PAGE DOWN (tai välilyönti) Selaa alaspäin.
Koti Siirry sivun yläreunaan.
Lopetus Siirry sivun alareunaan.
TAB Siirrä kohdistinta.
ALT + vasen nuolinäppäin (tai BACKSPACE) Palaa edelliselle sivulle.
ALT + oikea nuolinäppäin (tai SHIFT + BACKSPACE) Siirry seuraavalle sivulle.
CTRL+ vasen nuolinäppäin (tai CTRL + SHIFT + TAB) Siirry vasemmanpuoleiseen ikkunaan.
CTRL+ oikea nuolinäppäin (tai CTRL + TAB) Siirry oikeanpuoleiseen ikkunaan.
