Videotiedostojen kopioiminen ja siirtäminen

Voit kopioida tallennusvälineeseen tallennettuja videotiedostoja järjestelmän tallennustilaan sekä kopioida tai siirtää järjestelmän tallennustilassa olevia tiedostoja tallennusvälineeseen. Paina tuotavan tai kopioitavan tiedoston kohdalla -näppäintä ja valitse sitten asetusvalikosta [Kopioi] tai [Siirrä]. Toimi näytön ohjeiden mukaisesti.

Kopioimisen ja siirtämisen ero

Käytettävissä olevat toiminnot vaihtelevat tiedostotyyppien mukaan. Kopiosuojattuja tiedostoja voi ainoastaan siirtää. Jos tiedostoa siirretään, sitä ei enää ole sen alkuperäisessä tallennuspaikassa.

HD-tarkkuudella tallennettua maksullista sisältöä (tiedostotyyppi: MNV), joka on ladattu PlayStation®Storesta, ei voi kopioida tai siirtää, mutta sen voi valita varmuuskopioitavaksi. Voit valita PlayStation®Storen Video Storesta ladattua sisältöä varmuuskopioitavaksi käyttämällä PS3™-järjestelmän varmuuskopiointitoimintoa. Lisätietoja on tämän oppaan kohdassa (Videot) > [Videotiedostojen varmuuskopiointi ja palauttaminen].

Vihjeitä

  • Videosisällön vuokraaminen/myyminen PS3™-järjestelmän PlayStation®Store-kaupassa on lopetettu.
  • Kopioitaessa tai siirrettäessä lapsilukittua sisältöä on kirjoitettava salasana. Voit määrittää salasanan [Vaihda salasana] -kohdassa valitsemalla (Asetukset) > (Turva-asetukset).
  • Kaikki laitteet eivät ehkä pysty toistamaan kaikkia kopioituja tiedostoja.
  • Tallennusvälineiden käyttö voi edellyttää USB-sovittimen (lisävaruste) käyttöä riippuen käytössä olevasta PS3™-mallista. Videotiedostojen siirtäminen Memory Stick PRO™ -tallennusvälineeseen edellyttää USB-laitetta, joka tukee Memory Stick™ -tallennusvälineen tekijänoikeussuojaustoimintoja, kuten PSP™- tai MRW-F3-järjestelmää (Sony-tuote).
  • Memory Stick Micro™ -muistikortin käyttäminen Memory Stick™ -korttipaikalla varustetussa PS3™-järjestelmässä edellyttää Memory Stick™ M2 Duo -sovitinta.
  • Joitakin kopiosuojattuja videotiedostoja ei voi siirtää.
  • Älä riko muiden immateriaalioikeuksia.
  • Videotiedostoja ei voi kopioida tai siirtää toiston aikana.*

    • * Tämä koskee myös muita toistotoimintoja, kuten musiikkitiedostojen toistotoimintoa.

Videoiden kopioiminen tai siirtäminen PSP™-järjestelmässä katseltavaksi

Voit kopioida ja siirtää videoita PSP™-järjestelmään ja katsella niitä.

1.

Kytke PSP™-järjestelmä PS3™-järjestelmään USB-kaapelilla.
Jos haluat kopioida tiedostoja Memory Stick™ -muistikorttiin, aseta Memory Stick™ -muistikortti PSP™-järjestelmään.

2.

Valitse PSP™-järjestelmässä (Asetukset) > (USB Connection).

3.

Valitse kopioitava tai siirrettävä videotiedosto PS3™-järjestelmästä ja paina sitten -näppäintä.

4.

Valitse [Kopioi] tai [Siirrä].
Kopioi tai siirrä tiedosto näytön ohjeiden mukaisesti. Voit toistaa kopioitua tai siirrettyä videotiedostoa valitsemalla sen kohdasta (Videot) > (Memory Stick™) tai (Videot) > (System Storage) PSP™-järjestelmässä.

Vihjeitä

  • Lisätietoja videotiedostojen toistamisesta PSP™-järjestelmässä on PSP™-järjestelmän käyttöoppaassa.
  • Tietyntyyppisten videotiedostojen kopioiminen ja siirtäminen edellyttää Memory Stick PRO Duo™ -muistikortin käyttämistä.
  • HD-resoluutiolla tallennettua videosisältöä ei voi siirtää.
