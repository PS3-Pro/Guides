Käyttäjätietojen hallinta

Tämän toiminnon käyttäminen saattaa edellyttää, että käyttöjärjestelmä päivitetään.


Tarkastele tai muokkaa PlayStation®Network-tilien tietoja. Nämä toiminnot edellyttävät kirjautumista PlayStation®Networkiin. Valitse (Käyttäjätietojen hallinta) kohdasta (PlayStation®Network).

Tarkasteltavat tai muokattavat asetukset
Account Information

Voit tarkistaa ja muokata omia PlayStation®Network-verkon tilejäsi.

  • Billing Information
  • Sign-In ID (E-mail Address)
  • Password
  • Name
  • Address
  • Avatar‎
  • Profile
  • Notification Preferences‎
Sub Account Management

Voit tarkistaa ja muokata käyttäjätunnukseesi liitetyn Sub Account -tilin asetuksia

  • Parental Control‎
  • Sub Account Password
Redeem Codes Voit lunastaa PlayStation®Network Card -numeron tai mainoskoodin.
Transaction Management

Voit lisätä rahaa lompakkoon, jota käytetään PlayStation®Network-palveluissa, kuten PlayStation®Store-kaupassa, tai voit tarkastaa eri palveluiden käyttöhistoriaa.

  • Add Funds
  • Require Password at Checkout
  • Automatic Funding
  • Transaction History
  • Download List
  • Services List
System Activation Voit ottaa tilissä käyttämäsi PS3™- tai PSP™-järjestelmän käyttöön tai poistaa järjestelmän käytöstä.
Facebook

Jos sinulla on Facebook®-tili, voit määrittää Facebookissa jaettaviin tietoihin liittyviä asetuksia.

  • Jaa Trophy-tiedot
  • Jaa PlayStation®Storesta hankkimaasi sisältöä koskevat tiedot
  • Jaa pelitapahtumien tiedot
  • Poista Facebook-tilin tiedot PS3™-järjestelmästä

Vihjeitä

  • Tarkistettavat ja muokattavat kohteet vaihtelevat PlayStation®Network-tilin tyypin sekä käyttömaan tai -alueen mukaan. Lisätietoja saat alueesi teknisestä tuesta.
  • Facebook on palvelu, jonka avulla voit pitää yhteyttä muihin ihmisiin. Facebook on Facebook, Inc:n rekisteröity tavaramerkki.
  • Tämän toiminnon käyttäminen edellyttää Facebook-tiliä. Voit luoda tilin tai hankkia lisätietoja osoitteessa http://www.facebook.com/.
