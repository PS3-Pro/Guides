Elenco dei sistemi PS Vita registrati

Viene visualizzato un elenco dei sistemi PS Vita registrati utilizzando (Gestione contenuto) su quei sistemi PS Vita. Per i dettagli sulle modalità di registrazione di un sistema PS Vita, fare riferimento a (Gestione contenuto) > [PS3™] > [Trasferimento dei dati mediante Wi-Fi da e a un sistema PS3™] nella guida utente del sistema PS Vita.


Note

  • Per eliminare un sistema PS Vita dall'elenco, selezionare il sistema PS Vita, quindi selezionare [Elimina].
  • Questa impostazione viene visualizzata dopo aver eseguito una volta il collegamento con un sistema PS Vita usando (Gestione contenuto) sul sistema PS Vita.
  • Per utilizzare questa funzione, il software del sistema PS Vita deve corrispondere alla versione 3.00 o successiva.
