Avvio remoto

È possibile accendere a distanza un sistema PS3™ che si trova in modalità standby (Wake On LAN) usando un dispositivo che supporta la riproduzione remota, come ad esempio un sistema PS Vita o PSP™. Prima di utilizzare questa funzione, è necessario eseguire le operazioni indicate di seguito:

Quando si utilizza la riproduzione remota tramite la funzionalità LAN wireless del sistema PS3™ o tramite un punto di accesso:
  • Se si utilizza un sistema PSP™ per la riproduzione remota, aggiornare il software del sistema PSP™ alla versione 3.72 o successiva.
  • Impostare un login automatico in (Utenti) sul sistema PS3™

Quando si utilizza la riproduzione remota tramite Internet:
  • Se si utilizza un sistema PSP™ per la riproduzione remota, aggiornare il sistema PSP™ e il sistema PS3™ alla versione più recente del software di sistema.
  • Impostare l'accesso automatico in (Utenti) sul sistema PS3™.
  • Completare le impostazioni di rete sul sistema PS3™ in modo da poterlo collegare a Internet.
  • Creazione di un account Sony Entertainment Network.
  • Impostazioni per accedere automaticamente a PSNSM.

Note

  • Per utilizzare la funzione di avvio remoto, gli utenti dei sistemi PS3™ serie CECH-4302, CECH-4303, CECH-4304 e CECH-4308 devono essere collegati a una rete mediante la funzione LAN wireless del sistema PS3™.
  • Per ulteriori dettagli sul login automatico in (Utenti), vedere (Utenti) > [Accesso] > [Impostazioni login automatico] in questa guida.
  • Per ulteriori dettagli sull'accesso automatico a PSNSM, vedere (PlayStation™Network) > [Salva password (accesso automatico)] in questa guida.

Attivazione dell'avvio remoto

1.

Selezionare (Impostazioni) > (Impostazioni di riproduzione remota).

2.

Selezionare [Avvio remoto] > [Attiva].

3.

Sulla schermata visualizzata, selezionare [OK]. Per utilizzare la riproduzione remota tramite Internet, verificare [Abilita Avvio remoto via Internet].

4.

Spegnere il sistema PS3™.
Selezionare (Utenti) > (Spegni sistema) per spegnere il sistema e portarlo nella modalità standby. Accertarsi che la spia dell'alimentazione sia illuminata in rosso e sia fissa (non intermittente).

5.

Riprodurre a distanza utilizzando un dispositivo che supporta la riproduzione remota, come un sistema PS Vita o PSP™.
Per i dettagli sull'utilizzo della riproduzione remota, consultare le istruzioni in dotazione con il dispositivo in uso.

Note

  • Per maggiori dettagli sulla riproduzione remota mediante un sistema PS Vita o PSP™, consultare (Rete) > (Riproduzione remota) > [Uso della riproduzione remota] in questa guida.
  • Se l'avvio remoto è attivato, la ventola interna del sistema PS3™ continuerà a funzionare anche dopo lo spegnimento del sistema.

Disattivazione dell'avvio remoto

1.

Selezionare (Impostazioni) > (Impostazioni di Riproduzione Remota).

2.

Selezionare [Avvio remoto] > [Disattiva].

Avvio remoto tramite Internet

La riproduzione remota tramite Internet potrebbe non essere disponibile per il dispositivo di rete in uso. In questo caso, consultare le seguenti informazioni:

Avviso

A seconda del tipo di router, il sistema PS3™ potrebbe essere ripetutamente avviato a intervalli fissi se l'avvio remoto è abilitato. Se non si stabilisce una connessione di riproduzione remota entro un determinato periodo di tempo dall'avvio del sistema PS3™, il sistema si spegnerà automaticamente. Per evitare che ciò accada, l'avvio remoto tramite Internet potrebbe essere disabilitato automaticamente.

  • Per utilizzare l'avvio remoto tramite Internet, è necessario un router.
  • Se il router in uso supporta UPnP, abilitare la funzione UPnP del router.
  • Se il router in uso non supporta UPnP, è necessario impostare l'inoltro di porta del router per consentire la comunicazione con il sistema PS3™ da Internet. Il numero di porta utilizzato per la riproduzione remota e per l'avvio remoto è TCP: 9293 oppure UDP: 9293. Per ulteriori informazioni sulle impostazioni di questa opzione, consultare le istruzioni fornite insieme al router.
  • L'inoltro di porta è una funzione per l'inoltro dei segnali in arrivo su una porta specifica (entrata) ad un'altra porta specificata (uscita). Questa funzione viene denominata anche "mappatura porte" o "conversione indirizzi".
  • Se l'indirizzo IP del router (indirizzo IP globale) viene modificato quando il sistema PS3™ si trova in modalità standby, l'avvio remoto non si attiverà.
