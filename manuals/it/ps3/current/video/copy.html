Copia/spostamento di file video

È possibile copiare nella memoria di sistema file video salvati su supporto di memorizzazione oppure copiare o spostare file importati dalla memoria di sistema su supporto di memorizzazione. Dopo avere selezionato il file da importare o copiare, premere il tasto e selezionare [Copia] o [Sposta] nel menu opzioni. Per completare l'operazione, seguire le istruzioni sullo schermo.

Differenze tra la copia e lo spostamento

L'operazione che può essere eseguita dipende dal tipo di file. I file protetti da copia possono solamente essere spostati. Un file spostato non esiste più nel percorso di salvataggio originale.

Il contenuto pagato (tipo di file: MNV) registrato in risoluzione HD e scaricato da PlayStation®Store non può essere copiato o spostato, ma se ne può effettuare il backup selettivo. Per effettuare il backup selettivo dei contenuti scaricati dal Video Store di PlayStation®Store, usare la funzione di backup del sistema PS3™. Per ulteriori informazioni, vedere (Video) > [Backup o ripristino dei file video] in questa guida.

Note

  • La vendita / noleggio di contenuto video da PlayStation®Store sul sistema PS3™ è stata interrotta.
  • Per copiare o spostare file video su cui è stato attivato il filtro contenuti, occorre inserire una password. La password può essere impostata in [Modifica la password] sotto (Impostazioni) > (Impostazioni di sicurezza).
  • In base al dispositivo utilizzato, potrebbe essere impossibile riprodurre alcuni file copiati.
  • In base al modello di sistema PS3™ utilizzato, potrebbe essere richiesto un adattatore USB appropriato (non in dotazione) per utilizzare i supporti di memorizzazione. Inoltre, quando si spostano file video su supporti Memory Stick PRO™, è richiesto un dispositivo USB che supporti le funzioni di protezione del copyright dei supporti Memory Stick™, come il sistema PSP™ o MRW-F3 (un prodotto Sony).
  • Durante l'uso di supporti Memory Stick Micro™ con un sistema PS3™ dotato di ingressi Memory Stick™, è necessario utilizzare il supporto con un adattatore Memory Stick™ M2 Duo.
  • Alcuni file video protetti da copia non possono essere spostati.
  • Fare attenzione a non violare la proprietà intellettuale di altri.
  • Non è possibile copiare né spostare i file video durante la riproduzione del contenuto.*

    • * Include la riproduzione del contenuto utilizzando altre funzioni, come la riproduzione di file musicali.

Copia o spostamento di video per la visione su un sistema PSP™

Consente la copia o lo spostamento di file video per la visione su un sistema PSP™.

1.

Collegare il sistema PSP™ al sistema PS3™ utilizzando un cavo USB.
Per copiare i file sul supporto Memory Stick™, inserire il supporto Memory Stick™ nel sistema PSP™.

2.

Sul sistema PSP™, selezionare (Impostazioni) > (Connessione USB).

3.

Sul sistema PS3™, selezionare il file video da copiare o spostare, quindi premere il tasto .

4.

Selezionare [Copia] o [Sposta].
Per copiare o spostare il file, seguire le istruzioni sullo schermo. È possibile riprodurre il file video copiato o spostato selezionando il file sotto (Video) > (Memory Stick™) o (Video) > (Memoria di sistema) sul sistema PSP™.

Note

  • Per ulteriori informazioni sulla riproduzione di file video sul sistema PSP™, fare riferimento alla guida per l'utente del sistema PSP™.
  • In base al tipo di file video copiato o spostato, è necessario utilizzare il supporto Memory Stick PRO Duo™.
  • I contenuti video registrati in risoluzione HD non possono essere spostati.
