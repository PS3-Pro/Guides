Backup o ripristino dei file video

Usare la funzione di backup del sistema PS3™ per effettuare il backup selettivo del contenuto scaricato dal Video Store di PlayStation®Store su un supporto di memorizzazione. I file di cui si è eseguito il backup con questa funzione possono essere ripristinati sullo stesso sistema PS3™.

Backup di un file video

Collegare il supporto di memorizzazione al sistema PS3™. Selezionare l'icona del contenuto di cui si desidera effettuare il backup. Premere il tasto e selezionare quindi [Effettua backup] nel menu opzioni. Viene automaticamente creata la cartella (Utilità di backup dei dati) nel supporto di memorizzazione e il contenuto viene salvato.

Note

  • La vendita / noleggio di contenuto video da PlayStation®Store sul sistema PS3™ è stata interrotta.
  • Questa funzione può essere utilizzata per effettuare il backup dei dati su Memory Stick™, SD Memory Card, Compact Flash® e dispositivi di archiviazione USB. Con alcuni modelli del sistema PS3™, per utilizzare supporti di memorizzazione è necessario disporre di un adattatore USB appropriato (non in dotazione). Non è possibile utilizzare dischi come i CD-R.
  • Per effettuare il backup dei dati è inoltre possibile utilizzare un disco rigido USB. Tuttavia, il disco deve essere formattato come sistema file FAT32 per essere riconosciuto dal sistema PS3™. Un disco rigido formattato come NTFS (sistema file NT) non può essere riconosciuto dal sistema PS3™.
  • Il contenuto di cui si è effettuato il backup non può essere riprodotto dal supporto di memorizzazione. Per riprodurre il contenuto è necessario prima ripristinarlo nella memoria di sistema del sistema PS3™.

Ripristino di un file video di cui si è effettuato il backup

È possibile ripristinare sul sistema PS3™ il contenuto di cui si è effettuato il backup in un supporto di memorizzazione.

1.

Collegare il supporto di memorizzazione contenente il contenuto di cui si è effettuato il backup al sistema PS3™.

2.

Selezionare l'icona del supporto di memorizzazione in (Video).

3.

Selezionare il contenuto che si desidera ripristinare da (Utilità di backup dei dati), quindi premere il tasto .

4.

Selezionare [Ripristina].

Note

  • Se il nome della cartelle o il nome del file dei dati di cui si è effettuato il backup sono stati modificati, potrebbe non essere possibile ripristinare tale contenuto.
  • Se si esegue una delle seguenti operazioni dopo aver effettuato il backup del contenuto, il contenuto potrebbe non essere ripristinato correttamente.
  • - Formattare la memoria di sistema
  • - Ripristinare il sistema PS3™
  • In alcuni casi, potrebbe non essere possibile utilizzare la funzione di backup per effettuare il backup o ripristinare il contenuto sul sistema in maniera corretta.
