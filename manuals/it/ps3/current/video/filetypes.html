Tipi di file che è possibile riprodurre

Sotto (Video) è possibile riprodurre i seguenti tipi di file.

  • Formato Video Memory Stick
  • - MPEG-4 SP (AAC LC)
  • - H.264/MPEG-4 AVC Alto profilo (AAC LC)
  • - MPEG-2 TS (H.264/MPEG-4 AVC, AAC LC)
  • Formato di file MP4
  • - H.264/MPEG-4 AVC Profilo elevato (AAC LC)
  • MPEG-1 (MPEG Audio Layer 2)
  • MPEG-2 PS (MPEG2 Audio Layer 2, AAC LC, AC3 (Dolby Digital), LPCM)
  • MPEG-2 TS (MPEG2 Audio Layer 2, AC3 (Dolby Digital), AAC LC)
  • MPEG-2 TS (H.264/MPEG-4 AVC, AAC LC)
  • AVI
  • - Motion JPEG (PCM lineare)
  • - Motion JPEG (μ-Law)
  • AVCHD (.m2ts / .mts)
  • DivX
  • WMV
  • - VC-1（WMA Standard V2）

Note

  • A seconda del tipo di dati, alcuni file potrebbero non essere riproducibili o alcune opzioni del pannello di controllo non utilizzabili durante la riproduzione.
  • Alcuni file video distribuiti su Internet possono disporre di limitazioni alla riproduzione. Per ulteriori informazioni, contattare il fornitore del contenuto.
  • Per riprodurre i file in formato WMV, è necessario aprire (Impostazioni) > (Impostazioni del sistema) e impostare [Abilita riproduzione WMA].
  • Quando si utilizza un adattatore USB per riprodurre file video, potrebbe essere necessario utilizzare un adattatore USB (non in dotazione) che supporta la funzioni di protezione del copyright (per riprodurre file protetti da copyright).
  • Se si utilizza un adattatore USB per riprodurre file in formato AVCHD salvati su supporto Memory Stick™, utilizzare un dispositivo che supporti Hi-Speed USB (USB 2.0).
  • I file protetti da copyright in formato WMV non possono essere riprodotti.
