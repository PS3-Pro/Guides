Copia di giochi da utilizzare su un sistema PSP™

Se il gioco scaricato (a pagamento o gratuitamente) da (PlayStation®Store) è compatibile con il sistema PSP™, è possibile copiarlo per utilizzarlo su un sistema PSP™.

1.

Accedere a PSNSM utilizzando l'account Sony Entertainment Network utilizzato per scaricare il gioco.

2.

Collegare il sistema PSP™ e il sistema PS3™ utilizzando un cavo USB.
Per copiare i file sul supporto Memory Stick™, inserire il supporto Memory Stick™ nel sistema PSP™.

3.

Sul sistema PSP™, selezionare (Impostazioni) > (Connessione USB).

4.

Sul sistema PS3™, selezionare il gioco da copiare sotto (Gioco), quindi premere il tasto .

5.

Selezionare [Copia].
Per copiare il gioco seguire le istruzioni sullo schermo. Al termine della copia, è possibile avviare il gioco sul sistema PSP™ sotto (Gioco) > (Memory Stick™) o (Gioco) > (Memoria di sistema).

Note

  • Per utilizzare questa funzione, il software del sistema PSP™ deve corrispondere alla versione 6.50 o successiva.
  • Per ulteriori informazioni sull'utilizzo di giochi sul sistema PSP™, fare riferimento alla guida per l'utente del sistema PSP™.

Giochi utilizzabili sui sistemi PS3™ o PSP™

Se si utilizza un gioco compatibile con entrambi i sistemi, è possibile copiare i dati salvati del gioco da un sistema all'altro per continuare a giocare dal punto più recente. Il metodo di copia dei dati salvati è diverso a seconda del tipo di gioco.

Dati salvati per il software in formato PlayStation®

I dati salvati per il software in formato PlayStation® vengono salvati su una scheda di memoria interna che viene creata nella memoria di sistema. Per copiare i dati salvati in un sistema PSP™, eseguire i passaggi 2 e 3 precedenti, quindi selezionare (Gioco) > (Utilità della Memory Card) > (Memory Card (PS) interna) sul sistema PS3™. Selezionare quindi l'icona dei dati salvati da copiare, premere il tasto e selezionare [Copia] nel menu opzioni.

Note

  • Occorre convertire il formato dei dati salvati per consentire l'utilizzo dei dati su un sistema PSP™. Se durante l'operazione di copia viene visualizzata una schermata di conferma in merito alla conversione dei dati, selezionare [Sì] per procedere.
  • Per ogni titolo di software salvato sul supporto Memory Stick™ (inserito nel sistema PSP™) o sulla memoria di sistema del sistema PSP™go vengono create più schede di memoria interne.
  • Se si copiano i dati salvati sul supporto Memory Stick™ inserito nel relativo alloggiamento di un sistema PS3™ o si utilizza un adattatore USB (venduto separatamente), i dati salvati non vengono riconosciuti.

Attivazione di un sistema PSP™

È possibile riprodurre i giochi scaricati (tramite acquisto o gratuitamente) da (PlayStation®Store) su un sistema PSP™ attivato. Se all'avvio di un gioco sul sistema PSP™ viene visualizzato un messaggio che indica che è richiesta l'attivazione, attivare il dispositivo attenendosi alla seguente procedura.

1.

Collegare il sistema PSP™ e il sistema PS3™ utilizzando un cavo USB.

2.

Sul sistema PSP™, selezionare (Impostazioni) > (Connessione USB).

3.

Sul sistema PS3™, selezionare (PlayStation™Network) > (Gestione account).

4.

Selezionare (Attivazione sistema).
Per completare la procedura di attivazione, attenersi alle istruzioni a video.

Note

  • Per eseguire l'attivazione del dispositivo è necessario accedere al sistema PS3™ con le credenziali dello stesso utente che ha scaricato il software in formato PlayStation®.
  • L'attivazione del dispositivo è una procedura che consente la riproduzione di contenuto sui dispositivi autenticati come mezzo per la protezione dei diritti digitali del contenuto.
