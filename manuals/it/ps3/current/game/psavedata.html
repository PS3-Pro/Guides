Uso dei dati salvati per il software minis e PSP™Game (gioco PSP™)

Copia dei dati salvati per PSP™Game (gioco PSP™) in un sistema PS3™.

1.

Collegare il sistema PSP™ al sistema PS3™ utilizzando un cavo USB.

2.

Sul sistema PS3™, selezionare (Gioco) > (Utilità dei dati salvati (minis / PSP™)).

3.

Selezionare i dati salvati che si desidera copiare, quindi premere il tasto .

4.

Selezionare [Copia].

Note

  • I dati salvati vengono gestiti separatamente da ogni utente. Se esistono più utenti in (Utenti),
    le voci visualizzate in (Utilità dei dati salvati (minis / PSP™)) dipendono dall'utente che ha effettuato l'accesso.
  • Selezionando l'icona dei dati salvati e premendo il tasto è possibile ordinare i dati salvati per data di aggiornamento o raggruppare i dati salvati per titolo dal menu visualizzato.
  • I giochi per il sistema PSP™ (nel formato PSP™Game) non possono essere riprodotti sul sistema PS3™.
  • Alcuni giochi possono imporre limitazioni all'uso dei dati salvati. Consultare il manuale del software per i dettagli.
  • Il software in formato PlayStation® scaricato da PlayStation®Store e salvato sul sistema PSP™ viene visualizzato in (Utilità della Memory Card).
