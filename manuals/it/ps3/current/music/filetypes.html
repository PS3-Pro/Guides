Tipi di file che è possibile riprodurre

Sotto (Musica) è possibile riprodurre i seguenti tipi di file.

  • Formato audio Memory Stick (ATRAC)
  • MP3
  • - MPEG-1/2 Audio Layer3
  • - MP3 Surround
  • MP4 (MPEG-4 AAC)
  • WAVE (PCM lineare)
  • WMA

Note

  • Potrebbe essere impossibile riprodurre alcuni file a causa del tipo di dati.
  • Alcuni file musicali distribuiti su Internet possono disporre di limitazioni alla riproduzione. Per ulteriori informazioni, contattare il fornitore del contenuto.
  • Per riprodurre i file in formato ATRAC, è necessario aprire (Impostazioni) > (Impostazioni del sistema) e impostare [Abilita ATRAC].
  • Per riprodurre i file in formato WMA è necessario aprire (Impostazioni) > (Impostazioni del sistema) e impostare [Abilita riproduzione WMA].
  • Non è possibile riprodurre file in formato WMA protetti da copyright.
  • I file MP3 Surround possono essere riprodotti solo quando il sistema è impostato per l'uscita audio nel formato Linear PCM.
  • Quando si utilizza un adattatore USB per riprodurre file musicali, potrebbe essere necessario utilizzare un adattatore USB (non in dotazione) che supporta le funzioni di protezione del copyright (per riprodurre file protetti da copyright).
