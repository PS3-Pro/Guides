Uso della riproduzione remota (tramite un punto di accesso)

Collegare il sistema PS3™ a un punto di accesso tramite un cavo Ethernet. Utilizzare la funzione di rete wireless di un dispositivo che supporta la riproduzione remota, come un sistema PS Vita o un sistema PSP™ , per effettuare il collegamento al sistema PS3™ tramite il punto di accesso.

Esempio di configurazione comune

Note

  • Un router senza fili è un dispositivo che attribuisce al router funzionalità di access point. Un punto di accesso è un dispositivo che consente di effettuare la connessione a una rete senza l'uso di cavi. Un router è un dispositivo impiegato per la condivisione di una connessione Internet tra più dispositivi.
  • Un modem può essere dotato di funzionalità router. Collegare il sistema PS3™ a un dispositivo dotato di funzionalità router.
  • Se il punto di accesso e il modem dispongono entrambi della funzionalità router, disattivare la funzionalità su uno dei dispositivi. Il sistema PS3™ e il dispositivo che supporta la riproduzione remota devono essere connessi all'interno della stessa rete. Se vengono utilizzati contemporaneamente due o più router, il sistema PS3™ e il dispositivo possono essere connessi a reti separate, impedendo l'uso della riproduzione remota.

Preparazione all'uso (del sistema PS3™ e del dispositivo che supporta la riproduzione remota)

Per utilizzare la riproduzione remota per la prima volta, è necessario registrare (operazione di pairing) il dispositivo che supporta la riproduzione remota, come ad esempio un sistema PS Vita o un sistema PSP™, con il sistema PS3™. Per registrare il dispositivo (pairing), selezionare (Impostazioni) > (Impostazioni di riproduzione remota) > [Registra dispositivo].

Preparazione all'uso (del dispositivo che supporta la riproduzione remota)

Creare una connessione di rete per collegare il dispositivo a un punto di accesso. Se il dispositivo possiede già una connessione di rete salvata, non è necessario crearne una nuova. Per ulteriori informazioni sulla creazione di una connessione di rete sul dispositivo, consultare la guida per l'utente per il dispositivo stesso.

Utilizzo della riproduzione remota su un sistema PS Vita

1.

Sul proprio sistema PS Vita, premere (Riproduzione remota PS3) > [Avvia].

2.

Sul sistema PS3™ , selezionare (Rete) > (Riproduzione remota).
Il sistema PS3™ attende che il sistema PS Vita stabilisca la connessone di riproduzione remota.

3.

Sul proprio sistema PS Vita, premere [Connetti via rete privata].
Quando i dispositivi si connettono correttamente, la schermata del sistema PS3™ viene visualizzata sul proprio sistema PS Vita.
Se viene visualizzata la schermata delle impostazioni Wi-Fi, selezionare il punto di accesso collegato al sistema PS3™.

Utilizzo della riproduzione remota su un sistema PSP™

1.

Sul sistema PS3™, selezionare (Rete) > (Riproduzione remota).
Il sistema entra nella modalità standby di connessione per la riproduzione remota.

2.

Sul sistema PSP™, selezionare (Rete) > (Riproduzione remota).

3.

Selezionare [Collega via rete privata].

4.

Selezionare nell'elenco la connessione al punto di accesso da utilizzare per la riproduzione remota.
Se la connessione avviene correttamente, la schermata del sistema PS3™ viene visualizzata sul sistema PSP™.

Note

  • La riproduzione remota può essere utilizzata nel raggio d'azione del segnale del punto di accesso.
  • Se si abilita l'impostazione di avvio remoto del sistema PS3™, è possibile impostare il sistema per l'accensione automatica (Attiva LAN). Per ulteriori informazioni, consultare (Impostazioni) > (Impostazioni di riproduzione remota) > [Avvio remoto] della presente guida.
  • Durante la riproduzione remota, se si va sulla schermata di un'applicazione diversa, la connessione di riproduzione remota viene chiusa dopo 30 secondi.
