Utilizzo di tasti di scelta rapida/mouse/tastiera

Utilizzo dei tasti di scelta rapida

È possibile eseguire le operazioni direttamente con i pulsanti del controller wireless senza utilizzare il menu. Le operazioni disponibili variano tra la modalità browse e la modalità finestra.

Modalità browse
Tasto Apre il collegamento.
Tasto (senza rilasciarlo) Apre il collegamento in una nuova finestra.
Tasto + levetta sinistra Consente di selezionare un testo.
Tasto Visualizza il menu.
Tasto Chiude (Browser per Internet).
Tasto (senza rilasciarlo) Chiude la finestra. *1
Tasto START Inserisce un indirizzo.
Tasto SELECT Apre [I miei segnalibri].
Tasti L1/R1 Consente di procedere o tornare indietro di una pagina.
Tasti L2/R2 Passano a una finestra diversa. *2
Tasti direzionali Spostano il puntatore a un collegamento nella direzione del pulsante premuto.
Levetta sinistra Sposta il puntatore nella direzione desiderata.
Levetta sinistra (senza rilasciarla) (tasto L3) Passa alla modalità finestra.
Levetta destra Scorre nella direzione desiderata.
Levetta destra (senza rilasciarla) (tasto R3) Utilizza visualizzazione zoom./ Annulla visualizzazione zoom.
Tasto PS Visualizza il menu XMB™.
*1

Questa operazione non può essere eseguita durante lo zoom.
*2

Consente l'ingrandimento o la riduzione durante lo zoom.
Modalità finestra
Tasto Visualizza la finestra selezionata nella modalità browse.
Tasto Visualizza il menu.
Levetta sinistra (senza rilasciarla) (tasto L3) Passa alla modalità browse.
Tasti direzionali Passano a una finestra diversa.
Tasto PS Visualizza il menu XMB™.

Utilizzo di un mouse (non in dotazione)

Le operazioni possono essere eseguite con un mouse disponibile in commercio.

Trascinare a sinistra tenendo premuto il tasto destro del mouse Torna alla pagina precedente.
Trascinare a destra tenendo premuto il tasto destro del mouse Passa alla pagina successiva.

Utilizzo di una tastiera (non in dotazione)

Utilizzare una tastiera disponibile in commercio.

CTRL + L (o F4) Inserire un indirizzo.
CTRL + R (o F5) Aggiornare la pagina.
CTRL + B (o CTRL + I) Aprire [I miei segnalibri].
PGSU (o MAIUSC+BARRA SPAZIATRICE) Scorrere verso l'alto.
PGGIÙ (o BARRA SPAZIATRICE) Scorrere verso il basso.
Principale Vai all'inizio della pagina.
Fine Vai alla fine della pagina.
TAB Spostare il cursore.
ALT + FRECCIA SINISTRA (o BACKSPACE) Ritornare alla pagina precedente.
ALT + FRECCIA DESTRA (o MAIUSC + BACKSPACE) Passare alla pagina successiva.
CTRL + FRECCIA SINISTRA (o CTRL + MAIUSC + TAB) Passare alla finestra sinistra.
CTRL + FRECCIA DESTRA (o CTRL + TAB) Passare alla finestra destra.
