Cambiare le dimensioni di visualizzazione di una pagina Web

La visualizzazione delle pagine Web può essere troppo grande o troppo piccola, a seconda delle impostazioni di uscita video del sistema PS3™ e del televisore collegato. In tal caso, è possibile utilizzare il metodo seguente per regolare le dimensioni di visualizzazione.

Utilizzare la funzione di zoom

Consente di ingrandire automaticamente alle dimensioni ottimali l'area dello schermo in cui è posizionato il puntatore. La percentuale di ingrandimento migliore viene calcolata automaticamente in base all'area dello schermo in cui è posizionato il puntatore. Posizionare il puntatore sull'area che si desidera ingrandire, premere il tasto , quindi selezionare [Zoom] sotto (Visualizza) nel menu opzioni.

Esempio di ingrandimento del testo

Il sistema calcola la percentuale di ingrandimento in base alle dimensioni del paragrafo del testo nell'area in cui è posizionato il puntatore, quindi visualizza il testo in modalità zoom.


Esempio di ingrandimento di un'immagine

Il sistema calcola la percentuale di ingrandimento in base alle dimensioni dell'immagine nell'area in cui è posizionato il puntatore, quindi visualizza l'immagine in modalità zoom.

Modificare la risoluzione

Modificare la risoluzione a schermo di una pagina Web. È possibile regolare la visualizzazione di una pagina Web ad una dimensione più comoda per adattarsi alla risoluzione di uscita video del sistema PS3™. Premere il tasto e selezionare quindi [Risoluzione] sotto (Strumenti) nel menu opzioni.


Se si imposta [-1] o [-2] quando la risoluzione di uscita video del sistema PS3™ è impostata su 1080p o 1080i, il display viene ingrandito per una visualizzazione migliore. Se si imposta [+1] o [+2] quando la risoluzione di uscita video del sistema PS3™ è impostata su Normale (NTSC: 480i / PAL: 576i) o 480p / 576p, il display viene ridotto per una visualizzazione migliore.
