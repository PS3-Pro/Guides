Stampa delle immagini

È possibile stampare le immagini in (Foto). Per utilizzare questa funzione, è necessario configurare una stampante utilizzando [Selezione stampante] in (Impostazioni) > (Impostazioni della stampante).

1.

Collegare una stampante al sistema PS3™.

2.

Sotto (Foto), selezionare l'immagine da stampare, quindi premere il tasto .

3.

Selezionare [Stampa].

4.

Controllare le impostazioni di stampa.
È possibile premere il tasto per visualizzare il menu delle opzioni e cambiare le impostazioni di stampa o il numero di copie da stampare. Le voci visualizzate dipendono dalla stampante in uso.

5.

Selezionare [Stampa].
L'immagine viene stampata.

Note

  • Le stampanti utilizzabili dipendono dal paese o dalla zona di residenza. Per ulteriori informazioni, visitare il sito Web di SCE della propria regione.
  • Per stampare l'immagine correntemente visualizzata, premere il tasto per visualizzare il pannello di controllo a schermo, quindi selezionare [Stampa].
  • Per stampare un'immagine salvata in un server multimediale DLNA, copiare prima l'immagine sul disco rigido del sistema PS3™.
