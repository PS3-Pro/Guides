Recupero o modifica di informazioni sui CD audio

Recupero di informazioni sui CD audio

Quando si inserisce un CD audio, il sistema PS3™ si connette automaticamente a Internet e reperisce informazioni sul CD. Per reperire informazioni sui CD, è innanzitutto necessario accettare le condizioni d'uso visualizzate sullo schermo.

Note

  • È inoltre possibile reperire informazioni sui CD nel menu opzioni. Una volta selezionata l'icona del CD, premere il tasto e selezionare [Reperisci informazioni sul CD]. Per completare l'operazione, seguire le istruzioni sullo schermo.
  • Se non sono state reperite informazioni sul CD, quando si inserisce un CD nel sistema non verranno visualizzati i nomi dettagliati dell'album e dei brani.

Modifica delle informazioni sui CD audio

È possibile modificare le informazioni sul CD ottenute. Selezionare l'icona del CD audio o del brano, quindi premere il tasto e selezionare [Informazioni] dal menu delle opzioni. Selezionare l'elemento da modificare.

Note

  • Le informazioni modificate possono essere trasmesse tramite Internet alla società All Media Guide, nel caso in cui le informazioni sul CD ottenute automaticamente dal sistema PS3™ non siano corrette. Selezionare l'icona del CD audio, premere il tasto e selezionare [Invia informazioni sul CD] dal menu delle opzioni.
  • All Media Guide è una società che fornisce un database di informazioni sui CD.
  • Se i campi [Album], [Artista] e [Genere] non contengono informazioni, non è possibile inviare informazioni a All Media Guide.
  • Non è possibile modificare o inviare le informazioni sul CD per i Super Audio CD.

Avviso

Su alcuni sistemi PS3™ non è consentita la riproduzione di Super Audio CD. Per ulteriori informazioni, consultare [Tipi di dischi riproducibili].
