Gestione delle informazioni sul proprio account

Per utilizzare questa funzione, potrebbe essere richiesto di aggiornare il software di sistema.


È possibile controllare o modificare le informazioni degli account PlayStation®Network. Per eseguire queste operazioni è necessario avere effettuato l'accesso a PlayStation®Network. Selezionare (Gestione account) in (PlayStation®Network).

Elementi che è possibile controllare o modificare
Informazioni sull'account

È possibile controllare o modificare le informazioni relative agli account PlayStation®Network.

  • Estremi di fatturazione
  • ID di accesso (indirizzo di e-mail)
  • Password
  • Nome
  • Indirizzo
  • Avatar
  • Profilo
  • Preferenze di notifica
Gestione account secondario

È possibile rivedere o modificare le impostazioni per un account secondario associato.

  • Filtro contenuti
  • Password account secondario
Riscatta codici Consente di riscattare un numero di PlayStation®Network Card o un codice promozionale.
Gestione transazioni

È possibile aggiungere fondi al portafoglio utilizzato per i servizi PlayStation®Network come PlayStation®Store o controllare la cronologia di utilizzo per vari servizi.

  • Aggiungi fondi
  • Richiedi password al pagamento
  • Aggiunta automatica di fondi
  • Cronologia transazioni
  • Contenuto scaricato
  • Lista servizi
Attivazione sistema È possibile attivare o disattivare il sistema PS3™ o il sistema PSP™ utilizzato per l'account.
Facebook

Se si dispone di un account Facebook®, è possibile regolare le impostazioni relative alla condivisione delle informazioni su Facebook.

  • Condividi informazioni sui trofei
  • Condividi informazioni sui contenuti acquistati in PlayStation®Store
  • Condividi informazioni sugli eventi di gioco
  • Elimina informazioni sull'account di Facebook dal sistema PS3™

Note

  • Le voci verificabili o modificabili dipendono dal tipo di account PlayStation®Network e dal paese o dalla regione di utilizzo. Per ulteriori informazioni, rivolgersi alla linea di supporto tecnico per la propria regione.
  • Facebook è un servizio che ti aiuta a connetterti e rimanere in contatto con le persone della tua vita. Facebook è un marchio registrato di Facebook, Inc.
  • È necessario disporre di un account di Facebook per poter utilizzare questa funzionalità. Per creare un account e per ulteriori informazioni, visitare il sito http://www.facebook.com/.
