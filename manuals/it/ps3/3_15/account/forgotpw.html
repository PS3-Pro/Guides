Se si dimentica la password

Per utilizzare questa funzione, potrebbe essere richiesto di aggiornare il software di sistema.


Per riconfigurare la password dimenticata, attenersi alla seguente procedura.

1.

Selezionare (PlayStation®Network) > (Accedi).

2.

Selezionare [Password smarrita?] nella schermata dell'ID di accesso (indirizzo di e-mail) e della password.

3.

Inserire l'ID di accesso (indirizzo di e-mail) e la data di nascita.

4.

Selezionare il metodo di modifica della password.

Reimposta usando la domanda di sicurezza È possibile riconfigurare la password rispondendo correttamente alla domanda di sicurezza selezionata quando è stato creato l'account PlayStation®Network.

Per completare l'operazione, seguire le istruzioni sullo schermo.
Reimposta tramite e-mail È possibile riconfigurare la password utilizzando il PC.

Un messaggio e-mail viene recapitato all'indirizzo utilizzato come ID di accesso. Per riconfigurare la password utilizzando il PC, seguire la procedura indicata nel messaggio e-mail.
