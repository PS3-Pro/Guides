Ripristina le impostazioni predefinite

È possibile ripristinare le impostazioni predefinite del software di sistema. Per eseguire questa operazione, seguire le istruzioni sullo schermo.


Una volta completata l'operazione, viene visualizzata la schermata di configurazione iniziale. Seguire le istruzioni sullo schermo per eseguire la configurazione iniziale del software di sistema.


Avvisi

  • Quando si esegue questa operazione, vengono ripristinate le impostazioni predefinite del software del sistema e delle informazioni per l'utente attualmente connesso. Fare attenzione quando si esegue questa operazione perché non è possibile annullare le modifiche apportate alle impostazioni. La responsabilità per perdita o corruzione dei dati è assunta dall'utente.
  • Se sul sistema PS3™ esistono più utenti, le informazioni gestite da utenti diversi da quello attualmente connesso non verranno ripristinate. Le informazioni che potrebbero essere gestite da altri utenti e che non verranno ripristinate sono:
  • - ID di accesso e password per PlayStation®Network
  • - Segnalibri, cronologia e impostazioni aggiunti in (Browser per Internet)
  • - Informazioni sull'immagine impostata come sfondo in (Foto)
  • - Parole del dizionario del testo predittivo, il testo immesso dalla tastiera e altri contenuti salvati sotto (Impostazioni) > (Impostazioni del sistema) > [Aggiungi/modifica termine]
  • - Le impostazioni della tastiera o del mouse impostate in (Impostazioni) > (Impostazioni degli accessori)
  • - Impostazioni di Cambia voce sotto (Impostazioni) > (Impostazioni degli accessori) > [Cambia voce]
  • - Impostazioni di temi. colori, sfondi e set di caratteri sotto (Impostazioni) > (Impostazioni dei temi)
  • Non spegnere il sistema PS3™ durante questa operazione. Se l'operazione viene annullata prima del completamento, il software di sistema può risultare danneggiato e potrebbe essere necessario riparare o cambiare il sistema.
  • Durante questa operazione il tasto di accensione situato sulla parte anteriore del sistema e il tasto PS sul controller wireless non sono attivi.
  • Non è possibile utilizzare questa funzione per ripristinare una versione precedente del software di sistema.
