Uso dei dati salvati

I dati salvati per il software in formato PlayStation®2 o PlayStation® vengono salvati su Memory Card interne create sul disco rigido. Le Memory Card interne possono essere utilizzate associandole a ingressi successivamente alla creazione. I dati vengono visualizzati sotto (Utilità della Memory Card (PS/PS2)).

Avvisi

  • Alcuni titoli di software in formato PlayStation®2 o PlayStation® possono essere eseguiti in modo differente sul sistema PS3™ rispetto all'esecuzione sui sistemi PlayStation®2 o PlayStation®, oppure non vengono eseguiti correttamente sul sistema PS3™.
  • Inoltre, il software in formato PlayStation®2 non è riproducibile su alcuni sistemi PS3™. Per i dettagli, vedere [Tipi di dischi riproducibili], visitare il sito Web di SCE per la propria zona o rivedere la documentazione inclusa con il sistema PS3™.

Creazione di una Memory Card interna

1.

Selezionare (Utilità della Memory Card (PS/PS2)) sotto (Gioco) nel menu iniziale.

2.

Selezionare (Crea nuova Memory Card interna).
Per completare l'operazione, seguire le istruzioni sullo schermo.

Nota

È possibile modificare i nomi delle memory card interne o le icone sotto [Informazioni] nel menu opzioni.

Assegnazione di un ingresso

1.

Selezionare (Gioco) > (Utilità della Memory Card (PS / PS2)).

2.

Selezionare la Memory Card interna da utilizzare e premere quindi il tasto .

3.

Selezionare [Assegna ingressi].

Note

  • In base al software, è possibile che gli ingressi siano preassegnati. Per ulteriori informazioni, consultare le istruzioni per l'uso in dotazione con il software.
  • È possibile assegnare ingressi durante il gioco. Premere il tasto PS sul controller wireless, quindi selezionare [Assegna ingressi] nella schermata visualizzata.
