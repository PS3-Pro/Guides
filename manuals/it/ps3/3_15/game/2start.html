Avvio/uscita dai giochi

Avvio di un gioco

Quando si inserisce il disco, il gioco viene avviato automaticamente.

Uscita da un gioco

Durante il gioco, premere il tasto PS sul controller wireless e selezionare quindi [Esci dal gioco].

Avviso

Quando si avvia o si chiude il software in formato PlayStation®2, le assegnazioni di numeri del controller vengono cancellate. Seguire la procedura sotto per assegnare numeri del controller.

Quando si avvia un gioco: Premere il tasto PS sul controller quando il gioco è visualizzato sullo schermo.
Quando si esce da un gioco:  Premere il tasto PS sul controller quando è visualizzato il menu XMB™.

Nota

Per salvare i dati dal software in formato PlayStation®2 / PlayStation®, è necessario creare una Memory Card interna. Per ulteriori informazioni sulle schede di memoria interne, vedere (Gioco) > [Riproduzione di software in formato PlayStation®2 e PlayStation®] > [Uso dei dati salvati] in questa guida.

Riconfigurazione dei giochi

Durante il gioco, premere il tasto PS sul controller wireless e selezionare quindi [Ripristina gioco] nella schermata visualizzata. È possibile ripristinare un gioco solo quando si utilizza un titolo software in formato PlayStation®2 o PlayStation®.

Avvisi

  • Alcuni titoli di software in formato PlayStation®2 o PlayStation® possono essere eseguiti in modo differente sul sistema PS3™ rispetto all'esecuzione sui sistemi PlayStation®2 o PlayStation®, oppure non vengono eseguiti correttamente sul sistema PS3™.
  • Inoltre, il software in formato PlayStation®2 non è riproducibile su alcuni sistemi PS3™. Per i dettagli, vedere [Tipi di dischi riproducibili], visitare il sito Web di SCE per la propria zona o rivedere la documentazione inclusa con il sistema PS3™.
