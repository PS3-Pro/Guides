Remote Start

Et PS3™-system, der er sat på standby, kan tændes automatisk, når et PSP™-system bruges til Remote Play (Wake On LAN). Følg trinnene nedenfor for at bruge denne funktion:

Brug af Remote Play via PS3™-systemets trådløse LAN-funktion eller via et adgangspunkt:
  • Opdater din PSP™ System Software til version 3.72 eller nyere.
  • Indstil Automatisk log på under (Brugere) på PS3™-systemet.

Brug af Remote Play via internettet:
  • Opdater PSP™-systemet og PS3™-systemet til den seneste version af systemsoftwaren.
  • Indstil til automatisk at logge på under (Brugere) på PS3™-systemet.
  • Angiv netværksindstillingerne på PS3™-systemet, så det kan sluttes til internettet.
  • Opret en PlayStation®Network-konto.
  • Indstil automatisk log-in under PlayStation®Network.

Tips

  • Yderligere oplysninger om Automatisk log på under (Brugere) findes under (Brugere) > [Log på] > [Indstilling af automatisk log på] i denne vejledning.
  • Yderligere oplysninger om automatisk log-in på PlayStation®Network findes under (PlayStation®Network) > [Gem adgangskode /Automatisk log ind] i denne vejledning.

Aktivering af Remote Start

1.

Vælg (Indstillinger) > (Remote Play indstillinger).

2.

Vælg [Remote Start] > [Aktiver].

3.

Vælg [OK] på den viste skærm. Se [Aktiver Remote Start via internettet] for at bruge Remote Play via internettet.

4.

Sluk PS3™-systemet.
Vælg (Brugere) > (Sluk system) for at slukke systemet og sætte det på standby. Kontroller, om strømindikatoren lyser rødt hele tiden.

5.

Brug af Remote Play på PSP™-systemet.
Yderligere oplysninger om brug af Remote Play findes under (Netværk) > (Remote Play) > [Brug af Remote Play] i denne vejledning.

Tip

Hvis du har aktiveret Remote Start, bliver den indbyggede blæser i PS3™-systemet ved med at køre, selvom der er slukket for systemet.

Deaktivering af Remote Start

1.

Vælg (Indstillinger) > (Remote Play indstillinger).

2.

Vælg [Remote Start] > [Sluk].

Remote Start via internettet

Du kan muligvis ikke bruge Remote Play via internettet, afhængigt af den aktuelle netværksenhed. Hvis dette sker, skal du kontrollere følgende:

Vigtigt

Afhængigt af typen af router, startes PS3™-systemet muligvis ved en fejl, hvis du har aktiveret Remote Start. Systemet slukkes automatisk, hvis der ikke oprettes Remote Play-forbindelse inden for et bestemt stykke tid efter, at PS3™-systemet er startet. Hvis du vil undgå dette, kan Remote Start via internettet deaktiveres automatisk.

  • Brug af Remote Start via internettet kræver en router.
  • Hvis den aktuelle router understøtter UPnP, skal du aktivere dens UPnP-funktion.
  • Hvis den aktuelle router ikke understøtter UPnP, skal du indstille dens "port forwarding" til at tillade kommunikation med dit PS3™-system via internettet. Portnummeret til Remote Play og Remote Start er TCP: 9293 eller UDP: 9293. Yderligere oplysninger om angivelse af denne indstilling findes i den vejledning, der fulgte med routeren.
  • "Port forwarding" er en funktion, der videresender signaler til en bestemt port (indgang) til en anden port (udgang). Dette kaldes også "port mapping" eller "adressekonvertering".
  • Hvis du ændrer routerens ip-adresse (den globale ip-adresse), når PS3™-systemet er i standby, kan du ikke bruge Remote Start.
