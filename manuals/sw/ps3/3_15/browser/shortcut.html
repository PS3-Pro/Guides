Använda snabbtangenter/mus/tangentbord

Använda snabbtangenter

Du kan använda knapparna på den trådlösa kontrollern direkt, utan att använda menyn. Kommandona kan skilja sig åt mellan bläddringsläget och fönsterläget.

Bläddringsläget
-knappen Öppna länken.
-knappen (håll nedtryckt) Öppna länk i ett nytt fönster.
-knappen + vänsterspaken Välj text.
-knappen Visa menyn.
-knappen Stäng (Webbläsare).
-knappen (håll nedtryckt) Stäng fönstret.*1
START-knappen Ange en adress.
SELECT-knappen Öppna [Mina bokmärken].
L1/R1-knapparna Gå bakåt eller framåt.
L2/R2-knapparna Flytta till ett annat fönster.*2
Riktningsknappar Flytta markören till en länk i den nedtryckta knappens riktning.
-knapp + riktningsknapp Rulla sidvis åt samma håll som den nertryckta knappen.
Vänsterspak Flytta markören i önskad riktning.
Vänsterspak (tryck ned) (L3-knappen) Växla till fönsterläge.
Högerspak Bläddra i önskad riktning.
Högerspak (tryck ned) (R3-knappen) Zooma / Icke-zooma.
PS-knappen Visa XMB™-menyn.
*1

Denna funktion kan inte användas vid zoomning.
*2

Förstorar eller förminskar vid zoomning.
Fönsterläget
-knappen Visa det valda fönstret i bläddringsläget.
-knappen Visa menyn.
Vänsterspak (tryck ned) (L3-knappen) Växla till bläddringsläge.
Riktningsknappar Flytta till ett annat fönster.
PS-knappen Visa XMB™-menyn.

Använda en mus (medföljer inte)

Använd med en kommersiellt tillgänglig mus.

Dra till vänster medan du håller ned höger musknapp Återgå till föregående sida.
Dra till höger medan du håller ned höger musknapp Gå till nästa sida.

Använda ett tangentbord (medföljer inte)

Använd ett vanligt tangentbord.

CTRL + L (eller F4) Ange en adress.
CTRL + R (eller F5) Uppdatera sidan.
CTRL + B (eller CTRL + I) Öppna [Mina bokmärken].
PAGE UP (eller SHIFT + BLANKSTEGSTANGENT) Rulla uppåt.
PAGE DOWN (eller BLANKSTEGSTANGENT) Rulla ned.
Hem Flytta upp överst på sidan.
Slut Flytta längst ner på sidan.
TAB Flytta markören.
ALT + PIL VÄNSTER (eller BACKSPACE) Återgå till föregående sida.
ALT + PIL HÖGER (eller SHIFT + BACKSPACE) Gå till nästa sida.
CTRL + PIL VÄNSTER (eller CTRL + SHIFT + TAB) Flytta till det vänstra fönstret.
CTRL + PIL HÖGER (eller CTRL + TAB) Flytta till det högra fönstret.
