Kontrollera/redigera kontouppgifter

För att använda denna funktion kanske du måste uppdatera systemprogramvaran.


Kontrollera eller redigera information på PlayStation®Network-konton. Du måste vara inloggad på PlayStation®Network för att utföra de här kommandona. Välj (Kontohantering) under (PlayStation®Network).

Alternativ som kan be kontrolleras eller redigeras
Account Information

Du kan kontrollera och ändra information som är kopplad till dina PlayStation®Network-konton.

  • Billing Information
  • Sign-In ID (E-mail Address)
  • Password
  • Name
  • Address
  • Avatar‎
  • Profile
  • Notification Preferences‎
Sub Account Management

Du kan granska och redigera inställningar för ett kopplat underkonto.

  • Parental Control‎
  • Sub Account Password‎
Redeem Codes‎ Du kan lösa in ett kortnummer eller en promotionkod för PlayStation®Network.
Transaction Management

Du kan lägga till pengar i plånboken som används för PlayStation®Network-tjänster, t.ex. PlayStation®Store eller kontrollera användningshistoriken för olika tjänster.

  • Add Funds
  • Require Password at Checkout
  • Automatic Funding
  • Transaction History
  • Download List
  • Services List
System Activation Du kan aktivera eller avaktivera PS3™-systemet eller PSP™-systemet som du använder för kontot.
Facebook

Om du har ett Facebook®-konto kan du anpassa inställningarna för att dela information på Facebook.

  • Dela trophy-information
  • Dela information om innehållet som du har köpt i PlayStation®Store
  • Dela information om spelhändelser
  • Radera information på Facebook-kontot från PS3™-systemet

Tips!

  • De alternativ som du kan kontrollera eller redigera varierar beroende på vilket PlayStation®Network-konto och i vilket land du bor. För mer information, kontakta teknisk support för din region.
  • Facebook är en tjänst som hjälper dig att ansluta till och dela med dig med personer i ditt liv. Facebook är ett registrerat varumärke som tillhör Facebook, Inc.
  • Du måste ha ett Facebook-konto för att kunna använda denna funktion. Gå in på http://www.facebook.com/ för att registrera ett konto eller för att läsa mer.
