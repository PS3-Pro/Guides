Registrera dig på PlayStation®Network

För att använda denna funktion kanske du måste uppdatera systemprogramvaran.


När du skapat ett PlayStation®Network-konto, kan du handla online på (PlayStation®Store), chatta under (Vänner) och använda olika online-tjänster i PlayStation®Network. Välj (Registrera dig för PlayStation®Network) under (PlayStation®Network) och följ därefter instruktionerna för att skapa ett konto..

Uppgifter som krävs för att skapa ett konto
Personlig information Ange information om den registrerade användaren, inklusive födelsedata och användarens namn och adress.
Master account / sub account Det finns två typer av PlayStation®Network-konton: huvudkonton och underkonton.

Master account:
Standardkontot vid användning av PlayStation®Network. Ett huvudkonto kan skapas av en registrerad användare vars ålder ligger över en bestämd gräns. Innehavare av ett huvudkonto kan ställa in bestämda användarvillkor angående tillhörande underkonton.

Sub account:
Användare som inte är behöriga för ett huvudkonto i sitt land kan bara använda ett underkonto. Innehavare av underkonto kan inte skapa en plånbok, men kan använda plånboken för det kopplade huvudkontot för betalning av produkter och tjänster. Ett underkonto kan inte skapas om det inte finns ett tillhörande huvudkonto.


Kraven för behörighet till huvudkonton respektive underkonton varierar beroende på i vilket land du bor i. För mer information, besök SCE-webbplatsen för din region.
Sign-In ID (E-mail Address)‎ Registrera ett ID som du kan använda för att logga in på PlayStation®Network. Använd en giltig e-postadress som kan användas för att ta emot bekräftelsemeddelanden i de fall du gör inköp under (PlayStation®Store).
Password‎

Skapa ett lösenord enligt följande anvisningar:

  • Använd minst sex bokstäver eller siffror.
  • Använd en kombination av bokstäver och siffror.
  • Använd inte samma tecken mer än två gånger i följd.
  • Använd en kod som inte är samma som ditt inloggnings-ID och online-ID.
  • Systemet skiljer på versaler och gemener
Security Question‎ Välj en säkerhetsfråga som används för att återställa ett glömt lösenordet.‎
Online ID‎

Registrera ett namn som alla användare kommer att kunna se på PlayStation®Network. Du kan inte ändra på ditt online-ID när det väl har skapats. Skapa ditt online-ID enligt följande:

  • Ditt online-ID måste innehålla 3-16 tecken, och kan bestå av bokstäver, siffror, bindestreck (-) och understreck (_).
  • Det första tecknet måste vara en bokstav.
  • Ditt online-ID får inte vara samma som ditt lösenord.
  • Systemet skiljer inte på versaler och gemener.

Tips!

  • Beroende på den minderåriges ålder måste en PC skapa ett underkonto. Medan kontot skapas, sänds ett e-postmeddelande till den e-postadress som är kopplad till huvudkontot. Följ instruktionerna i e-postmeddelandet för att färdigställa registreringen på en PC.
  • För att logga in på PlayStation®Network med det underkonto som skapades, måste du koppla kontot till en användare som kommer att logga in på PS3™-systemet. Se [Använda ett existerande konto] under (PlayStation®Network) i den här guiden.
  • Ditt inloggnings-ID (e-postadress) och lösenord kommer inte att visas för någon annan. Dela inte med dig av den här informationen med någon annan.
  • Du kan bara skapa ett konto per användare i PS3™-systemet. Om du vill skapa fler konton går du till (Användare) och skapar fler användare.
  • Mer information om hantering av personliguppgifter avseende användare finns på SCE-webbplatsen för din region.
  • Du måste ha en bredbandsanslutning till Internet för att få åtkomst till PlayStation®Network. Observera att uppringda modemanslutningar inte fungerar.
  • PlayStation®Network finns endast tillgängligt för en del regioner och språk. För mer information, kontakta teknisk support för din region.
  • (Registrera dig för PlayStation®Network) visas bara om ett PlayStation®Network-konto inte har skapats.
