Kopiera spel till ett PSP™-system

Om spelet som du har laddat ner (som ett köp eller gratis) från (PlayStation®Store) är kompatibelt med PSP™-systemet, kan du kopiera spelet för att spela det på ett PSP™-system.

1.

Logga in på (PlayStation®Network) med det PlayStation®Network-konto som du använde när du laddade ner spelet.

2.

Anslut PSP™-systemet till PS3™-systemet med en USB-kabel.
Anslut Memory Stick™ till PSP™-systemet om du vill kopiera filer till Memory Stick™.

3.

I PSP™-systemet, välj (Inställningar) > (USB-anslutning).

4.

Från PS3™-systemet väljer du det spel du vill kopiera under (Game) och därefter trycker du på -knappen.

5.

Välj [Kopiera].
Följ instruktionerna på skärmen för att kopiera spelet. När kopieringen är klar kan du starta spelet under (Spel) > (Memory Stick™) eller (Spel) > (Systemlagring) på PSP™-systemet.

Tips!

  • För att kunna använda denna funktion måste systemprogramvaran för PSP™-systemet vara version 3.40 eller senare.
  • För information om hur spel spelas i PSP™-systemet, se användarhandboken för PSP™-systemet.

Spel som kan spelas på både PS3™- och PSP™-system

Om du spelar ett spel som är kompatibelt med båda systemen, kan du kopiera sparad data från spelet från ena systemet till det andra så att du kan fortsätta spela där du slutade. Metoden för kopiering av sparad data varierar beroende på speltyp.

Sparade data för PlayStation®-programvara

Sparade data för PlayStation®-programvara sparas på ett internt minneskort som skapas på hårddisken. För att kopiera sparade data till ett PSP™-system, utför steg 2 och 3 ovan och välj därefter (Spel) > (Verktyg för Memory Card (PS/PS2)) > (Internt Memory Card (PS)) på PS3™-systemet. Välj sedan ikonen sparade data för att kopiera, tryck på knappen och välj [Kopiera] från alternativmenyn.

Tips!

  • Du måste konvertera formatet på den sparade datan för att den ska gå att använda på ett PSP™-system. Om en bekräftelseskärm om konvertering av data visas under kopieringen, välj [Ja] för att fortsätta.
  • Varje programtitel skapar ett internt memory card och sparas på ett Memory Stick Duo™ media (som sätts i PSP™-systemet) eller i systemlagringen i PSP™go-systemet.
  • Om du kopierar sparade data till Memory Stick™ som sitter i ett PS3™-system eller använder en USB-adapter (säljs separat), kommer sparade data inte att kännas igen.

Aktivera ett PSP™-system

Ett spel som laddats ner från (PlayStation®Store) kan bara startas på ett PSP™-system som är aktiverat. Om ett meddelande visas som indikerar att aktivering krävs när spelet startas på PSP™-systemet, aktivera enheten på följande sätt.

1.

Anslut PSP™-systemet till PS3™-systemet med en USB-kabel.

2.

I PSP™-systemet, välj (Inställningar) > (USB-anslutning).

3.

Välj > (Kontohantering) under (PlayStation®Network) på PS3™-systemet.

4.

Välj (System Activation).
Följ instruktionerna på skärmen för att färdigställa aktiveringen.

Tips!

  • För att aktivera enheten måste du vara inloggad i PS3™- systemet som samma användare som var inloggad när PlayStation®-programvaran laddades ned.
  • Enhetsaktivering är ett förfarande som enbart gör det möjligt att spela upp material på behöriga enheter. Detta för att skydda materialets digitala rättigheter.
