Spela nerladdade spel

Du kan spela spel som du laddat ner (som ett köp eller gratis) från (PlayStation®Store). Hur du spelar ett spel varierar beroende på speltyp. Information om speltyp visas bredvid spelikonen.

Tips!

För att sortera spel efter typ, välj en spelikon, tryck på -knappen och välj därefter [Sortera efter] > [Format] från alternativmenyn.

Spela PlayStation®3-programvara

Du kan i allmänhet spela PlayStation®3-programvara som laddats ner från (PlayStation®Store) på samma sätt som den PlayStation®3-programvara som finns tillgänglig på skivmedia. För mer information, se (Spel) > [Spela PlayStation®3-programvara] i denna guide.

Spela PlayStation®-programvara

Du kan i allmänhet spela PlayStation®-programvara som laddats ner från (PlayStation®Store) på samma sätt som den PlayStation®-programvara som finns tillgänglig på skivmedia. För mer information, se (Spel) > [Spela PlayStation®2 / PlayStation®-programvara] i denna guide.


Programvaruhandböcker

Du kan eventuellt visa programvaruhandboken för PlayStation®-programvaran du laddat ned. För att titta i handboken trycker du på PS-knappen på den trådlösa handkontrollen och väljer [Programvaruhandbok] från den skärm som visas.


Spel som kräver byte av skiva

En del PlayStation®-programvaror som laddas ned kräver att man byter skiva. När man spelar sådana spel på PS3™-systemet utförs bytet av skiva virtuellt. Om ett meddelande som ber dig byta skiva visas, ska du trycka på PS-knappen på den trådlösa handkontrollen och sedan välja [Byt skivor] på den skärm som visas. Följ instruktionerna på skärmen för att färdigställa hanteringen.

Spela spel i formatet PC Engine

Se den instruktion som medföljde spelet för mer information om hur du spelar spel i formatet PC Engine. Beroende på vilket spel det är kan det finnas olika metoder för att läsa instruktionerna. Formatet PC Engine kanske inte finns tillgängligt beroende på land eller område.
