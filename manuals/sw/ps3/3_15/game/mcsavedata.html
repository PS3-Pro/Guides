Använda sparade data på minneskort

Om du vill använda sparade data på ett memory card (8MB) (för PlayStation®2) eller ett minneskort för att spela ett spel måste du kopiera data till ett internt minneskort på hårddisken. Du måste använda en minneskortadapter (säljs separat) för att kopiera data.

Viktig information

  • Vissa PlayStation®2- eller PlayStation®-programvarutitlar kan spelas upp annorlunda på PS3™-systemet än de gör på PlayStation®2- och PlayStation®-systemen, eller inte spelas upp korrekt på PS3™-systemet.
  • PlayStation®2-programvaran kan inte heller spelas på vissa PS3™-system. För mer information, se [Olika typer av uppspelningsbara skivor], besök SCE-webbsidan för ditt land eller läs dokumentationen som följde med ditt PS3™-system.

1.

Välj (Spel) > (Verktyg för Memory Card (PS / PS2)).

2.

Anslut minneskortadaptern till PS3™-systemet och sätt in ett minneskort.
En ikon för (Memory Card (PS)) eller (Memory Card (PS2)) visas.

3.

Välj ikonen för de sparade data du vill kopiera från det minneskort som visas, och tryck därefter på -knappen.

4.

Välj [Kopiera].
Välj destination att kopiera till. Välj destination att kopiera till. Om det inte finns någon destination tillgänglig, välj (Skapa nytt internt Memory Card) och följ därefter instruktionerna på skärmen för att skapa ett internt memory card.

5.

Tilldela platser
Markera det interna minneskortet du vill använda från (Verktyg för Memory Card (PS/PS2)) och tryck sedan på -knappen. Välj [Tilldela fack] på alternativmenyn.

Tips!

  • Beroende på datatyp kopieras sparade data från ett memory card (8MB) (för PlayStation®2) eller ett memory card till ett internt minneskort enligt nedan.

  • Kopieringen kan ta upp till flera minuter för viss sparad data.
  • Välj minneskortet i steg 3 för att kopiera all sparad data på ett Memory Card (8MB) (för PlayStation®2) eller ett minneskort, tryck på knappen och välj därefter [Kopiera] i alternativmenyn.
  • Kopiering kan vara förbjuden för viss sparad data. När sådan data används i ett PS3™-system ska [Flytta] väljas i steg 4. Den sparade informationen flyttas till hårddisken och raderas från ditt Memory Card.
  • Du kan flytta tillbaka den sparade informationen till ditt Memory Card senare.

Kopiera sparad information till ett minneskort

Kopiera sparad data för PlayStation®2-/PlayStation®-programvara som sparats på hårddisken, till ett Memory Card eller Memory Card (8 MB) (för PlayStation®2). Du måste använda en Memory Card-adapter (säljs separat) för att kopiera informationen.

1.

Välj (Spel) > (Verktyg för Memory Card (PS / PS2)).

2.

Anslut din Memory Card-adapter till PS3™-systemet och sätt in ett Memory Card.

3.

Välj ikonen för de sparade data du vill kopiera från (Internt Memory Card (PS)) eller (Internt Memory Card (PS2)) där informationen finns sparad, och klicka därefter på knappen .

4.

Välj [Kopiera].
Ange (Memory Card (PS)) eller (Memory Card (PS2)) som destination att kopiera till.

Tips!

  • Flera poster med sparad information på ett internt Memory Card kan inte kopieras tillsammans till ett Memory Card.
  • Kopiering kan vara förbjuden för viss sparad data. När sådan data används i ett PS3™-system ska [Flytta] väljas i steg 4. Den sparade informationen flyttas till hårddisken och raderas från ditt interna Memory Card.
  • Du kan flytta tillbaka den sparade informationen till ditt Memory Card senare.
