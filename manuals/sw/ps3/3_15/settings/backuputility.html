Säkerhetskopiering

Säkerhetskopiera data på hårddisken till lagringsmedia eller en USB-masslagringsenhet, eller återställ säkerhetskopierade data.

Säkerhetskopiera Säkerhetskopiera hårddiskens data på lagringsmedia eller på en USB-enhet för masslagring.
Återställ Återställ data som säkerhetskopierats på lagringsmedia eller på en USB-enhet, tillbaka till hårddisken.
Radera säkerhetskopierade data Ta bort data som har säkerhetskopierats på lagringsmedia eller en USB-masslagringsenhet.

Obs!

Du kan inte göra säkerhetskopior av din trophy-information med funktionen för säkerhetskopior. Om du vill spara trophy-information bör du skapa ett PlayStation®Network-konto och spara informationen på PlayStation®Network-servern. För att säkerhetskopiera din trophy-information på PlayStation®Network-servern, välj (Spel) > (Trophysamling), tryck på knappen , och välj sedan [Synkronisera med server] från alternativmenyn.


Tips!

  • Data kan säkerhetskopieras på Memory Stick™, SD Memory Card, CompactFlash® och USB-masslagringsenheter. En lämplig USB-adapter (medföljer ej) krävs för att använda lagringsmedia med vissa modeller. Skivmedia som CD-R kan inte användas.
  • En USB-hårddisk kan också användas för säkerhetskopiering av data och visas som ikonen när den är ansluten. Observera dock att disken måste vara formaterad i filsystemet FAT32 för att godkännas av PS3™-systemet.
  • Säkerhetskopierade data sparas i mappen [PS3] - [EXPORT] - [BACKUP]. Mapparna skapas automatiskt.
  • Om du ändrar mapp- eller filnamnet av säkerhetskopierad data, kommer du inte kunna återställa datan.
  • Om du utför någon av följande åtgärder efter säkerhetskopieringen finns det risk för att copyright-skyddade filer i säkerhetskopierade data inte återställs ordentligt.
  • - Formatera hårddisken
  • - Återställ PS3™-systemet
  • - Flytta copyrightskyddade videofiler
  • - Hämta copyrightskyddade videofiler
  • - Spela copyrightskyddad video som har en tidsrestriktion för första gången
  • Om du säkerhetskopierar på ett PS3™-system och sedan överför data till ett annat PS3™-system med verktyget för dataöverföring, kan inte kopieringsförbjuden data som finns bland säkerhetskopierade data återställas på respektive system.
  • Vissa typer av säkerhetskopierade data kan återställas på ett annat PS3™-system. Data som kan återställas på ett annat system är:
  • - Data som sparats med PlayStation®3-programvara*1
  • - Bildfiler under (Foto)
  • - Musikfiler under (Musik)*2
  • - Videofiler under (Video)*2
  • - Bokmärken som lagts till under (Webbläsare)
  • - Ord som lagts till med (Inställningar) > (Systeminställningar) > [Lägg till/redigera term], eller förutsägande termer som "lärts in" med den förutsägande funktionen i skärmtangentbordet.
    • *1  Kopieringsskyddade data kan inte återställas. Dessutom kan kanske återställda data som sparats inte användas i vissa spel.
    *2  Innefattar inte data som skyddas av copyright.
  • I vissa fall kan du inte säkerhetskopiera eller återställa systemet ordentligt. Vi rekommenderar att du alltid kopierar eller flyttar viktiga data till lagringsmedia för att skapa en enskild säkerhetskopia.
