Fjärrstart

PS3™-system som står i standby-läge kan automatiskt sättas på när ett PSP™-system används för fjärrspel (Wake On LAN). För att använda denna funktion måste du först utföra följande steg:

För att använda fjärrspel via den trådlösa LAN-funktionen på PS3™-systemet eller via åtkomstpunkten:
  • Uppdatera PSP™-systemprogramvaran till version 3.72 eller senare version.
  • Ställ in automatisk inloggning under (Användare) i PS3™-systemet

För att använda fjärrspel via Internet:
  • Uppdatera PSP™-systemet och PS3™-systemet till den senaste versionen av systemprogramvaran.
  • Ställ in för att logga in automatiskt under (Användare) på PS3™-systemet.
  • Slutför nätverksinställningarna i PS3™-systemet så att anslutning till Internet är möjlig.
  • Skapa ett PlayStation®Network-konto.
  • Ställ in automatisk registrering till PlayStation®Network.

Tips!

  • För mer information om automatisk inloggning under (Användare), se (Användare) > [Inloggning] > [Ställ in automatisk inloggning] i denna guide.
  • För mer information om automatisk registrering till PlayStation®Network, se (PlayStation®Network) > [Spara ditt lösenord/logga in automatiskt] i denna guide.

Aktivera fjärrstart

1.

Välj (Inställningar) > (Inställningar för fjärrspel).

2.

Välj [Fjärrstart] > [På].

3.

Välj [OK] på bildskärmen som visas. För att använda fjärrspel via Internet, se [Aktivera fjärrstart via Internet].

4.

Stäng av PS3™ -systemet.
Välj (Användare) > (Stäng av systemet) för att stänga av systemet och sätta det i standbyläge. Kontrollera att strömindikatorn lyser rött.

5.

Utför fjärrspel med PSP™-systemet.
För information om fjärrspel, se (Nätverk) > (Fjärrspel) > [Använda fjärrspel] i denna guide.

Tips!

Om fjärrstart aktiveras, kommer PS3™-systemets interna fläkt fortsätta att vara igång även efter det att systemet har stängts av.

Avaktivera fjärrstart

1.

Välj (Inställningar) > (Inställningar för fjärrspel).

2.

Välj [Fjärrstart] > [Av].

Fjärrstart via Internet

Det är möjligt att du inte kommer kunna använda fjärrstart via Internet beroende på vilken nätverksenhet som används. Om detta händer, läs igenom följande information:

Obs!

Beroende på routern kan PS3™-systemet upprepade gånger startas vid specifika intervaller om fjärrstart är aktiverat. Om fjärrspelsanslutningen inte är etablerad inom en viss tid efter att PS3™-systemet har startats, stängs systemet automatiskt av. För att förebygga detta från att hända, kan fjärrstart via Internet automatiskt avaktiveras.

  • För att använda fjärrstart via Internet behövs en router.
  • Om routern som används stödjer UPnP, aktiverar du routerns UPnP-funktion.
  • Om routern som används inte stödjer UPnP, måste du ställa in routerns port forwarding för att tillåta kommunikation med PS3™ -systemet från Internet. Portnumret som används för fjärrspel och fjärrstart är TCP: 9293 eller UDP: 9293. För information om inställning av detta val, läs instruktionerna för routern.
  • Port forwarding är en funktion för att vidarebefordra signaler som anländer till en specifik port (ingång) till en annan specifik port (utgång). Detta kallas även "port mapping" och "adressomvandling."
  • Om routerns IP-adress (global IP-adress) ändras när PS3™-systemet är i standby-läge, kommer fjärrstart inte att lyckas.
