Använda fjärruppspelning

Fjärrspelning är en funktion som gör det möjligt att visa skärmbilden från ett PS3™-system på en enhet som har stöd för fjärrspelning, exempelvis ett PS Vita-system eller PSP™-system, där du då kan fjärrstyra funktionerna via ett trådlöst nätverk.

Tips!

För att använda funktionen fjärrspel med ett PSP™-system, måste du uppdatera PSP™-systemet till version 3.72 eller senare.

Funktioner som kan utföras från en enhet som har stöd för fjärrspel

De huvudsakliga PS3™-systemfunktionerna som kan utföras via fjärrspel varierar beroende på typ av enhet som används. Med ett PS Vita- system eller PSP™-system, är följande funktioner tillgängliga:

  • (Inställningar) *1
  • (Foto) *1
  • (Musik)
  • (Video)*2
  • (Spel) *1*3
  • (Nätverk)
  • (PlayStation™Network) *1
  • (Vänner)

*1

Bara begränsade funktioner kan ändras via fjärrspel.
*2

Blu-ray-skivor och DVD-skivor kan inte spelas. Videofiler som skyddas av copyright kan inte heller spelas.
*3

vissa spel stödjer fjärruppspelning.
  • Om XMB™-menyn
  • Användare
  • Inställningar
  • Foto
  • Musik
  • Video
  • TV-/videotjänster
  • Spel
  • Nätverk
  • PlayStation™Network
  • Vänner
