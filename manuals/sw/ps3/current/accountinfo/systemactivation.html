Om systemaktivering

Systemaktivering är ett förfarande för att skydda upphovsrättsskyddat material och andra digitala rättigheter. Det innehåll och de program som finns tillgängligt på PlayStation®Store kan endast användas på aktiverade system.

Du kan länka ditt Sony Entertainment Network-konto till flera system, men antalet system du kan aktivera per innehållstyp är begränsat för varje konto. När antalet aktiverade system nått maximal gräns, visas ett felmeddelande när du försöker ladda ner (köpa) innehåll på ett oaktiverat system. Du måste först avaktivera ett av dina andra system för att kunna använda innehållet på systemet.

Aktivera ett system manuellt

Normalt sett aktiveras ditt system automatiskt när du laddar ner (köper) innehåll. Du måste däremot aktivera ditt system manuellt om du försöker spela upp innehållet och ett meddelande där systemaktivering krävs visas.

Anmäl dig på PSNSM på ditt PS3™-system. Välj (PlayStation™Network) > (Kontohantering) > (Systemaktivering) och följ sedan anvisningarna på skärmen.

Tips!

  • Du kan aktivera ett PS3™ system för att titta på videoinnehåll högst 3 gånger inom 90 dagar per konto. Det går inte att använda ett konto för att aktivera samma system en fjärde gång inom 90 dagar. Du kan aktivera systemet igen 90 dagar efter att du första gången aktiverade det.
  • Försäljning/uthyrning av videoinnehåll från PlayStation®Store på PS3™-systemet har upphört.

Avaktivera ett system

Ett meddelande som anger att du inte kan köpa (laddar ner) valt innehåll visas, om du försöker överskrida begränsningen på aktiverat system för ditt konto. Om detta sker måste du avaktivera ett av dina andra system.

Anmäl dig på PSNSM på ditt PS3™-system. Välj (PlayStation™Network) > (Kontohantering) > (Systemaktivering) och följ sedan anvisningarna på skärmen.

När det inte går att avaktivera ett system

När det inte går att avaktivera ett aktiverat system via detta system, på grund av t.ex. ett fel eller om systemet har kasserats, kontakta teknisk support för din region.
Det går också att avaktivera alla aktiverade system för varje innehållstyp via följande webbsida:

http://account.sonyentertainmentnetwork.com/
Gå till [Konto] > [Media och enheter] och välj sedan [Aktivera alla] för den innehållstyp du vill avaktivera alla aktiverade system för.

Tips!

  • Det kanske inte går att avaktivera alla aktiverade system via denna sida beroende på innehållstypen.
  • Denna webbplats är bara tillgänglig i vissa länder eller regioner.
