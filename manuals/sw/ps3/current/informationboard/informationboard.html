Använda Information Board

Information Board visas alltid på XMB™-skärmen och visar de senaste nyheterna om spel och senaste informationen från PlayStation®Store.

Tips!

  • För att det ska gå att se nyheterna, måste PS3™-systemet vara anslutet till Internet. För information om nätverksinställningar, se (Inställningar) > (Nätverksinställningar) > [Anslutningsinställningar till Internet] i denna guide.
  • Visningsläget eller teckenstorleken på Information Board kan inte ändras.
  • Utformningen på Information Board kan ändras utan föregående meddelande. Utformningen kan även variera beroende på land eller region.

Visa detaljerad nyhetsinformation

1.

Välj (Information Board) från (Nätverk).
En lista på nya komponenter visas.

(1)

Välja ett land eller region
Om du trycker på -knappen, visas en skärm där land eller region kan väljas. De nyheter som distribueras varierar beroende på vilket land eller region som är valt. Knappen för att ange land eller region visas inte på PS3™-system som säljs i Japan eller Korea.

2.

Välj rubrik för det nyhetsämne som du vill veta mer om och tryck sedan på -knappen.
Detaljerad nyhetsinformation visas.

(2)

Återgå till listan på nya komponenter
Använd -knappen för att återgå till listan.

(3)

Länka till en webbsida
Använd -knappen för att starta (Webbläsare) och visa en webbsida.
Detta alternativ visas inte för en nyhet som inte har någon länk till en webbsida.

Inställning för att inte visa Information Board

Välj (Information Board) från (nätverk), och tryck sedan på -knappen. Välj därefter [Do Not Display] (visa inte) från alternativmenyn.

Tips!

För att ta fram Information Board igen, välj återigen ikonen, tryck på -knappen och välj därefter [Display] (Visa) från alternativmenyn.
