Använda sparade data för minis- och PSP™Game (PSP™-spel)-programvara

Kopiera sparade data för PSP™Game (PSP™-spel) till ett PS3™-system

1.

Anslut PSP™-systemet till PS3™-systemet med en USB-kabel.

2.

Välj (Spel) > (Verktyg för sparade data (minis / PSP™)) på PS3™-systemet.

3.

Välj de sparade data du vill kopiera och tryck på -knappen.

4.

Välj [Kopiera].

Tips!

  • Sparade data hanteras separat av varje användare. Om det finns mer än en användare under (Användare), kommer det som visas under
    (Verktyg för sparade data (minis / PSP™)) variera beroende på användaren som är inloggad.
  • Om du väljer en sparad dataikon och trycker på -knappen, kan du sortera sparade data genom att uppdatera datum eller gruppera sparade data efter titel i menyn som visas.
  • Spel för PSP™-systemet (i PSP™-spelsformat) kan inte spelas på ditt PS3™-system.
  • Vissa spel kan ha begränsningar för användning av sparade data. Se programvarans handbok för mer information.
  • PlayStation®-program som har laddats ner från PlayStation®Store och sparats på PSP™-systemet visas under (Verktyg för Memory Card).
