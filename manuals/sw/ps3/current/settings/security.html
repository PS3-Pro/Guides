Säkerhetsinställningar

Justera systemets säkerhetsinställningar.

Tips!

Dessa inställningar styr lokalt innehåll (digitalt innehåll som lagras på lagringsminnet, innehåll på lagringsmedia och skivor). Observera att dessa inställningar inte begränsar åtkomsten till onlineinnehåll.


Ändra lösenord

Ändra det lösenord som krävs för att justera systeminställningarna. Lösenordet krävs i följande fall:

  • När du spelar innehåll som spärras av föräldrakontroll
  • När du vill ändra inställningarna för föräldrakontroll eller säkerhetsläget Startkontroll för webbläsaren.
  • När du startar webbläsaren och säkerhetsläget Startkontroll för webbläsaren är inställt på [På].
  • När du vill ändra det aktuella lösenordet

Se till att du kommer ihåg det nya lösenordet. Lösenordet sätts till [0000] i standardinställningarna.

Tips!

Om du väljer (Inställningar) > (Systeminställningar) > [Återställ standardinställningar] kan du återställa lösenordet till [0000]. Observera att alla andra inställningar också återställs till sina standardvärden.

BD - Föräldrakontroll

Du kan justera uppspelningsnivån för BD-skivor (Blu-ray Disc) via föräldrakontrollspärren. Ett lösenord krävs för att ändra den här inställningen.

Begränsa inte (Av) Alla BD-skivor kan spelas upp oavsett föräldrakontrollnivå.
Begränsa (På) Endast BD-skivor med angiven föräldrakontrollnivå kan spelas upp.

När [Begränsa (På)] har angetts kan du välja en åldersgräns på nästa skärm. Ju lägre värdet är, desto strängare är begränsningen.

BD/DVD - Regionkod för föräldrakontroll

Ställ in en region som bas för standardnivåerna för föräldrakontroll till BD-/DVD-skivor. Ett lösenord krävs för att ändra den här inställningen.

USA Ställ in standardnivåerna för föräldrakontroll för USA.
Övriga Ställ in standardnivåerna för föräldrakontroll för övriga regioner.

Om du väljer [Övriga], kan du välja en region på nästa skärm.

DVD - Föräldrakontroll

Du kan justera uppspelningsnivån för DVD-skivor via föräldrakontrollspärren. Ett lösenord krävs för att ändra den här inställningen.

Av Alla DVD-skivor kan spelas upp oavsett föräldrakontrollnivå.
Nivå 8 till 1 Endast DVD-skivor med angiven föräldrakontrollnivå kan spelas upp.

Ju lägre värdet är, desto strängare är begränsningen.

Föräldrakontroll

Du kan ange uppspelningsnivån för spel via föräldrakontrollspärren. Ett lösenord krävs för att ändra den här inställningen.

Av Allt innehåll kan spelas upp oavsett föräldrakontrollnivå.
Nivå 11 till 1 Spela bara innehåll med ett värde som är på samma nivå eller lägre än den angivna föräldrakontrollnivån.

Observera att ju lägre värde, desto fler restriktioner. Om du väljer [Begränsa spelstart utan föräldrakontrollsinställningar], kan du begränsa användandet av oklassificerade spel i din region.

Tips!

  • Föräldrakontrollinställningarna för spel varierar beroende på i vilket land spelet köpts. Mer information finns på SIE-webbplatsen för din region. Vissa programhandböcker i vissa regioner kan innehålla information om dessa inställningar.
  • Föräldrakontrollens nivå kan variera mellan olika spel.

Startkontroll för webbläsare

Du kan begränsa möjligheten att starta webbläsaren. Ett lösenord krävs för att ändra den här inställningen.

Av Anger att startkontrollen inte ska användas.
På Anger att startkontrollen ska användas. Ett lösenord krävs för att starta webbläsaren.
