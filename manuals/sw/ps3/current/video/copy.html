Kopiera/flytta videofiler

Du kan kopiera videofiler som sparats på lagringsmedia till lagringsminnet eller kopiera eller flytta importerade filer från lagringsminnet till lagringsmedia. Välj filen du vill importera eller kopiera, tryck på -knappen och välj därefter [Kopiera] eller [Flytta] i alternativmenyn. Följ instruktionerna på skärmen för att färdigställa hanteringen.

Skillnader mellan att kopiera och flytta

Funktioner du kan utföra varierar beroende på filtypen. Kopieringsskyddade filer kan enbart flyttas. Om en fil flyttas kommer den inte längre att finnas kvar på den ursprungliga sparade platsen.

Betalt innehåll (filtyp: MNV) inspelat i HD-upplösning som laddats ner från PlayStation®Store kan inte kopieras eller flyttas, men det kan säkerhetskopieras selektivt. För att selektivt säkerhetskopiera innehåll som laddats ner från Video Store på PlayStation®Store använder du funktionen för säkerhetskopiering på PS3™. Mer information finns under (Video) > [Säkerhetskopiera eller återställa videofiler] i denna guide.

Tips!

  • Försäljning/uthyrning av videoinnehåll från PlayStation®Store på PS3™-systemet har upphört.
  • När man kopierar eller flyttar videofiler som begränsas av föräldrakontroll, måste du ange ett lösenord. Du kan ställa in lösenordet vid [Ändra lösenord] under (Inställningar) > (Säkerhetsinställningar).
  • Beroende på vilken enhet som används, kanske vissa kopierade filer inte kan spelas upp.
  • Beroende på vilken modell av PS3™-systemet som används så kan en lämplig USB-adapter (medföljer ej) krävas för att använda lagringsmedia. När du flyttar videofiler till Memory Stick PRO™-media behövs en USB-enhet som stödjer Memory Stick™-medias copyrightskydd, som t.ex. PSP™-systemet eller MRW-F3 (en Sonyprodukt).
  • När du använder Memory Stick Micro™-media med ett PS3™-system som är utrustat med ett Memory Stick™-fack, måste du använda media med en Memory Stick™ M2 Duo-adapter.
  • Somliga kopieringsskyddade videofiler kan inte flyttas.
  • Var noga med att inte göra intrång i andras immateriella rättigheter.
  • Det går inte att kopiera eller flytta videofiler medan de spelas upp.*

    • * Gäller även uppspelning av innehåll via andra funktioner, t.ex. uppspelning av musikfiler.

Kopiera och flytta video för att visa i ett PSP™-system

Kopiera eller flytta videofiler för att visa dem i ett PSP™-system

1.

Anslut PSP™-systemet till ditt PS3™-system med en USB-kabel.
Anslut Memory Stick™ till PSP™-systemet om du vill kopiera filer till Memory Stick™.

2.

I PSP™-systemet, välj (Inställningar) > (USB Connection).

3.

På PS3™-systemet väljer du videofilen du vill kopiera eller flytta, och därefter trycker du på -knappen.

4.

Välj [Kopiera] eller [Flytta].
Följ instruktionerna på skärmen för att kopiera eller flytta filen. Du kan spela upp den kopierade eller flyttade videofilen genom att välja filen under (Video) > (Memory Stick™) eller (Video) > (System Storage) på PSP™-systemet.

Tips!

  • För information om hur videofiler spelas i PSP™-systemet, se användarguiden för PSP™-systemet.
  • Beroende på vilken typ av videofil som du kopierar eller flyttar, måste du använda Memory Stick PRO Duo™-media.
  • Videoinnehåll som har spelats in i HD-upplösning kan inte flyttas.
