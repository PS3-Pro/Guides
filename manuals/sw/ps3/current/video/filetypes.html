Filtyper som kan spelas upp

Följande filtyper kan spelas upp under (Video).

  • Memory Stick-videoformat
  • - MPEG-4 SP (AAC LC)
  • - H.264/MPEG-4 AVC High Profile （AAC  LC）
  • - MPEG-2 TS(H.264/MPEG-4 AVC, AAC LC)
  • MP4-filformat
  • - H.264/MPEG-4 AVC High Profile (AAC LC)
  • MPEG-1 (MPEG Audio Layer 2)
  • MPEG-2 PS (MPEG2 Audio Layer 2, AAC LC, AC3 (Dolby Digital), LPCM)
  • MPEG-2 TS (MPEG2 Audio Layer 2, AC3 (Dolby Digital), AAC LC)
  • MPEG-2 TS(H.264/MPEG-4 AVC, AAC LC)
  • AVI
  • - Motion JPEG (Linjär PCM)
  • - Motion JPEG (μ-Law)
  • AVCHD (.m2ts / .mts)
  • DivX
  • WMV
  • - VC-1（WMA Standard V2）

Tips!

  • Beroende på typen av data kan det hända att vissa filer inte kan spelas upp, eller att en del alternativ i kontrollpanelen inte fungerar vid uppspelning.
  • Vissa videofiler som distribueras över Internet har begränsad uppspelning. Mer information kan du få från innehållsleverantören.
  • För att spela upp filer i WMV-format, måste du gå till (Inställningar) > (Systeminställningar) och ställ in [Aktivera uppspelning med WMA].
  • När du använder en USB-adapter till att spela upp videofiler kan du behöva en USB-adapter (medföljer inte) med funktioner för copyrightskydd (för uppspelning av copyrightskyddade filer).
  • När en USB-adapter används för uppspelning av videofiler i AVCHD-format och som sparats på ett Memory Stick™, ska en enhet som har stöd för Hi-Speed USB (USB 2.0) användas.
  • Copyright-skyddade filer i WMV-format kan inte spelas upp.
