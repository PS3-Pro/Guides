Fotokategori

Följande ikoner visas under (Foto). Ikonerna som visas varierar beroende på vilka villkor som används.

Sök mediaservrar Starta en sökning efter DLNA-mediaservrar som är anslutna till samma nätverk.
Använda Photo Gallery Använd detta program för att förstärka känslan när du tittar på fotografier som är sparade på ett PS3™-system.
Spara skärmklipp Spara skärmdumpar från PlayStation®3-programvara medan du spelar. Det här alternativet är bara tillgängligt när programmet som spelas kan hantera den här funktionen.
Mediaserver Anslut till DLNA-mediaservrar och visa de lagrade bilderna. Vilken ikon som visas varierar med typen av server.
Dataskiva Visa bildfiler som sparats på kompatibel, inspelbar media som t ex en CD-R- eller DVD-R-skiva.
Memory Stick™ Visa bildfiler som sparats på ett Memory Stick™.*
SD Memory Card Visa bildfiler som sparats på ett SD Memory Card.*
CompactFlash® Visa bildfiler som sparats på ett CompactFlash®.*
PSP™ (PlayStation®Portable) Visa bildfiler som sparats på PSP™-systemets Memory Stick™.
PSP™ (PlayStation®Portable) Visa bildfiler som sparats i systemlagringen i PSP™go-systemet.
Digitalkamera Visa bildfiler som sparats på en digitalkamera som är kompatibel med PS3™-systemet.
WALKMAN®/ATRAC Audio Device (WALKMAN®) Se bildfiler sparade på en WALKMAN®/ATRAC Audio Device (WALKMAN®).
ATRAC Audio Device Se bildfiler sparade på en ATRAC Audio Device.
USB-enhet Visa bildfiler som sparats på ett USB-minne.
Spellistor Du kan skapa spellistor och redigera och spela spellistor som redan har skapats.
Digitalkamerabilder Visa bildfiler som sparats i DCIM-mappen till en digitalkamera.
Mapp Den här ikonen visas när det finns mappar som skapats på lagringsmediet med en dator.
(filer som sparats i lagringsminnet) Visa bildfiler som sparats i lagringsminnet i PS3™-systemet. Miniatyrbilder visas.
*

En lämplig USB-adapter (medföljer ej) krävs för att använda lagringsmedia med vissa modeller av PS3™-systemet. När lagringsmediet används med en USB-adapter kommer den att visas som (USB-enhet).

Tips!

  • Detaljerad information om DLNA finns under (Inställningar) > (Nätverksinställningar) > [Mediaserveranslutning] i denna handbok.
  • I sällsynta fall kan det hända att skivor och annan media inte fungerar som de ska i PS3™-systemet. Detta beror i första hand på variationerna mellan tillverkningsprocesserna eller på kodningen av programvaran.
  • En 3D-kompatibel TV som överensstämmer med 3D-standarden och en höghastighets HDMI-kabel krävs för att titta på 3D-innehåll.
