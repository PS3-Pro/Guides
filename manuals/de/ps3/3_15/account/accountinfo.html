PlayStation®Network > Verwalten von Kontoinformationen

Verwalten von Kontoinformationen

Sie müssen eventuell die System-Software aktualisieren, bevor Sie diese Funktion verwenden können.


Sie können die Informationen für PlayStation®Network-Konten überprüfen oder bearbeiten. Dazu müssen Sie am PlayStation®Network angemeldet sein. Wählen Sie (Konto-Verwaltung) unter (PlayStation®Network).

Elemente, die überprüft oder bearbeitet werden können
Kontoinformationen

Sie können Informationen über Ihre PlayStation®Network-Konten überprüfen oder bearbeiten.

  • Rechnungsinformationen
  • Anmelde-ID (E-Mail-Adresse)
  • Passwort
  • Name
  • Adresse
  • Avatar
  • Profil
  • Benachrichtigungseinstellungen
Unterkonto-Verwaltung

Sie können die Einstellungen für ein zugehöriges Unterkonto überprüfen oder bearbeiten.

  • Kindersicherung
  • Unterkonto-Passwort
Codes einlösen Sie können eine PlayStation®Network Card-Nummer oder einen Promotion-Code einlösen.
Transaktionsverwaltung

Sie können Guthaben zu der Brieftasche hinzufügen, die für PlayStation®Network-Services wie PlayStation®Store verwendet wird, oder den Nutzungsverlauf für verschiedene Services überprüfen.

  • Geld hinzufügen
  • Passwort an Kasse benötigt
  • Automatisches Aufladen
  • Transaktionsverlauf
  • Download-Liste
  • Services-Liste
Systemaktivierung Sie können das für das Konto verwendete PS3™- oder PSP™-System aktivieren bzw. deaktivieren.
Facebook

Wenn Sie ein Facebook®-Konto haben, können Sie entsprechende Einstellungen vornehmen und Informationen in Facebook verfügbar machen.

  • Informationen über Trophäen verfügbar machen
  • Informationen zu im PlayStation®Store gekauften Inhalten verfügbar machen
  • Spielevent-Informationen anderen verfügbar machen
  • Facebook-Kontoinformationen vom PS3™-System löschen

Anmerkungen

  • Welche Optionen Sie überprüfen bzw. bearbeiten können, hängt vom PlayStation®Network-Kontotyp sowie vom Land bzw. der Region ab. Weitere Informationen dazu erhalten Sie beim technischen Support für Ihre Region.
  • Facebook ist ein Service, über den Sie mit anderen Menschen in Ihrem Leben in Verbindung treten und Inhalte austauschen können. Facebook ist eine eingetragene Marke der Facebook, Inc.
  • Für diese Funktion benötigen Sie ein Facebook-Konto. Wenn Sie sich für ein Konto anmelden oder weitere Informationen erhalten wollen, besuchen Sie http://www.facebook.com/.
