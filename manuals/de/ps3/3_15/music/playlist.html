Erstellen/Wiedergeben von Wiedergabelisten

Sie können auf der Festplatte gespeicherte Titel auswählen, in der gewünschten Reihenfolge anordnen und so für die Wiedergabe in einer Wiedergabeliste zusammenstellen.

1.

Wählen Sie (Musik) > (Wiedergabelisten).

2.

Wählen Sie (Neue Wiedergabeliste erstellen). Befolgen Sie zum Erstellen der Wiedergabeliste die Anweisungen auf dem Bildschirm.

3.

Wählen Sie eine vorhandene Wiedergabeliste aus und drücken Sie die -Taste.

4.

Wählen Sie [Bearbeiten].
Die auf der Festplatte gespeicherten Titel werden links auf dem Bildschirm angezeigt, und die Elemente der Wiedergabeliste werden rechts auf dem Bildschirm angezeigt.

5.

Wählen Sie den Titel, den Sie zur Wiedergabeliste hinzufügen möchten.
Der Titel wird zur Wiedergabeliste hinzugefügt. Wenn der Titel hinzugefügt wurde, drücken Sie die -Taste, um die Bearbeitung zu beenden. Eine vorhandene Wiedergabeliste können Sie über (Musik) > (Wiedergabelisten) wiedergeben lassen.

Anmerkung

Nur Titel, die auf der Festplatte gespeichert wurden, können zur Wiedergabeliste hinzugefügt werden.
