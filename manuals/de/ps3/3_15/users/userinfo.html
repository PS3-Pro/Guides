Bearbeiten von Benutzerinformationen

Sie können Benutzerinformationen, wie z. B. Benutzername und Icon, bearbeiten. Melden Sie sich als Benutzer an, dessen Informationen Sie bearbeiten wollen. Wählen Sie das Icon des Benutzers aus, drücken Sie die -Taste und wählen Sie [Informationen] aus dem Menü „Optionen“. Wählen Sie die zu bearbeitenden Elemente aus.


Anmerkungen

  • Nur Informationen zum aktuellen Benutzer können bearbeitet werden.
  • Sie können ein Icon aus den auf der Festplatte gespeicherten Bildern oder aus voreingestellten Icons auswählen.
