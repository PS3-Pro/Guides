PlayStation®Network > Verwenden der Brieftasche

Verwenden der Brieftasche

Sie müssen eventuell die System-Software aktualisieren, bevor Sie diese Funktion verwenden können.


Mit der Brieftasche können Sie Produkte kaufen, die im (PlayStation®Store) angeboten werden. Für jedes PlayStation®Network-Hauptkonto wird eine Brieftasche angelegt. Sie müssen die Brieftasche mit einem Guthaben ausstatten, bevor Sie etwas kaufen können.

Hinzufügen von Guthaben

Sie können Guthaben beispielsweise mit einer Kreditkarte oder einer, PlayStation®Network Card zur Brieftasche hinzufügen. Finanzierungsverfahren, Währung und Brieftaschenbeschränkungen hängen vom Land bzw. der Region ab, in dem bzw. der der Benutzer wohnt. Weitere Informationen dazu erhalten Sie beim technischen Support für Ihre Region.

*  Es gibt zwei Typen von Codes, mit denen im PlayStation®Network Zahlungen erfolgen können. Mit dem Code von einer PlayStation®Network Card können Sie Guthaben zur Brieftasche hinzufügen. Ein „Promotion-Code“ kann gegen Waren, wie z. B. Zubehör für Spiele, eingetauscht werden.

1.

Wählen Sie (PlayStation®Network) > (Konto-Verwaltung).

2.

Wählen Sie (Transaktionsverwaltung).

3.

Wählen Sie [Geld hinzufügen]. Gehen Sie zum Abschließen des Vorgangs nach den Anweisungen auf dem Bildschirm vor.

Einstellung für automatisches Hinzufügen von Guthaben

Für aktive Abonnements, die mit Ihrem Konto verbunden sind, können automatisch Beträge über Ihre Kreditkarte zum Guthaben hinzugefügt werden, wenn das aktuelle Guthaben zum Bezahlen der Abonnementverlängerung nicht ausreicht. Diese Funktion steht in Ihrem Land bzw. Ihrer Region möglicherweise nicht zur Verfügung. Weitere Informationen dazu erhalten Sie beim technischen Support für Ihre Region.

1.

Wählen Sie (PlayStation®Network) > (Konto-Verwaltung).

2.

Wählen Sie (Transaktionsverwaltung).

3.

Wählen Sie [Automatisches Aufladen].

Anmerkungen

  • Abonnements sind Services, die für einen bestimmten Zeitraum, z. B. 30 oder 60 Tage, genutzt werden können. Wenn das Abonnement ausläuft, wird automatisch eine Verlängerung für einen weiteren Abonnementzeitraum erworben.
  • Zum Konto wird entweder der Betrag hinzugefügt, der zum Bezahlen des Abonnementservice noch erforderlich ist, oder der Mindestbetrag für die Brieftasche, je nachdem, welcher Betrag höher ist.

Nutzung der Brieftasche durch Unterkontoinhaber

Der Inhaber eines Unterkontos kann keine Brieftasche erstellen, aber mit der Brieftasche für das dazugehörige Hauptkonto Produkte und Services bezahlen. Der Hauptkontoinhaber kann ein monatliches Ausgabelimit für zugehörige Unterkonten festlegen. Zum Festlegen von Ausgabelimits wählen Sie (Unterkonto-Verwaltung) unter (PlayStation®Network) > (Konto-Verwaltung).
