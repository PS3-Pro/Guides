Übersicht über PlayStation®Store

Sie müssen eventuell die System-Software aktualisieren, bevor Sie diese Funktion verwenden können.


(PlayStation®Store) ist ein Online-Shop innerhalb von PlayStation®Network, von dem Sie Produkte wie Spiele, Zubehör zu Spielen oder Videoinhalte (gekauft oder kostenlos) herunterladen können.


(1)

Shop wechseln

Spiele-Shop im PlayStation®Store Sie können Spiele und Zubehör für Spiele herunterladen.
Video-Shop im PlayStation®Store * Sie können Videoinhalte wie Spielfilme in voller Länge oder Fernsehsendungen kaufen. Sie können Inhalte mit einer zeitlichen Wiedergabeeinschränkung auch leihen.

*  Der Video-Shop im PlayStation®Store steht nur in einer begrenzten Anzahl von Ländern und Regionen zur Verfügung. Die unterstützten Sprachen sind ebenfalls begrenzt und die zur Verfügung stehenden Servicetypen variieren je nach Region. Weitere Informationen dazu erhalten Sie beim technischen Support für Ihre Region.

(2)

Steuertasten

Suchen Sie können im PlayStation®Store nach Inhalten suchen.
Codes einlösen Damit rufen Sie den Bildschirm auf, in dem Sie eine PlayStation®Network Card-Nummer oder einen Promotion-Code eingeben können. Durch Eingabe solcher Informationen können Sie Guthaben zur Brieftasche für das Konto hinzufügen oder einen Promotion-Code gegen Waren eintauschen.
Downloads anzeigen Damit rufen Sie eine Liste der Inhalte auf, die vom PlayStation®Store heruntergeladen wurden. Sie können Inhalte, die Sie zu einem früheren Zeitpunkt heruntergeladen haben, erneut herunterladen.*
Einkaufswagen anzeigen Damit rufen Sie eine Liste der Produkte in Ihrem Einkaufswagen auf. Sie können von hier zum Kassenbildschirm wechseln.

*  Manche Artikel können nicht mehrmals heruntergeladen werden.

(3)

Anzeigemodus
Damit ändern Sie die Art, wie Artikel angezeigt werden.

(7)

(8)

Anmerkungen

  • PlayStation®Network und (PlayStation®Store) stehen nur in bestimmten Regionen und Sprachen zur Verfügung. Welche Produkte und Inhalte im (PlayStation®Store) erhältlich sind, hängt vom Land bzw. der Region ab, in dem bzw. der der Benutzer wohnt. Weitere Informationen dazu erhalten Sie beim technischen Support für Ihre Region.
  • Wenn Sie Produkte (gekauft oder kostenlos) von (PlayStation®Store) herunterladen möchten, müssen Sie ein PlayStation®Network-Konto erstellen und eine Endbenutzer-Vereinbarung akzeptieren. Sie können über (Für das PlayStation®Network einschreiben) unter (PlayStation®Network) ein Konto erstellen.
