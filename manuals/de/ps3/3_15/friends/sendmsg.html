Erstellen/Senden von Nachrichten

Sie müssen eventuell die System-Software aktualisieren, bevor Sie diese Funktion verwenden können.


Sie können Nachrichten erstellen und an Personen senden, die eine Online-ID beim PlayStation®Network registriert haben. Zum Erstellen und Senden von Nachrichten müssen Sie am PlayStation®Network angemeldet sein.

1.

Wählen Sie (Freunde) > (Nachrichten-Eingang).

2.

Wählen Sie (Nachricht erstellen).

3.

Wählen Sie [An:].
Wählen Sie [Freund auswählen] oder [Online-ID eingeben]. Bei Letzterem müssen Sie die Online-ID der Person eingeben, an die Sie die Nachricht senden wollen.

4.

Geben Sie den Text für die Nachricht ein und wählen Sie [Senden].
Die Nachricht wird gesendet. Sie können die gesendeten Nachrichten unter (Freunde) > (Nachrichten-Eingang) > (Gesendet) anzeigen.

Anmerkungen

  • Sie können Nachrichten nicht über normale E-Mail-Adressen senden oder empfangen.
  • Die Online-ID wird beim Anmelden am PlayStation®Network erstellt. Fragen Sie vor dem Senden einer Nachricht die Person, der Sie eine Nachricht senden wollen, nach ihrer Online-ID.
  • Sie können bis zu 18 Zeichen für einen Titel und bis zu 512 Zeichen für den eigentlichen Text einer Nachricht eingeben.
  • Sie können Emoticons verwenden, indem Sie beim Erstellen einer Nachricht auf der Tastatur auswählen.
  • Sie können bis zu 200 gesendete Nachrichten speichern. Wenn die Höchstzahl erreicht ist, wird bei jedem Senden einer neuen Nachricht die älteste Nachricht automatisch gelöscht.

Anhängen von Dateien

Wenn Sie (Anhängen) auf dem Bildschirm zum Erstellen der Nachricht wählen, können Sie eine Bilddatei (Foto) anhängen.

Anmerkungen

  • Dateien, die größer als 3 MB sind, können nicht angehängt werden.
  • Sie können immer nur eine Datei anhängen.
  • Wenn Sie das Anhängen einer Datei abbrechen wollen, wählen Sie die Datei aus, drücken Sie die -Taste und wählen Sie dann [Anhängen abbrechen] aus dem Menü „Optionen“.
