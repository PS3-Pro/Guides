Verwenden des Bedienfelds

Sie müssen eventuell die System-Software aktualisieren, bevor Sie diese Funktion verwenden können.


Mit Hilfe des On-Screen-Bedienfelds können Sie verschiedene Funktionen durchführen. Das Menü können Sie mit der -Taste ein- oder ausblenden.

Einen Freund einladen

Laden Sie einen Freund zu einem Chat ein.

Anmerkung

Obwohl Sie mehrere Freunde zu einem Chat einladen können, werden nur die Avatars der ersten fünf ausgewählten Freunde angezeigt. Außerdem können bis zu sechs Personen einen Chat-Raum betreten.

Werkzeuge

Zeigen Sie ein Foto aus (Foto) an oder erstellen Sie eine Nachricht für Chat-Mitglieder.

Stimmlageregler Ändern Sie Ihre Stimmlage.

Sie können prüfen, wie die verfremdete Stimme klingt, indem Sie einen Wert auswählen und dann in das Mikrofon sprechen. Die hier eingestellten Werte werden unter (Einstellungen) > (Peripheriegeräte-Einstellungen) > [Stimmlageregler] übernommen.
Foto einblenden Zeigen Sie ein Bild aus (Foto) auf Ihrem Bildschirm an.
Nachricht an alle erstellen Erstellen Sie eine Nachricht für alle in der Chat-Sitzung.

Ansicht

Passen Sie die Einstellungen der Bildschirmanzeige des Chats an.

Anzeigen Stellen Sie hier die Anzeige der Audio-/Video-Bitrate ein, um den Status des Datentransfers zu überprüfen.

Wenn Sie den Chat verlassen, wird die Einstellung zurückgesetzt und die Rate wird nicht mehr angezeigt.
Bildschirm-Modus Ändern Sie den Anzeigemodus des Bildschirms.

Der Bildschirmmodus kann nur geändert werden, wenn zwei Personen miteinander chatten. Abhängig von den Videoausgabeeinstellungen des PS3™-Systems können einige Modi nicht angezeigt werden.

Normal: Das Bild wird an die Bildschirmgröße angepasst.

Normal (mich ausblenden): Das Bild wird an die Bildschirmgröße angepasst. Ihr eigenes Bild oder Ihr Avatar wird auf dem Bildschirm nicht angezeigt.*

Zoomen: Das Bild wird auf dem ganzen Bildschirm angezeigt. Die Proportionen werden beibehalten und die oberen und unteren Bildbereiche werden gegebenenfalls herausgeschnitten.

Zoomen (mich ausblenden): Das Bild wird auf dem ganzen Bildschirm angezeigt, wobei die Bildproportionen beibehalten werden (die oberen und unteren Bildbereiche werden gegebenenfalls herausgeschnitten). Ihr eigenes Bild oder Ihr Avatar wird auf dem Bildschirm nicht angezeigt.*

Original: Das Bild wird in Originalgröße angezeigt.

Wenn Sie den Voice-/Video-Chat verlassen, wird die Einstellung auf [Zoomen] oder [Normal] zurückgesetzt.
Der Rückgabewert hängt von den Videoausgabeeinstellungen des PS3™-Systems ab.

*  Auch wenn Sie Ihr Bild auf dem Bildschirm, den Sie verwenden, ausblenden, wird Ihr Bild oder Avatar auf dem Bildschirm Ihres Chat-Partners angezeigt.

Chat-Einstellungen

Stellen Sie die Audio- oder Video-Einstellungen für einen Voice-/Video-Chat ein.

Kamera Ein / Kamera Aus Schalten Sie die Kamera ein oder aus.

Verwenden Sie die Einstellung, wenn Sie kein Video an Ihren Chat-Partner senden möchten. Wenn Sie die Option [Kamera aus] wählen, wird im Chat-Raum Ihr Avatar angezeigt. Wenn Sie einen Voice-/Video-Chat verlassen, wird die Einstellung auf die Option zurückgesetzt, die Sie unter (Einstellungen) > (Chat-Einstellungen) gewählt haben.
Mikrofon Ein / Aus Schalten Sie das Mikrofon ein oder aus.

Verwenden Sie die Einstellung, wenn Sie kein Audiosignal an Ihren Chat-Partner senden möchten. Wenn Sie einen Voice-/Video-Chat verlassen, wird die Einstellung auf [Mikrofon ein] zurückgesetzt.
Audio-Gerät-Einstellungen Nehmen Sie hier die Einstellungen für die Geräte vor, die Sie für die Audioeingabe/-ausgabe verwenden.

Mikrofon-Empfindlichkeitsgrad: Stellen Sie die Lautstärke des Mikrofons ein.

Eingabe-Gerät: Wählen Sie das zu verwendende Eingabegerät.

Ausgabe-Gerät: Wählen Sie das zu verwendende Ausgabegerät.

Die hier eingestellten Werte werden unter (Einstellungen) > (Peripheriegeräte-Einstellungen) > [Audio-Gerät-Einstellungen] aufgeführt.
Lautstärkeeinstellung Stellen Sie hier die Lautstärke für den Chat ein.

Wenn Sie einen Voice-/Video-Chat verlassen, wird die Einstellung auf [Normal] zurückgesetzt.

Verlassen

Hiermit verlassen Sie den Chat-Raum.

Anmerkung

Wenn die Person, die den Voice-/Video-Chat veranlasst hat, den Chat verlässt, wird der Chat-Raum geschlossen.
