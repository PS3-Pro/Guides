Bearbeiten von Wiedergabelisten

Sie können Titel zu einer Wiedergabeliste hinzufügen oder daraus löschen oder die Titel in einer Wiedergabeliste in einer anderen Reihenfolge anordnen.

Hinzufügen von Titeln zu Wiedergabelisten

1.

Wählen Sie (Musik) > (Wiedergabelisten).

2.

Wählen Sie die zu bearbeitende Wiedergabeliste aus und drücken Sie die -Taste.

3.

Wählen Sie [Bearbeiten].
Die im Systemspeicher gespeicherten Titel werden auf der linken Seite des Bildschirms angezeigt, die Elemente der Wiedergabeliste, die bearbeitet werden sollen, werden auf der rechten Seite des Bildschirms angezeigt.

4.

Wählen Sie mit den Richtungs--Tasten den Titel, den Sie zur Wiedergabeliste hinzufügen möchten, aus den Titeln, die im Systemspeicher gespeichert sind.
Der Titel wird zur Wiedergabeliste hinzugefügt. Wenn Sie keine weiteren Titel mehr hinzufügen möchten, drücken Sie die -Taste, um die Bearbeitung zu beenden.

Löschen von Titeln aus Wiedergabelisten

1.

Wählen Sie (Musik) > (Wiedergabeliste).

2.

Wählen Sie die zu bearbeitende Wiedergabeliste aus und drücken Sie die -Taste.

3.

Wählen Sie [Bearbeiten].
Die im Systemspeicher gespeicherten Titel werden auf der linken Seite des Bildschirms angezeigt, die Elemente der Wiedergabeliste, die bearbeitet werden sollen, werden auf der rechten Seite des Bildschirms angezeigt.

4.

Wählen Sie den Titel, den Sie aus der Wiedergabeliste löschen möchten, und drücken Sie auf die -Taste.
Der Titel wird aus der Wiedergabeliste gelöscht. Wenn Sie keine weiteren Titel mehr löschen möchten, drücken Sie die -Taste, um die Bearbeitung zu beenden.

Anmerkungen

  • Auch wenn ein Titel aus einer Wiedergabeliste gelöscht wird, wird die Musikdatei nicht vom Systemspeicher gelöscht.
  • Wenn ein Titel, der zu einer Wiedergabeliste hinzugefügt wurde, vom Systemspeicher gelöscht wird, wird der Titel automatisch auch aus der Wiedergabeliste gelöscht.

Neuanordnen von Titeln in Wiedergabelisten

1.

Wählen Sie (Musik) > (Wiedergabelisten).

2.

Wählen Sie die zu bearbeitende Wiedergabeliste aus und drücken Sie die -Taste.

3.

Wählen Sie [Bearbeiten].
Die im Systemspeicher gespeicherten Titel werden auf der linken Seite des Bildschirms angezeigt, die Elemente der Wiedergabeliste, die bearbeitet werden sollen, werden auf der rechten Seite des Bildschirms angezeigt.

4.

Wählen Sie den Titel, den Sie verschieben möchten, und drücken Sie auf die -Taste.

5.

Verschieben Sie den Titel mit den -Tasten an die gewünschte Position und drücken Sie die -Taste. Der Titel wird an die gewünschte Position verschoben. Wenn Sie keine weiteren Titel mehr verschieben möchten, drücken Sie die -Taste, um die Bearbeitung zu beenden.
