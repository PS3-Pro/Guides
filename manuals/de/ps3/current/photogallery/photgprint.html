Drucken von Fotos

Zum Drucken eines Fotos müssen Sie zuerst den Drucker über [Druckerauswahl] unter (Einstellungen) > (Drucker-Einstellungen) konfigurieren.

1.

Schließen Sie einen Drucker an das PS3™-System an.

2.

Wählen Sie das Foto, das Sie drucken möchten, und drücken Sie dann die -Taste.

3.

Wählen Sie (Drucken).

4.

Prüfen Sie die Druck-Einstellungen.
Mit der -Taste können Sie das Menü „Optionen“ aufrufen. Sie können Einstellungen, wie z. B. die Anzahl der zu druckenden Exemplare, vornehmen. Welche Einstellungen zur Verfügung stehen, hängt vom verwendeten Drucker ab.

5.

Wählen Sie [Drucken].
Das Foto wird gedruckt.

Anmerkung

Die Drucker, die verwendet werden können, hängen vom Land bzw. der Region ab. Einzelheiten dazu finden Sie auf der SIE-Website für Ihre Region.
