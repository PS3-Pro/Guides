Importieren von Fotos auf das PS3™-System

Sie können Fotos im Systemspeicher des PS3™-Systems einfach anzeigen, indem Sie Photo Gallery starten. Sind im Systemspeicher noch keine Fotos gespeichert, können Sie mit Photo Gallery auch Fotos von einer Digitalkamera oder einem Datenträger in den Systemspeicher importieren.


Schließen Sie zum Importieren von Fotos die Digitalkamera oder einen USB-Adapter (mit einem Datenträger darin) mit einem USB-Kabel an das PS3™-System an. Wählen Sie mit dem linken Stick das daraufhin angezeigte Digitalkamerasymbol und drücken Sie dann die -Taste. Importieren Sie die Fotos in den Systemspeicher, wie in den Anweisungen auf dem Bildschirm erläutert.

Anmerkungen

  • Die importierten Fotos können Sie auch unter (Foto) auf dem XMB™ (XrossMediaBar)-Bildschirm anzeigen lassen.
  • Sie können Fotos nicht auf Datenträger exportieren, wenn Sie Photo Gallery verwenden. Zum Exportieren von Fotos müssen Sie Photo Gallery beenden und auf dem XMB™-Bildschirm (Foto) aufrufen.
  • Der Import von Fotos ist nicht von allen Digitalkameras oder Speichergeräten möglich.
  • Achten Sie darauf, die Urheberrechte anderer nicht zu verletzen.
