Erstellen/Wiedergeben von Wiedergabelisten

Sie können im Systemspeicher gespeicherte Bilder auswählen, in der gewünschten Reihenfolge anordnen und so für die Wiedergabe in einer Wiedergabeliste zusammenstellen.

1.

Wählen Sie (Foto) > (Wiedergabelisten).

2.

Wählen Sie (Neue Wiedergabeliste erstellen). Befolgen Sie zum Erstellen der Wiedergabeliste die Anweisungen auf dem Bildschirm.

3.

Wählen Sie eine vorhandene Wiedergabeliste aus und drücken Sie die -Taste.

4.

Wählen Sie [Bearbeiten].
Die im Systemspeicher gespeicherten Bilder werden auf der linken Seite des Bildschirms angezeigt und die Elemente der Wiedergabeliste werden auf der rechten Seite des Bildschirms angezeigt.

5.

Wählen Sie das Bild, das Sie zur Wiedergabeliste hinzufügen möchten.
Das Bild wird zur Wiedergabeliste hinzugefügt. Wenn das Bild hinzugefügt wurde, drücken Sie die -Taste, um die Bearbeitung zu beenden. Eine vorhandene Wiedergabeliste können Sie über (Foto) > (Wiedergabelisten) wiedergeben lassen.

Anmerkungen

  • Nur Bilder, die im Systemspeicher gespeichert wurden, können zur Wiedergabeliste hinzugefügt werden.
  • Sie können eine Slideshow starten oder ein Bild drucken, während Sie Bilder in einer Wiedergabeliste durchsuchen. Wählen Sie ein Bildsymbol in der Wiedergabeliste aus und drücken Sie die -Taste. Wählen Sie [Slideshow] oder [Drucken] aus dem Menü „Optionen“.
