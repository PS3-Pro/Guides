Informationen zu „Neuigkeiten“

Mit der Funktion „Neuigkeiten“ können Sie die neuesten Informationen aus dem PlayStation®Store anzeigen und die kürzlich wiedergegebenen Inhalte prüfen. Wenn Sie unter [Neuigkeiten] ein Element auswählen, können Sie detaillierte Informationen dazu anzeigen lassen.

Zu Elementen in der Inhaltsübersicht angezeigte Icons

Starten des Internet-Browsers zum Anzeigen einer Webseite.
Zugreifen auf den PlayStation®Store.
Wiedergeben von Videos.
Starten eines Spiels durch Drücken der START-Taste.

Anmerkungen

  • Vergewissern Sie sich, dass das PS3™-System mit dem Internet verbunden ist, wenn Sie die neuesten Informationen anzeigen lassen möchten. Einzelheiten zu Netzwerk-Einstellungen finden Sie unter (Einstellungen) > (Netzwerk-Einstellungen) > [Internetverbindungs-Einstellungen] in diesem Handbuch.
  • Wenn Sie Produkte (gekauft oder kostenlos) vom PlayStation®Store herunterladen möchten, müssen Sie ein Sony Entertainment Network-Konto erstellen.
  • Welche Inhalte angezeigt werden, hängt von dem Land bzw. der Region ab, von wo aus Sie auf den PlayStation®Store zugreifen.
