Verwalten von Kontoinformationen

Sie müssen eventuell die System-Software aktualisieren, bevor Sie diese Funktion verwenden können.


Sie können die Informationen für Sony Entertainment Network-Konten überprüfen oder bearbeiten. Dazu müssen Sie am PSNSM angemeldet sein. Wählen Sie (Konto-Verwaltung) unter (PlayStation™Network).

Elemente, die überprüft oder bearbeitet werden können
Kontoinformationen

Sie können Informationen über Ihre Sony Entertainment Network-Konten überprüfen oder bearbeiten.

  • Rechnungsinformationen
  • Anmelde-ID (E-Mail-Adresse)
  • Passwort
  • Systemsprache
  • Name
  • Adresse
  • Avatar
  • Profil
  • Benachrichtigungseinstellungen
Unterkonto-Verwaltung

Sie können die Einstellungen für ein zugehöriges Unterkonto überprüfen oder bearbeiten.

  • Kindersicherung
  • Unterkonto-Passwort
Codes einlösen Sie können eine PSNSM Card-Nummer oder einen Promotion-Code einlösen.
Transaktionsverwaltung

Sie können Guthaben zu der Brieftasche hinzufügen, die für PSNSM-Services wie PlayStation®Store verwendet wird, oder den Nutzungsverlauf für verschiedene Services überprüfen.

  • Geld hinzufügen
  • Passwort an Kasse benötigt
  • Automatisches Aufladen
  • Transaktionsverlauf
  • Download-Liste
  • Services-Liste
Systemaktivierung Sie können das für das Konto verwendete PS3™- oder PSP™-System aktivieren bzw. deaktivieren.
Privatsphäre-Einstellungen Sie können die Gruppe der Spieler einstellen, die Ihre Trophäen sehen können, und festlegen, von welchen Benutzern Sie Freundesanfragen oder Meldungen erhalten möchten.
Außerdem können Sie für jedes Spiel einstellen, ob die Trophäen angezeigt werden sollen, die Sie gewonnen haben. Näheres dazu finden Sie unter [Trophäen-Sammlung] in diesem Handbuch.

Anmerkung

Welche Optionen Sie überprüfen bzw. bearbeiten können, hängt vom Sony Entertainment Network-Kontotyp sowie vom Land bzw. der Region ab. Weitere Informationen dazu erhalten Sie beim technischen Support für Ihre Region.

  • Informationen zur XMB™
  • Benutzer
  • Einstellungen
  • Foto
  • Musik
  • Video
  • TV-/Video-Dienste
  • Spiel
  • Netzwerk
  • PlayStation™Network
  • Freunde
