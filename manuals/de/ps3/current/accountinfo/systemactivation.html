Informationen zur Systemaktivierung

Die Systemaktivierung ist ein Vorgang zum Schutz von Urheberrechten und anderen Rechten an digitalen Inhalten. Im PlayStation®Store erhältliche Inhalte und Anwendungen können nur auf aktivierten Systemen verwendet werden.

Sie können Ihr Sony Entertainment Network-Konto mit mehreren Systemen verknüpfen, doch die Systemanzahl, die pro Inhaltstyp aktiviert werden kann, ist für jedes Konto beschränkt. Wenn die Anzahl aktivierter Systeme die Obergrenze erreicht hat, erscheint eine Fehlermeldung beim Versuch, Inhalt auf ein nicht aktiviertes System herunterzuladen (zu kaufen). Um den Inhalt auf diesem System zu verwenden, müssen Sie zuerst eines Ihrer anderen Systeme deaktivieren.

Manuelles Aktivieren eines Systems

Normalerweise wird Ihr System automatisch aktiviert, wenn Sie den Inhalt herunterladen (kaufen). Wenn Sie jedoch versuchen, Inhalt wiederzugeben, und eine Meldung erscheint, dass eine Systemaktivierung erforderlich ist, müssen Sie Ihr System manuell aktivieren.

Melden Sie sich auf Ihrem PS3™-System am PSNSM an. Wählen Sie (PlayStation™Network) > (Konto-Verwaltung) > (Systemaktivierung), und gehen Sie nach den Anweisungen auf dem Bildschirm vor.

Anmerkungen

  • Sie können ein PS3™-System zum Anschauen von Videoinhalten innerhalb von 90 Tagen maximal 3-mal pro Konto aktivieren. Sie können dasselbe System nicht ein viertes Mal innerhalb von 90 Tagen über ein Konto aktivieren. Nach dem ersten Aktivieren können Sie das System erneut nach 90 Tagen aktivieren.
  • Der Erwerb/die Ausleihe von Video-Inhalten aus dem PlayStation®Store auf dem PS3™-System wurde eingestellt.

Deaktivieren eines Systems

Wenn Sie versuchen, die Höchstzahl der aktivierten Systeme für Ihr Konto zu überschreiten, erscheint eine Meldung, dass Sie den gewählten Inhalt nicht kaufen (herunterladen) können. Wenn dies der Fall ist, eines Ihrer anderen Systeme deaktivieren.

Melden Sie sich auf Ihrem PS3™-System am PSNSM an. Wählen Sie (PlayStation™Network) > (Konto-Verwaltung) > (Systemaktivierung), und gehen Sie nach den Anweisungen auf dem Bildschirm vor.

Wenn Sie ein System nicht deaktivieren können

Wenn Sie ein aktiviertes System mit diesem System nicht deaktivieren können, z. B. aufgrund einer Störung oder weil dieses System entsorgt wurde, kontaktieren Sie den technischen Support für Ihre Region.
Sie können auch alle aktivierten Systeme für jeden Kontotyp von den folgenden Webseiten deaktivieren:

http://account.sonyentertainmentnetwork.com/
Gehen Sie zu [Konto] > [Medien & Geräte] und wählen Sie dann [Alle deaktivieren] für den Inhaltstyp, dessen aktivierte Systeme Sie vollständig deaktivieren wollen.

Anmerkungen

  • Abhängig vom Kontotyp können Sie möglicherweise nicht alle aktivierten Systeme mit dieser Seite deaktivieren.
