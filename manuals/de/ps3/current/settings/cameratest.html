Kameragerät-Einstellungen

Testen Sie das Bild einer USB-Kamera (separat erhältlich), die über ein USB-Kabel mit dem System verbunden ist. Bei einigen Kameras können Sie Einstellungen vornehmen, um Flimmern zu reduzieren. Wenn Sie die Netzfrequenz auf die in der Region, in der die Kamera verwendet wird, gültige Netzfrequenz einstellen, lässt sich das Flimmern möglicherweise verringern. Angezeigte Daten hängen von der verwendeten Kamera ab.

Aus Deaktivieren der Flimmerreduzierung.
Standard-Kameraeinstellungen Verwenden der Standardeinstellungen für die Kamera.
50 Hz Stellen Sie diese Option ein, wenn die Netzfrequenz in Ihrer Region 50 Hz beträgt.
60 Hz Stellen Sie diese Option ein, wenn die Netzfrequenz in Ihrer Region 60 Hz beträgt.

Anmerkungen

  • Sie können eine kompatible USB-Kamera (EyeToy™), eine PlayStation®Eye bzw. eine mit UVC (USB Video Class) kompatible USB-Kamera mit dem PS3™-System verwenden.
  • Wenn Sie eine USB-Kamera über einen USB-Hub anschließen, verwenden Sie einen Hub, der USB 2.0 unterstützt. Wenn ein Hub verwendet wird, der USB 2.0 nicht unterstützt, verringert sich möglicherweise die Bildqualität oder gar kein Bild wird angezeigt.
  • Informationen zu unterstützten Peripheriegeräten und Anweisungen zum Gebrauch erhalten Sie bei dem Händler, der die Peripheriegeräte anbietet.
