Automatisches Update

Für die Verwendung bestimmter Funktionen müssen Sie den PlayStation®Plus-Abonnement-Service abonnieren.

Wenn diese Funktion auf [Ein] gesetzt ist, schaltet sich das PS3™-System jeden Tag zur vorgegebenen Zeit automatisch ein, führt die festgelegten Funktionen aus und schaltet sich dann wieder aus.

Aus Die Funktion zum automatischen Aktualisieren wird nicht verwendet
Ein Die Funktion zum automatischen Aktualisieren wird verwendet.

Sie können für die folgenden Optionen die Funktionen für „Automatisches Update“ wählen.

  • Mit anderen Geräten erworbene Inhaltsobjekte herunterladen
  • Aktuellste System-Software herunterladen
  • Patches für Spiele herunterladen
  • Trophäen-Information mit dem Server synchronisieren

Anmerkungen

  • Stellen Sie [Gespeicherte Daten in Online-Speicher hochladen] für jedes Spiel ein. Einzelheiten zur Einstellung dieser Option finden Sie unter (Spiel) > [Spielen mit Software im PlayStation®3-Format] > [Verwenden von Speicherdaten] in diesem Handbuch.
  • Wenn Sie [Ein] ausgewählt haben, wählen Sie mit den Richtungstasten den Zeitraum aus, in dem die automatische Aktualisierung ausgeführt werden soll. Befolgen Sie die Anweisungen auf dem Bildschirm, wenn ein Bildschirm erscheint, in dem Sie die Einstellungen für das automatische Anmelden am PSNSM verifizieren sollen.
  • Diese Funktion kann an nur einem PS3™-System pro Sony Entertainment Network-Konto verwendet werden. Wenn die Funktion zum automatischen Aktualisieren an zwei oder mehr PS3™-Systemen desselben Kontos auf [Ein] gesetzt wurde, bleibt sie am zuletzt eingestellten System auf [Ein] gesetzt und wird an allen anderen Systemen automatisch auf [Aus] gesetzt.
  • Das PS3™-System muss sich in dem Zeitraum, in dem die automatische Aktualisierung ausgeführt werden soll, im Bereitschaftsmodus befinden (Power-Kontroll-Leuchte leuchtet rot).
  • Aktualisierungsdaten für die System-Software werden automatisch heruntergeladen, aber nicht installiert. Sie müssen die Aktualisierungsdaten für die System-Software manuell installieren.
  • Bei Patches für Spiele und bei empfohlenen Spielen, die automatisch heruntergeladen wurden, wird angezeigt. Inhalte, die automatisch heruntergeladen und installiert, aber nicht verwendet wurden, werden nach einem Monat automatisch gelöscht.
  • Auch wenn [Automatisches Update] auf [Ein] gesetzt ist, werden keine Inhalte heruntergeladen, wenn im Systemspeicher weniger als 5 GB freier Speicherplatz vorhanden sind.
  • Stellen Sie [Aus] ein, um die Standardeinstellungen aller ausgewählten Optionen für die automatische Aktualisierung wiederherzustellen.
