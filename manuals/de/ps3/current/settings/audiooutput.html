Audio-Ausgangs-Einstellungen

Sie können Audio-Ausgangs-Einstellungen für das System vornehmen. Diese Einstellungen werden hauptsächlich verwendet, wenn das System an Audio-Geräte angeschlossen wird, die die digitale Audio-Ausgabe unterstützen, wie z. B. AV-Verstärker (Receiver) für Home-Entertainment-Systeme.

1.

Überprüfen Sie, welche Formate von Ihrem Audio-Gerät unterstützt werden.
Die Einstellungen hängen von den unterstützten Formaten ab. Näheres dazu finden Sie in den mit dem Audio-Gerät gelieferten Anweisungen.

2.

Wählen Sie (Einstellungen) > (Sound-Einstellungen).

3.

Wählen Sie [Audio-Ausgangs-Einstellungen].

4.

Wählen Sie den Eingangsanschluss am Audio-Gerät aus. Welche Kanalanzahl und Audioformate unterstützt werden, hängt vom verwendeten Anschluss ab.

Eingangsanschluss am Fernsehgerät oder AV-Verstärker (Receiver) Ausgangsanschluss am PS3™-System Für die Ausgabe verfügbare Kanäle
HDMI HDMI OUT-Anschluss 2 Kanäle, 5.1 Kanäle, 7.1 Kanäle
Optisch digital DIGITAL OUT (OPTICAL)-Anschluss 2 Kanäle, 5.1 Kanäle
Audio-Eingangsanschluss/SCART/AV MULTI AV MULTI OUT-Anschluss 2 Kanäle

5.

Wählen Sie die Audio-Ausgangsformate aus.
Wählen Sie alle Ausgangsformate aus, die vom verwendeten Audio-Gerät unterstützt werden. Wenn in Schritt 4 [Audio-Eingangsanschluss/SCART/AV MULTI] ausgewählt wird, wird der Bildschirm zum Auswählen der Audio-Ausgangsformate nicht angezeigt. Wenn [HDMI] ausgewählt ist, können Sie auch auswählen, dass das Audio-Ausgangsformat automatisch eingestellt wird. (In diesem Fall muss das HDMI-Gerät eingeschaltet sein.)

6.

Überprüfen Sie Ihre Einstellungen.
Sie können wieder den vorherigen Bildschirm aufrufen und die Einstellungen ändern, indem Sie die -Taste drücken.

7.

Speichern Sie Ihre Einstellungen.
Die Audio-Ausgangs-Einstellungen werden auf dem System gespeichert.

Anmerkungen

  • Standardmäßig wird Ton mit [Lineare PCM 2 K.] an allen Ausgängen ausgegeben. Wenn Sie die Audio-Ausgangseinstellungen ändern, wird der Ton nur über die eingestellten Anschlüsse ausgegeben.
  • Wenn Sie die Audio-Ausgangs-Einstellungen ändern, kann das System Ton nicht mehr über mehrere Ausgänge gleichzeitig ausgeben lassen. Wenn das System beispielsweise über ein HDMI-Kabel an ein Fernsehgerät und über ein optisches Digitalkabel an ein Audiogerät angeschlossen ist und Sie unter [Audio-Ausgangs-Einstellungen] die Option [Optisch digital] einstellen, wird vom Fernsehgerät kein Ton mehr ausgegeben. Wenn Ton vom Fernsehgerät ausgegeben werden soll, ändern Sie die Einstellung in [HDMI] oder wählen Sie (Einstellungen) > (Sound-Einstellungen) > [Audio-Mehrfachausgang] und setzen Sie die Option auf [Ein].
  • Wenn Sie in Schritt 5 [Lineare PCM 2 K. 88,2 kHz] oder [Lineare PCM 2 K. 176,4 kHz] wählen, setzt der Ton möglicherweise aus oder wird bei einigen Geräten gar nicht ausgegeben.
  • Wenn Sie ein HDMI-Kabel verwenden, wird bei Software im PlayStation®2- und PlayStation®-Format nur Ton im Format [Lineare PCM 2 K.] ausgegeben. Wenn Sie Dolby Digital- oder DTS®-Ton ausgeben wollen, müssen Sie das PS3™-System und das Audiogerät über ein optisches Digitalkabel verbinden und unter [Audio-Ausgangs-Einstellungen] auf [Optisch digital] umschalten.
  • Wenn ein Gerät, das nicht mit dem HDCP (High-bandwidth Digital Content Protection)-Standard kompatibel ist, über ein HDMI-Kabel an das System angeschlossen ist, können Bild und/oder Ton vom System nicht ausgegeben werden.
  • Wenn Dolby TrueHD als Audio-Ausgangsformat ausgewählt ist, wird der Ton bei der Wiedergabe von Blu-ray 3D™-Inhalten im Format Dolby Digital ausgegeben.

Hinweise

  • Einige Softwaretitel im PlayStation®2- oder PlayStation®-Format werden auf dem PS3™-System anders als auf einem PlayStation®2- oder PlayStation®-System ausgeführt oder sie werden auf dem PS3™-System nicht ordnungsgemäß ausgeführt.
  • Discs im PlayStation®2-Format können auf einigen PS3™-Systemen nicht abgespielt werden. Näheres dazu finden Sie unter [Typen abspielfähiger Discs] oder auf der SIE-Website für Ihre Region. Sie können auch in der Dokumentation zum PS3™-System nachschlagen.
