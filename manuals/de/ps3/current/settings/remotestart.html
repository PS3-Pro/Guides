Remote Start

Ein PS3™-System, das sich im Bereitschaftsmodus (Wake On LAN) befindet, lässt sich mit einem Gerät, das Remote Play unterstützt, wie z. B. einem PS Vita-System oder einem PSP™-System, ferngesteuert einschalten. Vor dem Verwenden dieser Funktion müssen Sie vorab die folgenden Schritte ausführen:

Bei Verwendung von Remote Play über die WLAN-Funktion des PS3™-Systems oder über einen Access Point:
  • Wenn Sie für Remote Play ein PSP™-System verwenden, aktualisieren Sie die PSP™-System-Software auf Version 3.72 oder höher.
  • Einstellen des automatischen Log-in unter (Benutzer) am PS3™-System

Bei Verwendung von Remote Play über das Internet:
  • Wenn Sie für Remote Play ein PSP™-System verwenden, aktualisieren Sie das PSP™-System und das PS3™-System anhand der neuesten Version der System-Software.
  • Einstellen der automatischen Anmeldung unter (Benutzer) am PS3™-System
  • Einrichten der für den Internetzugriff erforderlichen Netzwerkeinstellungen am PS3™-System.
  • Einrichten eines Sony Entertainment Network-Kontos.
  • Einstellen der automatischen Anmeldung an PSNSM.

Anmerkungen

  • Für die Remote Start-Funktion müssen Benutzer von PS3™-Systemen der Serien CECH-4302, CECH-4303, CECH-4304 und CECH-4308 die Netzwerkverbindung mithilfe der WLAN-Funktion des PS3™-Systems herstellen.
  • Einzelheiten zum automatischen Log-in unter (Benutzer) finden Sie in (Benutzer) > [Anmelden] > [Einstellen des automatischen Log-in] in diesem Handbuch.
  • Einzelheiten zum automatischen Anmelden am PSNSM finden Sie unter (PlayStation™Network) > [Passwort speichern (Autom. Anmeldung)] in diesem Handbuch.

Aktivieren von Remote Start

1.

Wählen Sie (Einstellungen) > (Remote-Play-Einstellungen).

2.

Wählen Sie [Remote Start] > [Ein].

3.

Wählen Sie [O. K.] auf dem angezeigten Bildschirm. Wenn Sie Remote Play über das Internet verwenden wollen, aktivieren Sie [Remote Start über das Internet aktivieren].

4.

Schalten Sie das PS3™-System aus.
Wählen Sie (Benutzer) > (System ausschalten), um das System auszuschalten und in den Bereitschaftsmodus zu wechseln. Vergewissern Sie sich, dass die Power-Kontroll-Leuchte rot leuchtet.

5.

Führen Sie Remote Play mit einem Gerät aus, das Remote Play unterstützt, wie z. B. einem PS Vita-System oder einem PSP™-System.
Einzelheiten zum Verwenden von Remote Play finden Sie in der mit dem verwendeten Gerät gelieferten Anleitung.

Anmerkungen

  • Einzelheiten zu Remote Play bei Verwendung eines PS Vita-Systems oder PSP™-Systems finden Sie unter (Netzwerk) > (Remote Play) > [Verwenden von Remote Play] in diesem Handbuch.
  • Wenn Remote Start aktiviert ist, läuft der interne Ventilator des PS3™-Systems nach dem Ausschalten des Systems weiter.

Deaktivieren von Remote Start

1.

Wählen Sie (Einstellungen) > (Remote-Play-Einstellungen).

2.

Wählen Sie [Remote Start] > [Aus].

Remote Start über das Internet

Sie können möglicherweise Remote Play abhängig vom verwendeten Netzwerk nicht über das Internet verwenden. Ist dies der Fall, überprüfen Sie Folgendes:

Hinweis

Je nach dem Router-Typ wird das PS3™-System möglicherweise unbeabsichtigt gestartet, wenn Remote Start aktiviert ist. Wenn eine Remote Play-Verbindung nicht innerhalb einer bestimmten Zeit nach dem Starten des PS3™-Systems hergestellt wird, schaltet sich das System automatisch aus. Um das zu verhindern, kann Remote Start über das Internet automatisch deaktiviert werden.

  • Zum Verwenden von Remote Start über das Internet ist ein Router erforderlich.
  • Falls der Router UPnP unterstützt, aktivieren Sie die UPnP-Funktion des Routers.
  • Falls der Router UPnP nicht unterstützt, müssen Sie die Anschlussweiterleitung des Routers einstellen, damit eine Internetverbindung zum PS3™-System möglich ist. Die für Remote Play und Remote Start verwendete Anschlussnummer ist bei TCP 9293 und bei UDP 9293. Informationen zum Einstellen dieser Option finden Sie in den mit dem Router gelieferten Anweisungen.
  • Mit der Anschlussweiterleitung werden Signale an einem bestimmten Anschluss (Eingang) zu einem bestimmten anderen Anschluss (Ausgang) weitergeleitet. Dies wird auch als „Port-Mapping“ oder „Adresskonvertierung“ bezeichnet.
  • Wenn sich das PS3™-System im Bereitschaftsmodus befindet und die IP-Adresse des Routers (globale IP-Adresse) geändert wird, verläuft Remote Start nicht erfolgreich.
