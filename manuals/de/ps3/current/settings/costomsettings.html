Benutzerdefinierte Verbindungseinstellungen

Diese Einstellung steht nur auf PS3™-Systemen zur Verfügung, die mit der WLAN-Funktion ausgestattet sind.


Wenn ein Gerät, das Remote Play unterstützt, bei einem PS3™-System registriert ist, das mit einer WLAN-Funktion ausgestattet ist, wird eine Netzwerkverbindung für Remote Play mit einer spezifischen SSID und einem Verschlüsselungsschlüssel (WPA-Schlüssel) automatisch für beide Systeme erstellt und die Systeme können im Infrastruktur-Modus miteinander kommunizieren. Über [Benutzerdefinierte Verbindungseinstellungen] können Sie die am PS3™-System eingestellte SSID und den Verschlüsselungsschlüssel manuell ändern. In der Regel ist es nicht erforderlich, diese Einstellungen zu ändern.

SSID Legen Sie die SSID fest.

Sie können eine beliebige SSID eingeben.
WLAN-Sicherheitseinstellung Legen Sie die Sicherheitsmethode fest.

Für Remote-Play-Einstellungen können Sie nur [WPA-PSK (AES)] auswählen.
WPA-Schlüssel Legen Sie einen Verschlüsselungsschlüssel fest.

Sie können einen beliebigen Schlüssel eingeben. Der Verschlüsselungsschlüssel wird als eine Reihe von Sternen angezeigt. Sie benötigen den hier festgelegten Schlüssel, wenn Sie die Netzwerkverbindung für das Gerät, das Remote Play unterstützt, ändern. Notieren Sie den Schlüssel daher, so dass Sie ihn später bei Bedarf zur Hand haben.

Anmerkung

Wenn die SSID und die WPA-Schlüssel für das PS3™-System geändert werden, müssen Sie für die Netzwerkverbindung des Geräts, das Remote Play unterstützt, dieselbe SSID und denselben WPA-Schlüssel festlegen. Vergewissern Sie sich, dass nach dem Ändern dieser Werte das Gerät, das Remote Play unterstützt, erneut registriert wird.
