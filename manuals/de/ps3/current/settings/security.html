Sicherheits-Einstellungen

Sie können Sicherheits-Einstellungen für das System vornehmen.

Anmerkung

Diese Einstellungen steuern lokale Inhalte (digitale Inhalte im Systemspeicher, Inhalte auf Datenträgern und Discs). Beachten Sie, dass mit diesen Einstellungen der Zugriff auf Online-Inhalte nicht eingeschränkt wird.


Passwort ändern

Ändern Sie das Passwort, das zum Vornehmen von System-Einstellungen benötigt wird. Ein Passwort ist in den folgenden Fällen erforderlich:

  • Bei der Wiedergabe von durch die Kindersicherung gesperrte Inhalte
  • Beim Ändern der Kindersicherungsstufe des Systems oder der Einstellung für die Internet-Browser-Startsteuerung
  • Beim Starten des Browsers, wenn die Option „Internet-Browser-Startsteuerung“ auf [Ein] gesetzt ist
  • Beim Ändern des aktuellen Passworts

Notieren Sie sich Ihr neues Passwort. Das Passwort ist standardmäßig auf [0000] gesetzt.

Anmerkung

Wenn Sie (Einstellungen) > (System-Einstellungen) > [Standardeinstellungen wiederherstellen] auswählen, können Sie das Passwort auf [0000] zurücksetzen. Beachten Sie jedoch, dass dabei alle anderen Einstellungen ebenfalls auf ihre Standardwerte zurückgesetzt werden.

BD - Kindersicherung

Legen Sie fest, wie durch die Kindersicherung eingeschränkte BDs (Blu-ray Disc) wiedergegeben werden sollen. Zum Ändern dieser Einstellung ist ein Passwort erforderlich.

Nicht beschränken (Aus) Alle BDs werden unabhängig von der Kindersicherungsstufe wiedergegeben.
Beschränken (Ein) Nur BDs mit der angegebenen Kindersicherungsstufe werden wiedergegeben.

Wenn Sie die Option auf [Beschränken (Ein)] gesetzt haben, können Sie auf dem nächsten Bildschirm eine Alterseinschränkung auswählen. Beachten Sie: Je niedriger der Wert, desto strikter die Einschränkung.

BD/DVD - Kindersicherungs-Regionalcode

Legen Sie eine Region als Grundlage für die Standard-Kindersicherungsstufen für BDs und DVDs fest. Zum Ändern dieser Einstellung ist ein Passwort erforderlich.

USA Die Standard-Kindersicherungsstufen für die USA werden festgelegt.
Andere Standard-Kindersicherungsstufen für andere Regionen werden festgelegt.

Wenn Sie [Andere] auswählen, können Sie auf dem nächsten Bildschirm eine Region auswählen.

DVD - Kindersicherung

Legen Sie fest, wie DVDs mit Kindersicherung wiedergegeben werden sollen. Zum Ändern dieser Einstellung ist ein Passwort erforderlich.

Aus Alle DVDs werden unabhängig von der Kindersicherungsstufe wiedergegeben.
Stufe 8 bis 1 Nur DVDs mit der angegebenen Kindersicherungsstufe werden wiedergegeben.

Beachten Sie: Je niedriger der Wert, desto strikter die Einschränkung.

Kindersicherung

Legen Sie fest, wie durch die Kindersicherung eingeschränkte Spiele wiedergegeben werden sollen. Zum Ändern dieser Einstellung ist ein Passwort erforderlich.

Aus Alle Inhalte werden unabhängig von der Kindersicherungsstufe wiedergegeben.
Stufe 11 bis 1 Nur Inhalte mit der angegebenen oder einer niedrigeren Kindersicherungsstufe werden wiedergegeben.

Beachten Sie: Je niedriger der Wert, desto strikter die Einschränkung. Wenn Sie [Den Start von Spielen ohne Kindersicherungseinstellungen sperren] auswählen, können Sie das Spielen ohne Kindersicherungseinstellungen für Ihre Region einschränken.

Anmerkungen

  • Kindersicherungseinstellungen für Spiele hängen von der Region ab, in der die Spiele verkauft werden. Einzelheiten dazu finden Sie auf der SIE-Website für Ihre Region. Je nach Region enthalten manche Softwarehandbücher Informationen zu diesen Einstellungen.
  • Kindersicherungsstufen hängen vom Spiel ab.

Internet-Browser-Startsteuerung

Sie können die Möglichkeit zum Starten des Internet-Browsers einschränken. Zum Ändern dieser Einstellung ist ein Passwort erforderlich.

Aus Die Startsteuerung wird nicht verwendet.
Ein Die Startsteuerung wird verwendet. Zum Starten des Browsers ist ein Passwort erforderlich.
