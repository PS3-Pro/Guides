Starten/Beenden von Spielen

Starten eines Spiels

Wenn Sie eine Disc einlegen, wird das Spiel automatisch gestartet.

Beenden eines Spiels

Drücken Sie während des Spielens die PS-Taste am Wireless-Controller und wählen Sie dann [Spiel verlassen].

Hinweis

Wenn Sie Software im PlayStation®2-Format starten oder beenden, werden die Zuweisungen von Controller-Nummern gelöscht. Gehen Sie zum Zuweisen von Controller-Nummern wie im Folgenden erläutert vor.

Beim Starten eines Spiels: Drücken Sie die PS-Taste am Controller, wenn das Spiel auf dem Bildschirm angezeigt wird.
Beim Beenden eines Spiels: Drücken Sie die PS-Taste am Controller, wenn das XMB™-Menü angezeigt wird.

Anmerkung

Zum Speichern von Daten von Software im PlayStation®2-/PlayStation®-Format müssen Sie eine interne Memory Card erstellen. Einzelheiten zu internen Memory Cards finden Sie unter (Spiel) > [Spielen mit Software im PlayStation®2- und PlayStation®-Format] > [Verwenden von Speicherdaten] in diesem Handbuch.

Zurücksetzen von Spielen

Drücken Sie während des Spielens die PS-Taste am Wireless-Controller und wählen Sie dann [Spiel zurücksetzen] auf dem angezeigten Bildschirm. Sie können ein Spiel nur zurücksetzen, wenn Sie einen Softwaretitel im PlayStation®2- oder PlayStation®-Format spielen.

Hinweise

  • Einige Softwaretitel im PlayStation®2- oder PlayStation®-Format werden auf dem PS3™-System anders als auf einem PlayStation®2- oder PlayStation®-System ausgeführt oder sie werden auf dem PS3™-System nicht ordnungsgemäß ausgeführt.
  • Discs im PlayStation®2-Format können auf einigen PS3™-Systemen nicht abgespielt werden. Näheres dazu finden Sie unter [Typen abspielfähiger Discs] oder auf der SIE-Website für Ihre Region. Sie können auch in der Dokumentation zum PS3™-System nachschlagen.
