Kopieren von auszuführenden Spielen auf ein PSP™-System

Wenn ein Spiel (gekauft oder kostenlos), das Sie von (PlayStation®Store) heruntergeladen haben, mit dem PSP™-System kompatibel ist, können Sie das Spiel auf ein PSP™-System kopieren und es dort ausführen.

1.

Melden Sie sich mit dem Sony Entertainment Network-Konto, das Sie auch zum Herunterladen des Spiels verwendet haben, bei PSNSM an.

2.

Verbinden Sie das PSP™-System und das PS3™-System mit einem USB-Kabel.
Zum Kopieren von Dateien auf einen Memory Stick™-Datenträger müssen Sie den Memory Stick™-Datenträger in das PSP™-System einsetzen.

3.

Wählen Sie am PSP™-System (Einstellungen) > (USB-Verbindung).

4.

Wählen Sie am PS3™-Systems unter (Spiel) das zu kopierende Spiel aus und drücken Sie dann die -Taste.

5.

Wählen Sie [Kopieren].
Befolgen Sie zum Kopieren des Spiels die Anweisungen auf dem Bildschirm. Nach Abschluss des Kopiervorgangs können Sie das Spiel auf dem PSP™-System über (Spiel) > (Memory Stick™) oder (Spiel) > (Systemspeicher) starten.

Anmerkungen

  • Für diese Funktion muss die System-Software des PSP™-Systems Version 6.50 oder später sein.
  • Einzelheiten zum Ausführen von Spielen auf dem PSP™-System finden Sie im Benutzerhandbuch zum PSP™-System.

Auf PS3™- und PSP™-Systemen ausführbare Spiele

Wenn Sie ein Spiel spielen, das mit beiden Systemen kompatibel ist, können Sie gespeicherte Daten aus dem Spiel von einem System auf das andere kopieren und das Spiel dann mit diesem Speicherstand auf dem anderen System fortsetzen. Das Verfahren zum Kopieren von gespeicherten Daten hängt vom Spieltyp ab.

Gespeicherte Daten für Software im PlayStation®-Format

Gespeicherte Daten für Software im PlayStation®-Format werden auf internen Memory Cards gespeichert, die im Systemspeicher erstellt wurden. Zum Kopieren der gespeicherten Daten auf ein PSP™-System führen Sie Schritt 2 und 3 oben aus und wählen dann am PS3™-System (Spiel) > (Memory Card-Dienstprogramm) > (Interne Memory Card (PS)). Wählen Sie dann das Icon der gespeicherten Daten, die kopiert werden sollen, drücken Sie die -Taste und wählen Sie [Kopieren] aus dem Menü „Optionen“.

Anmerkungen

  • Sie müssen das Format der gespeicherten Daten konvertieren, damit die Daten auf einem PSP™-System verwendet werden können. Wenn während des Kopiervorgangs ein Bestätigungsbildschirm zur Datenkonvertierung angezeigt wird, wählen Sie [Ja], um fortzufahren.
  • Für jeden Softwaretitel, der auf einem Memory Stick™-Datenträger (in das PSP™-System eingesetzt) oder im Systemspeicher des PSP™go-Systems gespeichert ist, werden mehrere interne Memory Cards erstellt.
  • Wenn Sie die gespeicherten Daten auf einen Memory Stick™-Datenträger kopieren, der in den Datenträger-Steckplatz eines PS3™-Systems eingesetzt ist, oder einen USB-Adapter (separat erhältlich) verwenden, werden die gespeicherten Daten nicht erkannt.

Aktivieren eines PSP™-Systems

Spiele, die vom (PlayStation®Store) heruntergeladen (gekauft oder kostenlos) wurden, können auf einem aktivierten PSP™-System gespielt werden. Wenn beim Starten des Spiels auf dem PSP™-System die Meldung erscheint, dass die Aktivierung erforderlich ist, aktivieren Sie das Gerät wie in den folgenden Schritten erläutert.

1.

Verbinden Sie das PSP™-System und das PS3™-System mit einem USB-Kabel.

2.

Wählen Sie am PSP™-System (Einstellungen) > (USB-Verbindung).

3.

Wählen Sie am PS3™-System (PlayStation™Network) > (Konto-Verwaltung).

4.

Wählen Sie (Systemaktivierung).
Gehen Sie zum Abschließen der Aktivierung nach den Anweisungen auf dem Bildschirm vor.

Anmerkungen

  • Für die Geräteaktivierung müssen Sie am PS3™-System als der Benutzer angemeldet sein, der beim Herunterladen der Software im PlayStation®-Format angemeldet war.
  • Die Geräteaktivierung stellt sicher, dass Inhalte nur auf authentifizierten Geräten wiedergegeben werden können. Dies ist erforderlich, um die Rechte an den digitalen Inhalten zu schützen.
