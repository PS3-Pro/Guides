Verwenden von Speicherdaten für minis und PSP™Game (PSP™-Spiele)-Software

Kopieren von Speicherdaten für PSP™Game (PSP™-Spiele) auf ein PS3™-System

1.

Schließen Sie das PSP™-System mit einem USB-Kabel an das PS3™-System an.

2.

Wählen Sie am PS3™-System (Spiel) > (Speicherdaten-Dienstprogramm (minis / PSP™)).

3.

Wählen Sie die Speicherdaten, die Sie kopieren möchten, und drücken Sie die -Taste.

4.

Wählen Sie [Kopieren].

Anmerkungen

  • Speicherdaten werden für jeden Benutzer separat verwaltet. Wenn unter (Benutzer) mehrere Benutzer vorhanden sind,
    variieren die unter (Speicherdaten-Dienstprogramm (minis / PSP™)) angezeigten Elemente je nach dem angemeldeten Benutzer.
  • Wenn Sie ein Speicherdaten-Symbol auswählen und die -Taste drücken, können Sie Speicherdaten nach Aktualisierungsdatum sortieren oder im angezeigten Menü nach Titel gruppieren.
  • Spiele für das PSP™-System (im PSP™-Spielformat) können nicht auf dem PS3™-System gespielt werden.
  • Bei manchen Spielen gelten möglicherweise Einschränkungen hinsichtlich der Speicherdaten. Einzelheiten dazu finden Sie in den Handbüchern zur Software.
  • Software im PlayStation®-Format, die vom PlayStation®Store heruntergeladen und auf dem PSP™-System gespeichert wurde, wird unter (Memory Card-Dienstprogramm) angezeigt.
