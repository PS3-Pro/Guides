Herunterladen von Spielen

Sie können Spiele (gekauft oder kostenlos) von (PlayStation®Store) herunterladen. Mehrere Spieltypen stehen zur Auswahl, darunter Spiele, die Sie nur auf PS3™-Systemen ausführen können, und Spiele, die auf PS Vita-Systeme oder PSP™-Systeme kopiert und dort ausgeführt werden können. Einzelheiten zu Spieltypen und kompatiblen Systemen finden Sie in den Informationen, die im PlayStation®Store bereitgestellt werden.


Anmerkungen

  • Für nähere Einzelheiten über den PlayStation®Store siehe (PlayStation™Network) > (PlayStation®Store) > [Übersicht über PlayStation®Store].
  • Wenn Sie die Spielsoftware auf einem PSP™-System ausführen möchten, müssen Sie die Daten für die Software zunächst auf das PSP™-System kopieren. Näheres dazu finden Sie unter (Spiel) > [Spielen von vom PlayStation®Store heruntergeladenen Spielen] > [Kopieren von auszuführenden Spielen auf ein PSP™-System] in diesem Handbuch.
  • Kopieren Sie Spiele für das PS Vita-System und das PSP™-System, die heruntergeladen wurden, jedoch (nicht installiert) sind. Ein Spiel, das bereits im Systemspeicher des PS3™-Systems installiert ist, muss erneut von (Download-Liste) im (PlayStation®Store) heruntergeladen werden, um den Status auf „nicht installiert“ zu setzen.
  • Bei der Erstveröffentlichung ist Software im PlayStation®-Format nicht unbedingt mit PSP™- und PS3™-Systemen kompatibel. Wenn Software im PlayStation®-Format, die Sie für die Verwendung auf einem PSP™-System heruntergeladen haben, später auch für das PS3™-System zur Verfügung gestellt wird, können Sie sie ohne weitere Kosten über (Download-Liste) in (PlayStation®Store) erneut herunterladen.
