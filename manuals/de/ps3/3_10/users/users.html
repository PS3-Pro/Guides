Benutzer-Kategorie

Sie können Benutzer erstellen oder das PS3™-System ausschalten. Wenn Sie mehrere Benutzer erstellen, werden Daten wie Speicherdaten für Software im PlayStation®3-Format, unter (Freunde) gesendete und empfangene Nachrichten sowie Lesezeichen unter (Internet-Browser) für jeden Benutzer getrennt gespeichert. Die folgenden Icons werden unter (Benutzer) angezeigt.

System ausschalten Ausschalten des PS3™-Systems.
Neuen Benutzer erstellen Erstellen eines neuen Benutzers.
(Benutzername) Anmelden am PS3™-System.

Anmerkung

Die folgenden auf der Festplatte gespeicherten Datentypen werden unabhängig davon, welcher Benutzer sich anmeldet, angezeigt. Wenn Daten gelöscht werden, können auch andere Benutzer sie nicht mehr verwenden. Achten Sie darauf, nicht versehentlich wichtige Daten zu löschen.

  • Speicherdaten für Software im PlayStation®2-/PlayStation®-Format
  • Unter (Spiel) angezeigte Spiele
  • Unter (Video) angezeigte Videodateien
  • Unter   (Musik) angezeigte Musikdateien
  • Unter (Foto) angezeigte Bilddateien

Hinweise

  • Einige Softwaretitel im PlayStation®2- oder PlayStation®-Format werden auf dem PS3™-System anders als auf einem PlayStation®2- oder PlayStation®-System ausgeführt oder sie werden auf dem PS3™-System nicht ordnungsgemäß ausgeführt.
  • Außerdem kann Software im PlayStation®2-Format auf einigen PS3™-Systemen nicht ausgeführt werden. Näheres dazu finden Sie unter [Typen abspielfähiger Discs] oder auf der SCE-Website für Ihre Region. Sie können auch in der Dokumentation zum PS3™-System nachschlagen.
