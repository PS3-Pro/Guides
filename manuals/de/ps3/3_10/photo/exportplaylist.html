Kopieren von Wiedergabelisten auf ein PSP™-System

Sie können Fotos als Wiedergabelisten kopieren und dann auf dem PSP™-System anzeigen lassen.

1.

Schließen Sie das PSP™-System mit einem USB-Kabel an Ihr PS3™-System an.
Zum Kopieren von Dateien auf einen Memory Stick™-Datenträger müssen Sie den Memory Stick™-Datenträger in das PSP™-System einsetzen.

2.

Wählen Sie am PSP™-System (Einstellungen) > (USB-Verbindung).

3.

Wählen Sie am PS3™-System (Foto) > (Wiedergabelisten).

4.

Wählen Sie das Symbol für die zu verwendende Wiedergabeliste aus und drücken Sie die -Taste.

5.

Wählen Sie [Kopieren].
Wählen Sie (PSP™ (PlayStation®Portable)) oder (PSP™ (PlayStation®Portable)) als Ziel.

Anmerkungen

  • Für diese Funktion muss die System-Software des PSP™-Systems Version 3.80 oder höher sein.
  • Sie können keine Wiedergabelisten vom PSP™-System auf das PS3™-System kopieren.
