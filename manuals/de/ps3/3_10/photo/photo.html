Foto-Kategorie

Die folgenden Icons werden unter (Foto) angezeigt. Welche Icons angezeigt werden, hängt von den Nutzungsbedingungen ab.

Medienserver suchen Starten einer Suche nach DLNA-Medienservern im gleichen Netzwerk.
Verwenden von Photo Gallery Diese Anwendung bietet verschiedene Komfortfunktionen zum Betrachten von Fotos, die auf einem PS3™-System gespeichert sind.
Screenshot speichern Speichern von Screenshots aus Software im PlayStation®3-Format beim Spielen. Diese Option ist nur verfügbar, wenn die Software, mit der gespielt wird, diese Funktion unterstützt.
Medienserver Herstellen einer Verbindung mit DLNA-Medienservern und Anzeigen der gespeicherten Bilder. Die eingeblendeten Icons hängen vom Typ des Servers ab.
Daten-Disc Anzeigen von Bilddateien auf kompatiblen, bespielbaren Disc-Datenträgern, wie z. B. auf einer CD-R oder DVD-R.
Memory Stick™ Anzeigen von Bilddateien auf einem Memory Stick™-Datenträger.*
SD Memory Card Anzeigen von Bilddateien auf einer SD Memory Card.*
CompactFlash® Anzeigen von Bilddateien auf einem CompactFlash®-Datenträger.*
PSP™(PlayStation®Portable) Anzeigen von Bilddateien auf einem Memory Stick™-Datenträger eines PSP™-Systems.
PSP™(PlayStation®Portable) Anzeigen von Bilddateien im Systemspeicher des PSP™go-Systems.
Digitalkamera Anzeigen von Bilddateien auf einer Digitalkamera, die mit dem PS3™-System kompatibel ist.
WALKMAN®/ATRAC Audio Device (WALKMAN®) Anzeigen von Bilddateien, die auf einem WALKMAN®/ATRAC Audio Device (WALKMAN®) gespeichert sind.
ATRAC Audio Device Anzeigen von Bilddateien, die auf einem ATRAC Audio Device gespeichert sind.
USB-Gerät Anzeigen von Bilddateien auf einem USB-Massenspeichergerät.
Wiedergabelisten Sie können Wiedergabelisten erstellen oder vorhandene Wiedergabelisten bearbeiten oder wiedergeben.
Digitalkamera-Bilder Anzeigen von Bilddateien im Ordner DCIM einer Digitalkamera.
(Ordner) Dieses Icon wird angezeigt bei Ordnern, die mit einem PC erstellt wurden.
(auf der Festplatte gespeicherte Dateien) Anzeigen von Bilddateien auf der Festplatte des PS3™-Systems. Dabei werden Miniaturbilder angezeigt.
*

Bei einigen Modellen des PS3™-Systems ist ein geeigneter USB-Adapter (nicht mitgeliefert) erforderlich, um Datenträger nutzen zu können. Wenn ein USB-Adapter verwendet wird, werden Datenträger als (USB-Gerät) angezeigt.

Anmerkungen

  • Einzelheiten zu DLNA siehe (Einstellungen) > (Netzwerk-Einstellungen) > [Verbindung mit dem Medienserver] in diesem Handbuch.
  • In seltenen Fällen kann es vorkommen, dass Disks und andere Datenträger auf dem PS3™-System nicht einwandfrei wiedergegeben werden. Dies ist hauptsächlich auf Abweichungen im Herstellungsverfahren oder bei der Software-Codierung zurückzuführen.
