Hochladen/Herunterladen

Sie können Inhalte auf der Festplatte oder auf einem Datenträger in das Internet hochladen oder Inhalte aus dem Internet auf die Festplatte oder einen Datenträger herunterladen.

Hochladen

Diese Funktion kann auf Webseiten ausgeführt werden, die über eine Hochladefunktion verfügen. Das Vorgehen zum Hochladen hängt von der Webseite ab.

Anmerkungen

  • Nur unter (Foto) gespeicherte Inhalte können von der Festplatte hochgeladen werden.
  • Bei einigen Modellen ist ein geeigneter USB-Adapter (nicht mitgeliefert) erforderlich, um Datenträger nutzen zu können.

Herunterladen

1.

Wählen Sie die Inhalte aus, die Sie von der Webseite herunterladen wollen.

2.

Wählen Sie einen Speicherort für die Inhalte und drücken Sie die START-Taste.

Anmerkungen

  • Bei manchen Inhalten ist der Speicherort bereits festgelegt.
  • Inhalte, die auf dem PS3™-System nicht wiedergegeben werden können, lassen sich nur auf einem Datenträger speichern.
  • Bei einigen Modellen ist ein geeigneter USB-Adapter (nicht mitgeliefert) erforderlich, um Datenträger nutzen zu können.
  • Beim Herunterladen von umfangreichen oder mehreren Datenelementen können Sie andere Funktionen ausführen. Einzelheiten dazu finden Sie unter (Netzwerk) > (Download-Management) > [Herunterladen im Hintergrund] in diesem Handbuch.
