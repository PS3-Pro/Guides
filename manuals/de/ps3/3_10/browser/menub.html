Menü im Normalmodus

Ansicht

Sie können die Ansicht der Seite ändern.

Zoomen/Zoom zurücksetzen Automatisches optimales Vergrößern des Bildschirmbereichs, in dem sich der Zeiger befindet, bzw. Aufheben der Vergrößerung.

Der optimale Vergrößerungsfaktor wird automatisch nach dem Inhaltstyp in dem Bereich, in dem sich der Zeiger befindet, berechnet.
Maximale Größe/Standardgröße Anpassen des Fensters an die Bildschirmgröße. / Anzeigen des Fensters in seiner ursprünglichen Größe.
Zeichengröße Ändern der Textgröße.

Text kann in fünf unterschiedlichen Größen angezeigt werden.
Zeichenverschlüsselung Zuweisen der Zeichenverschlüsselung.

In den meisten Fällen wird die Zeichenverschlüsselung automatisch festgelegt und braucht nicht zugewiesen zu werden.

Anmerkung

Auf manchen Seiten lässt sich die Zeichengröße nicht ändern und die Zeichenverschlüsselung nicht zuweisen.

Werkzeuge

Damit können Sie die Bedingungen zum Öffnen von Seiten festlegen und auf der Festplatte gespeicherte Daten löschen.

Cookies Erlauben: Das Speichern von Cookies ist immer erlaubt.

Blockieren: Das Speichern von Cookies ist nie möglich.
JavaScript Ein: JavaScript wird verwendet.

Aus: JavaScript wird nicht verwendet.
Darstellungsbereich Full Pixel: Das Fenster wird in voller Größe auf dem ganzen Fernsehschirm angezeigt.*1

Standard: Die Fenstergröße wird um 5 % verringert.

-1: Die Fenstergröße wird um 10 % verringert.

-2: Die Fenstergröße wird um 15 % verringert.
Auflösung Ändern der Anzeigeauflösung für die Webseite.

Webseiten können besser lesbar angezeigt werden, wenn Sie die Auflösung an die Videoausgabeauflösung des PS3™-Systems anpassen.
Flimmerreduktion Ein: Bei Bildschirmelementen wie Text, Bildern oder Linien auftretendes Flimmern wird reduziert.

Aus: Die Funktion zur Flimmerreduktion ist deaktiviert.

Mit dieser Einstellung lässt sich das Flimmern auf dem Bildschirm bei einer Interlace-Anzeige reduzieren. Setzen Sie die Option auf [Ein], wenn eine Auflösung wie z. B. 1080i für die Videoausgabeeinstellung des PS3™-Systems ausgewählt ist. Mit [Aus] wird die Bildqualität bei einer progressiven Anzeige wie 1080p oder 720p besser.
Schließen des Browsers bestätigen Ein: Beim Schließen von (Internet-Browser) wird eine Bestätigungsmeldung angezeigt.

Aus: Beim Schließen wird keine Bestätigungsmeldung angezeigt.
Homepage Festlegen der Seite, die beim Starten von (Internet-Browser) oder Auswählen von (Home) im Menü angezeigt wird.

Wenn Sie [Fenster beim Starten des Browsers wiederherstellen] aktivieren, wird die Seite, die beim Schließen des Browsers geöffnet war, beim nächsten Starten des Browsers wieder angezeigt.
Cookies löschen Löschen von Cookies.
Suchverlauf löschen Löschen von Informationen zum Suchverlauf.
Cache-Speicher löschen Löschen des Cache-Speichers.
Authentifikationsinformationen löschen Löschen von Authentifikationsinformationen.
Browser-Sicherheit beenden Web-Filter-Services werden nicht weiter verwendet. *2

Zum Ändern dieser Einstellung müssen Sie ein Passwort eingeben. Einzelheiten zu Passwörtern finden Sie unter (Einstellungen) > (Sicherheits-Einstellungen) > [Passwort ändern] in diesem Handbuch.
*1

Das Bild wird oben und unten möglicherweise abgeschnitten, wenn Sie ein Standardfernsehgerät verwenden und [Full Pixel] eingestellt ist.
*2

Welche Typen von Web-Filter-Services zur Verfügung stehen, hängt vom Land bzw. der Region ab.

Fensterliste

Wechseln in den Fenstermodus.

Suchen

Ausführen einer Internetsuche mit einem Schlüsselwort oder einer Phrase.

Datei

Adresseingabe Eingeben einer Adresse.
In neuem Fenster öffnen Öffnen des Links, auf dem der Zeiger steht, in einem neuen Fenster.
Fenster schließen Schließen geöffneter Fenster.
Bild speichern Speichern der Datei mit dem Bild auf der Festplatte oder einem Datenträger.*
Zielobjekt speichern Verknüpfte Inhalte, die Sie mit dem Zeiger auswählen, können Sie auf der Festplatte des Systems oder einem Datenträger speichern. *
Adresse dieser Seite kopieren Kopieren der Adresse der angezeigten Seite.
Adresse dieses Links kopieren Kopieren der Adresse des Links, auf dem der Zeiger positioniert ist.
Zu Lesezeichen hinzufügen Hinzufügen der Verknüpfung, auf der der Zeiger positioniert ist, zu den Lesezeichen.
Diesen Bildschirm drucken Sie können den angezeigten Bildschirm drucken.

Wenn Sie diese Funktion nutzen wollen, müssen Sie vorab (Einstellungen) > (Drucker-Einstellungen) > [Druckerauswahl] auswählen und einen Drucker konfigurieren.
Screenshot speichern Sie können den angezeigten Bildschirm als Bild speichern.

Der Screenshot wird unter (Foto) gespeichert.
Seiteninformationen Anzeigen von Name oder Adresse der geöffneten Seite.
Zertifikat anzeigen Anzeigen von Server-Zertifikaten, die von Seiten gesendet werden, die SSL unterstützen.
*

Bei einigen Modellen des PS3™-Systems ist ein geeigneter USB-Adapter (nicht mitgeliefert) erforderlich, um Datenträger nutzen zu können.

Zurück

Damit lassen Sie die zuvor geöffnete Seite anzeigen.

Vor

Damit lassen Sie die Seite anzeigen, die vor dem Ausführen von (Zurück) geöffnet war.

Aktualisieren/Abbrechen

Damit aktualisieren Sie die geöffnete Seite mit den neuesten Inhalten. / Das Laden der Seite wird gestoppt.

Home

Damit rufen Sie die Seite auf, die als Homepage definiert ist.

Lesezeichen

Sie können bevorzugte Seiten zu den Lesezeichen hinzufügen. Die Lesezeichen können Sie über [Meine Lesezeichen] öffnen.

Meine Lesezeichen Hinzufügen der Webseite zu den Lesezeichen und Anzeigen einer Liste der gespeicherten Lesezeichen.
PlayStation®3 Aufrufen der Website von Sony Computer Entertainment.

Anmerkung

Die Lesezeichenliste ist in chronologischer Reihenfolge angeordnet, wobei die zuletzt hinzugefügten Lesezeichen zuerst angezeigt werden.

Browser-Sicherheit

Mit einem Web-Filter können Sie Typ und Unbedenklichkeit von Websites prüfen und automatisch die Anzeige ungeeigneter Websites beim Surfen im Internet sperren.

i-Filter for PS3™*1 Anzeigen der Webseite des Serviceproviders von [i-Filter for PS3™].*2
Trend Micro™ Anzeigen der Webseite des Serviceproviders von [Trend Micro Web Security for PS3™].*2
*1

Diese Funktion steht nur bei in Japan verkauften PS3™-Systemen zur Verfügung.
*2

Für die Nutzung der Webfilterdienste können Gebühren anfallen.

Verlauf

Die Seiten, die geöffnet waren, werden automatisch als Verlauf gespeichert. Die Namen der zuvor geöffneten Seiten werden in einer Liste angezeigt und Sie können die Seiten durch Auswahl in der Liste einfach wieder anzeigen, ohne die Adresse eingeben zu müssen.

Anmerkung

Die Seiten werden in chronologischer Reihenfolge angeordnet, wobei die zuletzt geöffneten Seiten zuerst angezeigt werden.
