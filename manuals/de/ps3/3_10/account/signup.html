Anmelden beim PlayStation®Network

Sie müssen eventuell die System-Software aktualisieren, bevor Sie diese Funktion verwenden können.


Wenn Sie ein PlayStation®Network-Konto erstellt haben, können Sie im (PlayStation®Store) online einkaufen, unter (Freunde) Chats beitreten und verschiedene weitere Online-Services von PlayStation®Network nutzen. Wählen Sie (Für das PlayStation®Network einschreiben) unter (PlayStation®Network) und gehen Sie zum Erstellen eines Kontos nach den Anweisungen auf dem Bildschirm vor.

Zum Erstellen eines Kontos erforderliche Hauptoptionen
Persönliche Daten Geben Sie Informationen zum registrierten Benutzer ein, einschließlich des Geburtstags (Jahr, Monat, Tag), des Namens und der Adresse.
Hauptkonto/Unterkonto Es gibt zwei Typen von PlayStation®Network-Konten: Hauptkonten und Unterkonten.

Hauptkonto:
Das Standardkonto zum Verwenden von PlayStation®Network. Ein Hauptkonto kann von einem registrierten Benutzer ab einem bestimmten Alter erstellt werden. Hauptkontoinhaber können für zugehörige Unterkonten bestimmte Nutzungsbedingungen festlegen.

Unterkonto:
Benutzer, die die in der jeweiligen Region gültigen Voraussetzungen für ein Hauptkonto nicht erfüllen, können lediglich ein Unterkonto verwenden. Inhaber von Unterkonten können keine Brieftaschen erstellen, aber mit der Brieftasche für das dazugehörige Hauptkonto Produkte und Services bezahlen. Ein Unterkonto kann nur erstellt werden, wenn ein entsprechendes Hauptkonto vorhanden ist.


Die Voraussetzungen für Hauptkonten und Unterkonten hängen vom Land bzw. der Region ab, in dem bzw. der der Benutzer wohnt. Einzelheiten dazu finden Sie auf der SCE-Website für Ihre Region.
Anmelde-ID (E-Mail-Adresse) Registrieren einer ID für das Anmelden am PlayStation®Network. Verwenden Sie eine gültige E-Mail-Adresse, die zum Empfangen von Bestätigungsmeldungen beispielsweise bei einem Kauf unter (PlayStation®Store) verwendet werden kann.
Passwort

Definieren Sie anhand folgender Kriterien ein Passwort:

  • Verwenden Sie mindestens sechs Buchstaben oder Ziffern.
  • Verwenden Sie eine Kombination aus Buchstaben und Ziffern.
  • Verwenden Sie dasselbe Zeichen maximal zweimal hintereinander.
  • Verwenden Sie einen anderen Code als Ihre Anmelde-ID und Online-ID.
  • Bei Buchstaben wird die Groß-/Kleinschreibung berücksichtigt.
Sicherheitsfrage Wählen Sie eine Sicherheitsfrage, mit der Sie das Passwort zurücksetzen können, falls Sie es einmal vergessen.
Online-ID

Registrieren Sie einen Namen, der im PlayStation®Network öffentlich angezeigt wird. Die Online-ID kann nicht mehr geändert werden, nachdem sie einmal erstellt wurde. Beachten Sie beim Erstellen der Online-ID Folgendes:

  • Die Online-ID muss aus zwischen 3 und 16 Zeichen bestehen und kann Buchstaben, Ziffern, Bindestriche (-) und Unterstriche (_) enthalten.
  • Das erste Zeichen muss ein Buchstabe sein.
  • Die Online-ID darf nicht mit Ihrem Passwort identisch sein.
  • Bei Buchstaben wird die Groß-/Kleinschreibung nicht berücksichtigt.

Anmerkungen

  • Bei Minderjährigen wird je nach dem Alter zum Erstellen des Unterkontos ein PC benötigt. Beim Erstellen des Kontos wird eine E-Mail an die mit der Anmelde-ID des Hauptkontoinhabers verknüpfte E-Mail-Adresse geschickt. Gehen Sie zum Abschließen der Registrierung auf einem PC wie in den Anweisungen in der E-Mail erläutert vor.
  • Für die Anmeldung am PlayStation®Network mit einem neu erstellten Unterkonto muss das Konto einem Benutzer zugeordnet werden, der sich am PS3™-System einloggen will. Näheres dazu finden Sie unter [Verwendung eines bestehenden Kontos] unter (PlayStation®Network) in diesem Handbuch.
  • Ihre Anmelde-ID (E-Mail-Adresse) und das Passwort werden nicht öffentlich angezeigt. Achten Sie darauf, diese Informationen nicht an Dritte weiterzugeben.
  • Sie können auf dem PS3™-System nur ein Konto pro Benutzer erstellen. Wenn Sie weitere Konten erstellen wollen, wechseln Sie zu   (Benutzer) und erstellen zusätzliche Benutzer.
  • Einzelheiten zur Handhabung persönlicher Daten von Benutzern finden Sie auf der SCE-Website für Ihre Region.
  • Für den Zugriff auf das PlayStation®Network ist ein Breitband-Internet-Service erforderlich. Beachten Sie, dass Wählverbindungen nicht unterstützt werden.
  • PlayStation®Network steht nur in bestimmten Regionen und Sprachen zur Verfügung. Weitere Informationen dazu erhalten Sie beim technischen Support für Ihre Region.
  • (Für das PlayStation®Network einschreiben) wird nur angezeigt, wenn kein PlayStation®Network-Konto erstellt wurde.
