Ausführen heruntergeladener Spiele

Sie können Spiele spielen, die Sie von (PlayStation®Store) heruntergeladen haben (gekauft oder kostenlos). Wie Sie ein Spiel ausführen können, hängt vom Spieltyp ab. Informationen zum Spieltyp werden neben dem Spiel-Icon angezeigt.

Anmerkung

Um Spiele nach Typ zu sortieren, wählen Sie ein Spiel-Icon, drücken die -Taste und wählen dann [Sortieren nach] > [Format] aus dem Menü „Optionen“.

Spielen mit Software im PlayStation®3-Format

Generell können Sie mit Software im PlayStation®3-Format, die Sie von (PlayStation®Store) heruntergeladen haben, genauso spielen wie mit Software im PlayStation®3-Format, die auf Disc-Datenträgern zur Verfügung gestellt wird. Einzelheiten dazu finden Sie unter (Spiel) > [Spielen mit Software im PlayStation®3-Format] in diesem Handbuch.

Spielen mit Software im PlayStation®-Format

Generell können Sie mit Software im PlayStation®-Format, die Sie von (PlayStation®Store) heruntergeladen haben, genauso spielen wie mit Software im PlayStation®-Format, die auf Disc-Datenträgern zur Verfügung gestellt wird. Einzelheiten dazu finden Sie unter (Spiel)> [Spielen mit Software im PlayStation®2- und PlayStation®-Format] in diesem Handbuch.


Software-Handbücher

In manchen Fällen können Sie das Software-Handbuch zu heruntergeladener Software im PlayStation®-Format anzeigen lassen. Drücken Sie zum Anzeigen des Handbuchs während des Spielens die PS-Taste am Wireless-Controller und wählen Sie dann [Software-Handbuch] auf dem angezeigten Bildschirm.


Spiele, bei denen Discs gewechselt werden müssen

Bei mancher heruntergeladener Software im PlayStation®-Format müssen Sie Discs wechseln. Wenn Sie solche Spiele auf dem PS3™-System spielen, erfolgt das Wechseln der Discs virtuell. Wenn eine Meldung angezeigt wird, in der Sie dazu aufgefordert werden, die Disc zu wechseln, drücken Sie die PS-Taste am Wireless-Controller und wählen dann [Disc-Wechsel] auf dem angezeigten Bildschirm. Gehen Sie zum Abschließen des Vorgangs nach den Anweisungen auf dem Bildschirm vor.

Ausführen von Spielen im PC Engine-Format

Einzelheiten zum Ausführen von Spielen im PC Engine-Format finden Sie in der Anleitung zum Spiel. Die Schritte zum Aufrufen der Spieleanleitung können sich von Spiel zu Spiel unterscheiden. Das PC Engine-Format steht in manchen Ländern oder Regionen möglicherweise nicht zur Verfügung.
