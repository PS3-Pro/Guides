Kopieren von Speicherdaten auf ein Speichermedium (Erstellen einer Sicherungskopie)

Auf die Festplatte gespeicherte Daten können auf Datenträger exportiert werden und Speicherdaten, die exportiert wurden, können auf die Festplatte importiert werden. Wählen Sie die zu exportierenden oder importierenden Speicherdaten aus, drücken Sie die -Taste und wählen Sie dann [Kopieren] aus dem Menü „Optionen“. Gehen Sie zum Abschließen des Vorgangs nach den Anweisungen auf dem Bildschirm vor.Es empfiehlt sich, von wichtigen Daten eine Sicherungskopie anzulegen.


Anmerkungen

  • Nicht alle Speicherdaten können kopiert werden.
  • Speicherdaten können nicht kopiert werden, solange Inhalte mit einer anderen Funktion wiedergegeben werden, z. B. während der Wiedergabe von Musikdateien.
  • Gespeicherte Daten der Software im PlayStation®2- und PlayStation®-Format können auch auf eine Memory Card (8MB) (für PlayStation®2) oder eine Memory Card gespeichert werden. Einzelheiten dazu finden Sie unter [Verwenden von Speicherdaten auf Memory Cards] unter (Spiel) > [Spielen mit Software im PlayStation®2- und PlayStation®-Format] in diesem Handbuch.
  • Bei einigen Modellen ist ein geeigneter USB-Adapter (nicht mitgeliefert) erforderlich, um Datenträger nutzen zu können.

Hinweise

  • Einige Softwaretitel im PlayStation®2- oder PlayStation®-Format werden auf dem PS3™-System anders als auf einem PlayStation®2- oder PlayStation®-System ausgeführt oder sie werden auf dem PS3™-System nicht ordnungsgemäß ausgeführt.
  • Außerdem kann Software im PlayStation®2-Format auf einigen PS3™-Systemen nicht ausgeführt werden. Näheres dazu finden Sie unter [Typen abspielfähiger Discs] oder auf der SCE-Website für Ihre Region. Sie können auch in der Dokumentation zum PS3™-System nachschlagen.
