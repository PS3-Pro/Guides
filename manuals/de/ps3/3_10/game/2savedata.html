Verwenden von Speicherdaten

Speicherdaten für Software im PlayStation®2- oder PlayStation®-Format werden auf internen Memory Cards gespeichert, die auf der Festplatte erstellt wurden. Interne Memory Cards können Sie verwenden, indem Sie sie nach dem Erstellen Steckplätzen zuweisen. Die Daten werden unter (Memory Card-Dienstprogr. (PS/PS2)) angezeigt.

Hinweise

  • Einige Softwaretitel im PlayStation®2- oder PlayStation®-Format werden auf dem PS3™-System anders als auf einem PlayStation®2- oder PlayStation®-System ausgeführt oder sie werden auf dem PS3™-System nicht ordnungsgemäß ausgeführt.
  • Außerdem kann Software im PlayStation®2-Format auf einigen PS3™-Systemen nicht ausgeführt werden. Näheres dazu finden Sie unter [Typen abspielfähiger Discs] oder auf der SCE-Website für Ihre Region. Sie können auch in der Dokumentation zum PS3™-System nachschlagen.

Erstellen einer internen Memory Card

1.

Wählen Sie (Memory Card-Dienstprogr. (PS/PS2)) unter (Spiel) im Home-Menü.

2.

Wählen Sie (Neue interne Memory Card erstellen).
Gehen Sie zum Abschließen des Vorgangs nach den Anweisungen auf dem Bildschirm vor.

Anmerkung

Namen von internen Memory Cards oder Icons können unter [Informationen] im Menü „Optionen“ geändert werden.

Zuordnen eines Steckplatzes

1.

Wählen Sie (Spiel) > (Memory Card-Dienstprogr. (PS/PS2)).

2.

Wählen Sie die zu verwendende interne Memory Card und drücken Sie die -Taste.

3.

Wählen Sie [Steckplätze zuordnen].

Anmerkungen

  • Je nach Software sind die Steckplätze möglicherweise vorab zugeordnet. Erläuterungen dazu finden Sie in den mit der Software gelieferten Anweisungen.
  • Sie können Steckplätze während des Spielens zuordnen. Drücken Sie die PS-Taste am Wireless-Controller und wählen Sie dann [Steckplätze zuordnen] auf dem angezeigten Bildschirm aus.
