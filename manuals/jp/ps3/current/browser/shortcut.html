ショートカットキー／マウス／キーボードを使って操作する

ショートカットキーを使って操作する

メニューを使わずに、ワイヤレスコントローラのボタンから操作できます。ブラウズモードとウィンドウモードでは、操作できる内容が異なります。

ブラウズモード
ボタン リンク先を開く
ボタン（長押し） リンク先を別のウィンドウで開く
ボタン+左スティック テキストを選択する
ボタン メニューを表示する
ボタン （インターネットブラウザー）を終了する
ボタン（長押し） ウィンドウを閉じる*1
STARTボタン アドレスを入力する
SELECTボタン ［マイブックマーク］を開く
L1ボタン／R1ボタン 前のページに戻る／次のページに進む
L2ボタン／R2ボタン 別のウィンドウに移動する*2
方向キー 方向キーを押した方向にあるリンクにポインターを移動する
ボタン+方向キー 方向キーを押した方向にページスクロールする
左スティック 任意の方向にポインターを移動する
左スティック（押す）（L3ボタン） ウィンドウモードに切りかえる
右スティック 任意の方向にスクロールする
右スティック（押す）（R3ボタン） ズーム表示をする／ズーム表示を解除する
PSボタン XMB™を表示する
*1

ズーム中は操作できません。
*2

ズーム中は拡大／縮小をします。
ウィンドウモード
ボタン 選んだウィンドウをブラウズモードで表示する
ボタン メニューを表示する
左スティック（押す）（L3ボタン） ブラウズモードに切りかえる
方向キー ウィンドウを移動する
PSボタン XMB™を表示する

マウスを使って操作する

市販のマウスを使って操作できます。

右クリックしたまま左方向へドラッグ 前のページに戻る
右クリックしたまま右方向へドラッグ 次のページに進む

キーボードを使って操作する

市販のキーボードを使って操作できます。

Ctrl + L／F4 アドレスを入力する
Ctrl + R／F5 ページを最新の内容に更新する
Ctrl + B／Ctrl + I ［マイブックマーク］を開く
PageUp／Shift + Space 上へスクロールする
PageDown／Space 下へスクロールする
Home ページの一番上へ移動する
End ページの一番下へ移動する
Tab カーソルを移動する
Alt + ←／BackSpace 前のページに戻る
Alt + →／Shift + BackSpace 次のページに進む
Ctrl + ←／Ctrl + Shift + Tab 左のウィンドウに移動する
Ctrl + →／Ctrl + Tab 右のウィンドウに移動する
