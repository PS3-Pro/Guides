Obtention ou modification des informations sur le CD audio

Obtention d'informations de CD audio

Lorsque vous insérez un CD audio, le système PS3™ se connecte automatiquement à Internet et obtient des informations sur le CD. Pour obtenir des informations sur le CD, vous devez tout d'abord accepter l'accord d'utilisation affiché à l'écran.

Conseils

  • Vous pouvez également obtenir des informations sur le CD dans le menu d'options. Sélectionnez l'icône du CD, puis appuyez sur la touche et sélectionnez [Obtenir informations sur le CD]. Suivez les instructions affichées pour terminer l'opération.
  • Si vous n'avez pas obtenu d'informations sur le CD, les noms détaillés de l'album et de la piste ne sont pas affichés lorsque vous insérez un CD dans le système.

Modification des informations de CD audio

Vous pouvez modifier les informations obtenues sur le CD. Lorsque l'icône du CD ou de la piste audio est sélectionnée, appuyez sur la touche , puis sélectionnez [Informations] dans le menu d'options. Sélectionnez l'élément que vous souhaitez modifier.

Conseils

  • Vous pouvez également envoyer les informations modifiées sur Internet à la société All Media Guide si les informations sur le CD obtenues automatiquement par le système PS3™ sont incorrectes. Sélectionnez l'icône du CD audio, appuyez sur la touche , puis sélectionnez [Envoyer les informations sur le CD] dans le menu d'options.
  • All Media Guide est une société fournissant une base de données d'informations sur les CD.
  • Vous ne pouvez pas envoyer d'informations à All Media Guide si les champs [Album], [Artiste] et [Genre] ne contiennent aucune information.
  • Vous ne pouvez pas modifier ou envoyer les informations d'un Super Audio CD.

Avis

Les Super Audio CD ne peuvent pas être lus sur certains systèmes PS3™. Pour plus de détails, consultez la section [Types de disques lisibles].
