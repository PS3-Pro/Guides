Paramètres sécurité

Pour régler les paramètres de sécurité du système.

Conseil

Ces paramètres contrôlent le contenu local (contenu numérique enregistré sur le disque dur, sur des supports de stockage et sur des disques). Remarquez que ces paramètres ne limitent pas l'accès au contenu en ligne.


Changer le mot de passe

Changer le mot de passe requis pour régler les paramètres système. Un mot de passe est requis dans les cas suivants :

  • Lors de la lecture d'un contenu soumis à des restrictions du contrôle parental.
  • Lors de la modification du niveau du contrôle parental du système ou du paramètre Contrôle de démarrage du navigateur Internet.
  • Lors du démarrage du navigateur avec le paramètre Contrôle de démarrage du navigateur Internet défini sur [Oui].
  • Lors de la modification du mot de passe actuel.

Prenez note de votre nouveau mot de passe. Dans les paramètres par défaut, le mot de passe est défini sur [0000].

Conseil

Si vous sélectionnez (Paramètres) > (Paramètres système) > [Rétablir les paramètres par défaut], vous pouvez rétablir [0000] comme mot de passe. Remarquez que les valeurs par défaut de tous les autres paramètres sont également restaurées.

Contrôle parental BD

Pour régler le niveau de lecture des disques Blu-ray (BD) soumis à des restrictions du contrôle parental. Un mot de passe est requis pour modifier ce paramètre.

Ne pas restreindre (Non) Pour lire tout BD, quel que soit le niveau de contrôle parental.
Restreindre (Oui) Pour ne lire que les BD possédant le niveau de contrôle parental spécifié.

Une fois que [Restreindre (Oui)] est activé, vous pouvez sélectionner une limite d'âge dans l'écran suivant. Veuillez noter que plus la valeur est basse, plus la restriction est importante.

Code région pour le contrôle parental BD / DVD

Pour définir une région en tant que base pour des niveaux de contrôle parental standard des BD et des DVD. Un mot de passe est requis pour modifier ce paramètre.

États-Unis Pour définir les niveaux de contrôle parental standard pour les États-Unis.
Autres Pour définir les niveaux de contrôle parental standard pour d'autres régions.

Si vous sélectionnez [Autres], vous pouvez choisir une région dans l'écran suivant.

Contrôle parental DVD

Pour régler le niveau de lecture pour des DVD soumis au contrôle parental. Un mot de passe est requis pour modifier ce paramètre.

Non Pour lire tout DVD, quel que soit le niveau de contrôle parental.
Niveau 8-1 Pour ne lire que les DVD possédant le niveau de contrôle parental spécifié.

Veuillez noter que plus la valeur est basse, plus la restriction est importante.

Contrôle parental

Pour régler le niveau de lecture des jeux soumis à des restrictions du contrôle parental. Un mot de passe est requis pour modifier ce paramètre.

Non Pour lire tout contenu, quel que soit le niveau de contrôle parental.
Niveau 11-1 Pour ne lire que le contenu possédant une valeur inférieure ou égale au niveau de contrôle parental spécifié.

Veuillez noter que plus la valeur est basse, plus la restriction est importante. Si vous sélectionnez [Définit des restrictions sur le démarrage d'un jeu en l'absence de contrôle parental], vous pouvez limiter l'utilisation des jeux non classés pour votre région.

Conseils

  • Les paramètres de contrôle parental des jeux varient selon la région dans laquelle vous achetez les jeux. Pour plus de détails, visitez le site Web SCE de votre région. Selon la région, les manuels de certains logiciels peuvent contenir des informations relatives à ces paramètres.
  • Les niveaux de contrôle parental varient selon le jeu.

Contrôle de démarrage du navigateur Internet

Pour limiter la capacité à démarrer le navigateur Internet. Un mot de passe est requis pour modifier ce paramètre.

Non Pour choisir de ne pas utiliser le contrôle de démarrage.
Oui Pour choisir d'utiliser le contrôle de démarrage. Un mot de passe est requis pour démarrer le navigateur.
