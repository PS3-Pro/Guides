Utilitaire de sauvegarde

Sauvegardez sur un support de stockage ou un périphérique de stockage de masse USB les données enregistrées sur le disque dur, ou restaurez les données qui ont été sauvegardées.

Sauvegarder Pour sauvegarder sur un support de stockage ou un périphérique de stockage de masse USB des données se trouvant sur le disque dur.
Restaurer Pour restaurer sur le disque dur des données qui ont été sauvegardées sur un support de stockage ou un périphérique USB.
Effacer les données de sauvegarde Supprimer les données qui ont été sauvegardées sur un support de stockage ou sur un périphérique de stockage de masse USB.

Avis

Vous ne pouvez pas sauvegarder les informations de trophées à l'aide de l'utilitaire de sauvegarde. Si vous souhaitez enregistrer les informations de trophées, il est recommandé de créer un compte PlayStation®Network et de les enregistrer sur le serveur PlayStation®Network. Pour sauvegarder vos informations de trophées sur le serveur PlayStation®Network, sélectionnez (Jeu) > (Collection de trophées), appuyez sur la touche , puis sélectionnez [Synchronisation avec le serveur] dans le menu d'options.


Conseils

  • Les données peuvent être sauvegardées sur Memory Stick™, SD Memory Card, CompactFlash® et des périphériques de stockage de masse USB. Un adaptateur USB approprié (non fourni) est nécessaire pour utiliser le support de stockage avec certains modèles. Des supports disques, comme des CD-R, ne peuvent pas être utilisés.
  • Il est également possible d'utiliser un disque dur USB pour sauvegarder les données. S'il est connecté, il apparaîtra sous l'icône . Cependant, remarquez que pour être reconnu par le système PS3™, le disque doit être formaté avec le système de fichiers FAT32.
  • Les données sauvegardées sont enregistrées dans le dossier [PS3] - [EXPORT] - [BACKUP]. Les dossiers sont créés automatiquement.
  • Si vous modifiez le nom du dossier ou fichier des données sauvegardées, la restauration des données risque d’être impossible.
  • Si vous effectuez l'une des opérations suivantes après la sauvegarde, il se peut que les fichiers vidéo protégés par les droits d'auteur dans les données de sauvegarde ne soient pas correctement restaurés.
  • - Formatage du disque dur
  • - Restauration du système PS3™
  • - Déplacement de vidéo protégée par droits d'auteur
  • - Téléchargement de vidéo protégée par droits d'auteur
  • - Première lecture de vidéo protégée par droits d'auteur et ayant une date d'expiration
  • Si vous sauvegardez des données sur un système PS3™ et si vous les transférez ensuite vers un autre système PS3™ à l'aide de l'utilitaire de transfert de données, les données enregistrées dont la copie est interdite ne pourront être restaurées sur aucun des systèmes à partir de la sauvegarde.
  • Certains types de données sauvegardées peuvent être restaurées sur un autre système PS3™. Il s'agit des types de données suivants :
  • - Données enregistrées à partir du logiciel au format PlayStation®3 *1
  • - Fichiers image sous (Photo)
  • - Fichiers musicaux sous (Musique)*2
  • - Fichiers vidéo sous (Vidéo)*2
  • - Signets ajoutés sous (Navigateur Internet)
  • - Termes ajoutés à l'aide de (Paramètres) > (Paramètres système) > [Ajouter/Modifier terme], ou termes de saisie prédictive "appris" par le clavier virtuel.
    • *1  Les données protégées contre la copie ne peuvent pas être restaurées. Par ailleurs, il se peut que les données enregistrées qui ont été restaurées soient inutilisables dans certains jeux.
    *2  Ne comprend pas les données protégées par les droits d'auteur.
  • Dans certains cas, vous ne pourrez peut-être pas employer l'Utilitaire de sauvegarde pour sauvegarder ou restaurer correctement le système. Il vous est recommandé de toujours copier ou déplacer les données importantes vers un support de stockage afin d'en créer une version de sauvegarde séparée.
