Mode d'emploi

Paramètres > Paramètres système > Démarrage automatique disque

Démarrage automatique disque

Pour définir si le disque doit démarrer automatiquement ou non lors de son insertion.

Non Pour que le disque ne démarre pas automatiquement.
Oui Pour que le disque démarre automatiquement.

Conseils

  • Même si vous avez sélectionné [Oui], le disque ne démarre pas automatiquement dans les situations suivantes :
  • - Lorsque le système est allumé avec un disque inséré
  • - Lorsqu'une autre opération est exécutée sous la barre de menus XMB™
  • - Si vous avez inséré un CD-R ou un autre type de disque de données
  • - Au démarrage du système, s'il existe plusieurs utilisateurs et si la connexion automatique n'est pas définie
  • Pour les disques sur lesquels plusieurs couches de données sont enregistrées, tels que les Super Audio CD, la couche de données qui démarre automatiquement varie selon le disque.

Avis

Les Super Audio CD ne peuvent pas être lus sur certains systèmes PS3™. Pour plus de détails, consultez la section [Types de disques lisibles].
