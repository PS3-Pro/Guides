Utilisation de raccourcis / d'une souris / d'un clavier

Utilisation de raccourcis

Pour pouvoir utiliser directement l'appareil avec les touches de la manette sans fil, sans utiliser le menu. Les opérations exécutables sont différentes dans le mode navigation et dans le mode fenêtre.

Mode Navigation
Touche Ouvrir le lien.
Touche (maintenue enfoncée) Ouvrir le lien dans une nouvelle fenêtre.
Touche + joystick gauche Pour sélectionner du texte.
Touche Afficher le menu.
Touche Fermer (Navigateur Internet).
Touche (maintenue enfoncée) Fermer la fenêtre. *1
Touche START (mise en marche) Saisir une adresse.
Touche SELECT (sélection) Ouvrir [Mes signets].
Touches L1 / R1 Reculer ou avancer d'une page.
Touches L2 / R2 Accéder à une autre fenêtre. *2
Touches de navigation Déplacer le pointeur vers un lien dans le sens de la touche enfoncée.
Touche + touche de navigation Pour faire défiler par page dans le sens de la touche sur laquelle vous appuyez.
Joystick gauche Déplacer le pointeur dans la direction souhaitée.
Joystick gauche (enfoncer) (touche L3) Basculer en mode Fenêtre.
Joystick droit Faire défiler dans la direction souhaitée.
Joystick droit (enfoncer) (touche R3) Utiliser l'affichage du zoom. / Supprimer l'affichage du zoom.
Touche PS Afficher le menu XMB™.
*1

Cette opération ne peut pas être réalisée pendant un zoom.
*2

S'agrandit ou se réduit pendant un zoom.
Mode Fenêtre
Touche Afficher la fenêtre sélectionnée en mode Navigation.
Touche Afficher le menu.
Joystick gauche (enfoncer) (touche L3) Basculer en mode Navigation.
Touches de navigation Accéder à une autre fenêtre.
Touche PS Afficher le menu XMB™.

Utilisation d'une souris (non fournie)

Utilisez une souris disponible dans le commerce.

Faites glisser vers la gauche tout en maintenant le bouton droit de la souris enfoncé Revenir à la page précédente.
Faites glisser vers la droite tout en maintenant le bouton droit de la souris enfoncé Passer à la page suivante.

Utilisation d'un clavier (non fourni)

Utilisez un clavier disponible dans le commerce.

CTRL + L (ou F4) Saisir une adresse.
CTRL + R (ou F5) Actualiser la page.
CTRL + B (ou CTRL + I) Ouvrir [Mes signets].
PG. PRÉC (ou MAJ + ESPACE) Faire défiler vers le haut.
PG. SUIV (ou ESPACE) Faire défiler vers le bas.
Accueil Accéder en haut de la page.
Fin Accéder au bas de la page.
TAB Déplacer le curseur.
ALT + GAUCHE (ou RET. ARR) Revenir à la page précédente.
ALT + DROITE (ou MAJ + RET. ARR) Passer à la page suivante.
CTRL + GAUCHE (ou CTRL + MAJ + TAB) Accéder à la fenêtre de gauche.
CTRL + DROITE (ou CTRL + TAB) Modification des paramètres d'affichage à l'écran
