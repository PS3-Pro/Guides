Menu mode Navigation

Visualiser

Modifier le mode d'affichage de la page.

Zoom / Effacer le zoom Pour agrandir automatiquement à la taille optimale ou annuler l'agrandissement de la zone de l'écran dans laquelle se trouve le pointeur.

Le taux d'agrandissement optimal est automatiquement calculé sur la base du type de contenu de la zone dans laquelle se trouve le pointeur.
Taille maximale / Taille standard Agrandir la fenêtre pour l'afficher sur tout l'écran. / Afficher la fenêtre dans sa taille originale.
Taille des caractères Modifier la taille du texte.

Le texte peut être affiché dans cinq tailles différentes.
Encodage des caractères Attribuer l'encodage des caractères.

Dans la plupart des cas, l'encodage des caractères est déterminé automatiquement et ne doit pas être attribué.

Conseil

Sur certaines pages, la taille des caractères ne peut pas être modifiée et l'encodage des caractères ne peut pas être attribué.

Outils

Définir les conditions d'ouverture des pages et supprimer des données enregistrées sur le disque dur.

Cookies Permettre : toujours autoriser l'enregistrement de cookies.

Bloquer : toujours refuser l'enregistrement de cookies.
JavaScript Oui : utiliser JavaScript.

Non : ne pas utiliser JavaScript.
Surface d'affichage Full pixel : pour afficher la fenêtre sur l'ensemble de la surface d'affichage de l'écran du téléviseur.*1

Standard : pour réduire la taille de la fenêtre de 5 %.

-1 : pour réduire la taille de la fenêtre de 10 %.

-2 : pour réduire la taille de la fenêtre de 15 %.
Résolution Pour modifier la résolution d'affichage de la page Web.

Réglez les pages Web pour faciliter leur affichage en adaptant la résolution de sortie vidéo à celle du système PS3™.
Réduction du scintillement Oui : pour supprimer le scintillement des éléments affichés, notamment le texte, les images et les traits.

Non : pour désactiver la fonction de réduction du scintillement.

Celle-ci est efficace pour supprimer le scintillement sur un écran entrelacé. Choisissez [Oui] lorsque vous sélectionnez une résolution de 1080i, par exemple, comme réglage de la sortie vidéo du système PS3™. Le réglage [Non] améliore la qualité de l'image dans le cas d'un affichage progressif, par exemple 1080p ou 720p.
Confirmer fermeture du navigateur Oui : pour afficher un message de confirmation lors de la fermeture du (Navigateur Internet).

Non : pour fermer sans afficher de message de confirmation.
Page d'accueil Pour définir la page affichée lors du démarrage (Navigateur Internet) ou lors de la sélection de (Accueil) dans le menu.

Si vous activez [Rétablir la fenêtre au démarrage du navigateur], la page qui était ouverte au moment de la fermeture du navigateur apparaît la prochaine fois que vous le démarrez.
Effacer les cookies Effacer les cookies.
Supprimer l'historique des recherches Pour supprimer les informations de l'historique des recherches.
Effacer le cache Effacer le cache.
Effacer les informations d'authentification Effacer les informations d'authentification.
Arrêter la Sécurité du navigateur Pour cesser d'utiliser les services de filtrage Web. *2


Pour modifier ce paramètre, vous devez saisir un mot de passe. Pour plus de détails sur les mots de passe, consultez (Paramètres) > (Paramètres sécurité) > [Changer le mot de passe] dans le présent mode d'emploi.
*1

Le haut et le bas de l'image peuvent être rognés si [Full pixel] est activé quand vous utilisez un téléviseur ordinaire.
*2

Les types de services de filtrage Web disponibles varient selon le pays ou la région.

Recherche

Sauvegarder la capture d'écran Pour enregistrer l'écran affiché en tant qu'image.

La capture d'écran est enregistrée sous (Photo).
Informations de page Afficher le titre ou l'adresse de la page ouverte.
Afficher le certificat Afficher les certificats serveur envoyés par les pages qui prennent en charge SSL.
*

Un adaptateur USB approprié (non fourni) est nécessaire pour utiliser le support de stockage avec certains modèles.

Suivant

Actualiser / Annuler

Mettre à jour la page ouverte, à l'aide du contenu le plus récent. / Arrêter le chargement de la page.

Accueil

Afficher la page définie comme page d'accueil.

Signets

Ajouter vos pages favorites comme signets. Les signets sont accessibles à partir de [Mes signets].

Mes signets Ajouter la page Web comme signet et afficher la liste des signets enregistrés.
PlayStation®3 Afficher le site Web Sony Computer Entertainment.

Conseil

La liste des signets est classée dans l'ordre chronologique, avec les signets les plus récents en début de liste.

Sécurité du navigateur

Utilisez un service de filtrage Web pour vérifier le type et l'adéquation des sites Web afin de bloquer automatiquement l'affichage des sites Web inappropriés lors de l'utilisation d'Internet.

i-Filter for PS3™*1 Afficher le site Web du fournisseur de services [i-Filter for PS3™].*2
Trend Micro™ Afficher le site Web du fournisseur de services [Trend Micro Web Security for PS3™].*2
*1

Cette fonctionnalité n'est disponible que sur les systèmes PS3™ vendus au Japon.
*2

L'utilisation des services de filtrage Web peut être payante.

Historique

Les pages qui ont été ouvertes sont automatiquement enregistrées dans l'historique. Les titres des pages qui ont été ouvertes sont affichés dans une liste et peuvent être ouverts en les sélectionnant simplement dans cette liste, sans saisir d'adresse.

Conseil

Les pages sont classées dans l'ordre chronologique, avec les pages les plus récentes en début de liste.
