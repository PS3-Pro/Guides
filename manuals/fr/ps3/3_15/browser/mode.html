Mode Navigation / Mode Fenêtre

Mode Navigation

La fenêtre est affichée sur toute la hauteur et toute la largeur de l'écran. Lorsque plusieurs fenêtres sont ouvertes, elles apparaissent côte à côte. Vous pouvez modifier des fenêtres à l'aide des touches L2 ou R2.

Mode Fenêtre

L'affichage change pour s'adapter au nombre de fenêtres ouvertes. Sélectionnez une fenêtre en utilisant les touches de navigation, puis appuyez sur la touche pour afficher la fenêtre en mode Navigation.

Changer les modes

Le mode Navigation et le mode Fenêtre peuvent être permutés comme suit :

Mode Navigation > Mode Fenêtre Appuyez sur le joystick gauche (touche L3).
