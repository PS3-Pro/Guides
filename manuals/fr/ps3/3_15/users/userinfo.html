Modifier les informations de l'utilisateur

Pour modifier les informations de l'utilisateur, comme le nom et l'icône de l'utilisateur. Connectez-vous sous l'utilisateur que vous souhaitez modifier. Sélectionnez l'icône de l'utilisateur, appuyez sur la touche , puis sélectionnez [Informations] dans le menu d'options. Sélectionnez les éléments que vous souhaitez modifier.

  • Vous pouvez sélectionner une icône parmi les photos enregistrées sur le disque dur ou parmi les icônes prédéfinies.
