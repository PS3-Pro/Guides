Collection de trophées

Vous pouvez obtenir des trophées lorsque vous atteignez certains objectifs dans des jeux prenant en charge la fonctionnalité de trophées.

Types de trophées

Les trophées sont classés en quatre degrés. En général, les degrés se basent sur le niveau de difficulté permettant d'obtenir les trophées. Les types de trophées disponibles et les conditions selon lesquelles vous les obtenez varient en fonction du jeu.

Vérification de votre collection de trophées

1.

Sélectionnez (Jeu) sous (Collection de trophées).
Les taux d'obtention de trophées pour les différents jeux sont affichés.

2.

Sélectionnez le jeu que vous souhaitez vérifier.
Vous disposez d'informations relatives aux trophées disponibles dans le jeu. Des images de trophée sont affichées pour les trophées que vous avez obtenus.

Enregistrement de vos informations de trophées sur le serveur PlayStation®Network

Si vous créez un compte PlayStation®Network, vous pouvez enregistrer sur le serveur PlayStation®Network des informations relatives aux trophées que vous avez obtenus. Il est également possible d'afficher votre collection de trophées dans l'écran [Profil] sous (Amis) et de comparer votre état d'obtention de trophées avec celui de vos Amis.


Les informations de trophées sont automatiquement enregistrées sur le serveur PlayStation®Network dans les conditions suivantes :

  • Si vous sélectionnez (Jeu) > (Collection de trophées) une fois connecté à PlayStation®Network
  • Si vous sélectionnez (Comparer les trophées) dans l'écran [Profil], sous (Amis)
