Utilisation du panneau de configuration

Pour utiliser cette fonctionnalité, vous devrez peut-être mettre à jour le logiciel système.


Effectuez diverses opérations à l'aide du panneau de configuration qui s'affiche. Le menu peut être affiché ou masqué en appuyant sur la touche .

Inviter un ami

Pour inviter un Ami à se joindre au salon de chat.

Conseil

Même si vous pouvez inviter plusieurs Amis au chat, seuls les avatars des cinq premiers Amis sélectionnés à l'écran s'affichent dans le salon de chat. Par ailleurs, un salon de chat peut accueillir jusqu'à six personnes.

Outils

Pour afficher une image provenant de (Photo) ou créer un message pour les membres du chat.

Changeur de voix Pour changer la tonalité de votre voix.

Vous pouvez vérifier les changements de la voix en sélectionnant une valeur, puis en parlant dans le micro. Les valeurs définies se reflètent dans (Paramètres) > (Paramètres accessoires) > [Changeur de voix].
Afficher photo Pour afficher sur votre écran une image provenant de (Photo).
Créer message pour tous Pour créer un message destiné à tous les participants d'une session de chat.

Visualiser

Pour définir les paramètres liés à l'affichage de l'écran de chat.

Affichage Pour afficher le débit binaire audio / vidéo afin de vérifier l'état du transfert de données.

Lorsque vous quittez le chat, ce paramètre est réinitialisé et le débit ne s'affiche plus.
Mode écran Pour modifier le mode d'affichage à l'écran.

Le mode écran ne peut être modifié que si deux personnes sont en conversation. Certains modes ne peuvent pas être affichés, en fonction du paramètre de sortie vidéo du système PS3™.

Normal : pour que l'affichage de l'image corresponde à la taille de l'écran.

Normal (se masquer) : pour que l'affichage de l'image corresponde à la taille de l'écran. Votre photo ou avatar ne s'affiche pas sur le téléviseur.*

Zoom : pour afficher l'image en plein écran. Les proportions sont préservées et des parties de l'image sont éventuellement rognées en haut et en bas.

Zoom (se masquer) : pour afficher l'image en mode plein écran tout en conservant les proportions de l'image (le haut et le bas de l'image peuvent être rognés). Votre photo ou avatar ne s'affiche pas sur le téléviseur.*

Original : pour afficher l'image à sa taille originale.

Lorsque vous quittez le chat vocal / vidéo, ce paramètre est réinitialisé à [Zoom] ou [Normal].
La valeur rétablie varie selon le paramètre de sortie vidéo du système PS3™.

*  Même si vous choisissez de masquer votre photo sur votre écran, votre photo ou avatar s'affiche sur le téléviseur de la personne avec qui vous discutez.

Paramètres chat

Pour modifier les paramètres audio ou vidéo d'un chat vocal / vidéo.

Caméra activée / Caméra désactivée Pour activer ou désactiver la caméra.

Réglez ce paramètre si vous ne souhaitez pas envoyer de vidéo à la personne avec laquelle vous discutez. Si vous sélectionnez [Caméra désactivée], votre avatar s'affiche dans le salon de chat. Lorsque vous quittez le chat vocal / vidéo, ce paramètre revient à l'option sélectionnée sous (Paramètres) > (Paramètres chat).
Microphone activé / Microphone désactivé Pour activer ou désactiver le microphone.

Réglez ce paramètre si vous ne souhaitez pas envoyer de son à la personne avec laquelle vous discutez. Lorsque vous quittez une session de chat vocal / vidéo, ce paramètre retrouve la valeur [Microphone activé].
Paramètres périphériques audio Pour régler les paramètres des périphériques à utiliser pour l'entrée / sortie audio.

Niveau du microphone : pour définir le volume du microphone.

Périphérique d'entrée : pour sélectionner le périphérique d'entrée à utiliser.

Périphérique de sortie : pour sélectionner le périphérique de sortie à utiliser.

Les valeurs définies se reflètent dans (Paramètres) > (Paramètres accessoires) > [Paramètres périphériques audio].
Contrôle du volume Pour régler le volume d'un chat.

Lorsque vous quittez une session de chat, ce paramètre retrouve sa valeur [Normal].

Partir

Pour quitter le salon de chat.

Conseil

Si la personne qui a lancé le chat vocal / vidéo quitte la session, le salon de chat se referme.
