Gestion des informations sur les comptes

Pour utiliser cette fonctionnalité, vous devrez peut-être mettre à jour le logiciel système.


Vérifiez ou modifiez les informations des comptes PlayStation®Network. Vous devez être connecté à PlayStation®Network pour exécuter ces opérations. Sélectionnez (Gestion du compte) sous (PlayStation®Network).

Éléments qui peuvent être vérifiés ou modifiés
Informations du compte

Vous pouvez vérifier ou modifier des informations relatives aux comptes PlayStation®Network.

  • Informations de facturation
  • ID de connexion (adresse e-mail)
  • Mot de passe
  • Nom
  • Adresse
  • Avatar
  • Profil
  • Préférences de notification
Gestion du compte secondaire

Vous pouvez vérifier ou modifier les paramètres d'un compte secondaire associé.

  • Contrôle parental
  • Mot de passe du compte secondaire
Utiliser codes Vous pouvez échanger un numéro PlayStation®Network Card ou un code promotionnel.
Gestion des transactions

Vous pouvez ajouter des fonds au porte-monnaie utilisé pour les services PlayStation®Network, tels que PlayStation®Store, ou vérifier l'historique d'utilisation des divers services.

  • Approvisionner
  • Demander le mot de passe au paiement
  • Approvisionnement automatique
  • Historique de transactions
  • Liste de téléchargements
  • Liste de services
Activation du système Vous pouvez activer ou désactiver le système PS3™ ou PSP™ que vous utilisez pour le compte.
Facebook

Si vous possédez un compte Facebook®, vous pouvez régler des paramètres relatifs au partage d'informations sur Facebook.

  • Partager des informations de trophées
  • Partager des informations relatives à des contenus achetés dans PlayStation®Store
  • Partager des informations relatives à des événements de jeu
  • Supprimer des informations de compte Facebook à partir du système PS3™

Conseils

  • Les éléments que vous pouvez vérifier ou modifier varient selon le type de compte PlayStation®Network et selon le pays ou la région d'utilisation. Pour plus de détails, contactez la ligne d'assistance technique de votre région.
  • Facebook est un service qui vous permet de rester en contact et d'échanger avec les personnes qui vous entourent. Facebook est une marque déposée de Facebook, Inc.
  • Vous devez posséder un compte Facebook pour pouvoir utiliser cette fonction. Pour vous inscrire afin d'obtenir un compte ou des informations supplémentaires, visitez http://www.facebook.com/.
