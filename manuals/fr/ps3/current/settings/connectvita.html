Connectez le système PS Vita à l'aide du réseau

Active ou désactive l'utilisation du Wi-Fi pour le transfert des données avec un système PS Vita. Pour plus de détails, consultez la section (Gestionnaire de contenu) > [PS3™] > [Transfert de données de/vers un système PS3™ via le Wi-Fi] dans le mode d'emploi du système PS Vita.

Non Pour ne pas utiliser le Wi-Fi pour transférer des données.
Oui Active le transfert des données via le Wi-Fi.

Conseils

  • Ce paramètre est affiché lorsque vous vous êtes connecté une fois à un système PS Vita au moyen de (Gestionnaire de contenu) sur le système PS Vita. Le paramètre par défaut est [Oui].
  • Pour utiliser cette fonction, vous devez employer la version 3.00 ou ultérieure du logiciel système du système PS Vita.
