Utilitaire de formatage

Pour formater (initialiser) un carte Memory Stick™, une SD Memory Card, une carte CompactFlash® ou le stockage système. Dans ce but, suivez les instructions qui s'affichent.


Avis

  • Lorsque vous procédez à cette opération, toutes les données du support de stockage ou du stockage système sont effacées. Les données ne peuvent pas être restaurées, donc veillez à ne pas supprimer accidentellement des données importantes. L'utilisateur est responsable de toute perte ou altération de données.
  • Pendant cette opération, ne mettez pas le système PS3™ hors tension et ne retirez pas le support de stockage. Si l'opération est annulée avant son achèvement, le logiciel système risque d'être endommagé et il se peut que le système doive être réparé ou échangé.
  • Pendant le formatage du stockage système, la touche d'alimentation du système et la touche PS de la manette sans fil sont inactives.
  • Lorsque le stockage système est formaté, le logiciel système n'est pas effacé.
  • Les paramètres qui sont sauvegardés dans le stockage système, comme des signets sous (Navigateur Internet), sont supprimés.
  • Vous pouvez réduire la durée de formatage en sélectionnant [Formatage rapide] parmi les méthodes de formatage du stockage système.  Il est recommandé de sélectionner [Formatage complet] lors du formatage d'un stockage système comportant des données importantes ou sensibles.
  • Cette fonctionnalité ne permet pas de formater les Memory Stick™, les SD Memory Card ou les cartes CompactFlash® insérées dans des systèmes PS3™ non équipés de fentes multimédia.
