Enregistrer clavier / souris

Pour modifier les paramètres d'un clavier ou d'une souris.

Type de clavier

Définissez le type de clavier raccordé au système via un câble USB ou la technologie Bluetooth®.

Méthode de saisie clavier

Définissez la méthode de saisie du clavier raccordé au système via un câble USB ou la technologie Bluetooth®. Ce paramètre n'est disponible que dans les cas suivants :

  • Si la langue système est configurée pour afficher les caractères Chinois traditionnel
  • Si la langue système est réglée sur Japonais et si [Type de clavier] est réglé sur [Clavier japonais] ou sur [Clavier anglais (standard ÉU)]

Raccourci clavier

Pour régler l'attribution de clé pour le clavier. Ce paramètre n'est disponible que si la langue système est réglée sur Japonais et si [Type de clavier] est réglé sur [Clavier japonais] ou sur [Clavier anglais (standard ÉU)].

Intervalle de répétition clavier

Définissez le délai avant qu'un caractère soit répété lorsqu'une touche est maintenue enfoncée sur un clavier USB ou un clavier Bluetooth®.

Vitesse de répétition clavier

Définissez la vitesse de répétition d'un caractère lorsqu'une touche est maintenue enfoncée sur un clavier USB ou un clavier Bluetooth®.

Type de souris

Définissez le type de souris raccordé via un câble USB ou la technologie Bluetooth®. Définissez le type de souris en fonction de la main avec laquelle vous actionnez la souris.

Vitesse pointeur

Pour définir la vitesse à laquelle le pointeur de la souris se déplace.
