Copie de jeux en vue de les utiliser sur un système PSP™

Si le jeu téléchargé (gratuitement ou en payant) à partir de (PlayStation®Store) est compatible avec le système PSP™, vous pouvez le copier afin de l'utiliser sur un système PSP™.

1.

Connectez-vous à PSNSM à l'aide du compte Sony Entertainment Network que vous avez utilisé pour télécharger le jeu.

2.

Connectez le système PSP™ au système PS3™ à l'aide d'un câble USB.
Pour copier des fichiers sur le support Memory Stick™, insérez le support Memory Stick™ dans le système PSP™.

3.

Sur le système PSP™, sélectionnez (Paramètres) > (Connexion USB).

4.

Dans le système PS3™, sélectionnez le jeu que vous souhaitez copier sous (Jeu), puis appuyez sur la touche .

5.

Sélectionnez [Copier].
Suivez les instructions affichées pour copier le jeu. Une fois la copie terminée, vous pouvez démarrer le jeu sur le système PSP™ dans (Jeu) > (Memory Stick™) ou dans (Jeu) > (Stockage système).

Conseils

  • Pour utiliser cette fonction, vous devez employer la version 6.50 ou ultérieure du logiciel système du système PSP™.
  • Pour plus d'informations sur l'utilisation des jeux sur le système PSP™, reportez-vous au mode d'emploi du système PSP™.

Jeux pouvant être utilisés à la fois sur les systèmes PS3™ et PSP™

Si vous lisez un jeu compatible avec les deux systèmes, vous pouvez copier les données de jeu sauvegardées d'un système vers l'autre afin de reprendre le jeu là où vous l'avez quitté. La méthode de copie des données sauvegardées varie selon le type de jeu.

Données sauvegardées d'un logiciel au format PlayStation®

Les données sauvegardées d'un logiciel au format PlayStation® sont enregistrées sur une Memory Card interne créée dans le stockage système. Pour copier les données sauvegardées vers un système PSP™, suivez les étapes 2 et 3 ci-dessus, puis sélectionnez (Jeu) > (Utilitaire de Memory Card) > (Memory Card (PS) interne) dans le système PS3™. Ensuite, sélectionnez l'icône des données sauvegardées à copier, appuyez sur la touche , puis sélectionnez [Copier] dans le menu d'options.

Conseils

  • Pour permettre l'utilisation des données sauvegardées sur un système PSP™, vous devez convertir le format des données. Si un écran de confirmation relatif à la conversion des données s'affiche pendant l'opération de copie, sélectionnez [Oui] pour continuer.
  • Plusieurs Memory Cards internes sont créées pour chaque titre de logiciel enregistré sur le support Memory Stick™ (inséré dans le système PSP™) ou dans le stockage système du système PSP™go.
  • Si vous copiez les données sauvegardées sur le support Memory Stick™ inséré dans la fente pour support du système PS3™ ou si vous utilisez un adaptateur USB (vendu séparément), les données sauvegardées ne sont pas reconnues.

Activation d'un système PSP™

Les jeux (payants ou gratuits) téléchargés sur (PlayStation®Store) peuvent être utilisés sur un système PSP™ activé. Si, lorsque vous démarrez le jeu sur un système PSP™, un message vous indique que l'activation est requise, vous devez activer le périphérique en suivant la procédure ci-dessous.

1.

Connectez le système PSP™ au système PS3™ à l'aide d'un câble USB.

2.

Sur le système PSP™, sélectionnez (Paramètres) > (Connexion USB).

3.

Dans le système PS3™, sélectionnez (PlayStation™Network) > (Gestion du compte).

4.

Sélectionnez (Activation du système).
Suivez les instructions affichées pour terminer la procédure d'activation.

Conseils

  • Pour procéder à l'activation du périphérique, vous devez être connecté au système PS3™ sous le nom de l'utilisateur qui était connecté au moment du téléchargement du logiciel au format PlayStation®.
  • L'activation du périphérique est une procédure qui permet de lire du contenu situé sur des périphériques authentifiés. Cette procédure est nécessaire pour protéger les droits numériques de ce contenu.
