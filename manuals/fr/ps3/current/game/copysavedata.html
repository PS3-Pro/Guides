Copie des données enregistrées sur un support de stockage (sauvegarde)

Les données sauvegardées sur le stockage système peuvent être exportées vers un support de stockage et les données sauvegardées qui ont été exportées peuvent être importées sur le stockage système. Sélectionnez les données sauvegardées que vous souhaitez exporter ou importer, appuyez sur la touche , puis sélectionnez [Copier] dans le menu d'options. Suivez les instructions à l'écran pour terminer l'opération. Il est recommandé de copier les données importantes à des fins de sauvegarde.


Conseils

  • Certaines données sauvegardées ne peuvent pas être copiées.
  • Des données sauvegardées ne peuvent pas être copiées durant une lecture de contenu utilisant d'autres fonctionnalités, comme la lecture de fichiers musicaux.
  • Les données sauvegardées d'un logiciel au format PlayStation®2 ou PlayStation® peuvent également être copiées sur une Memory Card (8 MB) (pour PlayStation®2) ou sur une Memory Card. Pour plus de détails, consultez [Utilisation des données enregistrées sur des Memory Card] sous (Jeu) > [Lecture d'un logiciel aux formats PlayStation®2 / PlayStation®] dans le présent mode d'emploi.
  • Un adaptateur USB approprié (non fourni) est nécessaire pour utiliser le support de stockage avec certains modèles du système PS3™.

Avis

  • Il est possible que certains titres de logiciels au format PlayStation®2 ou PlayStation® fonctionnent différemment avec le système PS3™ par rapport aux systèmes PlayStation®2 ou PlayStation®, ou qu'ils ne fonctionnent pas correctement avec le système PS3™.
  • Les disques au format PlayStation®2 ne peuvent pas être lus sur certains systèmes PS3™. Pour plus d'informations, consultez [Types de disques lisibles], visitez le site Web SIE de votre région ou reportez-vous à la documentation qui accompagne votre système PS3™.
