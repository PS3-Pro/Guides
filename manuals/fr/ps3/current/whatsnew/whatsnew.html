A propos de Nouveautés

La fonctionnalité Nouveautés permet de consulter les dernières informations provenant de PlayStation®Store et de vérifier le contenu que vous avez lu récemment. Lorsque vous sélectionnez un élément sous [Nouveautés], des informations s'affichent à son sujet.

Icônes associées aux éléments de contenu

Pour lancer le navigateur Internet afin d'afficher une page Web.
Pour accéder à PlayStation®Store.
Pour lire une vidéo.
Pour lancer un jeu en appuyant sur la touche START (mise en marche).

Conseils

  • Pour afficher les dernières informations, vérifiez que le système PS3™ est connecté à Internet. Pour plus de détails sur les paramètres réseau, consultez (Paramètres) > (Paramètres réseau) > [Paramètres connexion Internet] dans le présent mode d'emploi.
  • Pour télécharger des produits (gratuitement ou en payant) à partir de PlayStation®Store, vous devez créer un compte Sony Entertainment Network.
  • Le contenu qui s'affiche dépend du pays ou de la région à partir duquel vous accédez à PlayStation®Store.
