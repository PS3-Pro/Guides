Groupement de photos

Vous pouvez sélectionner des événements, puis grouper des photos au sein de ces événements sélectionnés à l'aide d'une des options décrites ci-dessous. Sélectionnez les événements qui contiennent les photos que vous souhaitez grouper, appuyez sur la touche , puis sélectionnez (Grouper). Si vous souhaitez réduire le nombre de photos groupées, sélectionnez un ou plusieurs groupes qui contiennent les photos que vous souhaitez grouper, puis utilisez une autre option sous (Grouper) pour grouper les photos.

Date/heure Pour grouper selon la date et l'heure de prise de vue.
Nombre de personnes Pour grouper selon le nombre de personnes présentes sur les photos.
Tranche d'âge du groupe Pour grouper selon l'âge relatif des personnes présentes sur les photos.
Expression Pour grouper selon les expressions des visages des personnes présentes sur les photos.
Couleur Pour grouper selon les couleurs qui apparaissent dans les photos.
Type d'appareil photo Pour grouper selon le modèle de l'appareil photo utilisé pour prendre les photos.
Jeu Pour grouper par titre de jeu.
Album Pour grouper selon les albums créés sous (Photo) dans l'écran XMB™.

Conseils

  • Avec [Sélectionner tout], toutes les photos dans [Espace bibliothèque] seront groupées selon l'option sélectionnée.
  • Le groupement est basé sur l'analyse des photos et, dans certains cas, les résultats peuvent être différents de ceux que vous attendiez.
  • Vous pouvez créer une liste de lecture des photos groupées.
Exemples de photos groupées : photos d'enfants qui sourient

1.

Groupez les photos en sélectionnant (Grouper) > [Tranche d'âge du groupe].

2.

Sélectionnez le groupe nommé [Enfants], puis appuyez sur la touche .

3.

Sélectionnez (Grouper) > [Expression].
Vous pouvez visualiser des photos d'enfants souriants dans le groupe nommé [Avec sourires].
Exemples de photos groupées : photos présentant un ciel bleu

1.

Groupez les photos en sélectionnant (Grouper) > [Nombre de personnes].

2.

Sélectionnez le groupe nommé [Paysage/autre], puis appuyez sur la touche .

3.

Sélectionnez (Grouper) > [Couleur].
Recherchez les photos présentant un ciel bleu dans le groupe nommé [Bleu].

Suppression de photos

Sélectionnez la photo ou l'album à supprimer, appuyez sur la touche , puis sélectionnez (Supprimer).

Conseil

Si vous supprimez des photos dans [Espace bibliothèque], elles seront également supprimées du stockage système du système PS3™.
