Impression de photos

Pour imprimer une photo, vous devez d'abord configurer une imprimante dans [Sélection imprimante] sous (Paramètres) > (Paramètres imprimante).

1.

Connectez une imprimante au système PS3™.

2.

Sélectionnez la photo que vous souhaitez imprimer, puis appuyez sur la touche .

3.

Sélectionnez (Imprimer).

4.

Vérifiez les paramètres d'impression.
Vous pouvez appuyer sur la touche pour afficher le menu d'options afin de modifier des paramètres, tels que le nombre de copies à imprimer. Les paramètres disponibles varient selon l'imprimante utilisée.

5.

Sélectionnez [Imprimer].
La photo s'imprime.

Conseil

Les imprimantes pouvant être utilisées varient selon le pays ou la région. Pour plus de détails, visitez le site Web SIE de votre région.
