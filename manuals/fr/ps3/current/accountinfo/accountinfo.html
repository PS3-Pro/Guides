Gestion des informations sur les comptes

Pour utiliser cette fonctionnalité, vous devrez peut-être mettre à jour le logiciel système.


Vérifiez ou modifiez les informations des comptes Sony Entertainment Network. Vous devez être connecté à PSNSM pour exécuter ces opérations. Sélectionnez (Gestion du compte) sous (PlayStation™Network).

Éléments qui peuvent être vérifiés ou modifiés
Informations du compte

Vous pouvez vérifier ou modifier des informations relatives aux comptes Sony Entertainment Network.

  • Informations de facturation
  • ID de connexion (adresse e-mail)
  • Mot de passe
  • Langue système
  • Nom
  • Adresse
  • Avatar
  • Profil
  • Préférences de notification
Gestion du compte secondaire

Vous pouvez vérifier ou modifier les paramètres d'un compte secondaire associé.

  • Contrôle parental
  • Mot de passe du compte secondaire
Utiliser codes Vous pouvez échanger un numéro PSNSM Card ou un code promotionnel.
Gestion des transactions

Vous pouvez ajouter des fonds au porte-monnaie utilisé pour les services PSNSM, tels que PlayStation®Store, ou vérifier l'historique d'utilisation des divers services.

  • Approvisionner
  • Demander le mot de passe au paiement
  • Approvisionnement automatique
  • Historique de transactions
  • Liste de téléchargements
  • Liste de services
Activation du système Vous pouvez activer ou désactiver le système PS3™ ou PSP™ que vous utilisez pour le compte.
Paramètres de confidentialité Vous pouvez définir le groupe de joueurs qui peut voir vos trophées et spécifier ceux dont vous recevez des demandes d'ami et des messages.
Pour chaque jeu, vous pouvez aussi spécifier si les trophées que vous gagnez doivent être affichés ou non. Pour plus de détails, consultez [Collection de trophées] dans ce mode d'emploi.

Conseil

Les éléments que vous pouvez vérifier ou modifier varient selon le type de compte Sony Entertainment Network et selon le pays ou la région d'utilisation. Pour plus de détails, contactez la ligne d'assistance technique de votre région.
