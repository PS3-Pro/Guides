À propos de l'activation du système

L'activation du système est une procédure destinée à protéger les droits d'auteur du contenu, ainsi que d'autres droits numériques. Le contenu et les applications disponibles sur PlayStation®Store ne peuvent être utilisés que sur les systèmes activés.

Vous pouvez lier votre compte Sony Entertainment Network à plusieurs périphériques. Toutefois, le nombre de périphériques par type de contenu est limité pour chaque compte. Lorsque le nombre maximal de systèmes activés est atteint, un message d'erreur apparaît si vous essayez de télécharger (acheter) du contenu sur un système non activé.

Activation manuelle d'un système

Normalement, votre système est automatiquement activé lorsque vous téléchargez (achetez) du contenu. Toutefois, vous devez activer manuellement le système si un message indiquant que l'activation du système est requise s'affiche lorsque vous essayez de lire le contenu.

Connectez-vous à PSNSM sur votre système PS3™. Sélectionnez (PlayStation™Network) > (Gestion du compte) > (Activation du système), puis suivez les instructions à l'écran.

Conseils

  • Vous pouvez activer un système PS3™ pour regarder du contenu vidéo à 3 reprises maximum dans un délai de 90 jours pour chaque compte. Vous ne pouvez pas utiliser un compte pour activer une quatrième fois le même système en moins de 90 jours. Vous pourrez activer à nouveau le système 90 jours après sa première activation.
  • La vente/location de contenu vidéo depuis le PlayStation®Store sur le système PS3™ a été interrompue.

Désactivation d'un système

Si vous essayez de dépasser le nombre maximal de systèmes qui peuvent être activés pour votre compte, un message vous indique que vous ne pouvez pas acheter (télécharger) le contenu sélectionné. Dans ce cas, désactivez un de vos autres systèmes.

Connectez-vous à PSNSM sur votre système PS3™. Sélectionnez (PlayStation™Network) > (Gestion du compte) > (Activation du système), puis suivez les instructions à l'écran.

Lorsque vous ne pouvez pas désactiver un système

Lorsque vous ne pouvez pas désactiver un système activé, à partir de celui-ci, notamment en raison d'une défaillance ou parce que le système a été mis au rebut, contactez la ligne d'assistance technique de votre région.
Vous pouvez aussi désactiver tous les systèmes activés pour chaque type de contenu à partir du site Web suivant :

http://account.sonyentertainmentnetwork.com/
Allez à [Compte] > [Multimédia et périphériques], puis sélectionnez [Désactiver tout] pour le type de contenu pour lequel vous souhaitez désactiver tous les systèmes activés.

Conseils

  • Selon le type de contenu, il est possible que vous ne puissiez pas désactiver tous les systèmes activés en utilisant cette page.
  • Ce site Web n'est disponible que dans certains pays ou dans certaines régions.
