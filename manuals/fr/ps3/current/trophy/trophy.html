Collection de trophées

Vous pouvez obtenir des trophées lorsque vous atteignez certains objectifs dans des jeux prenant en charge cette fonctionnalité. Les trophées que vous avez obtenus sont enregistrés sur votre système PS3™.

Types de trophées

Les trophées sont classés en quatre degrés. En général, les degrés se basent sur le niveau de difficulté permettant d'obtenir les trophées. Les types de trophées et leurs conditions d'obtention varient selon le jeu.

Consultation de votre collection de trophées

1.

Sélectionnez (PlayStation™Network) > (Collection de trophées).
Les taux d'obtention de trophées des différents jeux sont affichés.
 

2.

Sélectionnez le jeu que vous souhaitez vérifier.
Des images de trophée sont affichées pour les trophées que vous avez obtenus.
 

Enregistrement de vos informations de trophées sur le serveur PSNSM

Si vous avez créé un compte Sony Entertainment Network, vous pouvez enregistrer sur le serveur PSNSM les informations de trophées que vous avez obtenus. Vous devez être connecté à PSNSM pour enregistrer les informations sur le serveur ou consulter les informations de trophées que vous avez enregistrées.


Les informations de trophées sont automatiquement enregistrées sur le serveur PSNSM dans les conditions suivantes :

  • Quand vous sélectionnez (PlayStation™Network) > (Collection de trophées)
  • Quand vous sélectionnez (Comparer les trophées) sous (Amis) > [Profil]

Conseils

  • Quand vous êtes connecté à PSNSM avec un compte lié à votre système PlayStation®4 ou système PlayStation®Vita, vous pouvez consulter les trophées que vous avez gagnés sur ces systèmes.
  • Connectez-vous à PSNSM, sélectionnez (Collection de trophées) sous (PlayStation™Network), appuyez sur la touche , puis sélectionnez [Changer de mode] dans le menu d'options pour basculer vers [Mode hors ligne]. Dans [Mode hors ligne], vous pouvez consulter les informations de trophées qui sont enregistrées sur votre système PS3™.
  • En cas de téléchargement d'une démo de jeu complet (service PlayStation®Plus), les trophées obtenus en cours de partie ne sont pas enregistrés sur le serveur PSNSM. Si vous achetez le jeu, les trophées obtenus avant l'achat sont enregistrés sur le serveur PSNSM.

Contrôle du groupe de joueurs pouvant voir les trophées que vous gagnez

Vous pouvez contrôler le groupe de joueurs pouvant voir les trophées que vous gagnez en accédant à (PlayStation™Network) > [Gestion du compte] > [Paramètres de confidentialité].
Pour chaque jeu, vous pouvez spécifier si les trophées que vous gagnez doivent être affichés ou non. Accédez à (PlayStation™Network) > (Collection de trophées) pour sélectionner le jeu à configurer, appuyez sur la touche , puis sélectionnez [Paramètres de confidentialité] dans le menu d'options. Désélectionnez [Afficher les trophées pour ce jeu] afin de masquer les informations relatives aux trophées uniquement pour les jeux sélectionnés.


Conseils

  • Lorsque [Personne] est sélectionné dans les paramètres d'affichage des trophées sous (PlayStation™Network) > [Gestion du compte] > [Paramètres de confidentialité], ce paramètre est prioritaire. Même lorsque la case à cocher [Afficher les trophées pour ce jeu] est activée pour chaque jeu, les informations relatives aux trophées ne sont pas partagées.
  • Lorsque les informations relatives aux trophées restent confidentielles, cela apparaît aux yeux des autres joueurs comme si vous n'aviez gagné aucun trophée.
  • Vous ne pouvez pas sélectionner une plage d'affichage différente pour chaque jeu.

Comparaison de l'état d'obtention de trophées avec vos amis

Sous (Amis), vous pouvez comparer l'état des trophées que vous avez obtenus, par rapport à vos amis.

Pour plus d'informations, reportez-vous à (Amis) > [Liste d'amis] > [Affichage des profils].
