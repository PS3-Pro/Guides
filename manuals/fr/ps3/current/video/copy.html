Copier / déplacer des fichiers vidéo

Pour copier sur le stockage système des fichiers vidéo sauvegardés sur un support de stockage ou pour copier ou déplacer sur un support de stockage des fichiers importés du stockage système. Sélectionnez le fichier que vous souhaitez importer ou copier, appuyez sur la touche , puis sélectionnez [Copier] ou [Déplacer] dans le menu d'options. Suivez les instructions à l'écran pour terminer l'opération.

Différences entre copier et déplacer

L'opération pouvant être réalisée dépend du type de fichier. Les fichiers protégés contre la copie peuvent uniquement être déplacés. Si un fichier est déplacé, il n'existe plus dans l'emplacement d'enregistrement original.

Du contenu payant (type de fichier : MNV) enregistré en résolution HD qui a été téléchargé à partir de PlayStation®Store ne peut pas être copié ou déplacé, mais peut être sauvegardé de manière sélective. Pour sauvegarder de manière sélective des contenus téléchargés à partir du Video Store de PlayStation®Store, utilisez la fonction de sauvegarde du système PS3™. Pour plus d'informations, consultez (Vidéo) > [Sauvegarde ou restauration de fichiers vidéo] dans le présent mode d'emploi.

Conseils

  • La vente/location de contenu vidéo depuis le PlayStation®Store sur le système PS3™ a été interrompue.
  • Lors de la copie ou du déplacement de fichiers vidéo disposant de restrictions de contrôle parental, vous devez entrer un mot de passe. Vous pouvez définir ce mot de passe dans [Changer le mot de passe] sous (Paramètres) > (Paramètres sécurité).
  • Selon le périphérique utilisé, il est possible que certains fichiers copiés ne puissent pas être lus.
  • Selon le modèle de système PS3™ utilisé, un adaptateur USB approprié (non fourni) peut s'avérer nécessaire pour utiliser un support de stockage. Par ailleurs, lors du déplacement de fichiers vidéo vers un support Memory Stick PRO™, un périphérique USB prenant en charge les fonctions de protection des droits d'auteur des supports Memory Stick™, tel que le système PSP™ ou le MRW-F3 (un produit Sony), est nécessaire.
  • Si vous utilisez un support Memory Stick Micro™ avec un système PS3™ doté d'une fente pour Memory Stick™, un adaptateur pour Memory Stick™ M2 Duo est nécessaire.
  • Certains fichiers protégés contre la copie ne peuvent pas être déplacés.
  • Veillez à ne pas enfreindre les droits de propriété intellectuelle de tiers.
  • Des fichiers vidéo ne peuvent pas être copiés ou déplacés durant la lecture.*

    • * Inclut la lecture du contenu à l'aide d'autres fonctionnalités comme la lecture de fichiers musicaux.

Copie ou déplacement d'une vidéo afin de la visionner sur un système PSP™

Pour copier ou déplacer des fichiers vidéo afin de les visionner sur un système PSP™.

1.

Connectez le système PSP™ au système PS3™ à l'aide d'un câble USB.
Pour copier des fichiers sur le support Memory Stick™, insérez le support Memory Stick™ dans le système PSP™.

2.

Sur le système PSP™, sélectionnez (Connexion USB) sous (Paramètres).

3.

Sur le système PS3™, sélectionnez le fichier vidéo que vous souhaitez copier ou déplacer, puis appuyez sur la touche .

4.

Sélectionnez [Copier] ou [Déplacer].
Suivez les instructions affichées pour copier ou déplacer le fichier. Vous pouvez démarrer le fichier vidéo copié ou déplacé en le sélectionnant dans (Vidéo) > (Memory Stick™) ou dans (Vidéo) > (Stockage système) sur le système PSP™.

Conseils

  • Pour plus d'informations sur la lecture de fichiers vidéo sur le système PSP™, reportez-vous au mode d'emploi du système PSP™.
  • Selon le type de fichier vidéo que vous copiez ou déplacez, il peut être nécessaire d'utiliser un support Memory Stick PRO Duo™.
  • Il est impossible de déplacer le contenu vidéo enregistré en résolution HD.
