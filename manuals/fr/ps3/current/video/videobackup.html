Sauvegarde ou restauration de fichiers vidéo

Utilisez la fonction de sauvegarde du système PS3™ pour sauvegarder de manière sélective sur un support de stockage du contenu qui a été téléchargé à partir du Video Store de PlayStation®Store. Vous pouvez restaurer les fichiers sauvegardés à l'aide de cette fonction sur le même système PS3™.

Sauvegarde d'un fichier vidéo

Connectez le support de stockage au système PS3™. Sélectionnez l'icône du contenu que vous souhaitez sauvegarder. Appuyez sur la touche , puis sélectionnez [Sauvegarder] dans le menu d'options. Le dossier (Utilitaire de sauvegarde des données) est automatiquement créé sur le support de stockage et le contenu est enregistré.

Conseils

  • La vente/location de contenu vidéo depuis le PlayStation®Store sur le système PS3™ a été interrompue.
  • Cette fonction peut être utilisée pour sauvegarder des données sur un Memory Stick™, une SD Memory Card, une carte Compact Flash® et un support de stockage USB. Un adaptateur USB approprié (non fourni) est nécessaire pour utiliser le support de stockage avec certains modèles du système PS3™. Des supports disques, comme des CD-R, ne peuvent pas être utilisés.
  • Un disque dur USB peut aussi être utilisé pour la sauvegarde des données. Cependant, remarquez que pour être reconnu par le système PS3™, le disque doit être formaté avec le système de fichiers FAT32. Le système PS3™ ne peut pas reconnaître un disque dur qui est formaté avec le système de fichiers NTFS (NT File System).
  • Le contenu sauvegardé ne peut pas être lu à partir du support de stockage. Pour lire le contenu, vous devez d'abord le restaurer sur stockage système du système PS3™.

Restauration d'un fichier vidéo sauvegardé

Le contenu qui a été sauvegardé sur le support de stockage peut être restauré sur le système PS3™.

1.

Connectez au système PS3™ le support de stockage qui contient le contenu sauvegardé.

2.

Sélectionnez l'icône du support de stockage sous (Vidéo).

3.

Sélectionnez le contenu que vous souhaitez restaurer à partir de (Utilitaire de sauvegarde des données), puis appuyez sur la touche .

4.

Sélectionnez [Restaurer].

Conseils

  • Si vous avez modifié le nom du dossier ou du fichier des données qui ont été sauvegardées, vous risquez de ne pas pouvoir restaurer ce contenu.
  • Si vous exécutez une des opérations suivantes après avoir sauvegardé du contenu, il est possible que vous ne puissiez pas restaurer celui-ci correctement.
  • - Formatage du stockage système
  • - Restauration du système PS3™
  • Dans certains cas, vous ne pourrez peut-être pas employer la fonction de sauvegarde pour sauvegarder ou restaurer correctement le contenu sur le système.
