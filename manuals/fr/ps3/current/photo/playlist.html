Création / lecture de listes de lecture

Vous pouvez collecter les images de votre choix parmi celles sauvegardées dans le stockage système et les réorganiser dans l'ordre souhaité afin de créer et de lire des listes de lecture.

1.

Sélectionnez (Photo) > (Listes de lecture).

2.

Sélectionnez (Créer une nouvelle liste de lecture). Suivez les instructions affichées pour créer la liste de lecture.

3.

Sélectionnez une liste de lecture créée, puis appuyez sur la touche .

4.

Sélectionnez [Modifier].
Les images sauvegardées dans le stockage système s'affichent dans la partie gauche de l'écran et les éléments de la liste de lecture s'affichent dans la partie droite.

5.

Sélectionnez l'image à ajouter à la liste de lecture.
L'image est ajoutée à la liste de lecture. Une fois l'image ajoutée, appuyez sur la touche pour arrêter la modification. Vous pouvez lire la liste de lecture créée sous (Photo) > (Listes de lecture).

Conseils

  • Seules les images sauvegardées dans le stockage système peuvent être ajoutées à une liste de lecture.
  • Vous pouvez lancer un diaporama ou imprimer une image lors de la navigation au sein des images d'une liste de lecture. Sélectionnez une icône d'image dans la liste de lecture, puis appuyez sur la touche . Dans le menu d'options, sélectionnez [Diaporama] ou [Imprimer].
