Types de fichiers pouvant être affichés

Les types de fichiers suivants peuvent être affichés sous (Photo).

  • JPEG (compatible DCF 2.0/Exif 2.21)
  • TIFF
  • BMP
  • GIF
  • PNG
  • MPO (MP format)

Conseil

Certains fichiers ne peuvent pas être affichés en raison du type de données.

  • À propos du menu XMB™
  • Utilisateurs
  • Paramètres
  • Photo
  • Musique
  • Vidéo
  • Services TV/vidéo
  • Jeu
  • Réseau
  • PlayStation™Network
  • Amis
