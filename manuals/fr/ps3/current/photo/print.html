Impression d'images

Pour imprimer des images sous (Photo). Pour utiliser cette fonction, vous devez d'abord configurer une imprimante dans [Sélection imprimante] sous (Paramètres) > (Paramètres imprimante).

1.

Connectez une imprimante au système PS3™.

2.

Sous (Photo), sélectionnez l'image à imprimer, puis appuyez sur la touche .

3.

Sélectionnez [Imprimer].

4.

Vérifiez les paramètres d'impression.
Vous pouvez appuyer sur la touche pour afficher le menu d'options et modifier les paramètres d'impression ou le nombre de copies à imprimer. Les options pouvant être sélectionnées varient selon l'imprimante utilisée.

5.

Sélectionnez [Imprimer].
L'image s'imprime.

Conseils

  • Les imprimantes pouvant être utilisées varient selon le pays ou la région. Pour plus d'informations, visitez le site Web SIE de votre région.
  • Pour imprimer une image actuellement affichée, appuyez sur la touche afin d'afficher le panneau de configuration, puis sélectionnez [Imprimer]).
  • Pour imprimer une image sauvegardée sur un serveur multimédia DLNA, vous devez d'abord copier l'image sur le stockage système du système PS3™.
