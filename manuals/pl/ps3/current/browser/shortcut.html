Używanie przycisków skrótów / myszy / klawiatury

Browse mode
Używanie przycisków skrótów

Za pomocą przycisków kontrolera bezprzewodowego można bezpośrednio operować konsolą bez korzystania z menu. Dostępne funkcje różnią się w trybie przeglądania i trybie okien.

Browse mode
Tryb przeglądania
Przycisk Otwieranie łącza.
Przycisk (przytrzymać) Otwieranie łącza w nowym oknie.
Przycisk + lewy drążek Zaznaczanie tekstu
Przycisk Wyświetlanie menu.
Przycisk Zamykanie przeglądarki (Przeglądarka internetowa).
Przycisk (przytrzymać) Zamykanie okna. *1
Przycisk START Wpisywanie adresu.
Przycisk SELECT Otwieranie listy [Zakładki].
Przyciski L1 / R1 Poprzednia / następna strona.
Przyciski L2 / R2 Przechodzenie do innego okna. *2
Przyciski kierunkowe Przenoszenie wskaźnika na łącze w kierunku oznaczonym na naciskanym przycisku.
Lewy drążek Przenoszenie wskaźnika w wybranym kierunku.
Lewy drążek (naciśnięcie) (przycisk L3) Przełączanie do trybu okien.
Prawy drążek Przewijanie w wybranym kierunku.
Prawy drążek (naciśnięcie) (przycisk R3) Powiększenie. / Anulowanie powiększenia.
Przycisk PS Naciśnięcie powoduje wyświetlenie menu XMB™.
*1

Tej czynności nie można wykonać w trybie powiększenia.
*2

Powiększenie lub pomniejszenie w trybie powiększenia.
Tryb okien
Przycisk Wyświetlanie wybranego okna w trybie przeglądania.
Przycisk Wyświetlanie menu.
Lewy drążek (naciśnięcie) (przycisk L3) Przełączanie do trybu przeglądania.
Przyciski kierunkowe Przechodzenie do innego okna.
Przycisk PS Naciśnięcie powoduje wyświetlenie menu XMB™.

Używanie myszy (niedołączona)

Konsolę można obsługiwać za pomocą zwykłej myszy.

Przeciągnięcie wskaźnika w lewo przy naciśniętym prawym przycisku myszy Powrót do poprzedniej strony.
Przeciągnięcie wskaźnika w prawo przy naciśniętym prawym przycisku myszy Przejście do następnej strony.

Używanie klawiatury (niedołączona)

Konsolę można obsługiwać za pomocą zwykłej klawiatury.

CTRL + L (lub F4) Wpisywanie adresu.
CTRL + R (lub F5) Odświeżanie strony.
CTRL + B (lub CTRL + I) Otwieranie listy [Zakładki].
PAGE UP (lub SHIFT + SPACJA) Przewijanie do góry.
PAGE DOWN (lub SPACJA) Przewijanie w dół.
Strona główna Przejście na początek strony.
Koniec Przejście na koniec strony.
TAB Przesuwanie kursora.
ALT + STRZAŁKA W LEWO (lub BACKSPACE) Powrót do poprzedniej strony.
ALT + STRZAŁKA W PRAWO (lub SHIFT + BACKSPACE) Przejście do następnej strony.
CTRL + STRZAŁKA W LEWO (lub CTRL + SHIFT + TAB) Przejście do okna po lewej stronie.
CTRL + STRZAŁKA W PRAWO (lub CTRL + TAB) Przejście do okna po prawej stronie.
