Guia do usuário

Como utilizar este guia

Este guia contém informações detalhadas relacionadas ao uso do software do sistema PS3™. Para informações sobre as funções de hardware e a segurança do produto, consulte a documentação fornecida com o sistema.

Notas sobre como visualizar o guia

Recomenda-se que o guia seja exibido nas seguintes condições:

  • Ative o JavaScript em seu navegador. Se o JavaScript estiver desativado no navegador utilizado, o guia poderá não ser exibido corretamente ou poderá não ser exibido.
  • Ao exibir o guia em um PC, utilize o Microsoft Internet Explorer 6.0 ou mais recente.

Navegando no guia usando o sistema PS3™

Utilize as funções básicas abaixo ao exibir o guia no (Navegador de Internet) do sistema PS3™.

Botões de direção Move o ponteiro para um link.
Botão Abre o link.
Controle direito Rola em qualquer direção.
Botão L1 Volta para a página anterior.

Você pode usar o seguinte método para aplicar o zoom na tela.

Pressione o botão R3 (controle direito) Utiliza o zoom. / Limpa o zoom da tela.
Segure o botão L2 / botão R2 durante o zoom Aumenta a tela. / Reduz a tela.
Segure o botão durante o zoom Limpa o zoom da tela.

Explicação das referências sobre botões no guia

Os botões do sistema PS3™ usados para entrar nos itens e cancelá-los variam dependendo da região e do produto. Como convenção, as versões em inglês ou outro idioma europeu deste guia devem utilizar para entrar em um item e para cancelá-lo, enquanto em outras versões de idioma utilizam para entrar e para cancelar.

Imprimindo o guia

Você pode imprimir o guia utilizando um PC. Seguindo os passos abaixo, você pode imprimir diversas páginas de uma vez.

1.

Utilize o Microsoft Windows Internet Explorer para exibir o [Índice do manual] deste guia.

2.

No menu arquivo do Internet Explorer, selecione [Imprimir].

3.

Selecione a guia [Opções] e, então, selecione a caixa de seleção [Imprimir todos os documentos vinculados] para imprimir o guia.
Dependendo da impressora, a impressão poderá não seguir a ordem do [Índice do Manual].
