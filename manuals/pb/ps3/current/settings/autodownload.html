Atualização automática

Para usar alguns recursos, você deve assinar o serviço PlayStation®Plus.

Quando esta configuração estiver [Ativado], o sistema PS3™ iniciará automaticamente na hora especificada todos os dias, executará as operações especificadas, então desativará.

Desativado Selecione para não utilizar o recurso de atualização automática
Ativado Selecione para utilizar o recurso de atualização automática

Você pode selecionar as operações de atualização automática para os seguintes itens.

  • Fazer download de itens de conteúdo comprados com outros dispositivos
  • Fazer download do software de sistema mais recente
  • Fazer download de patches do jogo
  • Sincronizar as informações de troféu com o servidor

Dicas

  • Selecione [Fazer upload dos dados salvos no armazenamento online] para cada jogo. Para obter detalhes sobre como configurar este item, veja (Jogo) > [Jogando um software no formato PlayStation®3] > [Utilizando dados salvos] neste guia.
  • Após selecionar [Ativado], utilize os botões de direção para selecionar o período de tempo durante o qual você deseja que a atualização automática seja realizada. Siga as instruções na tela se uma tela aparecer solicitando a verificação das configurações para seu início de sessão automático na PSNSM.
  • Este recurso pode ser utilizado somente em um sistema PS3™ por conta Sony Entertainment Network. Se o recurso de atualização automática estiver definido como [Ativado] em dois ou mais sistemas PS3™ na mesma conta, ele permanecerá [Ativado] no último sistema definido e será automaticamente alterado para [Desativado] em todos os outros sistemas.
  • O sistema PS3™ deve estar em modo de espera (indicador de alimentação aceso vermelho constante) durante o período de tempo quando desejar que o sistema realize a atualização automática.
  • Os dados de atualização do software de sistema serão baixados automaticamente mas não instalados. Você deve instalar os dados de atualização do software de sistema manualmente.
  • é exibido para patches de jogos e jogos recomendados que forem baixados automaticamente. Qualquer conteúdo que tenha sido baixado e instalado automaticamente, mas não tenha sido usado será excluído automaticamente após um mês.
  • Mesmo que [Atualização automática] esteja definido como [Ativado], o conteúdo não será baixado se o espaço livre no armazenamento do sistema for menor do que 5 GB.
  • Defina como [Desativado] para restaurar todas as opções de atualização automática para suas configurações padrão.
