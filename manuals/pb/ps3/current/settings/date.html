Configurações de data e hora

Ajuste as configurações relacionadas à data e hora do sistema.

Data e hora

Ajuste a data e hora do sistema.

Definir manualmente Ajuste manualmente o ano / mês / dia / hora / minuto / segundo (e AM / PM se utilizar um relógio de 12 horas).
Definir pela Internet Obtenha as informações de data e hora da internet, e então ajuste a data e hora do sistema usando essa informação.

Definir automaticamente

Quando esta opção está ajustada para [Ativado], cada vez que você entrar na PSNSM, a data e hora corretas são obtidas automaticamente via internet e ajustadas no seu sistema.

Desativado Não ajuste a data e hora para este sistema automaticamente.
Ativado Ajuste a data e hora deste sistema automaticamente.

Dica

Se um jogo ou alguns tipos de aplicações estiverem sendo usados quando você entrar na PSNSM, a data e hora não é ajustada automaticamente.

Formato de data

Define a ordem de exibição do ano / mês / dia.

Formato de hora

Define a exibição da hora como um relógio de 12 horas ou um relógio de 24 horas.

Fuso horário

Define o fuso horário que será utilizado como base para a exibição da data e hora. Selecione uma cidade ou região próxima de onde você vive. A data e a hora irão mudar de acordo com o fuso horário selecionado.

Horário de verão

Ajuste para o horário de verão.

Padrão Selecione para não ajustar para o horário de verão.
Horário de verão Selecione para ajustar para o horário de verão.
