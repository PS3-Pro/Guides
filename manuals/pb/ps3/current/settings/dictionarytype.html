Tipo de dicionário

Selecione o tipo de dicionário que será utilizado para a entrada de texto quando utilizar o teclado na tela.

Tipo de Dicionário (繁體中文) (Chinês tradicional)

Esta configuração pode ser selecionada somente quando o idioma do sistema estiver definido para utilizar caracteres Chineses tradicionais.

Utiliza o dicionário Chinês (caracteres tradicionais) de Taiwan.
Utiliza o dicionário Chinês (caracteres tradicionais) de Hong Kong.

Tipo de Dicionário (English)

Esta configuração pode ser selecionada somente quando o idioma do sistema estiver definido para utilizar caracteres Chineses tradicionais.

Inglês (EUA) Utiliza um dicionário de Inglês Americano.
Inglês (RU) Utiliza um dicionário de Inglês Britânico.

Tipo de dicionário
