Gerenciar dispositivos Bluetooth®

Registre ou emparelhe dispositivos compatíveis com Bluetooth® em seu sistema PS3™. Você também pode gerenciar os dispositivos Bluetooth® conectados ao seu sistema.

Registrando um dispositivo compatível com Bluetooth®

1.

Prepare o dispositivo compatível com Bluetooth® e a chave de acesso.
Uma "chave de acesso" é um tipo de ID de hardware utilizado para registrar ou emparelhar dispositivos Bluetooth®. Alguns dispositivos podem não exigir uma chave de acesso. Para mais informações, consulte as instruções fornecidas com o dispositivo.

2.

Selecione (Configurações) > (Configurações de acessórios).

3.

Selecione [Gerenciar dispositivos Bluetooth®].
Se houver registrado um ou mais dispositivos Bluetooth®, uma lista de dispositivos registrados será exibida.

4.

Selecione [Registrar novo dispositivo].
Se não houver registrado nenhum dispositivo Bluetooth®, você será solicitado se deseja registrar o dispositivo. Selecione [Sim] para continuar.

5.

Selecione [Iniciar busca].
Seu sistema PS3™ irá exibir uma lista de dispositivos Bluetooth® ao alcance do sistema.

6.

Selecione o dispositivo que deseja registrar ou emparelhar com seu sistema PS3™.
Complete o registro inserindo a chave de acesso de seu dispositivo Bluetooth®, se necessário.

Dicas

  • Quando estiver utilizando o número máximo de controle sem fio, apague qualquer dispositivo que não estiver utilizando da lista de dispositivos registrados para liberar espaço para o novo dispositivo Bluetooth®.
  • Para detalhes sobre o dispositivo compatível com Bluetooth®, consulte as instruções fornecidas com o dispositivo.

Gerenciando dispositivos Bluetooth®

Verifique informações sobre os dispositivos compatíveis com Bluetooth® que estão conectados ao seu sistema PS3™ ou conecte e desconecte dispositivos. Após selecionar o dispositivo que você deseja gerenciar, pressione o botão e, então, selecione opções no menu de opções.
