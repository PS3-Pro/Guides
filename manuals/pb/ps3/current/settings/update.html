Atualização do sistema

Atualizações de software podem incluir patches de segurança, configurações, recursos e outros itens novos ou revisados que irão alterar seu sistema operacional atual. É recomendado que você sempre mantenha seu sistema com a versão mais atual do software de sistema.

Há duas maneiras para realizar a atualização, listadas abaixo:

  • Atualizar pela Internet
  • Atualizar por mídia de armazenamento

Avisos

  • Não desligue o sistema ou remova a mídia durante uma atualização. Se uma atualização for cancelada antes de seu término, o software de sistema poderá ser danificado e o sistema poderá precisar de manutenção ou ser trocado.
  • Durante uma atualização, o botão de alimentação na frente do sistema e o botão PS no controle sem fio ficam inativos.
  • Dependendo do conteúdo, você pode não ser capaz de reproduzi-lo sem antes atualizar o software de sistema.

Atualizar pela Internet

Faça download dos dados da Internet diretamente para o sistema. A atualização mais recente será baixada automaticamente.

1.

Selecione (Configurações) > (Atualização do sistema).

2.

Selecione [Atualizar pela Internet].
Faça o download da atualização mais recente da Internet. Siga as instruções na tela para completar a operação.

Atualizar por mídia de armazenamento

Utilize os dados de atualização salvos em um disco, Memory Stick™ ou outras mídias. Faça o download dos dados de atualização de um site utilizando um PC. Para mais informações, visite o site da SIE de sua região.

Dicas

  • Os dados de atualização também podem ser armazenados em discos de jogo, software de vídeo BD disponível comercialmente e outros tipos de disco. Ao reproduzir um disco que contém dados de atualização, uma tela será exibida para guiá-lo pelo processo de atualização. Siga as instruções na tela para executar a atualização.
  • Um adaptador USB adequado (não incluído) é necessário para utilizar a mídia de armazenamento com alguns modelos do sistema PS3™.
