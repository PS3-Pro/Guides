Utilitário de formatação

Formate (inicialize) um Memory Stick™, SD Memory Card, CompactFlash® ou o armazenamento do sistema. Siga as instruções na tela para executar esta operação.


Avisos

  • Quando você realizar esta operação, todos os dados da mídia de armazenamento ou do armazenamento do sistema serão excluídos. Os dados não poderão ser restaurados, portanto tome cuidado para não excluir acidentalmente dados importantes. A perda ou corrompimento de dados é de responsabilidade do usuário.
  • Não desligue o sistema PS3™ ou remova a mídia de armazenamento durante esta operação. Se a operação for cancelada antes de seu término, o software de sistema poderá ser danificado e o sistema poderá precisar de manutenção ou ser trocado.
  • Durante a formatação do armazenamento do sistema, o botão de alimentação na frente do sistema e o botão PS no controlador sem fio ficam inativos.
  • O software de sistema não é excluído quando o armazenamento do sistema é formatado.
  • As configurações gravadas no armazenamento do sistema, como os favoritos em (Navegador de Internet), serão excluídas.
  • Você pode encurtar o tempo de formatação selecionando [Formatação rápida] um dos métodos de formatação do armazenamento do sistema.  É recomendado que você selecione [Formatação completa] quando formatar um armazenamento do sistema que contenha dados importantes ou sigilosos.
  • Você não pode utilizar este recurso para formatar um Memory Stick™, SD Memory Card ou CompactFlash® em sistemas PS3™ não equipados com compartimentos de mídia.
