Início remoto

Você pode ativar remotamente um sistema PS3™ que está no modo auxiliar (Wake On LAN) utilizando um dispositivo que suporta o uso remoto, como um sistema PS Vita ou um sistema PSP™. Antes de utilizar este recurso, primeiro você deve executar os seguintes passos:

Ao utilizar o uso remoto pelo recurso de LAN sem fio do sistema PS3™ ou por um ponto de acesso:
  • Se utilizar o sistema PSP™ para o uso remoto, atualize o software de sistema PSP™ para a versão 3.72 ou mais atual.
  • Selecione para fazer login automático em (Usuários) no sistema PS3™.

Ao utilizar o uso remoto pela Internet:
  • Se estiver utilizando um sistema PSP™ para o uso remoto, atualize o sistema PSP™ e o sistema PS3™ para a versão mais atual do software de sistema.
  • Selecione para fazer login automático em (Usuários) no sistema PS3™.
  • Complete as configurações de rede no sistema PS3™ para que possa conectar-se à Internet.
  • Crie uma conta Sony Entertainment Network.
  • Selecione para iniciar a sessão automaticamente na PSNSM.

Dicas

  • Para usar o recurso de início remoto, usuários de sistemas PS3™ séries CECH-4302, CECH-4303, CECH-4304 e CECH-4308 devem estar conectados a uma rede usando o recurso LAN sem fio do sistema PS3™.
  • Para detalhes sobre o início automático em (Usuários), veja (Usuários) > [Fazer login] > [Configurando o login automático] neste guia.
  • Para detalhes sobre o início automático de sessão na PSNSM, veja (PlayStation™Network) > [Salvar senha (início automático de sessão)] neste guia.

Habilitando o início remoto

1.

Selecione (Configurações) > (Configurações de uso remoto).

2.

Selecione [Início remoto] > [Ativado].

3.

Selecione [OK] na tela exibida. Para utilizar o uso remoto pela Internet, selecione [Habilitar início remoto pela Internet].

4.

Desligar o sistema PS3™.
Selecione (Usuários) > (Desativar sistema) para desligar o sistema e colocá-lo no modo de espera. Verifique se o indicador de alimentação está aceso vermelho constantemente.

5.

Use remotamente utilizando um dispositivo que suporta o uso remoto, como um sistema PS Vita ou um sistema PSP™.
Para obter detalhes sobre como utilizar o uso remoto, consulte as instruções fornecidas com o dispositivo em uso.

Dicas

  • Para obter detalhes sobre o uso remoto utilizando um sistema PS Vita ou um sistema PSP™, veja (Rede) > (Uso remoto) > [Utilizando o uso remoto] neste guia.
  • Se o início remoto estiver habilitado, a ventoinha interna do sistema PS3™ continuará funcionando mesmo após o sistema ser desligado.

Desabilitando o início remoto

1.

Selecione (Configurações) > (Configurações de uso remoto).

2.

Selecione [Início remoto] > [Desativado].

Início remoto pela Internet

O uso remoto através da internet pode não funcionar dependendo do dispositivo de rede em uso. Se isto acontecer, confira as seguintes informações:

Atenção

Dependendo do tipo de roteador, o sistema PS3™ pode iniciar involuntariamente se o início remoto estiver ativado. Se uma conexão de uso remoto não for estabelecida dentro de certo tempo após o sistema PS3™ ter sido iniciado, o sistema será desligado automaticamente. Para prevenir isto, o início remoto pela Internet pode ser desabilitado automaticamente.

  • É necessário um roteador para utilizar o início remoto pela Internet.
  • Se o roteador em uso for compatível com UPnP, habilite a função UPnP do roteador.
  • Se o roteador em uso não for compatível com UPnP, você deve definir o redirecionamento de portas do roteador para que permita a comunicação com o sistema PS3™ pela Internet. O número de porta utilizado pelo uso remoto e início remoto é TCP: 9293 ou UDP: 9293. Para informações sobre como configurar esta opção, consulte as instruções do roteador.
  • O redirecionamento de portas é uma função que redireciona os sinais que chegam em uma porta específica (de entrada) para outra porta especificada (de saída). Isto também é conhecido como "mapeamento de porta" ou "conversão de endereço".
  • Se o endereço IP do roteador (endereço IP global) for alterado quando o sistema PS3™ estiver no modo de espera, o início remoto não será bem sucedido.
