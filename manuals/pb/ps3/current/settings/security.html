Configurações de segurança

Ajusta as configurações de segurança do sistema.

Dica

Estas configurações controlam o conteúdo local (conteúdo digital armazenado no armazenamento do sistema, conteúdo em mídias de armazenamento e discos). Note que estas configurações não restringem o acesso ao conteúdo online.


Alterar senha

Altere a senha necessária para ajustar as configurações do sistema. Uma senha é necessária nos seguintes casos:

  • Ao reproduzir conteúdo com restrições de controle parental
  • Ao alterar o nível de controle parental do sistema ou a configuração Controle de Início do navegador de Internet
  • Ao iniciar o navegador com Controle de início do navegador de Internet com [Ativado].
  • Ao alterar a senha atual

Anote sua nova senha. A senha é definida como [0000] nas configurações padrão.

Dica

Se você selecionar (Configurações) > (Configurações do sistema) > [Restaurar configurações padrão], você pode redefinir a senha para [0000]. Note que todas suas outras configurações serão restauradas aos seus valores padrão.

BD - Controle parental

Ajuste o nível de reprodução de BDs (Blu-ray Disc) definido com restrições de controle parental. Uma senha é necessária para alterar esta configuração.

Não restringir (desativado) Reproduza qualquer BD independentemente do nível de controle parental.
Restringir (ativado) Reproduza apenas BDs com o nível de controle parental especificado.

Após selecionar [Restringir (ativado)], você poderá selecionar uma restrição de faixa etária na próxima tela. Quanto menor o valor, maior a restrição.

BD/DVD - Código da região de controle parental

Selecione uma região como a base para os níveis de controle parental de BDs e DVDs. Uma senha é necessária para alterar esta configuração.

Estados Unidos Selecione o padrão dos níveis de controle parental para os Estados Unidos.
Outros Selecione o padrão dos níveis de controle parental para outras regiões.

Se você selecionar [Outros], você poderá selecionar uma região na próxima tela.

DVD - Controle parental

Ajuste o nível de reprodução de DVDs com restrições de controle parental. Uma senha é necessária para alterar esta configuração.

Desativado Reproduza qualquer DVD independentemente do nível de controle parental.
Nível 8 a 1 Reproduza apenas DVDs com o nível de controle parental especificado.

Quanto menor o valor, maior a restrição.

Controle parental

Ajuste o nível de reprodução de jogos definidos com restrições de controle parental. Uma senha é necessária para alterar esta configuração.

Desativado Reproduza qualquer conteúdo independentemente do nível de controle parental.
Nível 11 a 1 Reproduza apenas conteúdo com um valor igual ou inferior ao nível de controle parental especificado.

Quanto menor o valor, maior a restrição. Se selecionar [Restringir a inicialização de um jogo sem configurações de controle parental], você poderá restringir o uso de jogos sem classificação para a sua região.

Dicas

  • As configurações de controle parental para jogos variam dependendo da região onde os jogos são vendidos. Para obter detalhes, visite o site da SIE de sua região. Dependendo da região, alguns manuais de softwares podem conter informações sobre estas configurações.
  • Os níveis de controle parental variam dependendo do jogo.

Controle de início do navegador de Internet

Restringe a habilidade de iniciar o Navegador de Internet. Uma senha é necessária para alterar esta configuração.

Desativado Selecione para não utilizar o controle de inicialização.
Ativado Selecione para utilizar o controle de inicialização. Uma senha é necessária para iniciar o navegador.
