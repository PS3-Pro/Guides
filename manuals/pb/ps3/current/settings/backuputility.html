Utilitário de backup

Faça backup dos dados salvos no armazenamento do sistema em uma mídia de armazenamento ou um dispositivo USB de armazenamento em massa ou restaure os dados de backup.

Fazer backup Faz backup dos dados do armazenamento do sistema em uma mídia de armazenamento ou um dispositivo USB de armazenamento em massa.
Restaurar Restaura os dados de backup de uma mídia de armazenamento ou dispositivo USB para o armazenamento do sistema.
Excluir dados de backup Exclui os dados de backup em uma mídia de armazenamento ou dispositivo USB de armazenamento em massa.

Atenção

Você não pode fazer backup das informações de troféus utilizando o recurso utilitário de backup. Se deseja salvar as informações de troféus, é recomendado que você crie uma conta Sony Entertainment Network e salve as informações no servidor. Para fazer backup das informações de troféus no servidor PSNSM, selecione (PlayStation™Network) > (Coleção de troféus), pressione o botão e selecione [Sincronizar com servidor] no menu de opções.


Dicas

  • Os dados podem ser salvos em dispositivos Memory Stick™, SD Memory Card, CompactFlash® e USB de armazenamento em massa. Um adaptador USB adequado (não incluído) é necessário para utilizar a mídia de armazenamento com alguns modelos do sistema PS3™. Discos do tipo CD-R não podem ser utilizados.
  • Um disco rígido USB também pode ser utilizado para fazer backup dos dados e aparecerá com o ícone quando conectado. Entretanto, o disco deve ser formatado no sistema de arquivos FAT32 para ser reconhecido pelo sistema PS3™.
  • Os dados de backup serão salvos na pasta [PS3] - [EXPORT] - [BACKUP]. As pastas são criadas automaticamente.
  • Se você alterar a pasta ou o nome de arquivo dos dados de backup, você poderá não ser capaz de restaurar os dados.
  • Se você realizar algumas das seguintes operações após fazer o backup, os arquivos de vídeo protegidos por direitos autorais nos dados salvos poderão não ser restaurados corretamente.
  • - Formatar o armazenamento do sistema
  • - Restaurar o sistema PS3™
  • - Mover o vídeo protegido por direitos autorais
  • - Fazer download de vídeo protegido por direitos autorais
  • - Reproduzir pela primeira vez um vídeo protegido por direitos autorais que possui restrição de tempo
  • Se fizer backup de dados em um sistema PS3™ e então transferir os dados para outro sistema PS3™ utilizando o utilitário de transferência de dados, os dados de cópia proibida salvos incluídos nos dados de backup não poderão ser restaurados em qualquer um dos sistemas.
  • Alguns tipos de dados de backup podem ser restaurados em outro sistema PS3™. Os tipos de dados que podem ser restaurados em outro sistema são os seguintes:
  • - Dados salvos de software de formato PlayStation®3 *1
  • - Dados salvos de minigames ("minis")
  • - Dados salvos de software de PSP™Game
  • - Arquivos de imagem em (Foto)
  • - Arquivos de música em (Música) *2
  • - Arquivos de vídeo em (Vídeo) *2
  • - Favoritos adicionados em (Navegador de Internet)
  • - Verbetes adicionados utilizando (Configurações) > (Configurações do sistema) > [Adicionar/editar verbete] ou verbetes preditivos "aprendidos" pelo teclado virtual
    • *1  Dados protegidos de cópia não podem ser restaurados. Além disso, dados salvos que tiverem sido restaurados podem não ser utilizáveis em alguns jogos.
    *2  Não inclui os dados protegidos por direitos autorais.
  • Em alguns casos, você poderá não ser capaz de utilizar o recurso Utilitário de Backup para fazer backup ou restaurar o sistema corretamente. É recomendado que você sempre copie ou mova dados importantes para mídias de armazenamento para fazer backup independente de seus dados.
