Bitmapping

Ajuste as configurações para o conteúdo de áudio. Selecione as configurações para a faixa de música sendo reproduzida ou para se adequar às suas preferências.

Desativado Desabilita o bitmapping.
Tipo 1 Utiliza uma técnica chamada dithering para reduzir ruído ou distorção produzidos durante a reprodução de áudio.
Tipo 2 Utiliza uma técnica chamada de noise shaping para reduzir o ruído na faixa audível.
Tipo 3 Utiliza uma técnica desenvolvida especificamente para o sistema PS3™ para aprimorar a reprodução de áudio.

Dica

Estas funções estão disponíveis apenas quando conteúdo de áudio estiver sendo reproduzido nas frequências 88,2 kHz ou 176,4 kHz. As seguintes condições são necessárias para reproduzir áudio em 88,2 kHz ou 176,4 kHz:

  • O dispositivo de áudio em uso deve ser compatível com as frequências de amostragem 88,2 kHz ou 176,4 kHz.
  • [PCM linear 2 canais 88,2 kHz] ou [PCM linear 2 canais 176,4 kHz] for selecionado quando [HDMI] ou [Digital óptico] for definido em (Configurações) > (Configurações de som) > [Configurações de saída de áudio].
  • [44,1/88,2/176,4 kHz] for selecionado em (Configurações) > (Configurações de música) > [Frequência de saída].
