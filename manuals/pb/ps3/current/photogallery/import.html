Importando fotos para o sistema PS3™

Você pode visualizar as fotos salvas no armazenamento do sistema PS3™ simplesmente iniciando Photo Gallery. Se não houver nenhuma foto salva no armazenamento do sistema, importe as fotos salvas em uma câmera digital ou mídia de armazenamento para o armazenamento do sistema para utilizar com o Photo Gallery.


Para importar as fotos, conecte sua câmera digital ou um adaptador USB (com a mídia de armazenamento inserida) ao sistema PS3™ utilizando um cabo USB. Utilize o controle esquerdo para selecionar o ícone da câmera digital exibido e, depois, pressione o botão . Siga as instruções na tela para importar as fotos para o armazenamento do sistema.

Dicas

  • As fotos importadas também podem ser exibidas em (Foto) na tela XMB™ (XrossMediaBar).
  • Você não pode exportar as fotos para a mídia de armazenamento quando estiver utilizando o Photo Gallery. Para exportar as fotos, saia do Photo Gallery e vá para (Foto) na tela XMB™.
  • Pode não ser possível importar as fotos de algumas câmeras digitais e dispositivos de armazenamento.
  • Cuidado para não infringir a propriedade intelectual de terceiros.
