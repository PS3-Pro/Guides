Criando uma lista de reprodução de fotos selecionadas

Você pode selecionar fotos para criar uma lista de reprodução. Com uma lista de reprodução, você pode exibir as fotos selecionadas na mesma ordem em qualquer momento.

Criando uma lista de reprodução

1.

Na [Área de biblioteca], selecione uma foto que deseja adicionar à lista de reprodução, pressione o botão e, então, selecione (Adicionar à lista de reprodução).
A [Área de lista de reprodução] é exibida.

2.

Utilize o controle esquerdo para ir para uma área vazia na [Área de lista de reprodução] e, então, pressione o botão .
Uma nova lista de reprodução será adicionada nesse local.

3.

Selecione as seguintes opções para a lista de reprodução.
Após definir estas opções, a lista de reprodução será criada.

Moldura Seleciona uma moldura para a lista de reprodução.
Lista de reprodução Cria um nome para a lista de reprodução.
Estilo da apresentação de slides Seleciona a forma como as fotos são exibidas na apresentação de slides.
Velocidade da apresentação de slides Seleciona a velocidade da apresentação de slides.
Música da apresentação de slides Seleciona a música que será reproduzida durante a apresentação de slides a partir do conteúdo musical fornecido com o aplicativo Photo Gallery.
Seleciona a música que será reproduzida durante a apresentação de slides na categoria (Música) na tela XMB™.

Dicas

  • As configurações da lista de reprodução podem ser editadas posteriormente em (Editar).
  • Cada lista de reprodução pode ter suas próprias configurações.

Adicionando fotos a uma lista de reprodução

1.

Selecione as fotos que você deseja adicionar à lista de reprodução, pressione o botão e, então, selecione (Adicionar à lista de reprodução).
A tela da Lista de Reprodução é exibida.

2.

Selecione a lista de reprodução e, então, pressione o botão .
As fotos selecionadas são adicionadas à lista de reprodução.

Editando as configurações de uma lista de reprodução

Você pode editar as configurações de uma lista de reprodução. Selecione a lista de reprodução que deseja editar, pressione o botão e, então, selecione (Editar).

Movendo uma lista de reprodução

Você pode mover uma lista de reprodução para outra localização. Selecione a lista de reprodução que você deseja mover, pressione o botão e, então, selecione (Mover). Você pode mover a lista de reprodução utilizando o controle esquerdo.

Dica

Você também pode mover a lista de reprodução sem acessar o menu. Selecione a lista de reprodução e, então, pressione e segure o botão enquanto utiliza o controle esquerdo para movê-la.

Excluindo uma lista de reprodução

Para excluir uma lista de reprodução, selecione a lista de reprodução que deseja excluir, pressione o botão e, então, selecione (Excluir).
