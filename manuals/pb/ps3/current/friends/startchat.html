Iniciando ou saindo de um bate-papo de voz / vídeo

Para utilizar este recurso, pode ser necessário atualizar o software de sistema.


Você pode utilizar o bate-papo de voz / vídeo com as pessoas em sua lista de Amigos. Para um bate-papo de voz, você precisará de um dispositivo de entrada / saída de áudio (tal como um fone de ouvido, vendido separadamente). Para um bate-papo de vídeo, você também precisará de uma câmera USB (vendida separadamente).

Iniciando o bate-papo de voz / vídeo

1.

Selecione (Amigos) > (Iniciar novo bate-papo).

2.

Selecione (Bate-papo de voz/vídeo).
A sala de bate-papo é exibida.

3.

Selecione (Convidar um amigo) no menu exibido na tela.
Se você selecionar a pessoa com quem deseja bater papo na lista de Amigos e, em seguida, selecionar [Confirmar], a tela de mensagem do convite de bate-papo será exibida.

4.

Digite uma mensagem e, depois, selecione [Enviar].
O avatar do Amigo que você convidou é exibido na sala de bate-papo.

Se a pessoa participar do bate-papo, sua imagem será exibida e o bate-papo de voz / vídeo começará.

Dicas

  • O sistema PS3™ é compatível com o bate-papo de voz / vídeo. Opções adicionais de bate-papo, tais como o bate-papo no jogo, podem estar disponíveis no software de jogo. Para obter detalhes, consulte as instruções fornecidas com o software utilizado.
  • Você deve iniciar a sessão na PSNSM para bater papo.
  • Embora você possa convidar diversos Amigos para bater papo, são exibidos os avatares, na sala de bate-papo, apenas dos cinco primeiros Amigos selecionados na tela.
  • Até seis pessoas podem participar em uma sala de bate-papo.
  • O recurso de bate-papo de voz / vídeo não poderá ser usado se limites em seu uso forem definidos. Para obter informações sobre as configurações do controle parental, veja [Sobre o menu XMB™] > [Utilizando as configurações de controle parental] neste guia.
  • Você pode utilizar um fone de ouvido USB / fone de ouvido Bluetooth® / câmera USB EyeToy™ / PlayStation®Eye / câmera USB compatível com a classe de vídeos USB (UVC) no sistema PS3™.
  • Ao conectar uma câmera USB utilizando um hub USB, utilize um hub que seja compatível com o USB 2.0. Se um hub não compatível com o USB 2.0 for utilizado, poderá ocorrer uma degradação da imagem ou a imagem poderá não ser exibida.
  • Para obter informações sobre os periféricos suportados e as instruções de uso, contate o distribuidor onde os periféricos são vendidos.

Saindo da sala de bate-papo (saindo do bate-papo de voz / vídeo)

Durante um bate-papo, selecione (Sair) no painel de controle.

Dica

Se a pessoa que iniciou o bate-papo de voz / vídeo sair, a sala de bate-papo será fechada.
