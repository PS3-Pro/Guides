Criando ou enviando mensagens

Para utilizar este recurso, pode ser necessário atualizar o software de sistema.


Você pode criar e enviar mensagens para as pessoas que possuem IDs on-line registradas para o uso na PSNSM. Você deve iniciar a sessão na PSNSM para criar e enviar mensagens.

1.

Selecione (Amigos) > (Caixa de mensagens).

2.

Selecione (Criar mensagem).

3.

Selecione [Para].
Selecione [Selecione entre os amigos] ou [Inserir ID online] e neste caso, você precisará digitar a ID online da pessoa para quem deseja enviar.

4.

Digite uma mensagem e, depois, selecione [Enviar].
Sua mensagem é enviada. Você pode verificar as mensagens enviadas em (Amigos) > (Caixa de mensagens) > (Enviados).

Dicas

  • Você não pode enviar ou receber mensagens utilizando os endereços de e-mail padrão.
  • Uma ID online será registrada quando você criar (inscrever-se em) uma conta Sony Entertainment Network. Antes de enviar uma mensagem, pergunte a ID online da pessoa para quem você deseja enviá-la.
  • Você pode digitar até 18 caracteres em um título e até 512 caracteres no corpo de uma mensagem.
  • Você pode utilizar emoticons selecionando no teclado ao criar uma mensagem.
  • Você pode salvar até 200 mensagens enviadas. Após atingir este limite, sua mensagem mais antiga será apagada automaticamente sempre que você enviar uma nova mensagem.

Anexando arquivos

Ao selecionar (Anexar) na tela de criação de mensagens, você poderá anexar um arquivo de imagem de (Foto).

Dicas

  • Você não pode anexar arquivos maiores que 3 MB.
  • Você pode anexar apenas um arquivo por vez.
  • Para cancelar a anexação de um arquivo, selecione-o, pressione o botão e, depois, selecione [Cancelar anexo] no menu de opções.
