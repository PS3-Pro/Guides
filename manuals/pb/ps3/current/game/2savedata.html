Utilizando dados salvos

Os dados salvos de software no formato PlayStation®2 ou PlayStation® são salvos nos memory cards internos criados no armazenamento do sistema. Os memory cards internos podem ser utilizados atribuindo-os a compartimentos após serem criados. Os dados são exibidos em (Utilitário do Memory Card).

Avisos

  • Alguns títulos de software de formato PlayStation®2 ou PlayStation® podem apresentar desempenhos diferentes no sistema PS3™ em comparação com os sistemas PlayStation®2 ou PlayStation®, ou podem não apresentar um desempenho adequado no sistema PS3™.
  • Além disso, discos no formato PlayStation®2 não podem ser reproduzidos em alguns sistemas PS3™. Para obter detalhes, consulte [Tipos de discos reproduzíveis], visite o site da SIE de sua região ou leia a documentação incluída com seu sistema PS3™.

Crie um memory card interno

1.

Selecione (Jogo) > (Utilitário do Memory Card).

2.

Selecione (Criar novo Memory Card interno).
Siga as instruções na tela para completar a operação.

Dica

Os nomes ou os ícones dos memory cards internos podem ser alterados em [Informações] no menu de opções.

Atribua um compartimento

1.

Selecione (Jogo) > (Utilitário do Memory Card).

2.

Selecione o memory card interno que você deseja utilizar e, depois, pressione o botão .

3.

Selecione [Atribuir compartimentos].

Dicas

  • Dependendo do software, os compartimentos podem ser atribuídos previamente. Para obter detalhes, consulte as instruções fornecidas com o software.
  • Você pode atribuir compartimentos durante o jogo. Pressione o botão PS no controle sem fio e, depois, selecione [Atribuir compartimentos] na tela exibida.
