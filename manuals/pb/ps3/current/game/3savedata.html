Utilizando dados salvos

Os dados salvos do software no formato PlayStation®3 são salvos no armazenamento do sistema. Os dados são exibidos em (Utilitário de dados salvos (PS3™)).


Dicas

  • Os dados salvos são gerenciados separadamente por cada Usuário. Se houver mais de um Usuário em (Usuários), os itens exibidos em (Utilitário de dados salvos (PS3™)) irão variar dependendo do Usuário conectado.
  • Se você selecionar um ícone de dados salvos e pressionar o botão , poderá classificar os dados salvos pela data de atualização ou agrupar os dados salvos pelo título no menu exibido.

Armazenando os dados salvos no servidor da PSNSM

Você pode armazenar os dados salvos do software no formato PlayStation®3 em um servidor da PSNSM e fazer download deles em outro sistema PlayStation®3 para continuar a jogar seu jogo. Para utilizar este recurso, você deve possuir uma conta Sony Entertainment Network e fazer assinatura do serviço PlayStation®Plus.

Armazenando automaticamente os dados salvos

Você pode armazenar automaticamente os dados salvos e recém-atualizados no armazenamento on-line regularmente.
Você deve definir este recurso para cada jogo individual.

1.

Em (Jogo), selecione o jogo com os dados salvos que você deseja salvar e pressione o botão .

2.

Selecione [Upload automático de dados salvos] e selecione para [Ativado].

Dicas

  • Os dados salvos que são atualizados após a configuração ser ativada serão transferidos automaticamente.
  • Em (Configurações), selecione (Configurações do sistema) > [Atualização automática] para [Desativado] para desativar a atualização automática dos dados salvos.
Armazenando manualmente os dados salvos

1.

Selecione (Jogo) > (Utilitário de dados salvos (PS3™)), selecione os dados que você deseja salvar, então pressione o botão .

2.

Selecione [Copiar].

3.

Selecione [Armazenamento online] como o destino da gravação.

Fazendo download dos dados salvos do armazenamento online para o sistema PS3™

1.

Selecione (Jogo) > (Utilitário de dados salvos (PS3™)) e, depois, selecione [Armazenamento online].

2.

Selecione os dados salvos que você deseja baixar e, depois, pressione o botão .

3.

Selecione [Copiar].

Dicas

  • A capacidade máxima de armazenamento disponível é de 1 GB e o número máximo de itens de dados salvos que podem ser armazenados é 1000.
  • Os dados salvos que não são para o software nos formatos PlayStation®3, PC Engine ou NEOGEO não podem ser armazenados.
  • Os dados salvos protegidos contra cópia são tratados da seguinte maneira:
  • - Upload para o armazenamento on-line: Pode ser feito a qualquer momento.
  • - Download dos dados salvos do armazenamento online: Assim que os dados salvos protegidos contra cópia são transferidos ou baixados do armazenamento on-line, você deve aguardar pelo menos 24 horas antes de fazer o download dos mesmos dados novamente.
  • Você não pode utilizar o armazenamento online para alguns jogos. Para obter detalhes sobre jogos ou serviços que não são compatíveis com o armazenamento on-line, selecione aqui.
