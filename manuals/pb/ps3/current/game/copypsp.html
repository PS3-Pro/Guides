Copiando jogos para jogar em um sistema PSP™

Se o jogo baixado (como uma compra ou gratuitamente) da (PlayStation®Store) for compatível com o sistema PSP™, você poderá copiar o jogo para jogá-lo em um sistema PSP™.

1.

Inicie a sessão na PSNSM utilizando a conta Sony Entertainment Network utilizada para fazer o download do jogo.

2.

Conecte o sistema PSP™ ao seu sistema PS3™ utilizando um cabo USB.
Para copiar arquivos para a mídia Memory Stick™, insira-a no sistema PSP™.

3.

No sistema PSP™, selecione (Configurações) > (Ligação USB).

4.

No sistema PS3™, selecione o jogo que você deseja copiar em (Jogo) e, depois, pressione o botão .

5.

Selecione [Copiar].
Siga as instruções na tela para copiar o jogo. Após o término da cópia, você poderá iniciar o jogo em (Jogo) > (Memory Stick™) ou (Jogo) > (Memória do Sistema) no sistema PSP™.

Dicas

  • Para utilizar este recurso, o software do sistema PSP™ deve ser a versão 6.50 ou posterior.
  • Para obter informações sobre como jogar no sistema PSP™, consulte o guia do usuário do sistema PSP™.

Jogos que podem ser jogados nos sistemas PS3™ ou PSP™

Se você estiver jogando um jogo compatível com ambos os sistemas, poderá copiar os dados salvos do jogo de um sistema para outro para que possa continuar jogando de onde parou. O método para copiar os dados salvos varia dependendo do tipo de jogo.

Dados salvos do software no formato PlayStation®

Os dados salvos do software no formato PlayStation® são salvos em um memory card interno criado no armazenamento do sistema. Para copiar os dados salvos para um sistema PSP™, execute os passos 2 e 3 acima e, depois, selecione (Jogo) > (Utilitário do Memory Card) > (Memory Card interno (PS)) no sistema PS3™. Então, selecione o ícone dos dados salvos a serem copiados, pressione o botão e, depois, selecione [Copiar] no menu de opções.

Dicas

  • Você deve converter o formato dos dados salvos para permitir que os dados sejam utilizados em um sistema PSP™. Se uma tela de confirmação sobre a conversão de dados for exibida durante a operação de cópia, selecione [Sim] para continuar.
  • Diversos memory cards internos são criados para cada título de software salvo na mídia Memory Stick™ (inserida no sistema PSP™) ou no armazenamento do sistema PSP™go.
  • Se você copiar os dados salvos para a mídia Memory Stick™ inserida no compartimento de mídia do sistema PS3™ ou utilizar um adaptador USB (vendido separadamente), os dados salvos não serão reconhecimentos.

Ativando um sistema PSP™

Os jogos que foram baixados (para comprar ou gratuitos) na (PlayStation®Store) podem ser reproduzidos em um sistema PSP™ ativo. Se aparecer uma mensagem indicando que a ativação é requerida quando o jogo for iniciado no sistema PSP™, ative o dispositivo usando o seguinte procedimento.

1.

Conecte o sistema PSP™ ao seu sistema PS3™ utilizando um cabo USB.

2.

No sistema PSP™, selecione (Configurações) > (Ligação USB).

3.

No sistema PS3™, selecione (PlayStation™Network) > (Gerenciamento da conta).

4.

Selecione (Ativação do sistema).
Siga as instruções na tela para completar o procedimento de ativação.

Dicas

  • Para realizar a ativação do dispositivo, você deve iniciar a sessão no sistema PS3™ como o mesmo usuário que havia iniciado a sessão ao fazer o download do software no formato PlayStation®.
  • A ativação do dispositivo é um procedimento que permite reproduzir o conteúdo nos dispositivos autenticados. Esse procedimento é necessário para proteger os direitos digitais do conteúdo.
