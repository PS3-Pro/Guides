Utilizando os dados salvos nos memory cards

Para utilizar os dados salvos em um memory card (8MB) (para o PlayStation®2) ou um memory card para jogar, você deve copiar os dados para um memory card interno no armazenamento do sistema. Você deve utilizar um adaptador de memory card (vendido separadamente) para copiar os dados.

Avisos

  • Alguns títulos de software no formato PlayStation®2 ou PlayStation® podem apresentar desempenhos diferentes no sistema PS3™ em comparação com os sistemas PlayStation®2 ou PlayStation®, ou podem não apresentar um desempenho adequado no sistema PS3™.
  • Além disso, discos no formato PlayStation®2 não podem ser reproduzidos em alguns sistemas PS3™. Para obter detalhes, consulte [Tipos de discos reproduzíveis], visite o site da SIE de sua região ou leia a documentação incluída com seu sistema PS3™.

1.

Selecione (Jogo) > (Utilitário do Memory Card).

2.

Conecte o adaptador de memory card ao sistema PS3™ e insira um memory card.
Um ícone para (Memory Card (PS)) ou (Memory Card (PS2)) é exibido.

3.

Selecione o ícone dos dados salvos que você deseja copiar do memory card exibido e, depois, pressione o botão .

4.

Selecione [Copiar].
Selecione o destino da cópia. Se nenhum destino estiver listado, selecione (Criar novo Memory Card interno) e siga as instruções na tela para criar um memory card interno.

5.

Atribua compartimentos
Selecione o memory card interno que você deseja utilizar em (Utilitário do Memory Card) e, depois, pressione o botão . No menu de opções, selecione [Atribuir compartimentos].

Dicas

  • Dependendo do tipo de dados, os dados salvos de um memory card (8MB) (para o PlayStation®2) ou um memory card são copiados para um memory card interno, como mostrado abaixo.

  • Para alguns dados salvos, a cópia pode levar vários minutos.
  • Para copiar todos os dados salvos gravados em um memory card (8MB) (para o PlayStation®2) ou um memory card, selecione o memory card no passo 3, pressione o botão e, depois, selecione [Copiar] no menu de opções.
  • A cópia de alguns dados salvos pode ser proibida. Ao utilizar tais dados em um sistema PS3™, selecione [Mover] no passo 4. Os dados salvos serão movidos para o armazenamento do sistema e excluídos do memory card.
  • Você pode mover os dados salvos de volta para o memory card posteriormente.

Copiando os dados salvos para um memory card

Copie os dados salvos do software no formato PlayStation®2 / PlayStation® que foram salvos no armazenamento do sistema para um memory card ou um memory card (8MB) (para o PlayStation®2). Você deve utilizar um adaptador de memory card (vendido separadamente) para copiar os dados.

1.

Selecione (Jogo) > (Utilitário do Memory Card).

2.

Conecte o adaptador de memory card ao sistema PS3™ e insira um memory card.

3.

Selecione o ícone dos dados salvos que você deseja copiar em (Memory Card interno (PS)) ou (Memory Card interno (PS2)), onde os dados estão salvos e, depois, pressione o botão .

4.

Selecione [Copiar].
Especifique (Memory Card (PS)) ou (Memory Card (PS2)) como o destino da cópia.

Dicas

  • Os diversos itens de dados salvos em um memory card interno não podem ser copiados coletivamente para um memory card.
  • A cópia de alguns dados salvos pode ser proibida. Ao utilizar tais dados em um sistema PS3™, selecione [Mover] no passo 4. Os dados salvos serão movidos para o armazenamento do sistema e excluídos do memory card interno.
  • Você pode mover os dados salvos de volta para o memory card posteriormente.
