Fazendo backup ou restaurando arquivos de vídeo

Use o recurso de backup do sistema PS3™ para seletivamente fazer o backup do conteúdo que foi baixado da Loja de Vídeo da PlayStation®Store na mídia de armazenamento. Você pode restaurar os arquivos salvos em backup usando esse recurso no mesmo sistema PS3™.

Fazendo backup de um arquivo de vídeo

Conecte a mídia de armazenamento ao sistema PS3™. Selecione o ícone do conteúdo que deseja salvar. Pressione o botão e selecione [Fazer backup] no menu de opções. A pasta (Utilitário de backup de dados) será automaticamente criada na mídia de armazenamento e o conteúdo será salvo nela.

Dicas

  • A venda e o aluguel do conteúdo do vídeo da PlayStation®Store no sistema PS3™ foram descontinuados.
  • Esse recurso pode ser usado para fazer backup em Memory Stick™, SD Memory Card, Compact Flash® e dispositivos USB de armazenamento em massa. Um adaptador USB apropriado (não incluído) é necessário para usar mídias de armazenamento com alguns modelos do sistema PS3™. Mídia em disco, como CD-R, não pode ser usada.
  • Um disco rígido USB também pode ser usado para fazer backup de dados. Observe, no entanto, que o disco deverá ser formatado como um sistema de arquivo FAT32 pelo sistema PS3™. Um disco rígido que é formatado como NTFS (sistema de arquivo NT) não pode ser reconhecido pelo sistema PS3™.
  • O conteúdo salvo em backup não pode ser reproduzido a partir da mídia de armazenamento. Para reproduzir o conteúdo você deve primeiro restaurá-lo no armazenamento de sistema PS3™.

Restaurando um arquivo de vídeo que você salvou em backup

O conteúdo que foi salvo na mídia de armazenamento poderá ser restaurado para o sistema PS3™.

1.

Conecte a mídia de armazenamento que contém o conteúdo salvo ao sistema PS3™.

2.

Selecione o ícone da mídia de armazenamento sob (Vídeo).

3.

Selecione o conteúdo que deseja restaurar de (Utilitário de backup de dados) e pressione o botão .

4.

Selecione [Restaurar].

Dicas

  • Se o nome do arquivo ou da pasta dos dados salvos em backup foi alterado, é possível que você não consiga restaurar o conteúdo salvo.
  • Se você executar uma das seguintes operações depois de ter feito backup do conteúdo, é possível que você não consiga restaurar o conteúdo corretamente.
  • - Formatar o armazenamento do sistema
  • - Restaurar o sistema PS3™
  • Em alguns casos, pode ser que você não consiga usar o recurso de backup para fazer o backup do conteúdo no sistema ou para restaurá-lo corretamente.
