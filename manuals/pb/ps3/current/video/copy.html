Copiando ou movendo arquivos de vídeo

Copie os arquivos de vídeo salvos na mídia de armazenamento para o armazenamento do sistema, ou copie ou mova os arquivos importados do armazenamento do sistema para a mídia de armazenamento. Com o arquivo que você deseja importar ou copiar selecionado, pressione o botão e selecione [Copiar] ou [Mover] no menu de opções. Siga as instruções na tela para completar a operação.

Diferenças entre copiar e mover

A operação que você realiza varia dependendo do tipo do arquivo. Arquivos de cópia proibida podem apenas ser movidos. Se um arquivo for movido, ele deixará de existir no local de gravação de origem.

Dicas

  • A venda e o aluguel do conteúdo do vídeo da PlayStation®Store no sistema PS3™ foram descontinuados.
  • Ao copiar ou mover arquivos de vídeo com restrições por controle parental, você deve inserir uma senha. Você pode definir esta opção na [Alterar senha] em (Configurações) > (Configurações de segurança).
  • Dependendo do dispositivo utilizado, alguns arquivos copiados poderão não ser reproduzidos.
  • Dependendo do modelo do sistema PS3™ em uso, um adaptador USB adequado (não incluído) pode ser necessário para utilizar a mídia de armazenamento. Além disso, ao mover arquivos de vídeo para a mídia Memory Stick PRO™, um dispositivo USB compatível com os recursos de proteção de cópia da mídia Memory Stick™ como um sistema PSP™ ou MRW-F3 (um produto Sony) é necessário.
  • Ao utilizar a mídia Memory Stick Micro™ com um sistema PS3™ equipado com uma entrada para Memory Stick™, você deve utilizá-lo com um Adaptador Memory Stick™ M2 Duo.
  • Alguns arquivos de vídeo protegidos por direitos autorais não podem ser movidos.
  • Cuidado para não infringir a propriedade intelectual de terceiros.
  • Os arquivos de vídeo não podem ser copiados ou movidos durante a reprodução.*

    • * Inclui a reprodução do conteúdo utilizando outros recursos, tais como a reprodução de arquivos de música.

Copiando ou movendo vídeo para ser exibido em um sistema PSP™

Copie ou mova os arquivos de vídeo para visualizá-los em um sistema PSP™.

1.

Conecte o sistema PSP™ ao seu sistema PS3™ utilizando um cabo USB.
Para copiar os arquivos para a mídia Memory Stick™, insira-a no sistema PSP™.

2.

No sistema PSP™, selecione (Configurações) > (Ligação USB).

3.

No sistema PS3™, selecione o arquivo de vídeo que você deseja copiar ou mover e depois, pressione o botão .

4.

Selecione [Copiar] ou [Mover].
Siga as instruções na tela para copiar ou mover o arquivo. Você pode reproduzir o arquivo de vídeo copiado ou movido selecionando o arquivo em (Vídeo) > (Memory Stick™) ou (Vídeo) > (Memória do Sistema) no sistema PSP™.

Dicas

  • Para obter informações sobre como reproduzir arquivos de vídeo no sistema PSP™, consulte o guia do usuário do sistema PSP™.
  • Dependendo do tipo do arquivo de vídeo que irá copiar ou mover, você deverá utilizar o Memory Stick PRO Duo™.
  • O conteúdo de vídeo gravado em resolução HD não pode ser movido.
