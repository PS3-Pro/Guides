Operações durante o uso remoto

Durante o uso remoto, os botões do sistema PS Vita ou do sistema PSP™ são usados para operar o sistema PS3™.

Usando um sistema PS Vita para operar o sistema PS3™

Durante o uso remoto, você opera a maioria dos recursos do sistema PS3™ utilizando os botões em seu sistema PS Vita.
Você opera vários recursos usando a barra de ferramentas. Toque na tela para exibir a barra de ferramentas.


Operando o botão PS do sistema PS3™

Isto imita a ação de pressionar o botão PS no controle sem fio do sistema PS3™.

1.

Toque na tela.

2.

Toque em (PS).

Dica

O ícone (PS) não suporta as operações para as quais você pressiona e segura o botão PS no controle sem fio do sistema PS3™ por um segundo ou mais. Para desativar o sistema PS3™, toque em (Desativar sistema), então siga as instruções na tela.


Alterando as atribuições do botão

Você pode escolher entre as atribuições do botão [Tipo 1] e [Tipo 2]. Se você escolher [Tipo 2], poderá executar algumas operações pressionando simultaneamente as combinações de botões não disponíveis no sistema PS Vita, tais como os botões L2 e R3.

1.

Toque na tela.

2.

Toque em (Configurações) > [Atribuir botões].

3.

Toque no tipo de atribuição do botão que você deseja utilizar.

Configurando a qualidade da imagem

Você pode selecionar a qualidade de imagem [+1], [Padrão] ou [-1].

1.

Toque na tela.

2.

Toque em (Configurações) > [Qualidade da imagem].

3.

Toque na qualidade de imagem desejada.

Dica

Dependendo do ambiente de rede, com uma alta qualidade de imagem, o vídeo e o áudio associado podem ser interrompidos.


Restaurando as configurações do uso remoto

Para limpar o registro do dispositivo e restaurar as atribuições do botão e a configuração da qualidade de imagem com seus valores padrão:

1.

Toque na tela.

2.

Toque em (Configurações) > [Restaurar configurações] > [Restaurar] > [OK].

Dica

Você também pode restaurar as configurações na tela onde seleciona o método de conexão de uso remoto. Toque em (Opções) > [Configurações] > [Restaurar configurações] e siga as instruções na tela.


Alterando o modo de tela

Você pode alterar o modo de tela tocando duas vezes nela.

Dica

Você não pode alterar o modo de tela quando a barra de ferramentas estiver sendo exibida na tela ou estiver jogando.

Usando um sistema PSP™ para operar o sistema PS3™

Se você estiver usando um sistema PSP™ para o uso remoto, quando pressionar o botão PS (botão HOME), aparecerá um menu para operar o sistema PS3™.

Itens de menu

Os itens de menu disponíveis no sistema PSP™ variam dependendo da versão do software de sistema em uso.

PS button Realize as mesmas operações que o botão PS no controle sem fio. *1
Quit Remote Play Saia do uso remoto.

Quit and Turn Off the PS3™ System: Sai do uso remoto e desliga o sistema PS3™.

Quit Without Turning Off the PS3™ System: Sai do uso remoto e mantém o sistema PS3™ ligado. Selecione esta opção se você estiver utilizando seu sistema PS3™ para copiar arquivos ou para fazer download em segundo plano ou outras tarefas que exigem que o sistema permaneça ligado.
Settings Ajuste as configurações relacionadas aos botões do sistema PSP™.

Assign Buttons: Utilize os botões do sistema PSP™ da mesma maneira que os botões do controlador sem fio do sistema PS3™. Selecione um dos dois tipos de atribuições.

Communication Settings: Selecione a velocidade de resposta dos botões do sistema PSP™. Selecione um dos cinco níveis que combinam a velocidade de resposta com a qualidade de imagem ou selecione [Personalizado]. *2
Connection Status Selecione para exibir o status da conexão do uso remoto.
*1

As operações nas quais o botão PS é pressionado por pelo menos 2 segundos não são compatíveis.
*2

Embora configurar [Response Speed] e [Image Quality] para o nível máximo produza uma velocidade de resposta mais rápida e uma melhor qualidade de imagem, a imagem ou o áudio poderão ficar distorcidos.
