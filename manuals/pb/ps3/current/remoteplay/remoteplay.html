Sobre o uso remoto

O uso remoto é um recurso que permite à tela do sistema PS3™ ser exibida em um dispositivo que suporta o uso remoto, tal como um sistema PS Vita ou um sistema PSP™, e permite que você opere remotamente em uma LAN sem fio.

Dica

Para utilizar o recurso de uso remoto com um sistema PSP™, você deve atualizar o software do sistema PSP™ para a versão 3.72 ou mais atual.

Operações que podem ser realizadas de um dispositivo compatível com o uso remoto

Os principais recursos do sistema PS3™ que podem ser usados via uso remoto variam dependendo do tipo de dispositivo em uso. Com um sistema PS Vita ou um sistema PSP™, os seguintes recursos estão disponíveis:

  • (Configurações) *1
  • (Foto) *1
  • (Música)
  • (Vídeo) *2
  • (Jogo) *1*3
  • (Rede)
  • (PlayStation™Network) *1
  • (Amigos)

*1

Apenas os recursos limitados podem ser revisados através do uso remoto.
*2

Os Blu-ray Discs e os DVDs não podem ser reproduzidos. Além disso, os arquivos de vídeo protegidos por direitos autorais não podem ser reproduzidos.
*3

Alguns jogos são compatíveis com o uso remoto.
  • Sobre o menu XMB™
  • Usuários
  • Configurações
  • Foto
  • Música
  • Vídeo
  • Serviços de TV/Vídeo
  • Jogo
  • Rede
  • PlayStation™Network
  • Amigos
