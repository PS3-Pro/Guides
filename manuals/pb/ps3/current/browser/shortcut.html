Utilizando teclas de atalho / mouse / teclado

Usando teclas de atalho

Você pode operar diretamente com os botões do controle sem fio sem utilizar o menu. As operações disponíveis variam entre o modo de navegação e o modo janela.

Modo de navegação
Botão Abre o link.
Botão (segure) Abre o link em uma nova janela.
Botão + controle esquerdo Seleciona o texto
Botão Exibe o menu.
Botão Fecha o (Navegador de Internet).
Botão (segure) Fecha a janela. *1
Botão START Insere um endereço.
Botão SELECT Abre [Meus favoritos].
Botões L1 / R1 Volta ou avança uma página.
Botões L2 / R2 Vai para uma janela diferente. *2
Botões de direção Move o ponteiro para um link na direção do botão pressionado.
Botão + botão de direção Rola por página na direção do botão pressionado.
Controle esquerdo Move o ponteiro na direção desejada.
Controle esquerdo (pressione) (botão L3) Muda para o modo janela.
Controle direito Rola na direção desejada.
Controle direito (pressione) (botão R3) Utiliza o zoom. / Limpa o zoom da tela.
Botão PS Exibe o menu XMB™.
*1

Esta operação não pode ser realizada durante o zoom.
*2

Aumentará ou reduzirá durante o zoom.
Modo janela
Botão Exibe a janela selecionada no modo de navegação.
Botão Exibe o menu.
Controle esquerdo (pressione) (botão L3) Muda para o modo de navegação.
Botões de direção Vai para uma janela diferente.
Botão PS Exibe o menu XMB™.

Utilizando um mouse (não incluído)

Opere com um mouse disponível comercialmente.

Arraste para a esquerda enquanto segura um clique direito Volta para a página anterior.
Arraste para a direita enquanto segura um clique direito Avança para a próxima página.

Utilizando um teclado (não incluído)

Opere com um teclado disponível comercialmente.

CTRL + L (ou F4) Insere um endereço.
CTRL + R (ou F5) Atualiza a página.
CTRL + B (ou CTRL + I) Abre [Meus favoritos].
PAGE UP (ou SHIFT + SPACEBAR) Rola para cima.
PAGE DOWN (ou SPACEBAR) Rola para baixo.
Início Vai para o início da página.
Fim Vai para o final da página.
TAB Move o cursor.
ALT + SETA ESQUERDA (ou BACKSPACE) Volta para a página anterior.
ALT + SETA DIREITA (ou SHIFT + BACKSPACE) Avança para a próxima página.
CTRL + SETA ESQUERDA (ou CTRL + SHIFT + TAB) Vai para a janela esquerda.
CTRL + SETA DIREITA (ou CTRL + TAB) Vai para a janela direita.
