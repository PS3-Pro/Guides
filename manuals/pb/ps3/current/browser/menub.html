Menu do modo de navegação

Exibir

Altera o modo como a página é exibida.

Zoom / Tirar zoom Aumenta automaticamente para o tamanho otimizado ou cancela o aumento da área na tela onde o ponteiro está localizado.

A proporção do aumento otimizado é calculada automaticamente com base no tipo de conteúdo na área onde o ponteiro está localizado.
Tamanho máximo / Tamanho padrão Expande a janela para exibir a tela inteira. / Exibe a janela em seu tamanho original.
Tamanho dos caracteres Altera o tamanho do texto.

O texto pode ser exibido em cinco tamanhos diferentes.
Codificação dos caracteres Atribui a codificação dos caracteres.

Na maioria dos casos, a codificação dos caracteres é determinada automaticamente e não precisa ser atribuída.

Dica

Em algumas páginas, o tamanho dos caracteres não pode ser alterado e a codificação dos caracteres não pode ser atribuída.

Ferramentas

Define as condições de abertura das páginas e apaga os dados salvos no armazenamento do sistema.

Cookies Permitir: Sempre permite que os cookies sejam salvos.

Bloquear: Sempre proíbe que os cookies sejam salvos.
JavaScript Ativado: Utiliza o JavaScript.

Desativado: Não utiliza o JavaScript.
Área de exibição Full Pixel: Selecione para exibir a janela em toda a área de exibição da tela da TV. *1

Tamanho padrão: Selecione para diminuir o tamanho da janela em 5%.

-1: Selecione para diminuir o tamanho da janela em 10%.

-2: Selecione para diminuir o tamanho da janela em 15%.
Resolução Muda a resolução de exibição da página Web.

Ajusta as páginas Web para uma exibição melhor combinando com a resolução de saída de vídeo do sistema PS3™.
Redução de tremulação Ativado: Elimina a tremulação nos elementos na tela que apresentam tremulação, como, por exemplo, texto, imagens e linhas.

Desativado: Desativa o recurso de redução de tremulação.

É eficiente para eliminar a tremulação da tela para uma tela entrelaçada. Selecione [Ativado] quando uma resolução, tal como 1080i, for definida como a configuração da saída de vídeo do sistema PS3™. Selecionar [Desativado] melhorará a qualidade da imagem para uma tela progressiva, tal como 1080p ou 720p.
Confirmar fechamento do navegador Ativado: Selecione para exibir uma mensagem de confirmação ao fechar (Navegador de Internet).

Desativado: Selecione para fechar sem exibir uma mensagem de confirmação.
Página inicial Define a página exibida ao iniciar (Navegador de Internet) ou selecionar (Início) no menu.

Ao marcar [Restaurar janela ao iniciar o navegador], a página aberta quando o navegador for fechado será exibida na próxima vez que o navegador for iniciado.
Excluir cookies Exclui cookies.
Excluir histórico de pesquisas Exclui as informações do histórico de pesquisas.
Excluir cache Exclui o cache.
Excluir informações de autenticação Exclui as informações de autenticação.
Cancelar Segurança do navegador Interrompe o uso dos serviços de filtro Web. *2

Para mudar esta configuração, você deve inserir uma senha. Para obter detalhes sobre as senhas, veja (Configurações) > (Configurações de segurança) > [Alterar senha] neste guia.
*1

As partes superior e inferior da imagem poderão ser cortadas se [Full Pixel] estiver selecionado ao utilizar uma TV padrão.
*2

Os tipos de serviços de filtro Web disponíveis variam dependendo do país ou da região.

Lista de Janelas

Muda para o modo janela.

Pesquisar

Realiza uma pesquisa na Internet utilizando uma palavra-chave ou frase.

Arquivo

Entrada de endereço Insere um endereço.
Abrir em uma nova janela Abre o link sobre o qual o ponteiro está colocado em outra janela.
Fechar janela Fecha as janelas abertas.
Salvar imagem Salva a imagem no armazenamento do sistema ou na mídia de armazenamento.*
Salvar destino Salva o conteúdo com link selecionado com o ponteiro no armazenamento do sistema ou na mídia de armazenamento. *
Copiar o endereço dessa página Copia o endereço da página exibida atualmente.
Copiar o endereço desse link Copia o endereço do link sobre o qual o ponteiro está colocado.
Adicionar aos favoritos Adiciona o link sobre o qual o ponteiro está colocado aos favoritos.
Imprimir essa tela Imprime a tela sendo exibida.

Para utilizar este recurso, primeiro você deve configurar uma impressora selecionando (Configurações) > (Configurações de impressora) > [Seleção de impressora].
Salvar captura de tela Salva a tela sendo exibida como uma imagem.

A captura de tela será armazenada em (Foto).
Informações da página Exibe o título ou o endereço da página aberta.
Mostrar certificado Exibe os certificados do servidor enviados das páginas compatíveis com o SSL.
*

Um adaptador USB adequado (não incluído) é necessário para utilizar a mídia de armazenamento com alguns modelos do sistema PS3™.

Voltar

Exibe a página aberta anteriormente.

Encaminhar

Exibe a página aberta antes de realizar a operação (Voltar).

Atualizar / Cancelar

Atualiza a página aberta com o conteúdo mais recente. / Impede a página de ser carregada.

Início

Exibe a página definida como a página inicial.

Favoritos

Adiciona as páginas preferidas como favoritos. Os favoritos podem ser abertos em [Meus favoritos].

Meus favoritos Adiciona a página Web como um favorito e exibe uma lista de favoritos salvos.
PlayStation®3 Exibe o site da Sony Interactive Entertainment.

Dica

A lista de favoritos é organizada em ordem cronológica, com os favoritos adicionados mais recentemente exibidos primeiro.

Segurança do navegador

Utilize um serviço de filtro Web para verificar o tipo e a adequação dos sites Web e bloquear automaticamente a exibição dos sites Web inadequado ao utilizar a Internet.

i-Filter for PS3™ *1 Exibe o site do provedor de serviço [i-Filter for PS3™].*2
Trend Micro™ for PS3™ Exibe o site do provedor de serviço [Trend Micro™ for PS3™]. *2
*1

Este recurso está disponível apenas nos sistemas PS3™ vendidos no Japão.
*2

Pode haver taxas para o uso dos serviços de filtro Web.

Histórico

As páginas que foram abertas são salvas automaticamente como histórico. Os títulos das páginas que foram abertas previamente são exibidos em uma lista e podem ser abertos simplesmente selecionando-os a lista sem inserir o endereço.

Dica

As páginas são organizadas em ordem cronológica, com as abertas mais recentemente exibidas primeiro.
