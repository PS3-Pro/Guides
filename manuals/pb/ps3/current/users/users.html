Categoria de usuários

Cria usuários ou desliga o sistema PS3™. Ao criar diversos usuários, os dados salvos de software de formato PlayStation®3, mensagens enviadas e recebidas em (Amigos) e favoritos em (Navegador de Internet) são mantidos separadamente para cada usuário. Os seguintes ícones são exibidos em (Usuários).

Desativar sistema Desliga o sistema PS3™.
Criar novo usuário Cria um novo usuário.
(nome de usuário) Faz login no sistema PS3™.

Dica

Os seguintes tipos de dados armazenados no armazenamento do sistema são exibidos independentemente de qual usuário fizer login. Se os dados forem excluídos, outros usuários também não serão capazes de usá-los. Cuidado para não excluir dados importantes acidentalmente.

  • Dados salvos para software do formato PlayStation®2 / PlayStation®
  • Jogos exibidos em (Jogo)
  • Arquivos de vídeo exibidos em (Vídeo)
  • Arquivos de música exibidos em (Música)
  • Arquivos de imagem exibidos em (Foto)
  • Ícones exibidos em (Serviços de TV/Vídeo)

Avisos

  • Alguns títulos de software de formato PlayStation®2 ou PlayStation® podem apresentar desempenhos diferentes no sistema PS3™ em comparação com os sistemas PlayStation®2 ou PlayStation®, ou podem não apresentar um desempenho adequado no sistema PS3™.
  • Além disso, discos no formato PlayStation®2 não podem ser reproduzidos em alguns sistemas PS3™. Para obter detalhes, consulte [Tipos de discos reproduzíveis], visite o site da SIE de sua região ou leia a documentação incluída com seu sistema PS3™.
