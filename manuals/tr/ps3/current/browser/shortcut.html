Kısayol tuşlarını kullanma

Fare kullanma (birlikte verilmez)

Satın alınarak kullanılabilen bir fare ile çalıştırın.

Sağ tıklamayı basılı tutarken sola sürükleyin Önceki sayfaya döner.
Sağ tıklamayı basılı tutarken sağa sürükleyin Sonraki sayfaya gider.

Klavye kullanma (birlikte verilmez)

Satın alınarak kullanılabilen bir klavye ile çalıştırın.

CTRL + L (veya F4) Bir adres girin.
CTRL + R (veya F5) Sayfayı yeniler.
CTRL + B (veya CTRL + I) [Yer İmlerim] öğesini açar.
PAGE UP (veya ÜST KARAKTER + ARA ÇUBUĞU) Yukarı kaydırır.
PAGE DOWN (veya ARA ÇUBUĞU) Aşağı kaydırır.
Ana Sayfa Sayfanın en üstüne gider.
Sonlandır Sayfanın en altına gider.
SEKME İmleci taşır.
ALT + SOL OK (veya GERİ) Önceki sayfaya döner.
ALT + SAĞ OK (veya ÜST KARAKTER + GERİ) Sonraki sayfaya gider.
CTRL + SOL OK (veya CTRL + ÜST KARAKTER + SEKME) Sol pencereye gider.
CTRL + SAĞ OK (veya CTRL + SEKME) Sağ pencereye gider.
