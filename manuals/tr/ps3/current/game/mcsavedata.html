Bellek kartlarına kayıtlı verileri kullanma

Bir memory card (bellek kartı) içine (8 MB) (PlayStation®2 için) kayıtlı verileri veya oyun oynamak için bir memory card (bellek kartı) kullanmak için, verileri sistem depolama alanında dahili bir memory card (bellek kartı) içine kopyalamanız gerekir. Verileri kopyalamak için bir memory card (bellek kartı) adaptörü (ayrıca satılır) kullanmanız gerekir.

Uyarılar

  • Bazı PlayStation®2 veya PlayStation® formatındaki yazılım başlıkları PS3™ sisteminde PlayStation®2 veya PlayStation® sistemlerinde çalıştıklarından farklı çalışabilir veya PS3™ sisteminde düzgün çalışmayabilir.
  • PlayStation®2 formatındaki diskler bazı PS3™ sistemlerinde oynatılamayabilir. Ayrıntılar için, [Oynatılabilir Disk Türleri] konusuna bakın, bölgeniz için olan SIE Web sitesini ziyaret edin veya PS3™ sisteminizle verilen belgeleri inceleyin.

1.

(Oyun) > (Memory Card Yardımcı Programı) öğesini seçin.

2.

Memory card (bellek kartı) adaptörünü PS3™ sistemine bağlayın ve bir memory card (bellek kartı) takın.
(Memory Card (PS)) veya (Memory Card (PS2)) için bir simge görüntülenir.

3.

Görüntülenen memory card (bellek kartı) içinden kopyalamak istediğiniz kayıtlı verilerin simgesini seçin ve sonra düğmesine basın.

4.

[Kopyala] öğesini seçin.
Kopyalanacak hedefi seçin. Hiç hedef listelenmezse, (Yeni Dahili Memory Card Oluştur) öğesini seçin ve dahili memory card (bellek kartı) oluşturmak için ekran yönergelerini izleyin.

5.

Yuvalar atama
Kullanmak istediğiniz dahili memory card (bellek kartı) (Memory Card Yardımcı Programı) içinden seçin ve sonra düğmesine basın. Seçenekler menüsünden [Yuva Atama] öğesini seçin.

İpuçları

  • Veri türüne bağlı olarak bir memory card (bellek kartı) içinden (8 MB) (PlayStation®2 için) veya dahili bellek kartına kopyalanan bellek kartına kayıtlı veriler aşağıdaki gibi gösterilir.

  • Bazı kayıtlı veriler için, kopyalama birkaç dakika sürebilir.
  • Memory card (bellek kartı) içine (8 MB) (PlayStation®2 için) veya bir memory card (bellek kartı) içine kayıtlı tüm verileri kopyalamak için, adım 3'te bellek kartını seçin, düğmesine basın ve sonra seçenekler menüsünden [Kopyala] öğesini seçin.
  • Bazı kayıtlı veriler için kopyalama yasaklanmış olabilir. Bu tür verileri PS3™ sisteminde kullanırken, adım 4'te [Hareket Ettir] öğesini seçin. Kayıtlı veriler sistem depolama alanına taşınacak ve memory card (bellek kartı) içinden silinecektir.
  • Kayıtlı verileri daha sonra memory card (bellek kartı) içine geri taşıyabilirsiniz.

Kayıtlı verileri memory card (bellek kartı) içine kopyalama

PlayStation®2 / PlayStation® formatındaki yazılımın sistem depolama alanında kayıtlı verilerini bir memory card (bellek kartı) içine veya bir memory card (bellek kartı) içine (8 MB) (PlayStation®2 için) kopyalayın. Verileri kopyalamak için bir memory card (bellek kartı) adaptörü (ayrıca satılır) kullanmanız gerekir.

1.

(Oyun) > (Memory Card Yardımcı Programı) öğesini seçin.

2.

Memory card (bellek kartı) adaptörünü PS3™ sistemine bağlayın ve bir memory card (bellek kartı) takın.

3.

Verilerin kayıtlı olduğu (Dahili Memory Card (PS)) veya (Dahili Memory Card (PS2)) içinden kopyalamak istediğiniz kayıtlı verilerin simgesini seçin ve sonra düğmesine basın.

4.

[Kopyala] öğesini seçin.
Kopyalama hedefi olarak (Memory Card (PS)) veya (Memory Card (PS2)) öğesini belirtin.

İpuçları

  • Dahili memory card (bellek kartı) içine birden fazla kayıtlı veri öğesi bir memory card (bellek kartı) içine toptan kopyalanamaz.
  • Bazı kayıtlı veriler için kopyalama yasaklanmış olabilir. Bu tür verileri PS3™ sisteminde kullanırken, adım 4'te [Hareket Ettir] öğesini seçin. Kayıtlı veriler sistem depolama alanına taşınacak ve dahili memory card (bellek kartı) içinden silinecektir.
  • Kayıtlı verileri daha sonra memory card (bellek kartı) içine geri taşıyabilirsiniz.
